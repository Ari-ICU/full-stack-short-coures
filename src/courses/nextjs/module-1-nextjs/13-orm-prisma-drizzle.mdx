## 🛠️ អ្វីទៅជា ORM?

ដើម្បីអាចទាញយក ឬបញ្ចូលទិន្នន័យទៅក្នុង Database ប្រភេទ SQL (ដូចជា PostgreSQL) បាន កាលពីមុនអ្នកអភិវឌ្ឍន៍ត្រូវអង្គុយសរសេរកូដភាសា SQL (Structured Query Language) វែងៗដោយផ្ទាល់។

**ឧទាហរណ៍កូដ SQL សុទ្ធ:**
```sql
SELECT * FROM users WHERE email = 'ratha@example.com';
```

ការសរសេរកូដបែបនេះគឺប្រឈមនឹងបញ្ហាច្រើន ងាយនឹងសរសេរខុសអក្ខរាវិរុទ្ធ (Typos) និងពិបាករក្សាទុក។
ដើម្បីដោះស្រាយបញ្ហានេះ គេបានបង្កើត **ORM (Object-Relational Mapping)**!

ORM គឺជាអ្នកបកប្រែ។ វាអនុញ្ញាតអោយអ្នកសរសេរកូដដោយប្រើប្រាស់ភាសា JavaScript/TypeScript ធម្មតា ដែលអ្នកធ្លាប់ស្គាល់ រួចវានឹងបម្លែងកូដនោះទៅជាកូដ SQL ដោយស្វ័យប្រវត្តិ។

---

## 1. Prisma ORM 🏆

**Prisma** គឺជា ORM ដែលមានប្រជាប្រិយភាពបំផុតនៅក្នុងសហគមន៍ Next.js (សឹងតែអាចនិយាយបានថាជាស្តង់ដារទីផ្សារបច្ចុប្បន្ន)។

**លក្ខណៈពិសេសរបស់ Prisma:**
- **រចនាសម្ព័ន្ធទិន្នន័យងាយអាន (Prisma Schema):** អ្នកអាចរៀបចំតារាង Database របស់អ្នកនៅក្នុងឯកសារតែមួយគត់ (`schema.prisma`) ដែលមានទម្រង់ងាយស្រួលមើលបំផុតទោះអ្នកជាអ្នកថ្មីក៏ដោយ។
- **Type-Safety ដ៏អស្ចារ្យ:** ដោយសារវាធ្វើការជាមួយ TypeScript ប្រសិនបើអ្នកសរសេរកូដហៅឈ្មោះ Column ខុស វានឹងលោតក្រហមប្រាប់ភ្លាមៗ។
- **មានកម្មវិធីមើលទិន្នន័យ (Prisma Studio):** ផ្តល់ជូនផ្ទាំង Admin ស្រាប់សម្រាប់បើកមើល និងកែប្រែទិន្នន័យ។

**របៀបសរសេរកូដទាញយកទិន្នន័យដោយប្រើ Prisma:**
```ts
// កូដ TS នេះមើលទៅងាយស្រួលយល់ជាង SQL ឆ្ងាយណាស់!
const user = await prisma.user.findUnique({
  where: {
    email: 'ratha@example.com',
  },
})
```

## 2. Drizzle ORM 🚀

ទោះបីជា Prisma ល្អយ៉ាងណាក៏ដោយ ក៏វាមានបញ្ហាមួយដែរគឺ ទំហំបណ្ណាល័យរបស់វាធំបន្តិច ដែលជួនកាលធ្វើអោយកម្មវិធីដែលដាក់នៅលើ Cloud (ជាពិសេស Serverless/Edge Environments ដូចជា Vercel) ដើរយឺតបន្តិចនៅពេលហៅលើកដំបូង (Cold start)។

ដោយសារហេតុនេះហើយ ទើប **Drizzle ORM** ត្រូវបានបង្កើតឡើងមកថ្មី និងកំពុងតែទទួលបានការចាប់អារម្មណ៍យ៉ាងខ្លាំង!

**លក្ខណៈពិសេសរបស់ Drizzle:**
- **ទម្ងន់ស្រាល និងលឿន:** វាគ្មានកម្មវិធីរត់ពីក្រោយ (Engine) ដូច Prisma ទេ ធ្វើអោយវាលឿនខ្លាំង។
- **សរសេរកូដស្រដៀង SQL (SQL-like):** ប្រសិនបើអ្នកចេះក្បួន SQL ការសរសេរ Drizzle គឺងាយស្រួលណាស់។
- **សាកសមបំផុតសម្រាប់ Serverless/Edge:** ដំណើរការបានយ៉ាងរលូននៅលើ Vercel Edge Functions ឬ Cloudflare Workers។

**របៀបសរសេរកូដទាញយកទិន្នន័យដោយប្រើ Drizzle:**
```ts
// Drizzle តម្រូវអោយអ្នកសរសេរកូដទម្រង់ស្រដៀង SQL បន្តិច
const user = await db.select().from(users).where(eq(users.email, 'ratha@example.com'));
```

## 3. តើគួររើសមួយណា? 🤔

- **រើសយក Prisma** ប្រសិនបើអ្នកជាអ្នកថ្មីទើបនឹងរៀន ឬចង់បានកូដដែលស្រួលមើល ស្រួលសរសេររហ័សទាន់ចិត្ត និងមិនសូវចង់ឈឺក្បាលជាមួយច្បាប់របស់ Database។ (គម្រោងធំៗរាប់ពាន់កំពុងប្រើវាជារៀងរាល់ថ្ងៃ)។
- **រើសយក Drizzle** ប្រសិនបើគម្រោងរបស់អ្នកទាមទារអោយមានល្បឿនប្រតិកម្មលឿនបំផុត (Performance) ឬអ្នកចង់ដាក់អោយវាដើរនៅលើ Edge Computing (ដូចជា Vercel Edge ជាដើម)។

> នៅក្នុងគម្រោងពិតប្រាកដដែលយើងនឹងសាងសង់នៅផ្នែកបន្ទាប់នៃវគ្គសិក្សានេះ យើងនឹងប្រើប្រាស់ **Prisma** ព្រោះវាមានសហគមន៍ធំ ងាយស្រួលរៀន និងមានមេរៀនបង្រៀនជាច្រើននៅលើអុីនធឺណិត។
