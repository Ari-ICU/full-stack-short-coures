## 🔐 ការរៀបចំប្រព័ន្ធ Authentication ដ៏មានសុវត្ថិភាព

នៅក្នុងមេរៀនមុនៗនៃ React យើងបានបង្កើតប្រព័ន្ធ Login បែបក្លែងក្លាយដោយប្រើ `localStorage`។ តែនៅក្នុងការងារជាក់ស្តែង វិធីនេះមិនមានសុវត្ថិភាពគ្រប់គ្រាន់នោះទេ ព្រោះ Hacker អាចលួច Token នោះបានយ៉ាងងាយ។

នៅក្នុង Next.js វិធីដែលមានសុវត្ថិភាព និងពេញនិយមបំផុតគឺការប្រើប្រាស់ **NextAuth.js** (ឥឡូវនេះគេហៅថា Auth.js)។ វាជួយអោយអ្នកអាចអោយអតិថិជន Login ជាមួយគណនី Facebook, Google, GitHub, ឬ តាមរយៈអុីមែល+លេខសម្ងាត់ បានយ៉ាងងាយ!

## 1. ការដំឡើង និងរៀបចំ

ដំបូងត្រូវដំឡើងបណ្ណាល័យនេះសិន៖
```bash
npm install next-auth
```

បន្ទាប់មក អ្នកត្រូវបង្កើតឯកសារ **១ គត់** ដែលមានទីតាំងជាក់លាក់ (កុំដាក់ខុសអោយសោះ): `app/api/auth/[...nextauth]/route.ts`។
ទីតាំងនេះមានន័យថា NextAuth នឹងគ្រប់គ្រងរាល់ URL ទាំងអស់ដែលផ្តើមដោយ `/api/auth/` (ឧ. `/api/auth/signin`, `/api/auth/signout`)។

**ឯកសារ `app/api/auth/[...nextauth]/route.ts`:**
```ts
import NextAuth from "next-auth";
import GithubProvider from "next-auth/providers/github";

const handler = NextAuth({
  // កំណត់ថាតើអ្នកចង់អោយគេ Login តាមរយៈអ្វីខ្លះ? (Providers)
  providers: [
    GithubProvider({
      clientId: process.env.GITHUB_ID as string,
      clientSecret: process.env.GITHUB_SECRET as string,
    }),
    // អ្នកអាចបន្ថែម GoogleProvider, CredentialsProvider (អុីមែល+លេខសម្ងាត់) នៅទីនេះទៀតបាន
  ],
  // កំណត់ទំព័រ Login ផ្ទាល់ខ្លួនរបស់អ្នក បើមិនដាក់ទេវានឹងប្រើទំព័រដើមរបស់ NextAuth
  pages: {
    signIn: '/login', 
  }
});

// ចាំបាច់ត្រូវ Export ជា GET និង POST
export { handler as GET, handler as POST };
```

## 2. ការទាញយកព័ត៌មានអតិថិជន (Server Component)

បន្ទាប់ពីអ្នកប្រើប្រាស់បាន Login រួចរាល់ តើយើងអាចដឹងថាគាត់ឈ្មោះអ្វី? រូបថតប្រូហ្វាលគាត់មួយណា? 
អ្នកអាចហៅមុខងារ `getServerSession()` របស់ NextAuth នៅក្នុង Server Component ណាមួយក៏បាន!

**ឯកសារ `app/page.tsx`:**
```tsx
import { getServerSession } from "next-auth";

export default async function Home() {
  // ទាញយកទិន្នន័យ (Session) របស់បុគ្គលដែលកំពុង Login
  const session = await getServerSession();

  return (
    <main style={{ padding: 20 }}>
      {session ? (
        <div>
          <h1>សូមស្វាគមន៍, {session.user?.name}!</h1>
          <p>អុីមែលរបស់អ្នកគឺ: {session.user?.email}</p>
          <img src={session.user?.image || ""} alt="Profile" style={{ width: 100, borderRadius: '50%' }} />
          
          <br /><br />
          {/* កូដសម្រាប់ Logout */}
          <a href="/api/auth/signout">ចាកចេញ (Logout)</a>
        </div>
      ) : (
        <div>
          <h1>សូមស្វាគមន៍មកកាន់គេហទំព័រយើង!</h1>
          <p>អ្នកមិនទាន់បានចូលគណនីទេ។</p>
          
          {/* បើកទំព័រ Login របស់ NextAuth */}
          <a href="/api/auth/signin">ចូលគណនី (Login)</a>
        </div>
      )}
    </main>
  );
}
```

> **កំណត់សម្គាល់:** នៅក្នុងឧទាហរណ៍ខាងលើ យើងប្រើតំណ `<a>` ធម្មតាដើម្បីបាញ់ទៅកាន់ `/api/auth/signin`។ នៅពេលគេចុច វាបញ្ជូនអ្នកប្រើប្រាស់ទៅកាន់ទំព័រ Login របស់ Google/Github ហើយក្រោយពេលជោគជ័យ វានឹងបញ្ជូនគាត់ត្រលប់មកវិញយ៉ាងរលូន ដោយរក្សាទុក Token ក្នុង HTTP-only Cookie យ៉ាងមានសុវត្ថិភាពបំផុត!
