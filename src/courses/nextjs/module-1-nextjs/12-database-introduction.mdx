## 🗄️ អ្វីទៅជា Database (មូលដ្ឋានទិន្នន័យ)?

នៅក្នុងមេរៀនមុនៗ ពេលយើងបន្ថែមទិន្នន័យ (ឧ. ចុះឈ្មោះអ្នកប្រើប្រាស់) ទៅក្នុង State ឬ អថេរ `const` នោះទិន្នន័យនឹងត្រូវបាត់បង់ទាំងស្រុងនៅពេលដែលកុំព្យូទ័រ Server បិទ ឬ Refresh។ 
ដើម្បីរក្សាទុកទិន្នន័យអោយនៅស្ថិតស្ថេរជារៀងរហូត យើងត្រូវការប្រព័ន្ធមួយហៅថា **Database**។

នៅក្នុងពិភពអ្នកសរសេរកម្មវិធី Database ត្រូវបានបែងចែកជា ២ គ្រួសារធំៗ៖

---

## 1. Relational Database (SQL) 📊

វាជាប្រភេទ Database ដែលមានអាយុកាលចំណាស់ តែនៅតែពេញនិយមបំផុតរហូតដល់សព្វថ្ងៃ។ វាផ្ទុកទិន្នន័យក្នុងទម្រង់ជា **តារាង (Tables)** ដែលមានជួរដេក (Rows) និងជួរឈរ (Columns) ដូចទៅនឹងកម្មវិធី Microsoft Excel ដែរ។

**លក្ខណៈពិសេស:**
- ទិន្នន័យត្រូវតែមានរចនាសម្ព័ន្ធច្បាស់លាស់ (Strict Schema) ឧទាហរណ៍ ជួរឈរ `Age` ត្រូវតែជា "លេខ"។
- ពូកែខាងភ្ជាប់ទំនាក់ទំនង (Relationships) រវាងតារាងមួយទៅតារាងមួយ (ឧ. តារាង User និងតារាង Post)។
- **ឈ្មោះពេញនិយម:** **PostgreSQL** (និយមបំផុតសម្រាប់ Next.js), MySQL, SQLite។

---

## 2. Non-Relational Database (NoSQL) 📂

NoSQL គឺមានភាពបត់បែនខ្ពស់! វាមិនមានតារាងតឹងរ៉ឹងទេ វាផ្ទុកទិន្នន័យជាទម្រង់កញ្ចប់ឯកសារ (Documents) ដែលមានរូបរាងដូច Object (JSON) នៅក្នុង JavaScript បេះបិទ។

**លក្ខណៈពិសេស:**
- មិនមានរចនាសម្ព័ន្ធច្បាស់លាស់ (Flexible Schema) ឯកសារទី១អាចមាន ៣ ចំណុច ឯកសារទី២អាចមាន ៥ ចំណុចក៏បាន។
- ល្អបំផុតសម្រាប់កម្មវិធីដែលកំពុងលូតលាស់លឿន ហើយត្រូវការកែប្រែទម្រង់ទិន្នន័យញឹកញាប់។
- **ឈ្មោះពេញនិយម:** **MongoDB**, Firebase Firestore, Redis។

## 3. តើគួរប្រើមួយណាសំរាប់គម្រោង Next.js របស់អ្នក?

ដោយសារតែ Next.js (App Router) ដំណើរការកូដនៅលើ Server ដោយផ្ទាល់ វាងាយស្រួលណាស់ក្នុងការភ្ជាប់ទៅកាន់ Database ណាមួយក៏បាន!

**ក្បួនក្នុងការសម្រេចចិត្ត:**
- **ជ្រើសរើស PostgreSQL (SQL)**: ប្រសិនបើគម្រោងរបស់អ្នកជាប្រព័ន្ធ ហិរញ្ញវត្ថុ កម្មវិធីគណនេយ្យ ឫប្រព័ន្ធលក់ទំនិញ (E-commerce) ដែលទិន្នន័យមានទំនាក់ទំនងគ្នាយ៉ាងតឹងរ៉ឹងបំផុត និងត្រូវការភាពត្រឹមត្រូវខ្ពស់ (ACID compliance)។ 
*(សូមណែនាំអោយប្រើសេវាកម្មដូចជា Supabase ឫ Vercel Postgres)*

- **ជ្រើសរើស MongoDB (NoSQL)**: ប្រសិនបើអ្នកកំពុងសាងសង់កម្មវិធីឆាត (Chat) បណ្តាញសង្គម ឫគម្រោងដែលអ្នកខ្លួនឯងក៏មិនទាន់ដឹងច្បាស់ថាទិន្នន័យអនាគតវាមានរូបរាងបែបណា។
*(សូមណែនាំអោយប្រើសេវាកម្ម MongoDB Atlas)*

> 💡 **ចំណាំ:** នៅក្នុងមេរៀនបន្ទាប់ យើងនឹងរៀនពីរបៀបដែលកូដ Next.js ទាក់ទងទៅកាន់ Database ទាំងនេះដោយមិនចាំបាច់សរសេរកូដ SQL ស្មុគស្មាញ តាមរយៈបច្ចេកវិទ្យាមួយឈ្មោះថា **ORM**។
