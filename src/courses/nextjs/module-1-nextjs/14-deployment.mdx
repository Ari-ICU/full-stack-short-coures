## 🚀 ការបង្ហោះគម្រោងអោយពិភពលោកបានឃើញ (Deployment)

បន្ទាប់ពីអ្នកបានសរសេរកូដយ៉ាងហត់នឿយអស់ជាច្រើនថ្ងៃ ទីបំផុតក៏ដល់ពេលដែលត្រូវយកគម្រោង Next.js របស់អ្នកទៅដាក់លើអុីនធឺណិត (Live) អោយអ្នកប្រើប្រាស់ពិតប្រាកដអាចចូលមើលបាន។ កន្លែងដែលល្អបំផុតក្នុងការបង្ហោះនោះគឺ **Vercel**។

---

## 1. ការរៀបចំមុនពេល Deploy (The Build Step)

មុននឹង Vercel យកកូដរបស់អ្នកទៅបើកអោយគេមើល វាត្រូវធ្វើការបម្លែង (Compile) កូដ TypeScript និង React ទាំងអស់អោយទៅជាកូដ HTML, CSS, និង JS សុទ្ធ ព្រមទាំងបង្រួមវាអោយតូចបំផុតសិន។ ដំណើរការនេះហៅថា **Build**។

មុននឹង Deploy អ្នកគួរសាកល្បង Build វានៅលើម៉ាស៊ីនអ្នកជាមុនសិន ដើម្បីប្រាកដថាគ្មានកំហុស។ បើក Terminal រួចវាយ៖

```bash
npm run build
```

ប្រសិនបើអ្នកមានកំហុស TypeScript ណាមួយ (ឧទាហរណ៍ ភ្លេចប្រាប់ប្រភេទអថេរ ឬសរសេរឈ្មោះ Prop ខុស) ការ Build នេះនឹងបរាជ័យ (Crash) ហើយវានឹងមិនអនុញ្ញាតអោយអ្នក Deploy ឡើយ! នេះគឺជាចំណុចដ៏ល្អរបស់ Next.js គឺវាការពារមិនអោយកម្មវិធីដែលមានបញ្ហាចេញទៅក្រៅបាន។

---

## 2. ជំហានក្នុងការ Deploy ទៅកាន់ Vercel

1. **បញ្ជូនកូដទៅ GitHub:** ដំបូងអ្នកត្រូវប្រាកដថា កូដរបស់អ្នកទាំងអស់ត្រូវបាន Commit និង Push ទៅកាន់គណនី GitHub របស់អ្នករួចរាល់។
2. **ចូលទៅកាន់ Vercel.com:** បង្កើតគណនីមួយដោយភ្ជាប់ជាមួយ (Sign in with) GitHub។
3. **បន្ថែមគម្រោងថ្មី:** ចុចប៊ូតុង "Add New..." រួចរើសយក "Project"។
4. **នាំចូលពី GitHub:** ជ្រើសរើស (Import) ឈ្មោះ Repository របស់គម្រោង Next.js របស់អ្នកពីក្នុងបញ្ជី។
5. **បញ្ចូល Environment Variables:** នេះជាចំណុចសំខាន់! ចងចាំឯកសារ `.env` ទេ? ដោយសារយើងមិនបានបញ្ជូនវាទៅ GitHub នោះ Vercel មិនស្គាល់ API_KEY របស់អ្នកទេ។ អ្នកត្រូវចម្លងទិន្នន័យក្នុងឯកសារ `.env` ហើយយកមកបិទភ្ជាប់ (Paste) ក្នុងប្រអប់ Environment Variables របស់ Vercel នៅពេលវាសួរ។
6. **ចុចប៊ូតុង Deploy:** រង់ចាំប្រហែល ១ ទៅ ២ នាទី នោះអ្នកនឹងទទួលបាន URL មួយ (ឧ. `my-project.vercel.app`) ដែលអ្នកអាចផ្ញើអោយមិត្តភក្តិ ឬដាក់ក្នុងប្រវត្តិរូប (CV) របស់អ្នកបាន!

## 3. មន្តអាគមនៃការបញ្ជូនដោយស្វ័យប្រវត្តិ (CI/CD)

ចំណុចដែលអស្ចារ្យបំផុតរបស់ Vercel គឺការភ្ជាប់គ្នាដោយស្វ័យប្រវត្តិជាមួយ GitHub (Continuous Deployment)។ 

បន្ទាប់ពីអ្នក Deploy លើកដំបូងរួច ប្រសិនបើនៅថ្ងៃស្អែកអ្នកកែប្រែកូដបន្ថែមមុខងារថ្មី អ្នក **មិនចាំបាច់** ចូលទៅ Vercel ដើម្បី Deploy ម្តងទៀតទេ! 
អ្នកគ្រាន់តែធ្វើការ `git push` ទៅកាន់ GitHub នោះ Vercel នឹងដឹងដោយស្វ័យប្រវត្តិ។ វានឹងទាញយកកូដថ្មីនោះទៅ Build រួចបញ្ជូនវាទៅកាន់គេហទំព័ររបស់អ្នកដោយខ្លួនឯង!
