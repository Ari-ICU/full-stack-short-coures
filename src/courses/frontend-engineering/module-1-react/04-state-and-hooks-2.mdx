## 🌐 ហេតុអ្វីត្រូវប្រើ Redux Toolkit?

នៅក្នុងមេរៀនមុន យើងបានរៀនប្រើប្រាស់ **Context API** ដើម្បីគ្រប់គ្រងទិន្នន័យសកល (Global State)។ ប៉ុន្តែប្រសិនបើកម្មវិធីរបស់អ្នកមានទំហំធំ (ឧទាហរណ៍៖ មានប្រព័ន្ធ Login, កន្ត្រកទំនិញ, ទិន្នន័យអ្នកប្រើប្រាស់, ភាសា។ល។) ការប្រើប្រាស់ Context API ច្រើនអាចធ្វើអោយកូដយឺត និងពិបាកគ្រប់គ្រង (Performance Issues & Hard to Debug)។

**Redux Toolkit (RTK)** គឺជាវិធីសាស្ត្រផ្លូវការ និងងាយស្រួលបំផុតក្នុងការសរសេរ Redux។ វាជួយដោះស្រាយបញ្ហាកូដរញ៉េរញ៉ៃរបស់ Redux ចាស់ៗ និងធ្វើអោយការគ្រប់គ្រង Global State មានភាពរលូន និងងាយស្រួល។

---

## 🛠️ រចនាសម្ព័ន្ធរបស់ Redux

ដើម្បីយល់ពី Redux អ្នកត្រូវស្គាល់ពាក្យសំខាន់ៗ ៣៖
1. **Store:** ជាឃ្លាំងផ្ទុកទិន្នន័យសកលទាំងអស់។
2. **Slice:** ជាផ្នែកតូចៗនៃទិន្នន័យនៅក្នុងឃ្លាំង (ឧ. User Slice, Cart Slice)។ វារួមបញ្ចូលទាំងទិន្នន័យ (State) និងរបៀបកែប្រែវា (Reducers/Actions)។
3. **Dispatch:** ជាការបញ្ជាអោយ Reducer ណាមួយធ្វើការកែប្រែទិន្នន័យ។

---

## 📝 ឧទាហរណ៍ជាក់ស្តែង: បង្កើតកម្មវិធីកន្ត្រកទំនិញ (Cart)

សូមមើលពីរបៀបដំឡើង និងប្រើប្រាស់ RTK មួយជំហានម្តងៗ។
*(អ្នកត្រូវដំឡើងកញ្ចប់កូដជាមុនសិន៖ `npm install @reduxjs/toolkit react-redux`)*

### ជំហានទី ១៖ បង្កើត Slice (Slice.js)

```javascript
// ឯកសារ: src/store/cartSlice.js
import { createSlice } from '@reduxjs/toolkit';

const cartSlice = createSlice({
  name: 'cart', // ឈ្មោះ Slice
  initialState: {
    itemsCount: 0 // ទិន្នន័យដើម (កន្ត្រកទទេ)
  },
  reducers: {
    // Action ទី១: បន្ថែមទំនិញចូលកន្ត្រក
    addToCart: (state) => {
      state.itemsCount += 1;
    },
    // Action ទី២: ជម្រះកន្ត្រកចោល
    clearCart: (state) => {
      state.itemsCount = 0;
    }
  }
});

// Export Actions យកទៅប្រើនៅក្នុង Components
export const { addToCart, clearCart } = cartSlice.actions;

// Export Reducer យកទៅប្រាប់ Store
export default cartSlice.reducer;
```

### ជំហានទី ២៖ បង្កើតឃ្លាំងផ្ទុក (Store.js)

```javascript
// ឯកសារ: src/store/index.js
import { configureStore } from '@reduxjs/toolkit';
import cartReducer from './cartSlice';

export const store = configureStore({
  reducer: {
    cart: cartReducer, // បញ្ចូល Cart Slice ទៅក្នុង Store
    // បើមាន User Slice, ដាក់វានៅទីនេះ...
  },
});
```

### ជំហានទី ៣៖ ភ្ជាប់ Store ជាមួយ React (main.jsx)

ដូចគ្នានឹង Context ដែរ យើងត្រូវរុំ App របស់យើងជាមួយ Provider។

```jsx
// ឯកសារ: src/main.jsx
import React from 'react';
import ReactDOM from 'react-dom/client';
import { Provider } from 'react-redux';
import { store } from './store';
import App from './App';

ReactDOM.createRoot(document.getElementById('root')).render(
  <Provider store={store}>
    <App />
  </Provider>
);
```

### ជំហានទី ៤៖ អាន និងផ្លាស់ប្តូរទិន្នន័យក្នុង Component

ឥឡូវនេះ Component ណាក៏ដោយនៅក្នុង App របស់អ្នក អាចអាន ឬកែប្រែចំនួនកន្ត្រកបានយ៉ាងងាយស្រួល។

```jsx
// ឯកសារ: src/App.jsx
import { useSelector, useDispatch } from 'react-redux';
import { addToCart, clearCart } from './store/cartSlice';

export default function App() {
  // ១. អានទិន្នន័យ: ទាញយក itemsCount ចេញពី cart slice
  const count = useSelector((state) => state.cart.itemsCount);
  
  // ២. រៀបចំឧបករណ៍បញ្ជា (Dispatch)
  const dispatch = useDispatch();

  return (
    <div className="p-10 text-center">
      <h1 className="text-2xl font-bold mb-4">🛒 កន្ត្រកទំនិញ: {count} មុខ</h1>
      
      <div className="flex gap-4 justify-center">
        {/* បញ្ជាអោយ addToCart ដំណើរការ */}
        <button 
          className="bg-green-500 text-white px-4 py-2 rounded"
          onClick={() => dispatch(addToCart())}
        >
          បូកទំនិញចូល
        </button>
        
        {/* បញ្ជាអោយ clearCart ដំណើរការ */}
        <button 
          className="bg-red-500 text-white px-4 py-2 rounded"
          onClick={() => dispatch(clearCart())}
        >
          លុបចោលទាំងអស់
        </button>
      </div>
    </div>
  );
}
```

**សន្និដ្ឋាន:** ទោះបីជាការរៀបចំដំបូង (Setup) របស់ Redux Toolkit មើលទៅរាងវែងបន្តិច ប៉ុន្តែនៅពេលដែលកម្មវិធីរបស់អ្នកកាន់តែធំ ការប្រើប្រាស់ `useSelector` និង `useDispatch` នឹងធ្វើអោយជីវិតរបស់អ្នកកាន់តែងាយស្រួល និងកាត់បន្ថយការឈឺក្បាលបានច្រើនបំផុត!
