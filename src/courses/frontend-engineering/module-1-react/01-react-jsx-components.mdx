## ⚛️ អ្វីទៅជា React.js?

![React Logo](https://upload.wikimedia.org/wikipedia/commons/a/a7/React-icon.svg)


React.js គឺជា JavaScript Library ដ៏ពេញនិយមបំផុតមួយដែលបង្កើតឡើងដោយក្រុមហ៊ុន **Meta (Facebook)** សម្រាប់ការសាងសង់ **User Interfaces (UI)**។ អ្វីដែលធ្វើអោយ React ពិសេសគឺគំនិតនៃការបង្កើត UI តាមរយៈការផ្គុំ **Components** តូចៗចូលគ្នា ប្រៀបដូចជាការលេងកាតូ (Lego) អញ្ចឹងដែរ។

**លក្ខណៈពិសេសរបស់ React:**
- **Component-Based:** បំបែក UI ស្មុគស្មាញទៅជាផ្នែកតូចៗដែលងាយស្រួលគ្រប់គ្រង។
- **Declarative:** ប្រាប់ React ថាអ្នកចង់បាន UI បែបណា នោះវានឹងរៀបចំ DOM ឱ្យអ្នកដោយស្វ័យប្រវត្តិ។
- **Virtual DOM:** React ដំណើរការបានលឿន ព្រោះវាកែប្រែតែផ្នែកណាដែលមានការផ្លាស់ប្តូរទិន្នន័យពិតប្រាកដប៉ុណ្ណោះ។

## 🚀 ការបង្កើត Project ជាមួយ Vite

ទោះបីជា React មាន Tool ផ្លូវការឈ្មោះ Create React App ក៏ដោយ ប៉ុន្តែបច្ចុប្បន្ន **Vite** គឺជាជម្រើសដ៏ល្អបំផុត និងលឿនបំផុតសម្រាប់ការបង្កើត React Project។

បើក Terminal របស់អ្នក ហើយវាយបញ្ជាខាងក្រោម៖

```bash
# ១. បង្កើត Project ថ្មី
npm create vite@latest my-react-app -- --template react-ts

# ២. ចូលទៅកាន់ Folder នោះ
cd my-react-app

# ៣. ដំឡើងកញ្ចប់កូដ (Dependencies)
npm install

# ៤. ដំណើរការ Server
npm run dev
```

## 📝 ស្គាល់ពី JSX (JavaScript XML)

**JSX** គឺជាទម្រង់ពិសេសមួយដែលអនុញ្ញាតអោយយើងសរសេរកូដ **HTML នៅក្នុង JavaScript**។ ទោះបីជាវាមើលទៅដូចជា HTML តែតាមពិតវាជាកូដ JavaScript សុទ្ធសាធ។

**ច្បាប់សំខាន់ៗរបស់ JSX:**

**១. ត្រូវមាន Parent Element តែមួយគត់៖**
```jsx
// ❌ ខុស: គ្មាន Parent រុំ
function App() {
  return (
    <h1>សួស្តី</h1>
    <p>ស្វាគមន៍មកកាន់ React</p>
  );
}

// ✅ ត្រូវ: ប្រើ `<div>` ឬ `<> </>` (Fragment) រុំ
function App() {
  return (
    <>
      <h1>សួស្តី</h1>
      <p>ស្វាគមន៍មកកាន់ React</p>
    </>
  );
}
```

**២. បិទ Tag អោយជិត (Close all tags):**
នៅក្នុង JSX រាល់ Element ទាំងអស់ទោះបីជាគ្មានកូន (Self-closing) ក៏ត្រូវតែមានសញ្ញាបិទ `/` ដែរ (ឧទាហរណ៍ `<img />`, `<br />`, `<input />`)។

**៣. ការប្រើប្រាស់ `className` ជំនួសអោយ `class`:**
ដោយសារពាក្យ `class` គឺជាពាក្យតំណាងរបស់ JavaScript រួចទៅហើយ ទើបនៅក្នុង JSX យើងត្រូវប្រើ `className` សម្រាប់កំណត់ CSS។
```jsx
<div className="bg-blue-500 text-white">Button</div>
```

**៤. ការបង្កប់កូដ JavaScript ក្នុងវង់ក្រចក `{}`:**
```jsx
function Greeting() {
  const name = "រដ្ឋា";
  return <h1>សួស្តី, {name}! ថ្ងៃនេះគឺជា {new Date().toLocaleDateString()}</h1>;
}
```

## 🧩 Functional Components

នៅក្នុង React ទំនើប យើងប្រើប្រាស់ **Functional Components** (អនុគមន៍) ដើម្បីបង្កើត UI។ Component នីមួយៗគឺគ្រាន់តែជា JavaScript Function មួយដែល return កូដ JSX ត្រលប់មកវិញ។

**ក្បួនសរសេរ Component៖**
- ឈ្មោះ Component ត្រូវតែចាប់ផ្តើមដោយ **អក្សរធំ** ជានិច្ច (ឧ. `Header`, `Button`, `UserCard`)។ បើអ្នកសរសេរអក្សរតូច React នឹងគិតថាវាជា HTML tag ធម្មតា។

**ឧទាហរណ៍នៃការបង្កើត និងប្រើប្រាស់ Component:**

```jsx
// ឯកសារ: Button.jsx
export default function Button() {
  return <button className="btn">ចុចទីនេះ</button>;
}

// ឯកសារ: App.jsx
import Button from './Button';

function App() {
  return (
    <div>
      <h1>រៀន React Components</h1>
      {/* ហៅ Component មកប្រើ (អ្នកអាចហៅប៉ុន្មានដងក៏បាន) */}
      <Button />
      <Button />
    </div>
  );
}
```

**សន្និដ្ឋាន:** ការប្រើប្រាស់ Components ជួយអោយកូដរបស់យើងស្អាត ងាយស្រួលរកកំហុស និងអាចយកទៅប្រើឡើងវិញ (Reusable) នៅកន្លែងផ្សេងៗបាន។ នៅក្នុងមេរៀនបន្ទាប់ យើងនឹងរៀនពីរបៀបបញ្ជូនទិន្នន័យ (Props) ពី Component មួយទៅ Component មួយទៀត!
