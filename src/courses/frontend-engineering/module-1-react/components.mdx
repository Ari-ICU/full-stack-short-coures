## 🧩 ការគិតជាទម្រង់ Components

នៅក្នុងការបង្កើតគេហទំព័រជាទូទៅ អ្នកបង្កើត "ទំព័រ" (pages)។ នៅក្នុង React អ្នកបង្កើត **components**។

Component គឺជាផ្នែកតូចមួយនៃ UI (User Interface) ដែលអាចប្រើប្រាស់ឡើងវិញបាន។ តាមរយៈការបំបែក UI ដ៏ស្មុគស្មាញទៅជា components តូចៗ អ្នកអាចធ្វើឱ្យកូដរបស់អ្នកងាយស្រួលគ្រប់គ្រង ងាយស្រួលសាកល្បង (test) និងងាយស្រួលប្រើឡើងវិញ។

ចូរគិតប្រៀបធៀបវាទៅនឹងដុំឡេហ្គោ (Lego blocks)៖
អ្នកអាចសាងសង់ប្រាសាទដ៏ធំមួយ ប៉ុន្តែនៅពីក្រោយប្រាសាទនោះ វាគ្រាន់តែជាការផ្គុំបញ្ចូលគ្នានៃដុំឡេហ្គោតូចៗប៉ុណ្ណោះ។

## 🛠️ ការបង្កើត Functional Component

នៅក្នុង React ជំនាន់ថ្មី Components គ្រាន់តែជា JavaScript functions ធម្មតាដែល return កូដ JSX (កូដដែលមានទម្រង់ស្រដៀងនឹង HTML)។

នេះគឺជាឧទាហរណ៍ React component ជាមូលដ្ឋាន៖

```jsx
function WelcomeButton() {
  return (
    <button className="bg-blue-500 text-white px-4 py-2 rounded">
      ចុចទីនេះ!
    </button>
  );
}
```

បន្ទាប់មក អ្នកអាចយក component នេះទៅប្រើប្រាស់នៅក្នុង component ផ្សេងទៀត ដូចជា HTML tag ដែរ៖

```jsx
function App() {
  return (
    <div>
      <h1>សូមស្វាគមន៍មកកាន់ App</h1>
      <WelcomeButton />
      <WelcomeButton />
    </div>
  );
}
```

## 🎁 ការបញ្ជូនទិន្នន័យជាមួយ Props

Components គឺមានប្រយោជន៍ ប៉ុន្តែវានឹងកាន់តែមានថាមពលខ្លាំងនៅពេលដែលអ្នកអាចបញ្ជូនទិន្នន័យទៅឱ្យវា ដើម្បីធ្វើឱ្យវាមានភាពផ្លាស់ប្តូរ (dynamic)។ យើងធ្វើបែបនេះតាមរយៈការប្រើប្រាស់ **props** (មកពីពាក្យ properties)។

Props គឺប្រៀបបានទៅនឹង arguments ដែលបញ្ជូនទៅក្នុង function អញ្ចឹងដែរ។

```jsx
function Greeting(props) {
  return <h2>សួស្តី, {props.name}!</h2>;
}

function App() {
  return (
    <div>
      <Greeting name="សុខា" />
      <Greeting name="វិចិត្រ" />
      <Greeting name="មករា" />
    </div>
  );
}
```

**លទ្ធផល៖**
- សួស្តី, សុខា!
- សួស្តី, វិចិត្រ!
- សួស្តី, មករា!

### ការបំបែក Props (Destructuring Props)

ដើម្បីឱ្យកូដរបស់អ្នកមើលទៅកាន់តែស្អាត អ្នកអាចបំបែក (destructure) props ដោយផ្ទាល់នៅក្នុង function parameters៖

```jsx
function Greeting({ name }) {
  return <h2>សួស្តី, {name}!</h2>;
}
```

## 📝 សេចក្តីសង្ខេប

- **Components** គឺជាផ្នែកឯករាជ្យនៃ UI ដែលអាចប្រើប្រាស់ឡើងវិញបាន។
- **JSX** អនុញ្ញាតឱ្យអ្នកសរសេរកូដទម្រង់ដូច HTML នៅខាងក្នុងកូដ JavaScript។
- **Props** គឺជាទិន្នន័យ Read-only ដែលបញ្ជូនពី parent component ទៅកាន់ child component។
