## ⚡ React Server Components (RSC)

ភាពផ្លាស់ប្តូរដ៏ធំបំផុតនៅក្នុង Next.js App Router គឺការនាំយក **React Server Components (RSC)**។ 
តាមលំនាំដើម (Default) រាល់ Component ទាំងអស់ដែលអ្នកបង្កើតនៅក្នុងថតឯកសារ `app/` គឺជា **Server Components**។

**អត្ថប្រយោជន៍របស់ Server Components៖**
- **ដំណើរការលើ Server:** កូដនេះមិនត្រូវបានបញ្ជូនទៅកាន់ Browser (Client) នោះទេ វាបញ្ជូនតែលទ្ធផល HTML ទៅប៉ុណ្ណោះ ដែលធ្វើអោយ File ស្រាល និងដើរលឿនជាងមុន។
- **សុវត្ថិភាពខ្ពស់:** អ្នកអាចសរសេរកូដភ្ជាប់ទៅ Database ដោយផ្ទាល់ ឬលាក់ API Key នៅទីនេះដោយមានសុវត្ថិភាព ព្រោះ Hacker មិនអាចមើលឃើញកូដទាំងនេះបានទេ។
- **មិនអាចធ្វើអន្តរកម្មបាន (No Interactivity):** ដោយសារវាដំណើរការលើ Server អ្នកមិនអាចប្រើប្រាស់ `useState`, `useEffect`, ឬស្តាប់សកម្មភាព `onClick` បានទេ។

```tsx
// ឯកសារ: src/app/page.tsx (នេះគឺជា Server Component)
export default function Home() {
  console.log("អ្នកនឹងឃើញសារនេះនៅក្នុង Terminal (Server) ប៉ុន្តែមិនឃើញក្នុង Browser ទេ។");

  return (
    <div>
      <h1>នេះគឺជា Server Component</h1>
      <p>មិនត្រូវការ "use client" ទេ។</p>
    </div>
  )
}
```

## 💻 Client Components

ចុះបើវេបសាយរបស់យើងត្រូវការការចុចប៊ូតុង ឬប្រើប្រាស់ Form នោះ? ពេលនោះហើយដែលអ្នកត្រូវការ **Client Components** (វាមានលក្ខណៈដូចគ្នាទៅនឹង Component ដែលអ្នកធ្លាប់រៀនក្នុង React ធម្មតាដែរ)។

ដើម្បីបំប្លែង Server Component អោយទៅជា Client Component អ្នកគ្រាន់តែបន្ថែមពាក្យ `"use client"` នៅក្នុងបន្ទាត់ទីមួយបង្អស់នៃឯកសារនោះ។

```tsx
// ឯកសារ: src/app/counter/page.tsx
"use client" // <--- បញ្ជាក់ថាជា Client Component

import { useState } from 'react'

export default function Counter() {
  // ឥឡូវអ្នកអាចប្រើ State នឹង onClick បានហើយ!
  const [count, setCount] = useState(0)

  return (
    <div className="p-10 text-center">
      <h1 className="text-2xl font-bold mb-4">ពិន្ទុ: {count}</h1>
      <button 
        onClick={() => setCount(count + 1)}
        className="bg-blue-500 text-white px-4 py-2 rounded"
      >
        បូក ១
      </button>
    </div>
  )
}
```

## ⚖️ តើគួរប្រើមួយណា នៅពេលណា?

គោលការណ៍ដែលល្អបំផុត (Best Practice) នៅក្នុង Next.js គឺ៖
> **"រក្សាអ្វីៗគ្រប់យ៉ាងជា Server Components អោយបានច្រើនតាមដែលអាចធ្វើទៅបាន។ ប្រើ `"use client"` តែនៅពេលចាំបាច់បំផុត (ស្លឹកតូចៗ) ប៉ុណ្ណោះ។"**

- **ប្រើ Server Components នៅពេល៖** ទាញយកទិន្នន័យ (Fetch data), បង្ហាញអត្ថបទ, ប្រើជាមួយ Database ដោយផ្ទាល់។
- **ប្រើ Client Components នៅពេល៖** ត្រូវការអន្តរកម្មជាមួយអ្នកប្រើ (User interactions), ចង់ប្រើ `useState` / `useEffect` / Browser APIs (ឧ. `localStorage`)។

ការបែងចែកបែបនេះ ធានាថាកម្មវិធីរបស់អ្នកមានទំហំតូច និងមានល្បឿនលឿនបំផុត។ នៅក្នុងមេរៀនបន្ទាប់ យើងនឹងរៀនពីរបៀបប្តូរទំព័រ (Routing) នៅក្នុង App Router!
