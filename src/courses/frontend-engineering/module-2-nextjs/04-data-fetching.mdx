## 🚀 និយាយលាទៅកាន់ `useEffect`!

នៅក្នុង React ធម្មតា (Client Components) នៅពេលអ្នកចង់ទាញយកទិន្នន័យពី API អ្នកត្រូវរៀបចំ `useState` យ៉ាងហោចណាស់ ៣ (ទិន្នន័យ, Loading, Error) រួចសរសេរ `useEffect` ដើម្បីហៅ Axios ឬ `fetch()`។ វាធ្វើអោយកូដវែង និងស្មុគស្មាញ។

ប៉ុន្តែនៅក្នុង **Next.js Server Components** ការងារនេះក្លាយជារឿងសាមញ្ញបំផុត ព្រោះអ្នកអាចប្រើប្រាស់ `async/await` នៅលើ Component ដោយផ្ទាល់តែម្តង!

## 📥 របៀបទាញយកទិន្នន័យ (Data Fetching)

សូមមើលពីរបៀបដែលយើងទាញយកបញ្ជីឈ្មោះអ្នកប្រើប្រាស់ មកបង្ហាញនៅលើអេក្រង់ដោយមិនប្រើប្រាស់ State ឫ Effect អ្វីទាំងអស់៖

```tsx
// ឯកសារ: src/app/users/page.tsx

// ១. បន្ថែមពាក្យ `async` ទៅកាន់ Component
export default async function UsersPage() {
  
  // ២. ប្រើប្រាស់ `await fetch()` ធម្មតា
  // វានឹងរង់ចាំនៅលើ Server រហូតដល់ទិន្នន័យមកដល់ ទើបវាបញ្ជូន HTML ទៅអោយ Browser
  const response = await fetch('https://jsonplaceholder.typicode.com/users');
  const users = await response.json();

  return (
    <div className="p-10">
      <h1 className="text-2xl font-bold mb-4">👥 បញ្ជីអ្នកប្រើប្រាស់</h1>
      <ul className="list-disc pl-5">
        
        {/* ៣. បង្ហាញទិន្នន័យ */}
        {users.map((user: any) => (
          <li key={user.id} className="mb-2">
            {user.name} - {user.email}
          </li>
        ))}
        
      </ul>
    </div>
  );
}
```

តើអ្នកឃើញទេថាវាងាយស្រួលកម្រិតណា? កូដខ្លី, លឿន (ព្រោះទាញពី Server), និងល្អសម្រាប់ SEO!

## 💾 ប្រព័ន្ធ Caching របស់ Next.js

តាមលំនាំដើម (Default) នៅពេលអ្នកប្រើ `fetch()` នៅក្នុង Next.js, វានឹងទាញយកទិន្នន័យតែម្តងគត់ រួច **ចងចាំ (Cache)** លទ្ធផលនោះទុកជារៀងរហូត។ មានន័យថា ប្រសិនបើមានអ្នកចូលមើលវេបសាយនេះ ១០០០ នាក់ទៀត វាមិនទៅសុំទិន្នន័យពី Backend ទៀតទេ វាគ្រាន់តែបង្ហាញទិន្នន័យចាស់ដែលវាចាំនោះ។

នេះជួយអោយវេបសាយអ្នកលឿនខ្លាំង! ប៉ុន្តែ... ចុះបើទិន្នន័យនោះតែងតែផ្លាស់ប្តូរ (ឧ. តម្លៃភាគហ៊ុន ឬចំនួន Like)?

**របៀបប្រាប់ Next.js អោយទាញយកទិន្នន័យថ្មីរាល់ដង (`no-store`):**

```tsx
export default async function StockPricePage() {
  
  // បន្ថែមជម្រើស { cache: 'no-store' } ដើម្បីបិទការចងចាំ
  const res = await fetch('https://api.example.com/stocks/aapl', {
    cache: 'no-store' 
  });
  
  const data = await res.json();

  return (
    <div>
      <h1>តម្លៃហ៊ុន AAPL ថ្មីបំផុត: ${data.price}</h1>
    </div>
  );
}
```

*ចំណាំ: បើទិន្នន័យមិនសូវផ្លាស់ប្តូរទេ មិនបាច់ដាក់ { cache: 'no-store' } ទេ។*

**សន្និដ្ឋាន:** ការទាញយកទិន្នន័យនៅលើ Server Components គឺជាចំណុចខ្លាំងបំផុតរបស់ Next.js App Router។ វាកាត់បន្ថយទំហំកូដ JavaScript ដែលត្រូវបញ្ជូនទៅកាន់ Browser និងធ្វើអោយវេបសាយរបស់អ្នកមានដំណើរការលឿនជាងមុន។ នៅក្នុងមេរៀនចុងក្រោយ យើងនឹងរៀនពីរបៀប Optimize និងបញ្ចេញវេបសាយនេះទៅកាន់ពិភពលោក (Deployment)!
