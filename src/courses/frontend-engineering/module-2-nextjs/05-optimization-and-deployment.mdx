## ⚡ ការធ្វើអោយវេបសាយមានល្បឿនលឿន (Optimization)

ហេតុផលមួយក្នុងចំណោមហេតុផលដែលក្រុមហ៊ុនធំៗប្រើ Next.js គឺដោយសារវាមានភ្ជាប់មកជាមួយនូវប្រព័ន្ធធ្វើអោយកូដដើរលឿន (Optimization) រួចជាស្រេច ពិសេសគឺសម្រាប់រូបភាព និងអក្សរ (Fonts)។

### ១. ការរៀបចំរូបភាពជាមួយ `next/image`

រូបភាពធំៗ គឺជាមូលហេតុចម្បងដែលធ្វើអោយវេបសាយដើរយឺត។ ជំនួសអោយការប្រើ `<img>` ធម្មតា អ្នកគួរតែប្រើ `<Image>` របស់ Next.js។

```tsx
import Image from 'next/image'
// យក្សរូបភាពពីក្នុង folder public/ ឬប្រើ URL ក៏បាន
import profilePic from '../../public/profile.jpg'

export default function Profile() {
  return (
    <div className="p-10">
      <h1>ប្រវត្តិរូប</h1>
      
      {/* វានឹងមិនទាញយករូបភាពនេះទេ រហូតទាល់តែអ្នកអូស (Scroll) មកដល់ទីតាំងនេះ! */}
      <Image
        src={profilePic}
        alt="រូបថតប្រវត្តិរូប"
        width={500}       // ត្រូវកំណត់ទំហំជានិច្ច 
        height={500}      // (លុះត្រាតែអ្នក Import រូបភាពពី Local ផ្ទាល់)
        className="rounded-full"
      />
    </div>
  )
}
```

### ២. ការរៀបចំ Font ជាមួយ `next/font`

ប្រសិនបើអ្នកប្រើ Google Fonts (តាមរយៈ `<link>` ក្នុង HTML) វានឹងធ្វើអោយការ Load យឺតដោយសារត្រូវទាញយកពី Server របស់ Google។ 
Next.js ទាញយក Font នោះមករក្សាទុកក្នុងកុំព្យូទ័រ Server របស់អ្នកផ្ទាល់ (Self-hosted) ដោយស្វ័យប្រវត្តិ។

```tsx
// ឯកសារ: src/app/layout.tsx
import { Inter, Hanuman } from 'next/font/google' // ទាញយកពី Google Fonts
import './globals.css'

// កំណត់ Font ភាសាអង់គ្លេស
const inter = Inter({ subsets: ['latin'] })

// កំណត់ Font ភាសាខ្មែរ (ឧ. ហនុមាន)
const hanuman = Hanuman({ 
  weight: ['400', '700'], 
  subsets: ['khmer'] 
})

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    // បញ្ចូលឈ្មោះ Font ទៅក្នុងស្លាក HTML ដើម
    <html lang="km">
      <body className={`${inter.className} ${hanuman.className}`}>
        {children}
      </body>
    </html>
  )
}
```

## 🚀 ការបញ្ចេញវេបសាយទៅកាន់ពិភពលោក (Deployment)

តើអ្នកបង្កើត Next.js ហើយចង់អោយពិភពលោកឃើញមែនទេ? កន្លែងដែលល្អបំផុត ស្រួលបំផុត និង **ឥតគិតថ្លៃ** គឺ [Vercel](https://vercel.com/) (ក្រុមហ៊ុនដែលបង្កើត Next.js ផ្ទាល់តែម្តង)។

**ជំហានក្នុងការ Deploy:**

1. **Upload កូដទៅ GitHub:** ដំបូងអ្នកត្រូវ `git push` កូដ Next.js របស់អ្នកទៅកាន់ GitHub Repository ជាមុនសិន។
2. **ចូលគណនី Vercel:** បើកគេហទំព័រ [Vercel.com](https://vercel.com) ហើយ Login ជាមួយ GitHub។
3. **Import Project:** ចុចប៊ូតុង "Add New..." -> "Project" ហើយជ្រើសរើសយក Repository របស់អ្នកពី GitHub។
4. **ចុច Deploy!** 
5. រង់ចាំប្រហែល ១-២ នាទី Vercel នឹងរៀបចំអ្វីៗទាំងអស់អោយអ្នក រួចផ្តល់ជូននូវ Link ពិតប្រាកដមួយ (ឧ. `https://my-next-app.vercel.app`) ដែលអ្នកអាចផ្ញើទៅមិត្តភ័ក្តិមើលបានភ្លាមៗ!

*អ្វីដែលអស្ចារ្យនោះគឺ រាល់ពេលដែលអ្នក `git push` លើកក្រោយ Vercel នឹងទាញយកកូដថ្មី ហើយ Update វេបសាយរបស់អ្នកដោយស្វ័យប្រវត្តិ (Auto Deployment)។*

**អបអរសាទរ! 🎉** អ្នកបានបញ្ចប់ម៉ូឌុលជម្រើស Next.js នេះដោយជោគជ័យ។ អ្នកពេលនេះមានសមត្ថភាពគ្រប់គ្រាន់ក្នុងការបង្កើតវេបសាយដ៏ទំនើប និងមានស្តង់ដារកម្រិតពិភពលោក!
