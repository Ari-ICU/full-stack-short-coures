## 🚀 អ្វីទៅជា Next.js?

<img src="https://upload.wikimedia.org/wikipedia/commons/8/8e/Nextjs-logo.svg" alt="Next.js Logo" width="120" style={{ display: "block", margin: "0 auto" }} />


**Next.js** គឺជា React Framework ដែលបង្កើតឡើងដោយក្រុមហ៊ុន **Vercel**។ ប្រសិនបើ React គ្រាន់តែជាបណ្ណាល័យសម្រាប់បង្កើត UI (Library), Next.js គឺជា "ប្រព័ន្ធពេញលេញ (Framework)" សម្រាប់ការបង្កើតកម្មវិធីវេបសាយទាំងមូល ដោយមានរួមបញ្ចូលនូវមុខងារសំខាន់ៗដូចជា Routing, Data Fetching, និង Server-Side Rendering (SSR) រួចជាស្រេច។

*(ចំណាំ៖ មេរៀននេះគឺជាមេរៀនជម្រើស (Optional) សម្រាប់អ្នកដែលចង់ពង្រីកចំណេះដឹងពី React ទៅកាន់កម្រិតស្តង់ដារក្រុមហ៊ុនធំៗ)*។

## 🚀 ការបង្កើតគម្រោង Next.js

ដើម្បីចាប់ផ្តើម សូមបើក Terminal របស់អ្នក ហើយវាយបញ្ជាខាងក្រោម៖

```bash
npx create-next-app@latest my-next-app
```
នៅពេលដំឡើង វានឹងសួរអ្នកសំណួរមួយចំនួន។ សូមរើសយក៖
- TypeScript: **Yes**
- ESLint: **Yes**
- Tailwind CSS: **Yes**
- `src/` directory: **Yes**
- App Router: **Yes** (សំខាន់បំផុត!)

បន្ទាប់មក ចូលទៅកាន់ Folder នោះ ហើយដំណើរការវា៖
```bash
cd my-next-app
npm run dev
```

## 📁 ស្គាល់ពី App Router

ចាប់ពីជំនាន់ទី 13 មក Next.js បានណែនាំប្រព័ន្ធថ្មីមួយហៅថា **App Router**។ វារៀបចំរចនាសម្ព័ន្ធ Routing ដោយផ្អែកលើ Folder នៅក្នុងថតឯកសារ `src/app`។

ឯកសារសំខាន់ៗពីរដែលអ្នកត្រូវស្គាល់មុនគេគឺ៖

### ១. `layout.tsx` (ស៊ុមរុំខាងក្រៅ)
នេះគឺជាឯកសារសម្រាប់កំណត់ស៊ុមវេបសាយ (ឧ. Header និង Footer) ដែលនឹងបង្ហាញនៅលើគ្រប់ទំព័រទាំងអស់។

```tsx
// ឯកសារ: src/app/layout.tsx
import './globals.css'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="km">
      <body>
        <nav className="p-4 bg-gray-900 text-white">របារបញ្ជី (Navigation)</nav>
        
        {/* children គឺជាមាតិកានៃទំព័រនីមួយៗ */}
        <main className="p-8">{children}</main> 
        
        <footer className="p-4 bg-gray-200">រក្សាសិទ្ធិដោយ ខ្ញុំ</footer>
      </body>
    </html>
  )
}
```

### ២. `page.tsx` (មាតិកាទំព័រ)
រាល់ពេលដែលអ្នកបង្កើត Folder ថ្មីនៅក្នុង `app/` អ្នកត្រូវបង្កើតឯកសារ `page.tsx` នៅខាងក្នុងវា ដើម្បីអោយវាក្លាយជាទំព័រដែលអាចមើលបាន (Public Route)។

```tsx
// ឯកសារ: src/app/page.tsx (នេះគឺជាទំព័រដើម: /)
export default function Home() {
  return (
    <div>
      <h1 className="text-3xl font-bold">សួស្តី Next.js App Router 🚀</h1>
      <p>នេះគឺជាទំព័រដើមរបស់អ្នក។</p>
    </div>
  )
}
```

**សន្និដ្ឋាន:** Next.js ធ្វើអោយការចាប់ផ្តើមគម្រោងកាន់តែងាយស្រួលដោយមានរៀបចំអ្វីៗគ្រប់យ៉ាងរួចជាស្រេច ជាពិសេសគឺរចនាសម្ព័ន្ធ Routing។ នៅក្នុងមេរៀនបន្ទាប់ យើងនឹងស្វែងយល់ពីអាវុធសម្ងាត់របស់ Next.js គឺ **Server Components**!
