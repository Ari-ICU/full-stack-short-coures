## 💾 អ្វីទៅជា Local Storage?

ធម្មតា នៅពេលអ្នក Refresh គេហទំព័រ ទិន្នន័យដែលរក្សាទុកក្នុង Variables (`let` ឬ `const`) នឹងត្រូវបាត់បង់ទាំងអស់! តើធ្វើដូចម្តេចទើបអាចរក្សាទុកទិន្នន័យដូចជា ការកំណត់ Dark Mode, ព័ត៌មាន User លៃឡក, ឬទំនិញក្នុងកន្ត្រក អោយនៅជាប់ជារហូតបាន?

ចម្លើយគឺ **Local Storage**! វាគឺជាកន្លែងរក្សាទុកទិន្នន័យខ្នាតតូច (ប្រហែល 5MB) ដែលភ្ជាប់មកជាមួយ Browser នីមួយៗ (Chrome, Safari, Firefox)។ ទិន្នន័យនឹងមិនបាត់ទេ ទាល់តែអ្នកប្រើប្រាស់លុបវាដោយខ្លួនឯង (Clear Browsing Data)។

## 1. ការប្រើប្រាស់មូលដ្ឋាន

ការធ្វើការជាមួយ Local Storage គឺងាយស្រួលបំផុត ដោយវាដំណើរការជាទម្រង់ `Key: Value`។

### រក្សាទុកទិន្នន័យ (`setItem`)
អ្នកត្រូវកំណត់ឈ្មោះ (Key) និងតម្លៃ (Value) ដែលចង់រក្សាទុក។
```javascript
localStorage.setItem("theme", "dark");
localStorage.setItem("username", "Sok Dara");
```

### ទាញយកទិន្នន័យ (`getItem`)
នៅពេលអ្នកចង់បានទិន្នន័យមកវិញ គ្រាន់តែប្រាប់ឈ្មោះ (Key) ជាការស្រេច។ ប្រសិនបើកូនសោរនោះមិនមាន វានឹងត្រឡប់ `null`។
```javascript
const currentTheme = localStorage.getItem("theme");
console.log(currentTheme); // "dark"
```

### លុបទិន្នន័យ (`removeItem` និង `clear`)
អ្នកអាចលុបទិន្នន័យជាក់លាក់ណាមួយ ឬលុបទាំងអស់តែម្តងក៏បាន។
```javascript
// លុបតែឈ្មោះអ្នកប្រើប្រាស់ប៉ុណ្ណោះ
localStorage.removeItem("username");

// លុបទិន្នន័យទាំងអស់ដែលរក្សាទុកដោយគេហទំព័រនេះ!
localStorage.clear(); 
```

## 🔄 2. ការរក្សាទុក Objects និង Arrays 

នេះគឺជាចំណុចដែលសិស្សថ្មីៗតែងតែមានកំហុស! **Local Storage ស្គាល់តែ String ប៉ុណ្ណោះ!** បើអ្នកព្យាយាមរុញ Object ចូលផ្ទាល់ វាប្រែទៅជាពាក្យ `[object Object]` ដែលគ្មានន័យអ្វីទាំងអស់។

ដើម្បីដោះស្រាយបញ្ហានេះ យើងត្រូវពឹងផ្អែកលើ **JSON** ដែលបានរៀនក្នុងមេរៀនមុន!

### ជំហានទី ១៖ បំប្លែងទៅជា String មុនពេលរក្សាទុក
យើងប្រើ `JSON.stringify()` ដើម្បីបំប្លែង Array ឬ Object អោយទៅជាអត្ថបទ (String)។
```javascript
const cart = ["Apple", "Banana", "Milk"];

// ❌ ខុស: localStorage.setItem("myCart", cart);
// ✅ ត្រូវ: 
localStorage.setItem("myCart", JSON.stringify(cart));
```

### ជំហានទី ២៖ បំប្លែងមកជា Object វិញ ក្រោយពេលទាញយក
នៅពេលយើង `getItem` វានឹងត្រឡប់មកជា String។ យើងត្រូវប្រើ `JSON.parse()` ដើម្បីប្រែក្លាយវាមកជា Array ឬ Object ដើមវិញ។
```javascript
const savedCartString = localStorage.getItem("myCart");

// ត្រូវប្រាកដថាទិន្នន័យមានពិតមែន (មិន null) មុននឹង Parse
if (savedCartString) {
  const cartArray = JSON.parse(savedCartString);
  console.log(cartArray[0]); // "Apple"
}
```

> 💡 **ចំណាំ៖** តែងតែប្រើ `JSON.stringify()` ពេលរុញចូល និង `JSON.parse()` ពេលទាញចេញ ប្រសិនបើទិន្នន័យរបស់អ្នកមិនមែនជាអត្ថបទធម្មតា។ វានឹងជួយសង្គ្រោះអ្នកពីបញ្ហាឈឺក្បាលជាច្រើន!
