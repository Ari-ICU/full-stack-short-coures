## ⏳ អ្វីទៅជា Asynchronous JavaScript?

តាមធម្មជាតិ JavaScript គឺ **Synchronous** ពោលគឺវាធ្វើការម្តងមួយបន្ទាត់ៗពីលើចុះក្រោម។ បើបន្ទាត់ទី ១ ដើរមិនទាន់ចប់ទេ បន្ទាត់ទី ២ ត្រូវតែឈរចាំ។ 

ចុះបើបន្ទាត់ទី ១ ជាការទាញយកទិន្នន័យពី Server ដែលត្រូវចំណាយពេល ៥ វិនាទី? តើគេហទំព័រទាំងមូលត្រូវគាំង ៥ វិនាទីដែរឬ? 
ចម្លើយគឺ **អត់ទេ!** នេះហើយជាមូលហេតុដែលយើងមាន **Asynchronous (អសមកាល)**។ វាអនុញ្ញាតអោយ JavaScript យកការងារដែលយូរៗទៅទុកមួយឡែកសិន ដើម្បិបន្តធ្វើការងារផ្សេងទៀត ហើយចាំត្រឡប់មកយកលទ្ធផលពេលវាដើរចប់។ (`setTimeout` គឺជាឧទាហរណ៍នៃ Asynchronous)។

## 🤝 1. អ្វីទៅជា Promise?

ដើម្បីគ្រប់គ្រង Asynchronous កូដ អោយមានរបៀបរៀបរយ JavaScript បង្កើតនូវអ្វីដែលហៅថា **Promise** (ការសន្យា)។ 

ប្រៀបធៀបទៅនឹងជីវិតពិត៖ អ្នកកុម្ម៉ង់កាហ្វេ។ អ្នកលក់អោយ "វិក័យប័ត្រ (លេខរង់ចាំ)" មួួយមកអ្នក។ វិក័យប័ត្រនោះគឺជា **Promise** ថានឹងមានកាហ្វេ។ 
ខណៈពេលកំពុងចាំ អ្នកអាចលេងទូរស័ព្ទបាន (Asynchronous)។
*   **Pending:** កំពុងឆុង (មិនទាន់បានលទ្ធផល)
*   **Resolved/Fulfilled:** ឆុងឆ្អិន អ្នកទទួលបានកាហ្វេ (ជោគជ័យ)
*   **Rejected:** អស់កាហ្វេ (បរាជ័យ/Error)

ការប្រើប្រាស់ Promise បែបចាស់គេប្រើ `.then()` សម្រាប់ពេលជោគជ័យ និង `.catch()` សម្រាប់ពេលបរាជ័យ។ (វារាងស្មុគស្មាញបន្តិច ដូច្នេះយើងមានវិធីថ្មីនៅខាងក្រោម!)

## 🚀 2. ការប្រើប្រាស់ `async` / `await` (ES8)

ដោយសារតែការប្រើ `.then().catch()` ច្រើនតៗគ្នាធ្វើអោយកូដពិបាកអានពេក (Callback Hell / Promise Chain) JavaScript ក៏បានបញ្ចេញមុខងារថ្មីគឺ **`async` / `await`** ដែលធ្វើអោយកូដ Asynchronous មើលទៅស្រួលអានដូចកូដ Synchronous ធម្មតាអញ្ចឹង!

### របៀបប្រើប្រាស់៖
1. ដាក់ពាក្យ `async` នៅពីមុខ Function របស់អ្នក។ វាបញ្ជាក់ថា Function នេះនឹងមានការងារ Asynchronous នៅខាងក្នុង។
2. ដាក់ពាក្យ `await` នៅពីមុខ Promise (មុខងារដែលត្រូវការរង់ចាំ)។ វានឹងប្រាប់ JavaScript អោយផ្អាកមួយភ្លែតត្រង់បន្ទាត់នោះ រហូតទាល់តែបានលទ្ធផល ទើបទៅមុខបន្ត។

```javascript
// ១. ប្រកាសថាវាជា async function
const fetchUserData = async () => {
  console.log("១. ចាប់ផ្តើមទាញយកទិន្នន័យ...");

  // ២. ប្រើ try...catch ដើម្បីចាប់យក Error ក្រែងលោដាច់ Network
  try {
    // ៣. ប្រើ await ដើម្បីរង់ចាំអោយទិន្នន័យមកដល់សិន
    // ចំណាំ៖ ការហៅទៅ Server គឺតែងតែត្រឡប់មកជា Promise ជានិច្ច
    const data = await getServerData(); 
    
    // បន្ទាត់នេះនឹងមិនដើរទេ ដរាបណាបន្ទាត់ខាងលើមិនទាន់ចប់
    console.log("២. ទទួលបានទិន្នន័យ៖", data); 
    
  } catch (error) {
    console.log("បរាជ័យក្នុងការទាញយក៖", error.message);
  }
};

fetchUserData();
console.log("៣. ខ្ញុំជាកូដខាងក្រៅ ខ្ញុំមិនបាច់ចាំទេ! ខ្ញុំរត់មុនហើយ!");
```

**លទ្ធផលនៃការ Console:**
```
១. ចាប់ផ្តើមទាញយកទិន្នន័យ...
៣. ខ្ញុំជាកូដខាងក្រៅ ខ្ញុំមិនបាច់ចាំទេ! ខ្ញុំរត់មុនហើយ!
២. ទទួលបានទិន្នន័យ៖ { name: "Sok", age: 25 }  <-- (លោតចេញក្រោយគេ ព្រោះចំណាយពេលយូរ)
```

> 💡 **សរុបមក៖** `async/await` គឺជាវិធីដ៏ងាយស្រួលបំផុត និងជាស្តង់ដារបច្ចុប្បន្នក្នុងការទាញយកទិន្នន័យ (Fetch Data) ពី Server ដែលយើងនឹងអនុវត្តផ្ទាល់នៅក្នុងមេរៀនបន្ទាប់!
