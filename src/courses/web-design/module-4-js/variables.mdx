## 📦 Variables

នៅក្នុង JavaScript, **Variables** គឺជាប្រអប់សម្រាប់ផ្ទុកទិន្នន័យ (Data)។ ដើម្បីបង្កើត Variable យើងអាចប្រើ Keywords ៣ យ៉ាង៖ `var`, `let`, និង `const`។

### ១. ការប្រើប្រាស់ `let`
`let` ត្រូវបានណែនាំនៅក្នុង ES6 សម្រាប់ប្រកាសអថេរដែលអាចផ្លាស់ប្តូរតម្លៃបាន។ វាមាន **Block Scope** (មានន័យថាវាត្រូវបានស្គាល់តែក្នុងវង់ក្រចក `{}` ប៉ុណ្ណោះ)។

```javascript
let age = 25;
age = 26; // ✅ អាចផ្លាស់ប្តូរបាន
console.log(age); // 26
```

### ២. ការប្រើប្រាស់ `const`
`const` (Constant) ក៏មាន **Block Scope** ដែរ ប៉ុន្តែវាត្រូវបានប្រើសម្រាប់ប្រកាសអថេរដែល **មិនអាចផ្លាស់ប្តូរតម្លៃបាន**។

```javascript
const birthYear = 1998;
// birthYear = 1999; // ❌ Error: Assignment to constant variable.
```

> 💡 **Best Practice:** គួរប្រើប្រាស់ `const` ជានិច្ច លើកលែងតែអ្នកដឹងច្បាស់ថាតម្លៃនោះនឹងត្រូវផ្លាស់ប្តូរនៅពេលក្រោយ ទើបប្រើ `let`។ នេះជួយកាត់បន្ថយកំហុសនៅក្នុងកូដ។

### ៣. ការប្រើប្រាស់ `var` (បែបចាស់)
`var` គឺជាវិធីចាស់ (មុន ES6) ក្នុងការប្រកាសអថេរ។ វាមាន **Function Scope** មិនមែន Block Scope ទេ ព្រមទាំងមានបញ្ហាជាមួយ Hoisting ដែលធ្វើអោយមានភាពរញ៉េរញ៉ៃ។ នៅក្នុងការសរសេរកូដទំនើប យើង **មិនគួរ** ប្រើ `var` ទៀតទេ។

## 🔍 Scope

**Scope** គឺជាបរិបទ (Context) នៃកូដដែលកំណត់ថាតើ Variables ណាមួយអាចត្រូវបានមើលឃើញ ឬទាញយកទៅប្រើប្រាស់បាន។ JavaScript មាន Scopes ៣ សំខាន់ៗ៖

### 1. Global Scope
Variable ដែលប្រកាសនៅខាងក្រៅ Functions ឬ Blocks ទាំងអស់ គឺមាន Global Scope។ ពួកវាអាចត្រូវបានហៅប្រើនៅទីណាក៏បាន។

```javascript
const siteName = "My Website"; // Global Scope

function printSite() {
  console.log(siteName); // ✅ អាចហៅប្រើបាន
}
```

### 2. Function Scope
Variable ដែលប្រកាសនៅខាងក្នុង Function (មិនថាប្រើ `var`, `let`, ឬ `const` ទេ) គឺស្គាល់តែនៅខាងក្នុង Function នោះប៉ុណ្ណោះ។

```javascript
function greet() {
  let message = "សួស្តី"; // Function Scope
  console.log(message);
}

// console.log(message); // ❌ Error: message is not defined
```

### 3. Block Scope
`let` និង `const` ផ្តល់នូវ Block Scope ពោលគឺវាត្រូវបានស្គាល់តែនៅក្នុងវង់ក្រចក `{}` ដូចជាក្នុង `if`, `for`, ឬ `while`។ `var` មិនមាន Block Scope ទេ។

```javascript
if (true) {
  let blockScoped = "ខ្ញុំនៅទីនេះ";
  var functionScoped = "ខ្ញុំអាចចេញក្រៅបាន";
}

// console.log(blockScoped); // ❌ Error
console.log(functionScoped); // ✅ ដើរធម្មតា (នេះហើយជាមូលហេតុដែល var មានបញ្ហា!)
```

## ⬆️ Hoisting

**Hoisting** គឺជាយន្តការមួយរបស់ JavaScript ដែលទាញយកការប្រកាស (Declarations) ទាំងអស់ឡើងទៅលើគេបង្អស់នៃ Scope របស់វា មុនពេលកូដចាប់ផ្តើមដំណើរការ។

```javascript
console.log(myVar); // ចេញ undefined (មិន error ទេ!)
var myVar = 10;
```
ហេតុអ្វីបានជាវាមិន Error? ដោយសារតែ Hoisting ទាញយកការប្រកាសឡើងលើ៖
```javascript
// កូដខាងលើត្រូវបាន JS ប្រែទៅជាបែបនេះដោយស្វ័យប្រវត្តិ៖
var myVar;
console.log(myVar); // ទើបតែប្រកាស តែមិនទាន់អោយតម្លៃ ទើបចេញ undefined
myVar = 10;
```

**ចុះចំណែក `let` និង `const`?**
ពួកវាក៏ត្រូវបាន Hoisted ដែរ ប៉ុន្តែពួកវាមិនអាចត្រូវបានហៅមកប្រើមុនពេលកូដមកដល់បន្ទាត់របស់វាឡើយ។ តំបន់រវាងការ Hoist និងការប្រកាសនេះហៅថា **Temporal Dead Zone (TDZ)**។

```javascript
// console.log(myLet); // ❌ ReferenceError: Cannot access 'myLet' before initialization
let myLet = 20;
```
