## 📚 អ្វីទៅជា Arrays?

ប្រសិនបើ Object ជាទូសម្រាប់ដាក់ឯកសារមានឈ្មោះត្រឹមត្រូវ នោះ **Array** គឺជាធ្នើរដាក់សៀវភៅដែលរៀបជាជួរៗ។ Array គឺជាប្រភេទ Structural Data Type មួយដែលអនុញ្ញាតអោយយើងផ្ទុកទិន្នន័យច្រើនប្រភេទបញ្ចូលគ្នា ជាទម្រង់បញ្ជី (List) ហើយមានលំដាប់លំដោយច្បាស់លាស់។

---

## 1. ការបង្កើត និងប្រើប្រាស់ Arrays

យើងបង្កើត Array ដោយប្រើប្រាស់សញ្ញា `[]` (Square brackets)។ តម្លៃនីមួយៗត្រូវបានខណ្ឌចែកដោយសញ្ញាក្បៀស (`,`)។

```javascript
// Array ផ្ទុក String ទាំងអស់
const fruits = ["Apple", "Banana", "Orange", "Mango"];

// Array អាចផ្ទុកទិន្នន័យចម្រុះគ្នាបាន
const mixedArray = ["Sok", 25, true, null];
```

### ការទាញយកទិន្នន័យតាម Index
ដើម្បីយកទិន្នន័យណាមួយចេញមកប្រើ យើងត្រូវបញ្ជាក់ពីទីតាំង (Index) របស់វា។ **សំខាន់បំផុត៖ Index តែងតែចាប់ផ្តើមពីលេខ 0!**

```javascript
console.log(fruits[0]); // "Apple" (ផ្លែឈើទី១)
console.log(fruits[2]); // "Orange" (ផ្លែឈើទី៣)

// កែប្រែតម្លៃនៅក្នុង Array
fruits[1] = "Cherry"; // ប្តូរពី Banana ទៅ Cherry
console.log(fruits); // ["Apple", "Cherry", "Orange", "Mango"]
```

## 📂 2. Nested Arrays (Arrays ត្រួតគ្នា)

Array ក៏អាចផ្ទុក Array ផ្សេងទៀតនៅខាងក្នុងវាបានដែរ។ វាប្រៀបបាននឹងតារាង (Matrix ឬ Table)។

```javascript
const ticTacToe = [
  ["X", "O", "X"],
  ["O", "X", "O"],
  ["O", "O", "X"]
];

// ទាញយកអក្សរ "X" ដែលនៅចំកណ្តាលគេបង្អស់
// [1] គឺជួរទីពីរ, [1] បន្ទាប់គឺទីតាំងកណ្តាលក្នុងជួរនោះ
console.log(ticTacToe[1][1]); // "X"
```

## ✨ 3. មុខងារទំនើបៗ (ES6+) សម្រាប់ Arrays

ដូចគ្នានឹង Objects ដែរ ES6 បានផ្តល់ភាពងាយស្រួលដល់ការប្រើប្រាស់ Arrays ជាមួយ Destructuring និង Spread Operator។

### Array Destructuring
អនុញ្ញាតអោយទាញយកតម្លៃតាមលំដាប់ពី Array មកផ្ទុកក្នុង Variables ដាច់ដោយឡែក។

```javascript
const colors = ["red", "green", "blue", "yellow"];

// ទាញយកពណ៌ទី១ និងទី២
const [primaryColor, secondaryColor] = colors;

console.log(primaryColor); // "red"
console.log(secondaryColor); // "green"

// បើចង់រំលងពណ៌ទី២ ហើយយកទី៣ គ្រាន់តែទុកចន្លោះប្រហោង
const [first, , third] = colors;
console.log(third); // "blue"
```

### Spread Operator (`...`)
សញ្ញាចុចបី `...` អាចយកធាតុទាំងអស់ពីក្នុង Array មួយមក "ពង្រាយ" បញ្ចូលក្នុង Array មួយទៀត។
```javascript
const oldUsers = ["Sok", "Sao"];
const newUsers = ["Dara", "Chea"];

// បញ្ចូល Arrays ទាំងពីរចូលគ្នា ហើយថែម "Minea" មួយទៀត
const allUsers = [...oldUsers, ...newUsers, "Minea"];

console.log(allUsers); 
// ["Sok", "Sao", "Dara", "Chea", "Minea"]
```

## 📌 ការប្រើប្រាស់ទូទៅ (Common Use Cases)

*   **រក្សាទុកបញ្ជីទិន្នន័យពី Database៖** ឧទាហរណ៍ បញ្ជីអត្ថបទ បញ្ជីទំនិញ បញ្ជីអ្នកប្រើប្រាស់។
*   **ធ្វើការរួមគ្នាជាមួយ Loops៖** យើងតែងតែយក Loop (ដូចជា `for...of`) មកប្រើដើម្បីដើរអានតម្លៃនីមួយៗក្នុង Array ដោយស្វ័យប្រវត្តិ។
*   **បម្លែង និងត្រងទិន្នន័យ៖** នៅក្នុងមេរៀនបន្ទាប់ អ្នកនឹងរៀនពី Array Methods (`map`, `filter`, `reduce`) ដែលមានប្រយោជន៍ខ្លាំងបំផុត!
