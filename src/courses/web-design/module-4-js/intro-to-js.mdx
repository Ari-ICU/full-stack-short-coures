## 🚀 ស្វាគមន៍មកកាន់ JavaScript

<div align="center">
  <img src="https://upload.wikimedia.org/wikipedia/commons/9/99/Unofficial_JavaScript_logo_2.svg" alt="JavaScript Logo" width="120" />
</div>


JavaScript គឺជាភាសា Programming ដែលធ្វើឱ្យគេហទំព័ររបស់អ្នក **រស់រវើក**។ ខណៈពេលដែល HTML បង្កើតរចនាសម្ព័ន្ធ ហើយ CSS ធ្វើការតុបតែង, JavaScript គឺសម្រាប់បញ្ចូល **Logic** និង **Interactivity**។

### របៀបសរសេរកូដ JavaScript

អ្នកអាចបញ្ចូល JavaScript ទៅក្នុង HTML របស់អ្នកដោយប្រើប្រាស់ Tag `<script>`៖

```html
<!DOCTYPE html>
<html>
<body>
  <h1>ការសាកល្បង JavaScript</h1>
  
  <script>
    console.log("សួស្តី! នេះគឺជា JavaScript។");
  </script>
</body>
</html>
```

## 📦 Variables និង Scoping

នៅក្នុង JavaScript ទំនើប យើងប្រើ `let` និង `const` ដើម្បីបង្កើត Variable។ ពួកវាមាន **Block Scope** ដែលមានន័យថាវាត្រូវបានស្គាល់តែនៅក្នុងវង់ក្រចក `{}` ដែលវាត្រូវបានបង្កើតឡើងប៉ុណ្ណោះ។

```javascript
// ១. ប្រើ let សម្រាប់តម្លៃដែលអាចផ្លាស់ប្តូរ
let age = 25;
age = 26; // អាចផ្លាស់ប្តូរបាន

// ២. ប្រើ const សម្រាប់តម្លៃថេរ (មិនអាចផ្លាស់ប្តូរបានទេ)
const name = "Sok";
// name = "Sao"; // ❌ នឹងមាន Error

// ៣. Block Scope ឧទាហរណ៍
if (true) {
  let message = "Hello";
  console.log(message); // ✅ ដំណើរការ (Prints: Hello)
}
// console.log(message); // ❌ Error: message is not defined (ព្រោះវានៅក្រៅ Block)
```

## 🗂️ Data Types

JavaScript អាចផ្ទុកទិន្នន័យបានច្រើនប្រភេទ៖

```javascript
let isStudent = true; // Boolean (ពិត ឬ មិនពិត)
let score = 95.5; // Number (លេខ)
let text = "សួស្តី"; // String (អក្សរ)
let hobbies = ["អានសៀវភៅ", "សរសេរកូដ"]; // Array (បញ្ជីទិន្នន័យ)
let person = { name: "សុខ", age: 25 }; // Object (ទិន្នន័យមានលក្ខណៈសម្បត្តិ)
```

## ⚙️ Functions

**Functions** អនុញ្ញាតឱ្យយើងសរសេរកូដម្តង ហើយអាចហៅមកប្រើបានច្រើនដង។ វាជួយអោយកូដយើងស្អាត និងមិនជាន់គ្នា។

```javascript
// ការបង្កើត Function ដោយមាន Parameters (a, b)
function addNumbers(a, b) {
  let sum = a + b;
  return sum; // បញ្ជូនលទ្ធផលត្រឡប់ទៅវិញ
}

// ការហៅ Function មកប្រើ (Arguments: 10, 5)
let result = addNumbers(10, 5);
console.log(result); // លទ្ធផល: 15
```

## 🔀 Control Flow (If...Else)

ដើម្បីធ្វើការសម្រេចចិត្តក្នុងកូដ យើងប្រើ `if`, `else if`, និង `else`។

```javascript
let score = 85;

if (score >= 90) {
  console.log("អ្នកទទួលបាននិទ្ទេស A");
} else if (score >= 80) {
  console.log("អ្នកទទួលបាននិទ្ទេស B");
} else {
  console.log("អ្នកត្រូវខិតខំបន្ថែមទៀត");
}
```

JavaScript គឺជាបេះដូងរបស់ Web Application ទំនើបៗ។ នៅក្នុងមេរៀនបន្ទាប់ យើងនឹងរៀនពីមុខងារថ្មីៗរបស់ JavaScript ES6+!
