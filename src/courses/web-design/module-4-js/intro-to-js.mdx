## 🚀 ស្វាគមន៍មកកាន់ JavaScript

![JavaScript Logo](https://upload.wikimedia.org/wikipedia/commons/9/99/Unofficial_JavaScript_logo_2.svg)


JavaScript គឺជាភាសា Programming ដែលធ្វើឱ្យគេហទំព័ររបស់អ្នក **រស់រវើក**។ ខណៈពេលដែល HTML បង្កើតរចនាសម្ព័ន្ធ ហើយ CSS ធ្វើការតុបតែង, JavaScript គឺសម្រាប់បញ្ចូល **Logic** និង **Interactivity**។

### របៀបសរសេរកូដ JavaScript

អ្នកអាចបញ្ចូល JavaScript ទៅក្នុង HTML របស់អ្នកដោយប្រើប្រាស់ Tag `<script>`៖

```html
<!DOCTYPE html>
<html>
<body>
  <h1>ការសាកល្បង JavaScript</h1>
  
  <script>
    console.log("សួស្តី! នេះគឺជា JavaScript។");
  </script>
</body>
</html>
```

## 📌 តើត្រូវរៀនអ្វីខ្លះបន្ត?

នៅក្នុងមេរៀនបន្ទាប់ៗ យើងនឹងស្វែងយល់លម្អិតអំពី៖
- **Variables**: របៀបបង្កើត និងរក្សាទុកទិន្នន័យ។
- **Data Types**: ប្រភេទទិន្នន័យផ្សេងៗ។
- **Functions & Control Flow**: ការគ្រប់គ្រង Logic របស់កូដ។

តោះទៅកាន់មេរៀនទី ២ ដើម្បីចាប់ផ្តើមសរសេរកូដ JavaScript ទាំងអស់គ្នា!
