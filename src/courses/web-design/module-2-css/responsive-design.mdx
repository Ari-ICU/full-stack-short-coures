## 📱 អ្វីទៅជា Responsive Web Design?

Responsive Web Design (RWD) គឺជាវិធីសាស្ត្រនៃការបង្កើត Website ដែលអាចផ្លាស់ប្តូររូបរាង (Layout) ដោយស្វ័យប្រវត្តិ ទៅតាមទំហំអេក្រង់ (Screen Size) របស់ឧបករណ៍អ្នកប្រើប្រាស់ (ឧទាហរណ៍៖ Mobile, Tablet និង Desktop)។ 

---

## 🎯 វិធីសាស្ត្រ Mobile-First 

Mobile-First គឺជាការចាប់ផ្តើមរចនា Website សម្រាប់អេក្រង់ Mobile មុនគេ បន្ទាប់មកទើបយើងបន្ថែម CSS (តាមរយៈ Media Queries) ដើម្បីផ្លាស់ប្តូរ Layout សម្រាប់អេក្រង់ធំជាងនេះ (ដូចជា Tablet និង Desktop)។

**អត្ថប្រយោជន៍របស់ Mobile-First៖**
- ងាយស្រួលក្នុងការរៀបចំ (ព្រោះអេក្រង់តូចមានតែមួយជួរ)
- ជួយដល់ល្បឿន (Performance) Website នៅលើ Mobile
- កូដមានភាពស្អាត និងមិនសូវស្មុគស្មាញ

---

## 🛠️ ការប្រើប្រាស់ Media Queries (`@media`)

Media Queries គឺជាគន្លឹះសំខាន់របស់ Responsive Web Design។ វាអនុញ្ញាតឱ្យយើងសរសេរកូដ CSS ផ្សេងគ្នាសម្រាប់ Screen Size ផ្សេងគ្នា។

**ឧទាហរណ៍នៃការផ្លាស់ប្តូរពី Mobile ទៅ Desktop៖**

```css
/* ១. កូដសម្រាប់ Mobile (Mobile-First) ជាទូទៅដាក់នៅខាងលើគេ */
.container {
  width: 100%;
  padding: 10px;
  background-color: lightblue;
}

/* ២. សម្រាប់ Tablet (ឧទាហរណ៍៖ អេក្រង់ចាប់ពី 768px ឡើងទៅ) */
@media (min-width: 768px) {
  .container {
    width: 750px;
    margin: 0 auto;
    background-color: lightgreen;
  }
}

/* ៣. សម្រាប់ Desktop (ឧទាហរណ៍៖ អេក្រង់ចាប់ពី 1024px ឡើងទៅ) */
@media (min-width: 1024px) {
  .container {
    width: 960px;
    background-color: lightcoral;
  }
}
```

ក្នុងឧទាហរណ៍ខាងលើ៖
- ជាទូទៅ `container` នឹងមានពណ៌ `lightblue` ហើយលាតសន្ធឹងពេញអេក្រង់ Mobile។
- នៅពេលបើកលើ Tablet វាប្តូរទៅពណ៌ `lightgreen` នឹងមានទំហំ `750px`។
- នៅពេលបើកលើ Desktop វាប្តូរទៅពណ៌ `lightcoral` នឹងមានទំហំ `960px`។

## 📏 របៀបរៀបចំ Layout ជាទូទៅពី Mobile ទៅ Desktop

នៅពេលប្រើ Flexbox ឬ Grid យើងអាចផ្លាស់ប្តូរការតម្រៀប (Direction) យ៉ាងងាយស្រួល៖

```css
/* Mobile: តម្រៀបជាជួរឈរ (Column) */
.gallery {
  display: flex;
  flex-direction: column;
  gap: 16px;
}

/* Desktop: តម្រៀបជាជួរដេក (Row) */
@media (min-width: 1024px) {
  .gallery {
    flex-direction: row;
  }
}
```

ដោយប្រើវិធីសាស្ត្រនេះ អ្នកអាចបង្កើត Website ដែលមើលទៅស្រស់ស្អាតគ្រប់ Screen Size និងផ្តល់នូវ User Experience ដ៏ល្អដល់អ្នកប្រើប្រាស់!
