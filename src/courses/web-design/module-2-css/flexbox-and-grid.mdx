## 📐 បដិវត្តន៍នៃការរៀបចំ Layout

អស់រយៈពេលជាច្រើនឆ្នាំ Web Developers ត្រូវប្រើប្រាស់ "Hacks" ស្មុគស្មាញដូចជា Floats និង Table-Layouts ដើម្បីតម្រៀប Elements នានាឱ្យនៅទន្ទឹមគ្នា។ 

បច្ចុប្បន្ននេះ យើងមានប្រព័ន្ធ Layout ដ៏មានឥទ្ធិពលពីរដែលភ្ជាប់មកជាមួយ CSS ស្រាប់៖ **Flexbox** និង **CSS Grid**។

---

## 🤸‍♀️ Flexbox (Flexible Box Layout)

Flexbox ត្រូវបានរចនាឡើងសម្រាប់ Layout **១ វិមាត្រ (1-Dimensional)**—មានន័យថាវាដោះស្រាយការងារជាមួយ Row តែមួយ ឬ Column តែមួយក្នុងពេលតែមួយ។ វាស័ក្តិសមបំផុតសម្រាប់ការតម្រៀប Elements ការបែងចែកលំហ និងការបង្កើត Navbars។

ដើម្បីដំណើរការ Flexbox អ្នកត្រូវអនុវត្ត `display: flex;` ទៅកាន់ Parent Container។

### Properties សម្រាប់ Flex Container

```css
.container {
  display: flex;
  
  /* ទិសដៅ: row (លំនាំដើម) | column | row-reverse | column-reverse */
  flex-direction: row; 
  
  /* ការតម្រៀបតាម Main Axis (ផ្តេកតាមលំនាំដើម): 
     flex-start | center | flex-end | space-between | space-around */
  justify-content: space-between;
  
  /* ការតម្រៀបតាម Cross Axis (បញ្ឈរតាមលំនាំដើម): 
     stretch (លំនាំដើម) | center | flex-start | flex-end */
  align-items: center;
  
  /* ការរុំ (Wrapping): nowrap (លំនាំដើម) | wrap */
  flex-wrap: wrap;
}
```

### ភាពអស្ចារ្យនៃ `gap`
នៅក្នុង CSS ទំនើប អ្នកមិនចាំបាច់បន្ថែម Margin ទៅ Element នីមួយៗក្នុង Flex Container ទេ។ គ្រាន់តែប្រើ `gap` Property ប៉ុណ្ណោះ!
```css
.container {
  display: flex;
  gap: 16px; /* បន្ថែមគម្លាត 16px រវាង Elements ទាំងអស់ */
}
```

## 🏁 CSS Grid

ខណៈដែល Flexbox គឺសម្រាប់ ១ វិមាត្រ CSS Grid គឺសម្រាប់ Layout **២ វិមាត្រ (2-Dimensional)**—វាគ្រប់គ្រងទាំង Rows និង Columns ក្នុងពេលតែមួយ។ វាស័ក្តិសមបំផុតសម្រាប់រចនាសម្ព័ន្ធ Page ទាំងមូល និង Image Gallery ស្មុគស្មាញ។

### Properties សម្រាប់ Grid Container

```css
.grid-container {
  display: grid;
  
  /* កំណត់ Columns។ ទីនេះយើងបង្កើត ៣ Columns ដែលមានទទឹងស្មើគ្នា។ */
  grid-template-columns: 1fr 1fr 1fr;
  
  /* កំណត់ Rows។ ទីនេះយើងបង្កើត ២ Rows, នីមួយៗមានកម្ពស់ 200px។ */
  grid-template-rows: 200px 200px;
  
  /* បន្ថែមគម្លាតរវាង Elements ក្នុង Grid */
  gap: 20px;
}
```

### Fractional Unit (`fr`)
Grid បានណែនាំឯកតារង្វាស់ថ្មីមួយគឺ៖ `fr` (Fractional Unit)។ វាតំណាងឱ្យប្រភាគនៃទំហំទំនេរនៅក្នុង Grid Container។
- `grid-template-columns: 1fr 2fr 1fr;` បង្កើត ៣ Columns ដែល Column កណ្តាលមានទទឹងធំជាងគេពីរដង។

### អនុគមន៍ `repeat()`
ប្រសិនបើអ្នកចង់បាន ៤ Columns ស្មើគ្នា អ្នកមិនចាំបាច់សរសេរ `1fr 1fr 1fr 1fr` ទេ។
```css
.grid-container {
  grid-template-columns: repeat(4, 1fr);
}
```

## ⚖️ Flexbox vs Grid: តើគួរជ្រើសរើសមួយណា?

- ប្រើ **Flexbox** សម្រាប់ Layout តូចៗ (Navigation Bars, ដាក់ Icon ចំកណ្តាល Button, តម្រៀប Elements ក្នុង Card)។
- ប្រើ **CSS Grid** សម្រាប់ Layout ធំៗ (Page Layout, Gallery នៃ Product Cards, Dashboard Grids)។

នៅក្នុងការរចនា Website ទំនើប ពួកវាត្រូវបានបង្កើតឡើងដើម្បីប្រើរួមគ្នា! ជាញឹកញាប់អ្នកនឹងមាន Grid Layout សម្រាប់ Page ធំ ហើយ Card នីមួយៗនៅក្នុង Grid នោះនឹងប្រើប្រាស់ Flexbox ដើម្បីតម្រៀប Content ខាងក្នុងរបស់វា។
