## 📏 ខ្នាតរង្វាស់ទំនើប (Modern CSS Units)

កាលពីមុនគេតែងតែប្រើប្រាស់តែ `px` និង `%` ប៉ុណ្ណោះ ប៉ុន្តែបច្ចុប្បន្ន CSS មានខ្នាតរង្វាស់ទំនើបៗជាច្រើន ដើម្បីជួយក្នុងការធ្វើ Responsive Design៖

### ខ្នាតរឹង (Absolute Units)
- **`px` (Pixels):** ជារង្វាស់គោល។ 1px គឺ 1px វាមិនប្រែប្រួលតាមទំហំអេក្រង់ទេ។ (ប្រើសម្រាប់ Border ឬទំហំដែលយើងចង់អោយវានៅថេរ)

### ខ្នាតយឺត (Relative Units)
- **`%` (Percentage):** ធៀបនឹងទំហំរបស់ Element មេរបស់វា។ ឧទាហរណ៍ `width: 50%` មានន័យថាទំហំពាក់កណ្តាលនៃមេវា។
- **`em`:** ធៀបនឹងទំហំ Font (`font-size`) របស់ Element **មេ** របស់វា។ 
- **`rem` (Root EM):** ធៀបនឹងទំហំ Font របស់ `<html>` តែម្តង (តាមលំនាំដើម 1rem = 16px)។ **(ណែនាំអោយប្រើជាប្រចាំសម្រាប់ Font Size, Margin, Padding!)**
- **`vw` (Viewport Width):** 1vw ស្មើនឹង 1% នៃទទឹងអេក្រង់។ (100vw = ទទឹងពេញអេក្រង់)
- **`vh` (Viewport Height):** 1vh ស្មើនឹង 1% នៃកម្ពស់អេក្រង់។ (100vh = កម្ពស់ពេញអេក្រង់)
- **`fr` (Fraction):** ប្រើនៅក្នុង CSS Grid ប៉ុណ្ណោះ ដើម្បីបែងចែកកន្លែងទំនេរ។

### កំពូលអនុគមន៍ `clamp()`
`clamp(minimum, preferred, maximum)` គឺជាវិធីដ៏អស្ចារ្យក្នុងការធ្វើ Responsive Typography ។ អក្សរនឹងរួមតូច ឫរីកធំតាមទំហំអេក្រង់ ប៉ុន្តែមិនអោយតូចពេក ឫធំពេកនោះទេ។

```css
h1 {
  /* តូចបំផុត 24px, ល្មមបំផុត 5vw, ធំបំផុត 48px */
  font-size: clamp(1.5rem, 5vw, 3rem);
}
```

## 📦 CSS Variables (Custom Properties)

ជំនួសអោយការសរសេរកូដពណ៌ដដែលៗពេញកូដ CSS របស់អ្នក អ្នកអាចរក្សាទុកវាទុកក្នុង Variables បាន។ នេះជួយអោយការប្តូរពណ៌ (ឧ. ធ្វើ Dark Mode) មានភាពងាយស្រួលបំផុត!

```css
/* ១. បង្កើត Variables ដាក់ក្នុង Root (ស្រទាប់ខ្ពស់បំផុត) */
:root {
  --primary-color: #3b82f6;   /* ពណ៌ខៀវ */
  --text-dark: #1f2937;
  --spacing-md: 16px;
}

/* ២. ហៅយកមកប្រើតាមរយៈ var() */
button {
  background-color: var(--primary-color);
  padding: var(--spacing-md);
  color: white;
}

h1 {
  color: var(--text-dark);
}
```

## 🎨 ការលាយពណ៌ (Gradients)

ជំនួសអោយការប្រើពណ៌ធម្មតា (Solid Color) អ្នកអាចចាក់ពណ៌លាយបញ្ចូលគ្នាបានដោយមិនបាច់ប្រើរូបភាពឡើយ។

```css
/* Linear Gradient (ពីឆ្វេងទៅស្តាំ ឬ លើចុះក្រោម) */
.box-1 {
  background: linear-gradient(to right, #ff7e5f, #feb47b);
}

/* Radial Gradient (រង្វង់ពីកណ្តាលចេញក្រៅ) */
.box-2 {
  background: radial-gradient(circle, #00c6ff, #0072ff);
}
```

## 🖼️ រូបភាព Responsive (Responsive Images)

រូបភាពជារឿយៗតែងតែលៀនចេញពីប្រអប់របស់វា ឬបែក Layout នៅពេលមើលលើទូរស័ព្ទ។ ដើម្បីដោះស្រាយបញ្ហានេះ អ្នកគ្រាន់តែសរសេរកូដមួយជួរនេះប៉ុណ្ណោះ៖

```css
img {
  max-width: 100%; /* កុំអោយរូបភាពធំជាងប្រអប់មេរបស់វា */
  height: auto;    /* រក្សាទម្រង់ (Ratio) ដើមជានិច្ច */
}
```
