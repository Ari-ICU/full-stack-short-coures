## 🌐 ស្វែងយល់ពី Asynchronous JavaScript

ជាធម្មតា JavaScript ដំណើរការកូដពីលើចុះក្រោមតាមលំដាប់លំដោយ (Synchronous)។ ប៉ុន្តែពេលខ្លះ យើងត្រូវធ្វើការងារដែលស៊ីពេលយូរ ដូចជាការទាញយកទិន្នន័យ (Data fetching) ពីម៉ាស៊ីនមេ (Server) ជាដើម។ ប្រសិនបើយើងរង់ចាំអោយវាទាញយកចប់ទើបធ្វើការងារផ្សេង គេហទំព័ររបស់យើងនឹងគាំង (Freeze)។

ដើម្បីដោះស្រាយបញ្ហានេះ យើងប្រើប្រាស់ **Asynchronous JavaScript** តាមរយៈ **Promises** ឬ **Async/Await**។

---

## 1. អ្វីទៅជា Promises?

**Promise** គឺជាការសន្យាមួយក្នុង JavaScript ថាវានឹងផ្តល់លទ្ធផលអោយអ្នកនៅពេលអនាគត។ វាមាន ៣ ស្ថានភាព៖
1. **Pending**: កំពុងរង់ចាំ (មិនទាន់សម្រេច)
2. **Fulfilled (Resolved)**: ជោគជ័យ (បានលទ្ធផល)
3. **Rejected**: បរាជ័យ (មានបញ្ហា ឬ Error)

---

## 2. ការប្រើប្រាស់ `async` និង `await`

នេះគឺជាវិធីសាស្រ្តថ្មី (Modern Way) និងងាយស្រួលបំផុតក្នុងការសរសេរកូដ Asynchronous ដោយមិនមានភាពស្មុគស្មាញច្រើន។

- `async`: ដាក់នៅពីមុខ Function ដើម្បីបញ្ជាក់ថា Function នោះនឹងត្រឡប់មកវិញនូវ Promise។
- `await`: ប្រើសម្រាប់រង់ចាំ Promise មួយអោយដំណើរការចប់ មុននឹងបន្តទៅបន្ទាត់បន្ទាប់។

```javascript
// បង្កើត Async Function
const getUserData = async () => {
  console.log("កំពុងទាញយកទិន្នន័យ...");
  
  // កូដផ្សេងៗដែលប្រើពេលយូរ នឹងប្រើ await នៅទីនេះ
  
  console.log("ទាញយកជោគជ័យ!");
};
```

## 3. ការទាញយកទិន្នន័យដោយប្រើ Fetch API

**Fetch API** គឺជាមុខងារស្រាប់របស់ Browser ដែលអនុញ្ញាតអោយយើងទាញយកទិន្នន័យពី URL ឬ API ណាមួយ។

**ឧទាហរណ៍៖ ទាញយកបញ្ជីឈ្មោះពី Fake API**
```javascript
const fetchUsers = async () => {
  try {
    // 1. ស្នើសុំទិន្នន័យពី API
    const response = await fetch("https://jsonplaceholder.typicode.com/users");
    
    // 2. បំប្លែងទិន្នន័យទៅជាទម្រង់ JSON
    const data = await response.json();
    
    // 3. បង្ហាញទិន្នន័យ
    console.log(data); // នឹងបង្ហាញ Array នៃ Users នៅក្នុង Console
  } catch (error) {
    // ចាប់យក Error ប្រសិនបើមានបញ្ហា (ឧទាហរណ៍៖ ដាច់អ៊ីនធឺណិត)
    console.error("មានបញ្ហាក្នុងការទាញយកទិន្នន័យ:", error);
  }
};

fetchUsers();
```

## 4. អនុវត្តជាក់ស្តែង៖ Fetch ទិន្នន័យ រួចបង្ហាញលើ DOM

នេះគឺជាឧទាហរណ៍ដ៏ពេញលេញមួយ ដែលរួមបញ្ចូលការ **Fetch API** (មេរៀនទី៦), **Array Methods** (`.map()`, មេរៀនទី៣), និង **DOM Update** (មេរៀនទី៥) បញ្ចូលគ្នា!

**HTML:**
```html
<button id="load-btn">ទាញយកអ្នកប្រើប្រាស់</button>
<ul id="user-list"></ul>
```

**JavaScript:**
```javascript
const btn = document.querySelector("#load-btn");
const userList = document.querySelector("#user-list");

// មុខងារសម្រាប់បង្ហាញទិន្នន័យលើអេក្រង់
const renderUsers = (users) => {
  // លុបអ្វីៗចាស់ចោលសិន
  userList.innerHTML = "";
  
  // ប្រើ .map() ដើម្បីឆ្លងកាត់ User ម្នាក់ៗ
  users.map(user => {
    const li = document.createElement("li"); // បង្កើត Node ថ្មី
    li.textContent = `${user.name} (${user.email})`; // បញ្ចូលខ្លឹមសារ
    userList.appendChild(li); // បន្ថែមចូលទៅក្នុង DOM
  });
};

// មុខងារសម្រាប់ Fetch ទិន្នន័យ
const handleFetch = async () => {
  btn.textContent = "កំពុងទាញយក...";
  
  try {
    const response = await fetch("https://jsonplaceholder.typicode.com/users");
    const data = await response.json();
    
    renderUsers(data); // យក Data ទៅបង្ហាញ
  } catch (error) {
    console.error("Error:", error);
  } finally {
    btn.textContent = "ទាញយកអ្នកប្រើប្រាស់"; // ប្តូរអក្សរប៊ូតុងមកដើមវិញ
  }
};

// បញ្ជាអោយប៊ូតុងដំណើរការ
btn.addEventListener("click", handleFetch);
```
