## ⚙️ ការអាប់ដេត DOM (Advanced DOM Updating)

នៅក្នុងមេរៀនមុន (DOM Manipulation) យើងបានរៀនពីរបៀប Select និងកែប្រែ Elements ដែលមានស្រាប់។ ឥឡូវនេះ យើងនឹងរៀនពីការ **បង្កើត (Create)**, **បន្ថែម (Append)**, និង **លុប (Remove)** Elements ថ្មីៗទៅក្នុង DOM តែម្តង! 

ការប្រើប្រាស់វិធីសាស្ត្រទាំងនេះជួយអោយគេហទំព័រមានលក្ខណៈ Dynamic ដោយមិនចាំបាច់ Reload ទំព័រ (ឧទាហរណ៍៖ ការបន្ថែម Comment ថ្មីទៅក្នុងបញ្ជី Comments)។

## 1. ការបង្កើត Elements ថ្មី (Creating Nodes)

អ្នកអាចបង្កើត HTML Element ថ្មីបានគ្រប់ប្រភេទ (ដូចជា `div`, `p`, `li`) ដោយប្រើ `document.createElement()`។ វានឹងបង្កើត Element នេះនៅក្នុង Memory ប៉ុន្តែមិនទាន់បង្ហាញនៅលើគេហទំព័រនៅឡើយទេ។

```javascript
// បង្កើត Element ថ្មី
const newParagraph = document.createElement("p");
const newButton = document.createElement("button");

// បន្ថែមខ្លឹមសារ (Content) និង Classes
newParagraph.textContent = "This is a dynamically created paragraph.";
newParagraph.classList.add("text-primary");

newButton.textContent = "Click Me";
newButton.className = "btn btn-success";
```

## 2. ការបន្ថែម Elements ចូលទៅក្នុង DOM (Appending Nodes)

បន្ទាប់ពីបង្កើតរួចរាល់ អ្នកត្រូវបញ្ជូនវាទៅបង្ហាញនៅលើគេហទំព័រ។ អ្នកត្រូវ Select ទីតាំងណាមួយ (Parent Node) ដើម្បីដាក់វាចូល។

**ប្រើប្រាស់ `appendChild()` (ដាក់នៅខាងចុងគេ):**
```javascript
const article = document.querySelector("#main-article");

// បន្ថែម newParagraph ទៅចុងបញ្ចប់នៃ #main-article
article.appendChild(newParagraph);
```

**ប្រើប្រាស់ `prepend()` (ដាក់នៅខាងដើមគេ):**
```javascript
const list = document.querySelector(".todo-list");
const newItem = document.createElement("li");
newItem.textContent = "Task 1";

// បន្ថែមនៅខាងដើមបញ្ជី (ខាងលើគេ)
list.prepend(newItem);
```

**ប្រើប្រាស់ `insertBefore()` (ដាក់នៅពីមុខ Element ណាមួយ):**
```javascript
const container = document.querySelector(".container");
const oldBox = document.querySelector(".box-2");
const newBox = document.createElement("div");

// បន្ថែម newBox ទៅពីមុខ oldBox នៅក្នុង container
container.insertBefore(newBox, oldBox);
```

## 3. ការលុប Elements (Removing Nodes)

ដើម្បីលុប Element ណាមួយចេញពី DOM យើងអាចប្រើ Method `remove()` (Modern Way) ឬ `removeChild()` (Old Way)។

**ប្រើប្រាស់ `remove()`:**
```javascript
const alertBox = document.querySelector(".alert");

// លុប Element នេះចេញពីទំព័រទាំងស្រុង
if (alertBox) {
  alertBox.remove();
}
```

**ប្រើប្រាស់ `removeChild()` (តម្រូវអោយ Select Parent សិន):**
```javascript
const ul = document.querySelector("ul");
const firstLi = ul.querySelector("li");

// លុប li ទីមួយចេញពី ul
ul.removeChild(firstLi);
```

---

## 4. ការជំនួស Elements (Replacing Nodes)

យើងក៏អាចជំនួស Element ចាស់ដោយ Element ថ្មីបានផងដែរ តាមរយៈ `replaceChild()`។

```javascript
const parent = document.querySelector("#content");
const oldHeader = document.querySelector("h2");

const newHeader = document.createElement("h1");
newHeader.textContent = "New Main Header";

// ជំនួស oldHeader ដោយ newHeader
parent.replaceChild(newHeader, oldHeader);
```
