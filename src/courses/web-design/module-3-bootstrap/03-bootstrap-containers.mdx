## 📦 អ្វីទៅជា Container?

នៅក្នុង Bootstrap, **Container** គឺជាធាតុផ្សំ (Element) ជាមូលដ្ឋានបំផុតសម្រាប់គ្រប់គ្រង Layout។ វាប្រៀបបាននឹង "ប្រអប់" មួយដែលប្រើសម្រាប់ផ្ទុក ដាក់អោយចំកណ្តាល (Center) និងផ្តល់គម្លាត (Padding) ទៅអោយមាតិការបស់អ្នក។

អ្នកមិនគួរសរសេរមាតិកាផ្ទាល់ទៅក្នុង `<body>` ទេ អ្នកត្រូវរុំវាជាមួយ Container ជានិច្ច។

---

## 1. `.container` (Fixed-width)

នេះគឺជាប្រភេទ Container ដែលពេញនិយមបំផុត។ វានឹងដាក់មាតិការបស់អ្នកអោយនៅចំកណ្តាលអេក្រង់ ហើយវានឹងកំណត់ទំហំអតិបរមា (Max-width) អាស្រ័យលើទំហំអេក្រង់ (Breakpoints) របស់អ្នកប្រើប្រាស់។ 
ឧទាហរណ៍៖ បើអេក្រង់កុំព្យូទ័រធំ វានឹងមិនលាតពេញទេ គឺវាទុកចន្លោះសងខាង។

```html
<div class="container text-center bg-light p-3">
  <h1>Fixed-width Container</h1>
  <p>មាតិកានៅទីនេះនឹងមិនលាតពេញអេក្រង់ធំៗទេ។</p>
</div>
```

---

## 2. `.container-fluid` (Full-width)

ផ្ទុយពី `.container` ធម្មតា, `.container-fluid` នឹងលាតសន្ធឹង **100% នៃទំហំអេក្រង់** ជានិច្ច មិនថាអ្នកប្រើប្រាស់កុំព្យូទ័រអេក្រង់ធំប៉ុណ្ណាក៏ដោយ។ គេច្រើនប្រើវាសម្រាប់បង្កើត របារខាងលើ (Navbar) ឬ ផ្ទាំងបាតកថា (Footer)។

```html
<div class="container-fluid bg-dark text-white p-3">
  <h1>Full-width Container</h1>
  <p>មាតិកានេះនឹងលាតសន្ធឹងពីចុងម្ខាងទៅចុងម្ខាង។</p>
</div>
```

## 3. Responsive Containers

ចុះបើអ្នកចង់អោយវាលាតពេញ (100%) នៅលើទូរស័ព្ទ តែនៅពេលបើកលើកុំព្យូទ័រចង់អោយវាមានចន្លោះសងខាងវិញ?
Bootstrap ក៏មានផ្តល់ជូននូវ **Responsive Containers** ដែលអនុញ្ញាតអោយអ្នកបញ្ជាក់ពីទំហំអេក្រង់ (Breakpoint) ដែលវាគួរចាប់ផ្តើមប្រើ Fixed-width។

*   **`.container-sm`**: 100% រហូតដល់អេក្រង់ `sm` (Small - 576px) ទើបមាន Fixed-width។
*   **`.container-md`**: 100% រហូតដល់អេក្រង់ `md` (Medium - 768px) ទើបមាន Fixed-width។
*   **`.container-lg`**: 100% រហូតដល់អេក្រង់ `lg` (Large - 992px) ទើបមាន Fixed-width។
*   **`.container-xl`**: 100% រហូតដល់អេក្រង់ `xl` (Extra Large - 1200px) ទើបមាន Fixed-width។
*   **`.container-xxl`**: 100% រហូតដល់អេក្រង់ `xxl` (Extra Extra Large - 1400px) ទើបមាន Fixed-width។

```html
<div class="container-md bg-warning p-3">
  <h1>Responsive Container (.container-md)</h1>
  <p>នៅលើទូរស័ព្ទតូចៗ វានឹងលាតពេញ 100%។ នៅលើ Tablet និងកុំព្យូទ័រ វានឹងមានចន្លោះសងខាង។</p>
</div>
```
