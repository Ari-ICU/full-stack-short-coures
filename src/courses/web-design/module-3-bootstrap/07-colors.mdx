## 🎨 ប្រព័ន្ធពណ៌របស់ Bootstrap (Theme Colors)

ជំនួសអោយការប្រើឈ្មោះពណ៌ផ្ទាល់ (ដូចជា ក្រហម ខៀវ លឿង) Bootstrap ប្រើប្រាស់ **ពាក្យដែលមានន័យ (Semantic names)** ដើម្បីដាក់ឈ្មោះអោយពណ៌របស់វា។ ការធ្វើបែបនេះជួយអោយរចនាបថមានភាពស៊ីសង្វាក់គ្នា (Consistency) ទូទាំងគេហទំព័រ។

*   **`primary`**: ពណ៌ចម្បង (ជាទូទៅពណ៌ខៀវ) តំណាងអោយសកម្មភាពសំខាន់ៗ។
*   **`secondary`**: ពណ៌បន្ទាប់បន្សំ (ជាទូទៅពណ៌ប្រផេះ)។
*   **`success`**: ជោគជ័យ (ពណ៌បៃតង)។
*   **`danger`**: គ្រោះថ្នាក់ ឬ លុប (ពណ៌ក្រហម)។
*   **`warning`**: ព្រមាន (ពណ៌លឿង)។
*   **`info`**: ផ្តល់ព័ត៌មាន (ពណ៌ខៀវខ្ចី)។
*   **`light`**: ពន្លឺ (ពណ៌សប្រផេះ) ប្រើសម្រាប់ផ្ទៃខាងក្រោយដែលភ្លឺ។
*   **`dark`**: ងងឹត (ពណ៌ខ្មៅប្រផេះ) ប្រើសម្រាប់អត្ថបទ ឬផ្ទៃខាងក្រោយងងឹត។
*   **`white`**: ពណ៌សសុទ្ធ (អត់មាន Background color white ទេ មានតែ `text-white`)។

## 1. ពណ៌អក្សរ (Text Colors)

ដើម្បីប្តូរពណ៌អក្សរ យើងគ្រាន់តែបន្ថែមពាក្យ `text-` នៅពីមុខឈ្មោះពណ៌។

```html
<p class="text-primary">អត្ថបទនេះមានពណ៌ខៀវ (Primary)</p>
<p class="text-success">ទិន្នន័យត្រូវបានរក្សាទុកដោយជោគជ័យ!</p>
<p class="text-danger">មានកំហុសសូមព្យាយាមម្តងទៀត!</p>
```

មាន Classes ពិសេសមួយចំនួនទៀតដូចជា៖
*   **`.text-muted`**: ពណ៌ប្រផេះស្រាល ប្រើសម្រាប់អត្ថបទបន្ទាប់បន្សំដែលមិនសូវសំខាន់។
*   **`.text-white`**: ពណ៌ស (ស័ក្តិសមបំផុតពេលដាក់លើ Background ងងឹត)។

---

## 2. ពណ៌ផ្ទៃខាងក្រោយ (Background Colors)

ដើម្បីប្តូរពណ៌ផ្ទៃខាងក្រោយ (Background) យើងប្រើពាក្យ `bg-`។

```html
<div class="bg-primary text-white p-3">
  ប្រអប់នេះមាន Background ពណ៌ខៀវ និងអក្សរពណ៌ស
</div>

<div class="bg-warning text-dark p-3 mt-2">
  ប្រអប់ព្រមានពណ៌លឿង
</div>
```

> 💡 **ចំណាំ៖** នៅពេលអ្នកប្រើប្រាស់ពណ៌ Background ងងឹត (`bg-primary`, `bg-danger`, `bg-dark`) កុំភ្លេចបន្ថែម Class `.text-white` ដើម្បីអោយអក្សរមើលឃើញច្បាស់!
