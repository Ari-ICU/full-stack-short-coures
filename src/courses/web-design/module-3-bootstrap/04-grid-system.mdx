## 📏 អ្វីទៅជា Grid System?

**Grid System** របស់ Bootstrap គឺជាប្រព័ន្ធមួយដែលអនុញ្ញាតអោយអ្នកបែងចែកគេហទំព័ររបស់អ្នកជាជួរឈរ (Columns) យ៉ាងងាយស្រួលដោយប្រើ Flexbox។ 

ក្បួនសំខាន់បំផុតដែលអ្នកត្រូវចាំគឺ៖ **១ ជួរដេក (`.row`) ត្រូវបានបែងចែកជា ១២ ជួរឈរតូចៗជានិច្ច!**

---

## 1. ការប្រើប្រាស់ Auto Columns (`.col`)

ប្រសិនបើអ្នកចង់អោយប្រអប់ចែករំលែកទំហំស្មើៗគ្នាដោយស្វ័យប្រវត្តិ អ្នកគ្រាន់តែប្រើ Class `.col` ជាការស្រេច។

```html
<div class="container">
  <div class="row">
    <div class="col bg-primary text-white p-3">ប្រអប់ទី ១</div>
    <div class="col bg-success text-white p-3">ប្រអប់ទី ២</div>
    <div class="col bg-danger text-white p-3">ប្រអប់ទី ៣</div>
  </div>
</div>
```
*(ក្នុងឧទាហរណ៍នេះ ដោយសារមាន ៣ ប្រអប់ ដូច្នេះប្រអប់នីមួយៗនឹងយកទំហំ ៤ ជួរឈរដោយស្វ័យប្រវត្តិ ព្រោះ 12 / 3 = 4)*

---

## 2. ការកំណត់ទំហំជាក់លាក់ (Specific Column Sizes)

អ្នកអាចបញ្ជាក់ថាតើប្រអប់មួយចង់យកប៉ុន្មានជួរឈរ ដោយប្រើលេខពី 1 ដល់ 12 (ឧ. `.col-6`, `.col-4`)។

```html
<div class="container">
  <div class="row">
    <!-- ប្រអប់នេះយកពាក់កណ្តាល (6/12) -->
    <div class="col-6 bg-info p-3">ពាក់កណ្តាល (col-6)</div>
    
    <!-- ប្រអប់នេះយក 1/3 (4/12) -->
    <div class="col-4 bg-warning p-3">មួយភាគបី (col-4)</div>
    
    <!-- ប្រអប់នេះយកទំហំដែលនៅសល់ (2/12) -->
    <div class="col-2 bg-dark text-white p-3">សល់ (col-2)</div>
  </div>
</div>
```

## 3. Responsive Columns

នេះគឺជាថាមពលពិតប្រាកដរបស់ Bootstrap! អ្នកអាចកំណត់អោយប្រអប់លាតពេញលើទូរស័ព្ទ តែចែកជាពីរនៅលើកុំព្យូទ័របាន។ យើងប្រើប្រាស់ Breakpoints (`sm`, `md`, `lg`, `xl`) បញ្ចូលជាមួយ `col`។

*   **`.col-12`**: លាត 100% ជានិច្ច (លើទូរស័ព្ទតូចបំផុត)។
*   **`.col-md-6`**: ចាប់ពីអេក្រង់ Medium (Tablet) ឡើងទៅ វាទើបយកទំហំ 50%។

```html
<div class="container">
  <div class="row">
    <!-- លើទូរស័ព្ទវាលាត 12, លើ Tablet វាលាត 6, លើ Laptop វាលាត 4 -->
    <div class="col-12 col-md-6 col-lg-4 p-3 bg-light border">
      ប្រអប់ Responsive
    </div>
    <div class="col-12 col-md-6 col-lg-4 p-3 bg-light border">
      ប្រអប់ Responsive
    </div>
    <div class="col-12 col-md-6 col-lg-4 p-3 bg-light border">
      ប្រអប់ Responsive
    </div>
  </div>
</div>
```

## 4. Offsets (ការរុញប្រអប់ចោលចន្លោះ)

ប្រសិនបើអ្នកចង់រុញប្រអប់អោយទៅខាងស្តាំ ដោយទុកចន្លោះប្រហោងនៅខាងឆ្វេង អ្នកអាចប្រើ `.offset-*`។

```html
<div class="container">
  <div class="row">
    <!-- ប្រអប់ទំហំ 6 ហើយរុញចេញពីឆ្វេង 3 ល្វែង (ធ្វើអោយវានៅចំកណ្តាលព្រោះ 3+6+3=12) -->
    <div class="col-md-6 offset-md-3 bg-success text-white p-3">
      ខ្ញុំនៅចំកណ្តាល!
    </div>
  </div>
</div>
```

## 5. Nested Grids (Grid កូនកាត់ Grid)

អ្នកអាចបង្កើត `.row` ថ្មីមួយទៀតនៅខាងក្នុង `.col` ណាមួយក៏បាន! `.row` ថ្មីនោះនឹងមាន 12 ជួរឈរថ្មីរបស់វាផ្ទាល់។

```html
<div class="container">
  <div class="row">
    <div class="col-8 bg-light p-3">
      ផ្នែកខាងឆ្វេង (8)
      
      <!-- Nested Row បង្កើត 12 ជួរថ្មីនៅខាងក្នុងនេះ -->
      <div class="row mt-3">
        <div class="col-6 bg-info p-2">កូនទី ១</div>
        <div class="col-6 bg-warning p-2">កូនទី ២</div>
      </div>
      
    </div>
    
    <div class="col-4 bg-secondary text-white p-3">
      Sidebar ខាងស្តាំ (4)
    </div>
  </div>
</div>
```
