## 🎠 ផ្ទាំងរូបភាពរំកិល (Carousel)

**Carousel** (អានថា ការ៉ូសែល) គឺជា Slideshow សម្រាប់បង្ហាញរូបភាពវិលចុះវិលឡើង។ គេតែងតែប្រើប្រាស់វានៅផ្នែកខាងលើបង្អស់នៃគេហទំព័រ (Hero section) ដើម្បីបង្ហាញផ្ទាំងផ្សព្វផ្សាយធំៗ។

ដើម្បីប្រើវា អ្នកត្រូវការ JavaScript របស់ Bootstrap ដែលមានភ្ជាប់រួចជាស្រេច (Bundle)។

---

## 1. រចនាសម្ព័ន្ធ Carousel ពេញលេញ

Carousel មួយដែលមានលក្ខណៈពេញលេញ ປະກອບមាន ៣ ផ្នែកសំខាន់ៗ៖
1.  **Indicators**: ចំនុចតូចៗខាងក្រោមសម្រាប់បញ្ជាក់ថាអ្នកកំពុងមើលរូបទីប៉ុន្មាន។
2.  **Inner/Items**: រូបភាពនីមួយៗ និងអត្ថបទពីលើរូបភាព (Captions)។
3.  **Controls**: ប៊ូតុងសញ្ញាព្រួញ ឆ្វេង និងស្តាំ សម្រាប់ចុចរំកិល។

```html
<!-- ID របស់ប្រអប់នេះគឺ carouselExample វានឹងត្រូវប្រើនៅ Controls និង Indicators -->
<div id="carouselExample" class="carousel slide" data-bs-ride="carousel">
  
  <!-- 1. សញ្ញាបញ្ជាក់ទីតាំង (Indicators) -->
  <div class="carousel-indicators">
    <button type="button" data-bs-target="#carouselExample" data-bs-slide-to="0" class="active" aria-current="true" aria-label="Slide 1"></button>
    <button type="button" data-bs-target="#carouselExample" data-bs-slide-to="1" aria-label="Slide 2"></button>
    <button type="button" data-bs-target="#carouselExample" data-bs-slide-to="2" aria-label="Slide 3"></button>
  </div>

  <!-- 2. រូបភាពនីមួយៗ (Items) -->
  <div class="carousel-inner">
    <!-- Item ទី ១ ត្រូវតែមាន class active -->
    <div class="carousel-item active">
      <img src="https://via.placeholder.com/800x400?text=Slide+1" class="d-block w-100" alt="Slide 1">
      <!-- អត្ថបទពីលើរូបភាព (Caption) -->
      <div class="carousel-caption d-none d-md-block">
        <h5>ចំណងជើងរូបភាពទី ១</h5>
        <p>ពិពណ៌នារូបភាពទី ១</p>
      </div>
    </div>
    
    <!-- Item ទី ២ -->
    <div class="carousel-item">
      <img src="https://via.placeholder.com/800x400?text=Slide+2" class="d-block w-100" alt="Slide 2">
    </div>
    
    <!-- Item ទី ៣ -->
    <div class="carousel-item">
      <img src="https://via.placeholder.com/800x400?text=Slide+3" class="d-block w-100" alt="Slide 3">
    </div>
  </div>

  <!-- 3. ប៊ូតុងបញ្ជាឆ្វេងស្តាំ (Controls) -->
  <button class="carousel-control-prev" type="button" data-bs-target="#carouselExample" data-bs-slide="prev">
    <span class="carousel-control-prev-icon" aria-hidden="true"></span>
    <span class="visually-hidden">Previous</span>
  </button>
  <button class="carousel-control-next" type="button" data-bs-target="#carouselExample" data-bs-slide="next">
    <span class="carousel-control-next-icon" aria-hidden="true"></span>
    <span class="visually-hidden">Next</span>
  </button>
  
</div>
```

## 2. រំកិលដោយស្វ័យប្រវត្តិ (Auto-sliding)

ប្រសិនបើអ្នកចង់អោយវារំកិលខ្លួនឯងដោយមិនចាំបាច់មានអ្នកចុច អ្នកគ្រាន់តែប្រាកដថាអ្នកបានបន្ថែម `data-bs-ride="carousel"` ទៅលើ `<div class="carousel">`។ 

ដើម្បីផ្លាស់ប្តូរល្បឿនរំកិល (ឧទាហរណ៍៖ អោយនៅយូរបន្តិចមុនរំកិលទៅរូបបន្ទាប់) អ្នកអាចកំណត់ `data-bs-interval` (គិតជាមិល្លីវិនាទី - 1000 = 1 វិនាទី) ទៅលើ `.carousel-item` នីមួយៗបាន។

```html
<div class="carousel-item active" data-bs-interval="10000">
  <!-- រូបទី ១ នេះនឹងរង់ចាំដល់ ១០ វិនាទីទើបរំកិលបាត់ -->
  <img src="..." class="d-block w-100" alt="...">
</div>
<div class="carousel-item" data-bs-interval="2000">
  <!-- រូបទី ២ នេះរង់ចាំត្រឹម ២ វិនាទីទេ -->
  <img src="..." class="d-block w-100" alt="...">
</div>
```

## 3. ចលនារលាយបាត់ (Fade Transition)

ជាធម្មតា Carousel នឹងប្រើចលនារុញចូល (Slide)។ បើអ្នកចង់អោយវាមានចលនារលាយបាត់យឺតៗ (Fade) ជំនួសវិញ គ្រាន់តែបន្ថែម Class `.carousel-fade` នៅជាប់ `.carousel` គឺរួចរាល់!

```html
<div id="carouselExampleFade" class="carousel slide carousel-fade" data-bs-ride="carousel">
  <!-- ... -->
</div>
```
