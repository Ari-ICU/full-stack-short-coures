## 🔀 ការគ្រប់គ្រង Flexbox

Bootstrap បានផ្តល់នូវ Classes ជាច្រើនដែលធ្វើការផ្ទាល់ជាមួយ CSS Flexbox។ វាអនុញ្ញាតអោយអ្នករៀបចំ Layout យ៉ាងរហ័សដោយមិនចាំបាច់សរសេរ CSS ខ្លួនឯងសូម្បីតែមួយជួរ!

---

## 1. បើកមុខងារ Flexbox

ដើម្បីចាប់ផ្តើមប្រើប្រាស់ Flexbox អ្នកត្រូវតែបន្ថែម Class `.d-flex` ទៅលើ Element ធំ (Parent)។

```html
<div class="d-flex p-3 bg-light">
  <div class="p-2 bg-primary text-white">កូនទី ១</div>
  <div class="p-2 bg-success text-white">កូនទី ២</div>
</div>
```

---

## 2. ទិសដៅ (Direction)

តើអ្នកចង់តម្រៀបវាតាមជួរដេក ឬជួរឈរ?
*   **`.flex-row`**: ជាលំនាំដើម តម្រៀបពីឆ្វេងទៅស្តាំ (ជួរដេក)។
*   **`.flex-column`**: តម្រៀបពីលើចុះក្រោម (ជួរឈរ)។

```html
<div class="d-flex flex-column mb-3">
  <div class="p-2 bg-info">លើគេ</div>
  <div class="p-2 bg-warning">កណ្តាល</div>
  <div class="p-2 bg-danger text-white">ក្រោមគេ</div>
</div>
```

---

## 3. ការតម្រៀបទីតាំង (Justify & Align)

នេះគឺជាផ្នែកដ៏សំខាន់បំផុតរបស់ Flexbox!

**តម្រៀបតាមបណ្តោយ (Main Axis - Justify Content):**
*   `.justify-content-start`: ផ្តុំនៅខាងឆ្វេង (ដើម)
*   `.justify-content-center`: ផ្តុំនៅចំកណ្តាល
*   `.justify-content-end`: ផ្តុំនៅខាងស្តាំ (ចុង)
*   `.justify-content-between`: រុញដាច់សងខាង ទុកចន្លោះកណ្តាល

**តម្រៀបតាមទទឹង (Cross Axis - Align Items):**
*   `.align-items-start`: ផ្តុំនៅខាងលើ
*   `.align-items-center`: ផ្តុំនៅចំកណ្តាលកម្ពស់
*   `.align-items-end`: ផ្តុំនៅខាងក្រោម

```html
<!-- តម្រៀបអោយនៅចំកណ្តាលទាំងស្រុង (ទាំងដេក និងឈរ) -->
<div class="d-flex justify-content-center align-items-center bg-dark" style="height: 200px;">
  <div class="p-3 bg-light">ខ្ញុំនៅចំកណ្តាលផ្ទៃ!</div>
</div>
```

## 4. ការផ្តល់គម្លាត (Gap)

ជំនួសអោយការប្រើ Margin ញ៉ាំញ៉ៃ អ្នកអាចប្រើប្រាស់ `.gap-*` (ពី 0 ដល់ 5) នៅលើ `d-flex` ដើម្បីបង្កើតគម្លាតស្មើៗគ្នារវាងកូនៗទាំងអស់របស់វា។

```html
<div class="d-flex gap-3">
  <button class="btn btn-primary">ប៊ូតុង ១</button>
  <button class="btn btn-primary">ប៊ូតុង ២</button>
  <button class="btn btn-primary">ប៊ូតុង ៣</button>
</div>
```
*(ប៊ូតុងទាំង ៣ នេះនឹងមានចន្លោះឃ្លាតគ្នាស្មើៗគ្នា!)*

---

## 5. ការបត់ចុះបន្ទាត់ (Wrap)

បើកូនៗវាមានច្រើនពេក ហើយចង្អៀតតើគួរធ្វើយ៉ាងណា? ប្រើ `.flex-wrap` ដើម្បីអនុញ្ញាតអោយវាធ្លាក់ចុះមកបន្ទាត់ថ្មី!

```html
<div class="d-flex flex-wrap">
  <!-- បើមានប្រអប់ច្រើន វានឹងធ្លាក់ចុះមកក្រោមដោយស្វ័យប្រវត្តិ -->
</div>
```
