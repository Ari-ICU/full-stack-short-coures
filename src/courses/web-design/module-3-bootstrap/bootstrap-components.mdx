## 🧩 អ្វីទៅជា Bootstrap Components?

Components គឺជាកញ្ចប់ UI ដែល Bootstrap បានរចនាទុកជាស្រេចយ៉ាងស្រស់ស្អាត។ អ្នកគ្រាន់តែចម្លងកូដ HTML របស់ពួកគេមកប្រើប្រាស់ដោយផ្ទាល់ រួចកែប្រែទិន្នន័យ (Text/Image) ទៅតាមតម្រូវការជាការស្រេច។

---

## 1. របារបញ្ជា (Navbar)

Navbar គឺជាផ្នែកដ៏សំខាន់បំផុតសម្រាប់ Website រាល់លើក។ Bootstrap ផ្តល់ជូន Navbar ដែលមានភាព Responsive ដោយស្វ័យប្រវត្តិ (អាចបត់បែនជាទម្រង់ Hamburger Menu នៅលើទូរស័ព្ទដៃ)។

```html
<nav class="navbar navbar-expand-lg navbar-light bg-light">
  <div class="container-fluid">
    <a class="navbar-brand" href="#">ឡូហ្គូ (Logo)</a>
    
    <!-- ប៊ូតុង Hamburger សម្រាប់ Mobile -->
    <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#navbarNav">
      <span class="navbar-toggler-icon"></span>
    </button>
    
    <!-- ផ្នែក Menu សម្រាប់ចុច -->
    <div class="collapse navbar-collapse" id="navbarNav">
      <ul class="navbar-nav">
        <li class="nav-item">
          <a class="nav-link active" href="#">ទំព័រដើម</a>
        </li>
        <li class="nav-item">
          <a class="nav-link" href="#">សេវាកម្ម</a>
        </li>
      </ul>
    </div>
  </div>
</nav>
```
*(បញ្ជាក់៖ អ្នកត្រូវតែភ្ជាប់ Bootstrap JS (Script) នៅផ្នែកខាងក្រោមនៃ HTML ទើប Hamburger Menu នេះអាចដំណើរការចុចបញ្ចេញបិទបាន!)*

## 2. កាត (Cards)

Cards ពេញនិយមបំផុតសម្រាប់ការបង្ហាញ ផលិតផល អត្ថបទ Blog ឬព័ត៌មានសង្ខេបនានា។

```html
<div class="card" style="width: 18rem;">
  <img src="https://via.placeholder.com/300x200" class="card-img-top" alt="Product Image">
  <div class="card-body">
    <h5 class="card-title">ឈ្មោះផលិតផល</h5>
    <p class="card-text">ការពណ៌នាខ្លីៗពីផលិតផលនេះ។ វាពិតជាស្រស់ស្អាតនិងមានគុណភាព។</p>
    <a href="#" class="btn btn-primary">ទិញឥឡូវនេះ</a>
  </div>
</div>
```

## 3. ទម្រង់បញ្ញូលទិន្នន័យ (Forms)

Bootstrap ជួយអោយ Input នានាមើលទៅមានរបៀបរៀបរយ និងស្រស់ស្អាតតាមរយៈ Class `.form-control`។

```html
<form>
  <div class="mb-3">
    <label for="emailInput" class="form-label">អាសយដ្ឋាន Email</label>
    <input type="email" class="form-control" id="emailInput" placeholder="name@example.com">
  </div>
  
  <div class="mb-3">
    <label for="passwordInput" class="form-label">ពាក្យសម្ងាត់ (Password)</label>
    <input type="password" class="form-control" id="passwordInput">
  </div>
  
  <button type="submit" class="btn btn-primary">ចូលគណនី</button>
</form>
```

## 4. ផ្ទាំងលោត (Modal)

Modal គឺជាផ្ទាំង Popup ដែលលោតឡើងមកនៅចំកណ្តាលអេក្រង់ សម្រាប់សួរការបញ្ជាក់ ឬបង្ហាញព័ត៌មានលម្អិត ដោយមិនចាំបាច់ចូលទៅកាន់ទំព័រថ្មី។

```html
<!-- ប៊ូតុងដើម្បីបើក Modal នេះ -->
<button type="button" class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#myModal">
  បើកផ្ទាំងបញ្ជាក់
</button>

<!-- ផ្ទៃរបស់ Modal -->
<div class="modal fade" id="myModal" tabindex="-1">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">ការបញ្ជាក់</h5>
        <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
      </div>
      <div class="modal-body">
        <p>តើអ្នកពិតជាចង់លុបទិន្នន័យនេះមែនទេ?</p>
      </div>
      <div class="modal-footer">
        <button type="button" class="btn btn-secondary" data-bs-dismiss="modal">បោះបង់</button>
        <button type="button" class="btn btn-danger">យល់ព្រមលុប</button>
      </div>
    </div>
  </div>
</div>
```

## 5. សារព្រមាន (Alerts)

Alerts ប្រើសម្រាប់ផ្តល់សារជូនដំណឹងដល់អ្នកប្រើប្រាស់ ដូចជាពេលពួកគេ Login ជោគជ័យ ឬមានបញ្ហាអ្វីមួយកើតឡើង។

```html
<!-- ជោគជ័យ (ពណ៌បៃតង) -->
<div class="alert alert-success" role="alert">
  ការបញ្ចូលទិន្នន័យទទួលបានជោគជ័យ!
</div>

<!-- បរាជ័យ (ពណ៌ក្រហម) -->
<div class="alert alert-danger" role="alert">
  សូមអភ័យទោស! ពាក្យសម្ងាត់របស់អ្នកមិនត្រឹមត្រូវទេ។
</div>
```

## 6. តារាង (Tables)

គ្រាន់តែបន្ថែម Class ពីរបីពាក្យ អ្នកនឹងទទួលបានតារាងដ៏ស្រស់ស្អាត៖
- `.table`: Class គោល
- `.table-striped`: ពណ៌ផ្ទៃឆ្លាស់គ្នា
- `.table-bordered`: មានគែម (Border) ជុំវិញ
- `.table-hover`: ពេលយក Mouse ដាក់ពីលើ វាភ្លឺបន្តិច

```html
<table class="table table-striped table-hover">
  <thead>
    <tr>
      <th>ល.រ</th>
      <th>ឈ្មោះ</th>
      <th>មុខតំណែង</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>១</td>
      <td>សន សុវណ្ណ</td>
      <td>អ្នកអភិវឌ្ឍន៍</td>
    </tr>
    <tr>
      <td>២</td>
      <td>កែវ ធីតា</td>
      <td>អ្នករចនា</td>
    </tr>
  </tbody>
</table>
```
