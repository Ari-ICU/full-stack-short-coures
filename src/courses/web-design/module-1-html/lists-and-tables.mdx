## 📝 ការបង្កើត Lists (បញ្ជី)

មានបញ្ជី ២ ប្រភេទសំខាន់ៗដែលយើងតែងតែប្រើប្រាស់៖ Unordered List (`<ul>` - ចុចចំណុច) និង Ordered List (`<ol>` - លេខរៀង)។ 

ធាតុនីមួយៗក្នុងបញ្ជីត្រូវរុំដោយ `<li>` (List Item) ជានិច្ច។

```html
<!-- បញ្ជីគ្មានលេខរៀង (ចំណុចត្រេ) -->
<ul>
    <li>ផ្លែប៉ោម</li>
    <li>ផ្លែចេក</li>
    <li>ផ្លែក្រូច</li>
</ul>

<!-- បញ្ជីមានលេខរៀង (១, ២, ៣) -->
<ol>
    <li>ក្រោកពីគេង</li>
    <li>ដុសធ្មេញ</li>
    <li>ញ៉ាំអាហារពេលព្រឹក</li>
</ol>
```

## 📊 ការរៀបចំទិន្នន័យជា Tables (តារាង)

ការបង្កើតតារាងទាមទារការរួមបញ្ចូលគ្នានូវ Tags ជាច្រើន។ រចនាសម្ព័ន្ធជាមូលដ្ឋានមានដូចជា៖
- `<table>`: តំណាងឱ្យតារាងទាំងមូល
- `<tr>` (Table Row): តំណាងឱ្យជួរដេក
- `<th>` (Table Header): តំណាងឱ្យក្បាលតារាង (អក្សរដិត និងនៅកណ្តាល)
- `<td>` (Table Data): តំណាងឱ្យប្រអប់ទិន្នន័យធម្មតា

```html
<table border="1">
    <!-- ជួរដេកទី ១: សម្រាប់ក្បាលតារាង -->
    <tr>
        <th>ឈ្មោះ</th>
        <th>អាយុ</th>
        <th>មុខរបរ</th>
    </tr>
    <!-- ជួរដេកទី ២: សម្រាប់ទិន្នន័យអ្នកទី ១ -->
    <tr>
        <td>សុខ</td>
        <td>២៥</td>
        <td>Web Developer</td>
    </tr>
    <!-- ជួរដេកទី ៣: សម្រាប់ទិន្នន័យអ្នកទី ២ -->
    <tr>
        <td>សៅ</td>
        <td>៣០</td>
        <td>Graphic Designer</td>
    </tr>
</table>
```

*(ចំណាំ៖ ការប្រើប្រាស់ Attribute `border="1"` គឺគ្រាន់តែដើម្បីឱ្យងាយស្រួលមើលបន្ទាត់តារាងបណ្តោះអាសន្នប៉ុណ្ណោះ។ ក្នុងការអនុវត្តជាក់ស្តែង យើងប្រើប្រាស់ CSS ដើម្បីរចនាបន្ទាត់តារាង)*។
