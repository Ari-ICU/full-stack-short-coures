## 🚀 អ្វីទៅជា HTML5 APIs?

HTML5 មិនមែនមានត្រឹមតែ Tags ថ្មីៗសម្រាប់សរសេរកូដនោះទេ វាថែមទាំងបាននាំមកនូវ **APIs (Application Programming Interfaces)** ដ៏មានអានុភាពជាច្រើន។ APIs ទាំងនេះអនុញ្ញាតឱ្យអ្នកអភិវឌ្ឍន៍ប្រើប្រាស់កូដ JavaScript ដើម្បីភ្ជាប់ទៅកាន់មុខងារពិសេសៗរបស់ Browser ឬសូម្បីតែផ្នែករឹង (Hardware) របស់ឧបករណ៍អ្នកប្រើប្រាស់ដោយផ្ទាល់!

នៅក្នុងមេរៀននេះ យើងនឹងគ្រាន់តែស្វែងយល់ **ត្រួសៗ (Overview)** អំពី APIs សំខាន់ៗចំនួន ៣ ប៉ុណ្ណោះ។ អ្នកនឹងបានរៀនពីរបៀបសរសេរកូដប្រើវាផ្ទាល់នៅក្នុងម៉ូឌុល JavaScript ជាន់ខ្ពស់។

## 📍 1. Geolocation API

តើអ្នកធ្លាប់ចូល Website មួយ ហើយវាលោតសួរថា "Website នេះចង់ដឹងពីទីតាំងរបស់អ្នក" ដែរឬទេ? នោះហើយគឺជាការប្រើប្រាស់ Geolocation API!

*   **តើវាធ្វើអ្វី?** វាអនុញ្ញាតឱ្យ Website ដឹងពីទីតាំងបច្ចុប្បន្នរបស់អ្នកប្រើប្រាស់ (រយៈទទឹង និងរយៈបណ្តោយ - Latitude & Longitude)។
*   **សុវត្ថិភាពជាចម្បង៖** Browser នឹង **តែងតែ** ស្នើសុំការអនុញ្ញាតពីអ្នកប្រើប្រាស់ជាមុនសិន។ វាអាចដំណើរការបានតែនៅលើ Website ដែលមានសុវត្ថិភាព (HTTPS) ប៉ុណ្ណោះ។
*   **ការប្រើប្រាស់ជាក់ស្តែង៖** ប្រើសម្រាប់បង្ហាញហាងដែលនៅជិតអ្នកបំផុត, រក្សាកំណត់ត្រាទីតាំងសម្រាប់សេវាកម្មដឹកជញ្ជូន (Delivery), ឬដាក់ Pin លើផែនទីអូតូ។

## 💾 2. Web Storage API

ពីមុន បើយើងចង់រក្សាទុកទិន្នន័យអតិថិជននៅលើ Browser (ឧទាហរណ៍ ទិន្នន័យថាគាត់បាន Login ហើយ) យើងត្រូវប្រើ **Cookies** ដែលវាមានទំហំតូច និងយឺត។ ឥឡូវនេះយើងមាន Web Storage!

វាចែកចេញជាពីរប្រភេទធំៗ៖
1.  **Local Storage៖** រក្សាទុកទិន្នន័យរហូត! ទិន្នន័យមិនបាត់ទេទោះបីជាអ្នកប្រើប្រាស់បិទ Browser ឬបិទកុំព្យូទ័រក៏ដោយ (លុះត្រាតែគាត់ចុចលុបវាដោយខ្លួនឯង)។ ឧទាហរណ៍៖ រក្សាទុកការកំណត់ពណ៌ Theme (Dark/Light mode) របស់ Website។
2.  **Session Storage៖** រក្សាទុកទិន្នន័យតែក្នុងពេលបច្ចុប្បន្ន។ ទិន្នន័យនឹងត្រូវលុបចោលវិញភ្លាមៗ នៅពេលដែលអ្នកប្រើប្រាស់បិទ Tab នោះ។

*លក្ខណៈពិសេសរបស់វា គឺអាចផ្ទុកទិន្នន័យបានច្រើនជាង Cookies (ដល់ទៅ 5MB) និងមានសុវត្ថិភាពជាងមុន។*

## 🖐️ 3. Drag and Drop API

តើអ្នកធ្លាប់ទាញយករូបភាពពីកុំព្យូទ័ររបស់អ្នក យកទៅទម្លាក់ចូលក្នុង Facebook ដើម្បី Upload ដែរឬទេ? នេះគឺជាមុខងារ Drag and Drop!

*   **តើវាធ្វើអ្វី?** HTML5 ធ្វើឱ្យធាតុស្ទើរតែទាំងអស់ (រូបភាព, អត្ថបទ, ប្រអប់ div) អាចចាប់ទាញ (Drag) យកទៅទម្លាក់ (Drop) នៅទីតាំងមួយផ្សេងទៀតនៅលើ Website បាន។
*   **អន្តរកម្ម៖** អ្នកអាចសរសេរកូដ JavaScript ដើម្បីកំណត់ថាតើនឹងមានអ្វីកើតឡើង ពេលអ្នកប្រើទម្លាក់របស់ចូលក្នុងប្រអប់នោះ (ឧទាហរណ៍៖ បញ្ជូនវាទៅ Server ឬក៏ប្តូរពណ៌វាជាដើម)។

នេះគ្រាន់តែជាការចាប់ផ្តើមប៉ុណ្ណោះ! HTML5 នៅមាន APIs ឡូយៗជាច្រើនទៀត ដូចជា Canvas (សម្រាប់គូររូប និងធ្វើហ្គេម 2D), Web Workers (សម្រាប់ឱ្យកូដរត់លាក់ខ្លួនដោយមិនធ្វើឱ្យកុំព្យូទ័រគាំង), ជាដើម។ អ្នកនឹងជួបពួកវានៅពេលក្រោយ!
