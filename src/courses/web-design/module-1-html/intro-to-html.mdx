## 🌐 ឆ្អឹងខ្នងនៃ Web

រាល់គេហទំព័រដែលអ្នកចូលមើល ពី Google ដល់ Netflix គឺត្រូវបានបង្កើតឡើងនៅលើ **HTML (Hyper Text Markup Language)**។

HTML មិនមែនជាភាសាសរសេរកូដ (programming language) ទេ; វាគឺជា **markup language**។ វាប្រាប់កម្មវិធីរុករក (browser) ពីរបៀបរៀបចំ និងបង្ហាញមាតិកា។

### តើ HTML ធ្វើអ្វីខ្លះ?

HTML គ្រប់គ្រងផ្នែកទាំងនេះនៃគេហទំព័រ៖
- **រចនាសម្ព័ន្ធ (Structure)**: ការរៀបចំមាតិកាជា headings, paragraphs, lists
- **មាតិកា (Content)**: អត្ថបទ, រូបភាព, វីដេអូ, តំណភ្ជាប់
- **អត្ថន័យ (Semantics)**: ប្រាប់ browser ថាមាតិកានីមួយៗ *គឺជាអ្វី* (navigation, article, footer)

ចូរគិតពីការសាងសង់ផ្ទះមួយ៖
- **HTML** គឺជារចនាសម្ព័ន្ធ (ជញ្ជាំង, កម្រាល, បន្ទប់)។
- **CSS** គឺជាការរចនាផ្ទៃខាងក្នុង (ពណ៌ថ្នាំលាប, ម៉ូដគ្រឿងសង្ហារឹម)។
- **JavaScript** គឺជាអគ្គិសនី និងប្រព័ន្ធទឹក (ធ្វើឱ្យអ្វីៗដំណើរការ)។

### ប្រវត្តិខ្លីៗ

HTML ត្រូវបានបង្កើតឡើងដោយ **Tim Berners-Lee** នៅឆ្នាំ 1991។ ដំបូងវាមាន tags ចំនួន 18 តែប៉ុណ្ណោះ! សព្វថ្ងៃ HTML5 គឺជា version ចុងក្រោយបង្អស់ ដែលមាន tags ជាង 100។

## 🏗️ រចនាសម្ព័ន្ធនៃឯកសារ HTML

រាល់ទំព័រ HTML ទាំងអស់ត្រូវធ្វើតាមរចនាសម្ព័ន្ធស្តង់ដារមួយ។ តោះមើលឧទាហរណ៍ជាមូលដ្ឋាន៖

```html
<!DOCTYPE html>
<html lang="km">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="គេហទំព័រដំបូងរបស់ខ្ញុំ">
    <title>My First Website</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <header>
        <h1>សូមស្វាគមន៍មកកាន់ Full Stack Mastery!</h1>
        <nav>
            <a href="#about">អំពីខ្ញុំ</a>
            <a href="#contact">ទំនាក់ទំនង</a>
        </nav>
    </header>
    <main>
        <p>នេះគឺជាកថាខណ្ឌ (paragraph) នៃអត្ថបទ។</p>
    </main>
    <footer>
        <p>&copy; 2024 My Website</p>
    </footer>
</body>
</html>
```

### 🔍 ការពន្យល់ពីកូដ (Tags គោល)៖

#### 1. `<!DOCTYPE html>` (The Document Type Declaration)
ទោះបីជាវាមិនមែនជា HTML tag ក៏ដោយ វាគឺជាបន្ទាត់ទីមួយដែលត្រូវតែមានក្នុងឯកសាររបស់អ្នក។
* **មុខងារ:** វាប្រាប់ browser ថាទំព័រនេះត្រូវបានសរសេរជា HTML ជំនាន់ណា។ `<!DOCTYPE html>` បញ្ជាក់ថា "នេះគឺជាឯកសារ HTML5 ទំនើប"។
* **សារៈសំខាន់:** បើគ្មានវាទេ browser ចាស់ៗអាចនឹងបង្ហាញទំព័ររបស់អ្នកខុសប្រក្រតី។

#### 2. `<html>` (The Root Element)
នេះគឺជាកន្លែងផ្ទុកធំបំផុតសម្រាប់រាល់អ្វីៗទាំងអស់នៅលើគេហទំព័រ។ រាល់ HTML tag ផ្សេងទៀតត្រូវតែស្ថិតនៅក្នុង tag នេះ។
* **មុខងារ:** វាកំណត់ព្រំដែននៃឯកសារ HTML។
* **`lang` attribute:** អ្នកគួរតែដាក់ `lang` attribute ជានិច្ច (ឧ. `<html lang="km">` សម្រាប់ភាសាខ្មែរ, `lang="en"` សម្រាប់អង់គ្លេស)។ នេះជួយដល់ accessibility (ឧបករណ៍អានអេក្រង់) និង SEO ឱ្យដឹងពីភាសារបស់ទំព័រ។

#### 3. `<head>` (The Metadata Container)
Tag នេះផ្ទុកព័ត៌មាន "នៅពីក្រោយឆាក" អំពីឯកសារ។ គ្មានអ្វីនៅក្នុង `<head>` អាចមើលឃើញដោយផ្ទាល់នៅលើគេហទំព័រនោះទេ (លើកលែងតែ `<title>` ដែលបង្ហាញនៅលើ browser tab)។
* **មុខងារ:** វាផ្ទុកការណែនាំសម្រាប់ browser និង search engines រួមមាន ចំណងជើង, links ទៅកាន់ CSS, links ទៅកាន់ JavaScript, និង meta tags។

#### 4. `<meta>` (Metadata Tags)
មានទីតាំងនៅក្នុង `<head>`, tags ទាំងនេះផ្តល់ទិន្នន័យជាក់លាក់អំពីឯកសារ HTML។ ពួកវាគឺជា self-closing tags (មិនមាន closing tag `</meta>` ទេ)។
* **មុខងារ:** ផ្តល់ការណែនាំសំខាន់ៗដល់ browser។
* **ឧទាហរណ៍សំខាន់ៗ:**
  * `<meta charset="UTF-8">`: **សំខាន់ណាស់!** វាប្រាប់ browser ឱ្យប្រើ UTF-8 character encoding ដែលអាចអានបានគ្រប់ភាសា រួមទាំងអក្សរខ្មែរ។ បើគ្មានវាទេ អក្សរខ្មែរអាចនឹងលោតជាសញ្ញាសួរឬអក្សរញ៉េញ៉ៃ។
  * `<meta name="viewport" content="width=device-width, initial-scale=1.0">`: **សំខាន់សម្រាប់ទូរស័ព្ទ។** វាប្រាប់ browser ឱ្យតម្រូវទំហំទំព័រទៅតាមទំហំអេក្រង់ទូរស័ព្ទ ជៀសវាងការបង្ហាញទំព័រ Desktop តូចៗនៅលើទូរស័ព្ទ។

#### 5. `<body>` (The Visible Content)
នេះគឺជាកន្លែងផ្ទុកសម្រាប់រាល់មាតិកាដែលអ្នកចង់ឱ្យអ្នកប្រើប្រាស់មើលឃើញ និងទាក់ទងជាមួយ។
* **មុខងារ:** អ្វីៗដែលមើលឃើញនៅលើទំព័រ—headings, paragraphs, រូបភាព, ប៊ូតុង, links—សុទ្ធតែស្ថិតនៅក្នុង `<body>`។ ឯកសារ HTML មួយមាន `<body>` តែមួយគត់។

#### Tags ផ្សេងទៀតនៅក្នុងទំព័រ៖
* `<header>`: ផ្នែកខាងលើនៃទំព័រ។
* `<main>`: មាតិកាសំខាន់ៗ។
* `<footer>`: ផ្នែកខាងក្រោមនៃទំព័រ។

> 💡 **គន្លឹះ៖** ចាំថា `<head>` គឺជា metadata (មើលមិនឃើញ) ហើយ `<header>` គឺជាផ្នែកខាងលើទំព័រ (មើលឃើញ)។ កុំច្រឡំ!

## 🏷️ HTML Tags សំខាន់ៗ

HTML ប្រើប្រាស់ **tags** ដើម្បីកំណត់ធាតុ (elements) នៅលើទំព័រ។ tag ភាគច្រើនមាន opening tag `<tagname>` និង closing tag `</tagname>` ខណៈពេលដែល tag ខ្លះទៀតជា self-closing tags (មិនមាន closing tag) ដូចជា `<img>` ឬ `<br>`។

### 1. Headings (ចំណងជើង)

HTML ផ្តល់នូវ tags ចំណងជើងចំនួន 6 កម្រិត ដែលប្រើសម្រាប់រៀបចំរចនាសម្ព័ន្ធអត្ថបទ និងបញ្ជាក់ពីកម្រិតនៃសារៈសំខាន់របស់វា។

```html
<h1>ចំណងជើងធំបំផុត (Main Title - ប្រើតែ 1 ក្នុងទំព័រ)</h1>
<h2>ចំណងជើងអនុផ្នែក (Section Heading)</h2>
<h3>ចំណងជើងរង (Subsection)</h3>
<h4>ចំណងជើងតូច</h4>
<h5>ចំណងជើងតូចជាង</h5>
<h6>ចំណងជើងតូចបំផុត</h6>
```

**ការពន្យល់លម្អិត៖**
*   **`<h1>`**: គឺជាចំណងជើងធំបំផុត និងសំខាន់បំផុត។ ក្នុងមួយទំព័រគួរតែមាន `<h1>` តែមួយគត់ ដើម្បីប្រាប់ Search Engines ថាតើទំព័រនេះនិយាយអំពីអ្វីជារួម។
*   **`<h2>` ដល់ `<h6>`**: ប្រើសម្រាប់បំបែកអត្ថបទជាផ្នែកតូចៗតាមលំដាប់លំដោយ។

> ⚠️ **សំខាន់ (Hierarchy)៖** ត្រូវប្រើ headings ឱ្យមានលំដាប់ត្រឹមត្រូវ (h1 → h2 → h3)។ **កុំលោតរំលងកម្រិត!** ឧទាហរណ៍៖ កុំប្រើ `<h3>` ប្រសិនបើអ្នកមិនទាន់មាន `<h2>`។ ការធ្វើបែបនេះជួយយ៉ាងខ្លាំងដល់ SEO (Search Engine Optimization) និងអ្នកប្រើប្រាស់ឧបករណ៍អានអេក្រង់ (Screen Readers)។

### 2. Paragraphs & Text Formatting (អត្ថបទ និងការរៀបចំទម្រង់)

ការសរសេរអត្ថបទធម្មតានៅក្នុង HTML គឺត្រូវរុំព័ទ្ធដោយ tag `<p>` ។ ចំណែកឯ text formatting tags ផ្សេងទៀតជួយសង្កត់ន័យ ឬរៀបចំទម្រង់អត្ថបទឱ្យកាន់តែប្រសើរ។

```html
<p>នេះគឺជាកថាខណ្ឌ (Paragraph) ធម្មតា។ វានឹងបង្កើតគម្លាត (margin) បន្តិចនៅខាងលើ និងខាងក្រោមដោយស្វ័យប្រវត្តិ។</p>

<p>អ្នកអាចសង្កត់ន័យអត្ថបទដោយធ្វើជា <strong>អក្សរដិត (Bold)</strong> ឬ <em>អក្សរទ្រេត (Italic)</em>។</p>

<p>ប្រសិនបើអ្នកចង់<br>ចុះបន្ទាត់ថ្មីដោយមិនបង្កើតកថាខណ្ឌថ្មី ត្រូវប្រើ br tag។</p>

<p>អ្នកក៏អាច <mark>រំលេចអត្ថបទ (Highlight)</mark> ដោយប្រើ mark tag ផងដែរ។</p>
```

**ការពន្យល់ពីអត្ថន័យ (Semantics)៖**
*   **`<p>` (Paragraph):** កំណត់កថាខណ្ឌ។ Browser នឹងបន្ថែមចន្លោះទទេ (spacing) រវាងកថាខណ្ឌនីមួយៗដោយស្វ័យប្រវត្តិ។
*   **`<strong>` vs `<b>`**: ទាំងពីរនេះធ្វើឱ្យអក្សរដិត។ ប៉ុន្តែ `<strong>` ផ្តល់អត្ថន័យថាពាក្យនេះ **"សំខាន់ខ្លាំង"** សម្រាប់ screen readers ខណៈ `<b>` គ្រាន់តែដិតដើម្បីសោភ័ណភាពប៉ុណ្ណោះ។ (គប្បីប្រើ `<strong>` ជានិច្ច)។
*   **`<em>` vs `<i>`**: ទាំងពីរនេះធ្វើឱ្យអក្សរទ្រេត។ ដូចគ្នាដែរ `<em>` តំណាងឱ្យការសង្កត់សំឡេង (emphasis) ចំណែក `<i>` គ្រាន់តែទ្រេតសោភ័ណភាព។
*   **`<br>` (Line Break):** ប្រើសម្រាប់ចុះបន្ទាត់ភ្លាមៗ ដោយមិនបង្កើត block ថ្មី។ វាគឺជា self-closing tag។
*   **`<mark>`**: ប្រៀបដូចជាការគូសហាយឡាយ (highlight) ដោយប្រើហ្វឺតពណ៌ ដើម្បីឱ្យចំណាំងាយមើលឃើញ។
