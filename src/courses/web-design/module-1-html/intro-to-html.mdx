## 🌐 ឆ្អឹងខ្នងនៃ Web

![HTML5 Logo](https://upload.wikimedia.org/wikipedia/commons/6/61/HTML5_logo_and_wordmark.svg)


រាល់គេហទំព័រដែលអ្នកចូលមើល ពី Google ដល់ Netflix គឺត្រូវបានបង្កើតឡើងនៅលើ **HTML (Hyper Text Markup Language)**។

HTML មិនមែនជាភាសាសរសេរកូដ (Programming Language) ទេ; វាគឺជា **Markup Language**។ វាប្រាប់ **Browser** ពីរបៀបរៀបចំ និងបង្ហាញ Content។

### តើ HTML ធ្វើអ្វីខ្លះ?

HTML គ្រប់គ្រងផ្នែកទាំងនេះនៃគេហទំព័រ៖
- **រចនាសម្ព័ន្ធ (Structure)**: ការរៀបចំ Content ជា Headings, Paragraphs, Lists, Tables
- **មាតិកា (Content)**: Text, រូបភាព, វីដេអូ, Links
- **អត្ថន័យ (Semantics)**: ប្រាប់ Browser ថា Content នីមួយៗ *គឺជាអ្វី* (Navigation, Article, Footer)

---

## 🏗️ រចនាសម្ព័ន្ធនៃឯកសារ HTML

រាល់ទំព័រ HTML ទាំងអស់ត្រូវធ្វើតាមរចនាសម្ព័ន្ធស្តង់ដារមួយ។ តោះមើលឧទាហរណ៍ជាមូលដ្ឋាន៖

```html
<!DOCTYPE html>
<html lang="km">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Website</title>
</head>
<body>
    <header>
        <h1>សូមស្វាគមន៍មកកាន់ Full Stack Mastery!</h1>
    </header>
    <main>
        <p>នេះគឺជា Paragraph នៃ Text។</p>
    </main>
</body>
</html>
```

## 🏷️ HTML Tags សំខាន់ៗ

HTML ប្រើប្រាស់ **Tags** ដើម្បីកំណត់ **Elements**។ Tag ភាគច្រើនមាន Opening Tag និង Closing Tag។ 

### 1. Headings (ចំណងជើង)

HTML មាន 6 កម្រិតនៃ Headings ចាប់ពី `<h1>` ដល់ `<h6>`។ ការប្រើប្រាស់វាឱ្យបានត្រឹមត្រូវគឺសំខាន់ណាស់សម្រាប់ទាំងអ្នកអាន និង SEO (Search Engine)៖
- `<h1>`: ប្រើសម្រាប់ចំណងជើងគោល ឬចំណងជើងធំបំផុតនៃទំព័រ។ គួរមានតែមួយគត់ក្នុងមួយទំព័រ។
- `<h2>`: ប្រើសម្រាប់ចំណងជើងរងនៃផ្នែកសំខាន់ៗ។
- `<h3>` ដល់ `<h6>`: ប្រើសម្រាប់ចំណងជើងតូចៗ ឬអនុផ្នែកបន្តបន្ទាប់។

```html
<h1>Heading ធំបំផុត (ចំណងជើងគោល)</h1>
<h2>Heading អនុផ្នែក</h2>
<h3>Heading រង</h3>
```

### 2. Paragraphs & Text Formatting

ការប្រើប្រាស់ Tag សម្រាប់អត្ថបទ៖
- `<p>` (Paragraph): ប្រើសម្រាប់សរសេរអត្ថបទធម្មតា ឬកថាខណ្ឌនីមួយៗ។ រាល់ពេលអ្នកចង់ចុះបន្ទាត់ផ្តើមអត្ថបទថ្មី គួរប្រើ `<p>`។
- `<strong>`: ប្រើសម្រាប់បញ្ជាក់ថាពាក្យនោះ **មានសារៈសំខាន់ខ្លាំង** (ជាទូទៅលោតចេញជាអក្សរដិត Bold)។ វាក៏ជួយប្រាប់ Google ថាពាក្យនោះជា Keyword សំខាន់ផងដែរ។
- `<em>` (Emphasis): ប្រើសម្រាប់សង្កត់ន័យ ឬបញ្ជាក់អារម្មណ៍លើពាក្យ (ជាទូទៅលោតចេញជាអក្សរទ្រេត Italic)។

```html
<p>នេះគឺជា Paragraph ធម្មតា។</p>
<p>អ្នកអាចធ្វើ <strong>Bold</strong> និង <em>Italic</em> បាន។</p>
```
