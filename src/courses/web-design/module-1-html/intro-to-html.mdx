## 🌐 ឆ្អឹងខ្នងនៃ Web

រាល់គេហទំព័រដែលអ្នកចូលមើល ពី Google ដល់ Netflix គឺត្រូវបានបង្កើតឡើងនៅលើ **HTML (Hyper Text Markup Language)**។

HTML មិនមែនជាភាសាសរសេរកូដ (Programming Language) ទេ; វាគឺជា **Markup Language**។ វាប្រាប់ **Browser** ពីរបៀបរៀបចំ និងបង្ហាញ Content។

### តើ HTML ធ្វើអ្វីខ្លះ?

HTML គ្រប់គ្រងផ្នែកទាំងនេះនៃគេហទំព័រ៖
- **រចនាសម្ព័ន្ធ (Structure)**: ការរៀបចំ Content ជា Headings, Paragraphs, Lists
- **មាតិកា (Content)**: Text, រូបភាព, វីដេអូ, Links
- **អត្ថន័យ (Semantics)**: ប្រាប់ Browser ថា Content នីមួយៗ *គឺជាអ្វី* (Navigation, Article, Footer)

ចូរគិតពីការសាងសង់ផ្ទះមួយ៖
- **HTML** គឺជារចនាសម្ព័ន្ធ (ជញ្ជាំង, កម្រាល, បន្ទប់)។
- **CSS** គឺជាការរចនាផ្ទៃខាងក្នុង (ពណ៌ថ្នាំលាប, ម៉ូដគ្រឿងសង្ហារឹម)។
- **JavaScript** គឺជាអគ្គិសនី និងប្រព័ន្ធទឹក (ធ្វើឱ្យអ្វីៗដំណើរការ)។

### ប្រវត្តិខ្លីៗ

HTML ត្រូវបានបង្កើតឡើងដោយ **Tim Berners-Lee** នៅឆ្នាំ 1991។ ដំបូងវាមាន Tags ចំនួន 18 តែប៉ុណ្ណោះ! សព្វថ្ងៃ HTML5 គឺជា Version ចុងក្រោយបង្អស់ ដែលមាន Tags ជាង 100។

## 🏗️ រចនាសម្ព័ន្ធនៃឯកសារ HTML

រាល់ទំព័រ HTML ទាំងអស់ត្រូវធ្វើតាមរចនាសម្ព័ន្ធស្តង់ដារមួយ។ តោះមើលឧទាហរណ៍ជាមូលដ្ឋាន៖

```html
<!DOCTYPE html>
<html lang="km">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="គេហទំព័រដំបូងរបស់ខ្ញុំ">
    <title>My First Website</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <header>
        <h1>សូមស្វាគមន៍មកកាន់ Full Stack Mastery!</h1>
        <nav>
            <a href="#about">អំពីខ្ញុំ</a>
            <a href="#contact">ទំនាក់ទំនង</a>
        </nav>
    </header>
    <main>
        <p>នេះគឺជា Paragraph នៃ Text។</p>
    </main>
    <footer>
        <p>&copy; 2024 My Website</p>
    </footer>
</body>
</html>
```

### ការពន្យល់ពីកូដ៖

| Tag | មុខងារ |
|-----|--------|
| `<!DOCTYPE html>` | ប្រាប់ Browser ថានេះគឺជាឯកសារ HTML5 |
| `<html lang="km">` | ឫសគល់ដែលរុំ Content ទាំងអស់។ `lang` Attribute ប្រាប់ Browser ពីភាសា |
| `<head>` | ព័ត៌មាន Metadata (Title, Charset, Viewport, Stylesheets) |
| `<meta charset="UTF-8">` | កំណត់ Encoding អក្សរ — ចាំបាច់សម្រាប់អក្សរខ្មែរ |
| `<meta name="viewport">` | ធ្វើឱ្យទំព័រ Responsive នៅលើ Mobile |
| `<body>` | Content ទាំងអស់ដែលអាចមើលឃើញនៅលើគេហទំព័រ |
| `<header>` | ផ្នែក Header នៃទំព័រ |
| `<main>` | Content សំខាន់ៗ (Main Content) |
| `<footer>` | ផ្នែក Footer នៃទំព័រ |

> 💡 **គន្លឹះ៖** ចាំថា `<head>` គឺជា Metadata (មើលមិនឃើញ) ហើយ `<header>` គឺជាផ្នែកខាងលើទំព័រ (មើលឃើញ)។ កុំច្រឡំ!

## 🏷️ HTML Tags សំខាន់ៗ

HTML ប្រើប្រាស់ **Tags** ដើម្បីកំណត់ **Elements**។ Tag ភាគច្រើនមាន Opening Tag និង Closing Tag។

### Headings 

HTML មាន 6 កម្រិតនៃ Headings៖

```html
<h1>Heading ធំបំផុត (ប្រើតែ 1 ក្នុងទំព័រ)</h1>
<h2>Heading អនុផ្នែក</h2>
<h3>Heading រង</h3>
<h4>Heading តូច</h4>
<h5>Heading តូចជាង</h5>
<h6>Heading តូចបំផុត</h6>
```

> ⚠️ **សំខាន់៖** ប្រើ Headings ឱ្យមានលំដាប់ត្រឹមត្រូវ (h1 → h2 → h3)។ កុំប្រើ h3 មុន h2! នេះជួយ SEO និង Screen Readers។

### Paragraphs & Text Formatting

```html
<p>នេះគឺជា Paragraph ធម្មតា។</p>

<p>អ្នកអាចធ្វើ <strong>Bold</strong> និង <em>Italic</em> បាន។</p>

<p>ដើម្បីចុះបន្ទាត់ថ្មី ប្រើ <br> Tag។<br>នេះនៅបន្ទាត់ថ្មី។</p>

<p>ដើម្បី <mark>Highlight Text</mark> ប្រើ mark Tag។</p>

<p>Text <small>តូចជាង</small> ប្រើ small Tag។</p>
```
