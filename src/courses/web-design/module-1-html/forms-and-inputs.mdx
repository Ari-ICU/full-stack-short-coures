## 📝 ការប្រមូល User Data

HTML Forms គឺជារឿងចាំបាច់សម្រាប់អន្តរកម្ម។ មិនថាវាជាអេក្រង់ Login, ទំព័រ Checkout, ឬទម្រង់ទំនាក់ទំនង (Contact Form) ធម្មតា, Element `<form>` គឺជាឆ្អឹងខ្នងនៃការបញ្ចូលទិន្នន័យ។

Form គឺជាប្រអប់ (Container) សម្រាប់ប្រភេទ Input ផ្សេងៗ ដូចជា Text, Checkboxes, Radio Buttons, និង Submit Buttons។

---

## 🏗️ Element `<form>`

រាល់ Form ទាំងអស់ត្រូវចាប់ផ្តើម និងបញ្ចប់ដោយ `<form>` Tags។

```html
<form action="/submit-data" method="POST">
    <!-- Input Fields ដាក់នៅទីនេះ -->
</form>
```

### Attributes សំខាន់ៗ៖
- **`action`**: បញ្ជាក់ទីកន្លែងដែលត្រូវបញ្ជូនទិន្នន័យនៅពេល Form ត្រូវបាន Submit (ជាធម្មតាទៅកាន់ Server)។
- **`method`**: បញ្ជាក់ពីរបៀបបញ្ជូនទិន្នន័យ (HTTP Method)។ ទូទៅបំផុតគឺ `GET` និង `POST`។

## ⌨️ ប្រភេទ Inputs

Tag `<input>` គឺជា Form Element ដែលអាច অন্ততប្រើបានច្រើនយ៉ាង។ សកម្មភាពរបស់វាផ្លាស់ប្តូរទាំងស្រុងទៅតាម `type` Attribute របស់វា។

### 1. Text Input
ប្រើសម្រាប់ Text ខ្លីៗ ដូចជាឈ្មោះ។
```html
<label for="username">Username:</label>
<input type="text" id="username" name="username" placeholder="បញ្ចូល username របស់អ្នក">
```

### 2. Password Input
លាក់តួអក្សរដែលអ្នកប្រើប្រាស់បានបញ្ចូល។
```html
<label for="pwd">Password:</label>
<input type="password" id="pwd" name="pwd">
```

### 3. Email Input
ផ្ទៀងផ្ទាត់ (Validate) ដោយស្វ័យប្រវត្តិថាការបញ្ចូលគឺជាទម្រង់ Email ត្រឹមត្រូវ។
```html
<label for="email">Email:</label>
<input type="email" id="email" name="email" required>
```

### 4. Radio Buttons
អនុញ្ញាតឱ្យអ្នកប្រើជ្រើសរើស តែមួយ ជម្រើសគត់ពីបញ្ជី។ Radio Buttons ទាំងអស់ក្នុងក្រុមតែមួយត្រូវតែមាន `name` Attribute ដូចគ្នា។
```html
<p>ជ្រើសរើសវគ្គសិក្សារបស់អ្នក៖</p>
<input type="radio" id="frontend" name="course" value="frontend">
<label for="frontend">Frontend</label><br>

<input type="radio" id="backend" name="course" value="backend">
<label for="backend">Backend</label>
```

### 5. Checkboxes
អនុញ្ញាតឱ្យអ្នកប្រើជ្រើសរើស ច្រើន ឬគ្មាន ជម្រើស។
```html
<input type="checkbox" id="subscribe" name="subscribe" value="yes">
<label for="subscribe">ចុះឈ្មោះទទួលព័ត៌មាន</label>
```

## 🔘 Dropdowns & Textareas

### Dropdown List (`<select>`)
ប្រើនៅពេលអ្នកមានជម្រើសវែងៗច្រើន។
```html
<label for="country">ប្រទេស៖</label>
<select id="country" name="country">
    <option value="cambodia">កម្ពុជា</option>
    <option value="usa">សហរដ្ឋអាមេរិក</option>
    <option value="japan">ជប៉ុន</option>
</select>
```

### Multi-line Text (`<textarea>`)
ប្រើសម្រាប់ Text វែងៗ ដូចជាមតិយោបល់ ឬសារ។
```html
<label for="message">សារ៖</label>
<textarea id="message" name="message" rows="4" cols="50"></textarea>
```

## 🚀 ការ Submit Form

ចុងក្រោយ អ្នកត្រូវការ Button មួយដើម្បីបញ្ជូនទិន្នន័យពី Form ទៅកាន់ Server។

```html
<button type="submit">Submit Form</button>
```

*គន្លឹះ៖ គួរប្រើ `<label>` Tags ជានិច្ច និងភ្ជាប់វាទៅកាន់ Input របស់វាដោយប្រើ `for` Attribute និង `id` របស់ Input។ នេះគឺសំខាន់ណាស់សម្រាប់ Screen Readers និង Web Accessibility!*
