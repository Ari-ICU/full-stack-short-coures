## 🔗 ការប្រើប្រាស់ Attributes (Links និង Images)

**Attributes** គឺត្រូវបានប្រើប្រាស់ដើម្បីផ្តល់ព័ត៌មានបន្ថែមទៅកាន់ HTML Tags។ ពួកវាតែងតែត្រូវបានសរសេរនៅក្នុង Opening Tag ជានិច្ច។

### 1. Links (តំណភ្ជាប់)

យើងប្រើ Tag `<a>` (Anchor) ដើម្បីបង្កើតតំណភ្ជាប់។ វាទាមទារនូវ Attribute `href` ជាដាច់ខាត ដើម្បីប្រាប់ថាត្រូវលោតទៅណា។

```html
<!-- ប្រើ href ដើម្បីចង្អុលទៅកាន់ Website ផ្សេង -->
<a href="https://google.com">ទៅកាន់ Google</a>

<!-- បន្ថែម target="_blank" ដើម្បីបើកក្នុង Tab ថ្មី -->
<a href="https://facebook.com" target="_blank">ទៅកាន់ Facebook</a>
```

### 2. Images (រូបភាព)

Tag `<img>` មិនមាន Closing Tag ទេ។ វាទាមទារនូវ Attribute ពីរយ៉ាងតិច៖ 
- `src` (Source): ប្រភពនៃរូបភាព (URL ឬ ទីតាំង File)។
- `alt` (Alternative Text): អក្សរជំនួសពេលរូបភាពមិនដើរ ឬសម្រាប់ Screen Readers អានឱ្យជនពិការភ្នែកស្តាប់។

```html
<img src="profile.jpg" alt="រូបថតប្រវត្តិរូបរបស់ខ្ញុំ" width="200">
```

## 📝 ការបង្កើត Lists (បញ្ជី)

មានបញ្ជី ២ ប្រភេទសំខាន់ៗដែលយើងតែងតែប្រើប្រាស់៖ Unordered List (`<ul>` - ចុចចំណុច) និង Ordered List (`<ol>` - លេខរៀង)។ 

ធាតុនីមួយៗក្នុងបញ្ជីត្រូវរុំដោយ `<li>` (List Item) ជានិច្ច។

```html
<!-- បញ្ជីគ្មានលេខរៀង (ចំណុចត្រេ) -->
<ul>
    <li>ផ្លែប៉ោម</li>
    <li>ផ្លែចេក</li>
    <li>ផ្លែក្រូច</li>
</ul>

<!-- បញ្ជីមានលេខរៀង (១, ២, ៣) -->
<ol>
    <li>ក្រោកពីគេង</li>
    <li>ដុសធ្មេញ</li>
    <li>ញ៉ាំអាហារពេលព្រឹក</li>
</ol>
```

## 📊 ការរៀបចំទិន្នន័យជា Tables (តារាង)

ការបង្កើតតារាងទាមទារការរួមបញ្ចូលគ្នានូវ Tags ជាច្រើន។ រចនាសម្ព័ន្ធជាមូលដ្ឋានមានដូចជា៖
- `<table>`: តំណាងឱ្យតារាងទាំងមូល
- `<tr>` (Table Row): តំណាងឱ្យជួរដេក
- `<th>` (Table Header): តំណាងឱ្យក្បាលតារាង (អក្សរដិត និងនៅកណ្តាល)
- `<td>` (Table Data): តំណាងឱ្យប្រអប់ទិន្នន័យធម្មតា

```html
<table border="1">
    <!-- ជួរដេកទី ១: សម្រាប់ក្បាលតារាង -->
    <tr>
        <th>ឈ្មោះ</th>
        <th>អាយុ</th>
        <th>មុខរបរ</th>
    </tr>
    <!-- ជួរដេកទី ២: សម្រាប់ទិន្នន័យអ្នកទី ១ -->
    <tr>
        <td>សុខ</td>
        <td>២៥</td>
        <td>Web Developer</td>
    </tr>
    <!-- ជួរដេកទី ៣: សម្រាប់ទិន្នន័យអ្នកទី ២ -->
    <tr>
        <td>សៅ</td>
        <td>៣០</td>
        <td>Graphic Designer</td>
    </tr>
</table>
```

*(ចំណាំ៖ ការប្រើប្រាស់ Attribute `border="1"` គឺគ្រាន់តែដើម្បីឱ្យងាយស្រួលមើលបន្ទាត់តារាងបណ្តោះអាសន្នប៉ុណ្ណោះ។ ក្នុងការអនុវត្តជាក់ស្តែង យើងប្រើប្រាស់ CSS ដើម្បីរចនាបន្ទាត់តារាង)*។
