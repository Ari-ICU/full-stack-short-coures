## 🏷️ អ្វីទៅជា Semantic HTML?

នៅក្នុងភាសាអង់គ្លេស ពាក្យថា **Semantic** មានន័យថា "អត្ថន័យ" (Meaning)។ ដូច្នេះ **Semantic HTML** គឺជាការប្រើប្រាស់ HTML Tags ដែលមានអត្ថន័យច្បាស់លាស់ ដែលប្រាប់ទាំង Developer និង Browser ពីអ្វីដែល Content នោះតំណាងឱ្យ។

### ភាពខុសគ្នារវាង Semantic និង Non-semantic Elements:

- **Non-semantic Elements (`<div>`, `<span>`):** 
  ពួកវាមិនបានប្រាប់អ្វីសោះអំពី Content របស់វា។ វាគ្រាន់តែជាប្រអប់ទទេសម្រាប់ផ្ទុករបស់ផ្សេងៗប៉ុណ្ណោះ។ កាលពីមុន Developer ប្រើប្រាស់ `<div class="header">` ឬ `<div id="nav">` ដើម្បីរៀបចំរចនាសម្ព័ន្ធ ប៉ុន្តែ Browser មិនអាចយល់ពីអត្ថន័យនៃ class ឬ id ទាំងនោះទេ។
- **Semantic Elements (`<header>`, `<article>`, `<form>`):** 
  គ្រាន់តែឃើញឈ្មោះ Tag ភ្លាម អ្នកអភិវឌ្ឍន៍ កម្មវិធីរុករក (Browser) និងម៉ាស៊ីនស្វែងរក (Search Engine) អាចដឹងភ្លាមៗថាវាផ្ទុកទិន្នន័យប្រភេទអ្វី និងមានតួនាទីអ្វីនៅក្នុងទំព័រ។ ការប្រើប្រាស់ `<header>` គឺល្អជាង `<div class="header">` ដាច់។

## 🚀 ហេតុអ្វីបានជា Semantic HTML មានសារៈសំខាន់?

ការសរសេរកូដដោយប្រើប្រាស់ `<div>` សម្រាប់អ្វីៗទាំងអស់ គឺនៅតែអាចដំណើរការចេញជារូបរាងបានដូចគ្នា តែហេតុអ្វីបានជាយើងត្រូវខ្វល់ខ្វាយពី Semantic HTML?

1. **Accessibility (ភាពងាយស្រួលក្នុងការប្រើប្រាស់):** ជនពិការភ្នែកពឹងផ្អែកលើកម្មវិធី Screen Readers ដើម្បីអាន Website ឱ្យពួកគេស្តាប់។ Semantic Tags ប្រាប់កម្មវិធីទាំងនោះពីរបៀបអានទំព័រឱ្យបានត្រឹមត្រូវ។
2. **SEO (Search Engine Optimization):** Google និង Search Engines ផ្សេងៗចូលចិត្ត Semantic HTML។ ប្រសិនបើអ្នកប្រើ `<article>` ជំនួសឱ្យ `<div>` នោះ Google នឹងយល់ថាវាគឺជាអត្ថបទដ៏សំខាន់ ហើយជួយឱ្យ Website អ្នកឆាប់រុករកឃើញ។
3. **ងាយស្រួលថែទាំ (Maintainability):** កូដដែលមានអត្ថន័យគឺងាយស្រួលអាន និងងាយស្រួលកែប្រែនៅពេលក្រោយសម្រាប់ Developer ដទៃទៀត។

## 🏗️ Semantic Tags សំខាន់ៗក្នុង HTML5

HTML5 បានណែនាំ Semantic Tags ថ្មីៗជាច្រើនសម្រាប់ការសាងសង់ទំព័រ Web ឱ្យមានរចនាសម្ព័ន្ធច្បាស់លាស់ ដោយជំនួសឱ្យការប្រើប្រាស់ `<div>` ផ្តេសផ្តាស។

| Tag | អត្ថន័យ និងការប្រើប្រាស់ |
|---|---|
| `<header>` | កំណត់ផ្នែកខាងលើនៃទំព័រ (Global Header) ឬផ្នែកខាងលើនៃ `<article>` មួយ។ ជាទូទៅវាផ្ទុក Logo, ចំណងជើងធំ, ឬការណែនាំ។ |
| `<nav>` | តំណាងឱ្យ Navigation Links សំខាន់ៗ (ឧ. Menu ខាងលើ ឬ Menu ចំហៀង)។ មិនមែនរាល់ link ទាំងអស់សុទ្ធតែត្រូវដាក់ក្នុង `<nav>` នោះទេ លុះត្រាតែវាជា link គោល។ |
| `<main>` | កំណត់ Content គោល (Main Content) នៃទំព័រ។ វាគួរតែមានមាតិកាដែលពិសេសសម្រាប់តែទំព័រនោះ ហើយ **ត្រូវតែមាន `<main>` តែមួយគត់** ក្នុងមួយទំព័រ។ |
| `<article>` | កំណត់ Content ដែលអាចឈរឯករាជ្យបាន មានន័យថាបើគេយកវាទៅផុសនៅកន្លែងផ្សេង ក៏គេនៅតែយល់អត្ថន័យវា។ ឧទាហរណ៍៖ Blog Post មួយ, អត្ថបទព័ត៌មាន, ឬ Comment មួយ។ |
| `<section>` | តំណាងឱ្យផ្នែកមួយ (Section) នៃ Document ដែលទាក់ទងគ្នា។ ជាធម្មតាវាមាន Heading (h2, h3) ផ្ទាល់ខ្លួន។ ឧទាហរណ៍៖ ផ្នែក "សេវាកម្មរបស់យើង" ឬ "អំពីយើង"។ |
| `<aside>` | កំណត់ Content ដែលមិនសូវសំខាន់ ឬនៅចំហៀង (Sidebar) ដែលគាំទ្រដល់ Content គោល។ ឧទាហរណ៍៖ ការផ្សាយពាណិជ្ជកម្ម, តំណភ្ជាប់ពាក់ព័ន្ធ, ឬ Profile អ្នកសរសេរអត្ថបទ។ |
| `<footer>` | កំណត់ផ្នែកខាងក្រោមនៃទំព័រ (Global Footer) ឬផ្នែកខាងក្រោមនៃ `<article>`។ ជាទូទៅវាផ្ទុក Copyright, Contact Info, ឬ Links ទៅកាន់ Social Media។ |

> 💡 **ចំណាំ (<article> vs <section>):** ប្រើ `<article>` សម្រាប់មាតិកាដែលអាចឈរឯករាជ្យបាន (ដូចជាការបង្ហោះសារមួយ)។ ប្រើ `<section>` ដើម្បីបែងចែកមាតិកាធំៗជាផ្នែកតូចៗ (ដូចជាជំពូកនៅក្នុងសៀវភៅ)។

## 🖼️ ឧទាហរណ៍រចនាសម្ព័ន្ធ Semantic ពេញលេញ

នេះជារបៀបដែលគេរៀបចំ Semantic Tags បញ្ចូលគ្នាដើម្បីបង្កើតទំព័រ Web មួយ៖

```html
<body>
    <!-- ផ្នែកខាងលើ និង Menu -->
    <header>
        <h1>កំណត់ហេតុការធ្វើដំណើរ</h1>
        <nav>
            <a href="/">ទំព័រដើម</a>
            <a href="/destinations">គោលដៅ</a>
            <a href="/about">អំពីពួកយើង</a>
        </nav>
    </header>

    <!-- Content គោលនៃទំព័រ -->
    <main>
        <!-- អត្ថបទទី ១ -->
        <article>
            <header>
                <h2>ដំណើរកម្សាន្តនៅសៀមរាប</h2>
                <p>ផ្សាយនៅថ្ងៃទី ១៥ មករា ២០២៤</p>
            </header>
            <p>ប្រាសាទអង្គរវត្តពិតជាអស្ចារ្យណាស់...</p>
        </article>

        <!-- អត្ថបទទី ២ -->
        <article>
            <header>
                <h2>ឆ្នេរសមុទ្រក្រុងព្រះសីហនុ</h2>
                <p>ផ្សាយនៅថ្ងៃទី ២០ មករា ២០២៤</p>
            </header>
            <p>ទឹកសមុទ្រខៀវស្រងាត់...</p>
        </article>
    </main>

    <!-- របារចំហៀង -->
    <aside>
        <h3>អត្ថបទពេញនិយម</h3>
        <ul>
            <li><a href="/kampot">កំពត</a></li>
            <li><a href="/kirirom">គិរីរម្យ</a></li>
        </ul>
    </aside>

    <!-- ផ្នែកខាងក្រោម -->
    <footer>
        <p>&copy; 2024 Travel Blog. រក្សាសិទ្ធិគ្រប់យ៉ាង។</p>
    </footer>
</body>
```

តាមរយៈការប្រើប្រាស់ Semantic Elements បែបនេះ ទាំងអ្នកអាន ទាំង Developer និងទាំង Google ពិតជាងាយស្រួលយល់ពីរចនាសម្ព័ន្ធនៃ Website របស់អ្នក!
