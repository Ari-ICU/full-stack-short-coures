## 🔗 មូលដ្ឋានគ្រឹះនៃ Tag `<a>`

គេហទំព័រនឹងមិនអាចហៅថាជា "បណ្តាញ (Web)" ទេ ប្រសិនបើគ្មាន Links សម្រាប់ភ្ជាប់ពីទំព័រមួយទៅទំព័រមួយទៀត។ នៅក្នុង HTML យើងប្រើ Tag `<a>` (Anchor) សម្រាប់បង្កើត Links។

```html
<a href="https://google.com">ទៅកាន់ Google</a>
```
*   `href` (Hypertext Reference): ជា Attribute ដ៏សំខាន់បំផុតដែលប្រាប់ពីទីតាំង (URL) ដែលត្រូវលោតទៅកាន់។

## 🎯 Target Attribute

ជាលំនាំដើម ពេលអ្នកចុចលើ Link វានឹងបើកទំព័រថ្មីជំនួសទំព័រចាស់ក្នុង Tab តែមួយ។ ប៉ុន្តែជួនកាលយើងចង់ឱ្យវាបើកក្នុង Tab ថ្មី ដើម្បីកុំឱ្យអ្នកប្រើប្រាស់បាត់ទំព័រដើមយើង។ នោះហើយជាពេលដែលយើងប្រើ Attribute `target`។

*   **`target="_self"`**: (លំនាំដើម) បើកក្នុង Tab ជាមួយគ្នា។
*   **`target="_blank"`**: បើកក្នុង Tab ថ្មី (ឬ Window ថ្មី)។

```html
<!-- បើកទំព័រ Facebook ក្នុង Tab ថ្មី -->
<a href="https://facebook.com" target="_blank">Facebook របស់ពួកយើង</a>
```

> ⚠️ **សុវត្ថិភាព និងការអនុវត្តល្អ (Best Practice)៖**
> រាល់ពេលដែលអ្នកប្រើ `target="_blank"` ដើម្បីបើក Link ដែលជា Website របស់អ្នកដទៃ (External Link) អ្នក **ត្រូវតែ** បន្ថែម Attribute `rel="noopener"` (ឬ `rel="noopener noreferrer"`) ជានិច្ច។
> 
> ```html
> <a href="https://somewhere.com" target="_blank" rel="noopener">Link សុវត្ថិភាព</a>
> ```
> **ហេតុអ្វី?** នេះការពារមិនឱ្យទំព័រថ្មីនោះលួចចូលមកគ្រប់គ្រង (hijack) ទំព័រដើមរបស់អ្នកតាមរយៈ JavaScript នោះទេ! វាគឺជាបញ្ហាសុវត្ថិភាពដ៏សំខាន់មួយ។

## 📧 ការប្រើប្រាស់ `mailto:` និង `tel:`

Links មិនត្រឹមតែសម្រាប់បើកគេហទំព័រប៉ុណ្ណោះទេ វាក៏អាចធ្វើសកម្មភាពផ្សេងៗនៅលើឧបករណ៍របស់អ្នកប្រើប្រាស់បានដែរ៖

### 1. ផ្ញើ Email (mailto:)
នៅពេលអ្នកប្រើប្រាស់ចុចលើ Link ប្រភេទនេះ វានឹងបើកកម្មវិធី Email របស់ពួកគេ (ឧ. MS Outlook, Apple Mail) ដោយស្វ័យប្រវត្តិ ព្រមទាំងបំពេញអាសយដ្ឋាន Email ដែលអ្នកបានកំណត់។

```html
<a href="mailto:info@mywebsite.com">ទាក់ទងមកយើងខ្ញុំតាមអ៊ីមែល</a>
```
*(គន្លឹះបន្ថែម៖ អ្នកក៏អាចបញ្ចូលចំណងជើងស្រាប់បានដែរ `mailto:info@mywebsite.com?subject=សំណួរអំពីវគ្គសិក្សា`)*

### 2. ហៅទូរស័ព្ទ (tel:)
នេះគឺមានប្រយោជន៍ខ្លាំងណាស់សម្រាប់អ្នកប្រើប្រាស់ទូរស័ព្ទដៃ! ពេលពួកគេចុចលើ Link នេះ វានឹងលោតចូលទៅក្នុងផ្ទាំងចុចលេខទូរស័ព្ទ (Dialpad) ភ្លាមៗ។

```html
<a href="tel:+85512345678">ហៅមកកាន់លេខ៖ 012 345 678</a>
```

> 💡 **ចំណាំ៖** សម្រាប់ `tel:` អ្នកគួរប្រើទម្រង់អន្តរជាតិដែលមានសញ្ញា `+` និងលេខកូដប្រទេស (ឧ. ខ្មែរគឺ `+855`) ដើម្បីធានាថាវាដំណើរការបានទោះបីជាអ្នកហៅមកពីណាក៏ដោយ។
