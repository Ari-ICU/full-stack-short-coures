## 🧱 អ្វីទៅជា Block-level និង Inline-level?

រាល់ HTML Elements ទាំងអស់ត្រូវបាន Browser ចាត់ថ្នាក់ជាពីរប្រភេទធំៗ គឺ **Block** និង **Inline**។ ការយល់ពីភាពខុសគ្នានេះ គឺជារឿងសំខាន់បំផុតដើម្បីអាចរៀបចំ Layout គេហទំព័របានល្អ (ជាពិសេសនៅពេលអ្នកចាប់ផ្តើមរៀន CSS)។

---

## 1. Block-level Elements

Block Elements ប្រៀបដូចជាឥដ្ឋមួយដុំធំ។ 
*   **លក្ខណៈពិសេស៖** វាតែងតែចាប់ផ្តើមនៅលើ **បន្ទាត់ថ្មី** ជានិច្ច ហើយវាលាតសន្ធឹងទាញយកទំហំទទឹងពេញ (100%) នៃទំព័រ (លុះត្រាតែយើងកំណត់ប្រវែងឱ្យវាដោយប្រើ CSS)។
*   **ឧទាហរណ៍ពេញនិយម៖** `<div>`, `<p>`, `<h1>` ដល់ `<h6>`, `<ul>`, `<ol>`, `<li>`, `<section>`, `<form>`។

```html
<p>នេះគឺជា Block element ទី១។ វាស៊ីកន្លែងមួយបន្ទាត់ពេញ។</p>
<p>ដូច្នេះ Block element ទី២ នេះត្រូវធ្លាក់មកបន្ទាត់ថ្មីខាងក្រោម។</p>
```

---

## 2. Inline-level Elements

Inline Elements ប្រៀបដូចជាអក្សរមួយតួ ឬពាក្យមួយម៉ាត់។
*   **លក្ខណៈពិសេស៖** វាមិនចាប់ផ្តើមលើបន្ទាត់ថ្មីទេ។ វាបង្ហាញខ្លួននៅ **តពីក្រោយ (ក្បែរគ្នា)** ធាតុផ្សេងទៀត ហើយវាយកទំហំទទឹងត្រឹមតែអ្វីដែលវាត្រូវការប៉ុណ្ណោះ។ 
*   **ឧទាហរណ៍ពេញនិយម៖** `<span>`, `<a>` (Links), `<img>` (Images), `<strong>` (Bold), `<em>` (Italic)។

```html
<p>
    នេះគឺជាកថាខណ្ឌធម្មតា។ ប៉ុន្តែ 
    <a href="#">នេះគឺជា Inline Element</a> 
    ដែលស្ថិតនៅក្នុងបន្ទាត់តែមួយជាមួយកថាខណ្ឌ ដោយមិនធ្លាក់ទៅក្រោម។
</p>
```

---

## 🥊 ការប្រៀបធៀប `<div>` មុខទល់នឹង `<span>`

អ្នកទើបរៀន HTML តែងតែឆ្ងល់ថា តើពេលណាត្រូវប្រើ `<div>` ហើយពេលណាត្រូវប្រើ `<span>` ព្រោះ Tag ទាំងពីរនេះមើលទៅអត់មានមុខងារអ្វីពិសេសសោះ ក្រៅពីរុំរបស់ផ្សេង។

**ចម្លើយគឺ៖** ពួកវាគឺជា "ប្រអប់ទទេ" សម្រាប់ជួយយើងក្នុងការដាក់ CSS ឬ JavaScript ប៉ុន្តែភាពខុសគ្នាគឺស្ថិតត្រង់ Block និង Inline ហ្នឹងឯង!

### ប្រើប្រាស់ `<div>` (Block)
`<div>` មកពីពាក្យ Division (ការបែងចែកផ្នែក)។ យើងប្រើវាសម្រាប់រុំធាតុច្រើនចូលគ្នាបង្កើតជា **ផ្នែកធំៗ (Sections)** ឬជាប្រអប់ធំ។

```html
<div class="user-card">
    <!-- <div> នេះរុំកូដទាំងអស់ខាងក្រោមចូលជាដុំតែមួយ -->
    <h2>ឈ្មោះ៖ សុខ សាន្ត</h2>
    <p>អាយុ៖ ២៥ ឆ្នាំ</p>
</div>
```

### ប្រើប្រាស់ `<span>` (Inline)
យើងប្រើ `<span>` សម្រាប់រុំ **អត្ថបទខ្លីៗ ឬផ្នែកតូចមួយនៅក្នុងប្រយោគ** ដើម្បីរចនាវា (ដាក់ពណ៌ ប្តូរពុម្ពអក្សរ) ដោយមិនធ្វើឱ្យវាដាច់ធ្លាក់បន្ទាត់។

```html
<p>សូមបញ្ចូលលេខកូដ <span style="color: red; font-weight: bold;">សម្ងាត់</span> របស់អ្នក។</p>
<!-- ពាក្យ "សម្ងាត់" នឹងមានពណ៌ក្រហម ប៉ុន្តែនៅតែជាប់គ្នាក្នុងប្រយោគដដែល -->
```

**សរុបសេចក្តី៖** បើចង់រុំរបស់ធំៗ (ជាដុំ) ប្រើ `<div>`។ បើចង់រុំអក្សរក្នុងប្រយោគ ប្រើ `<span>`!
