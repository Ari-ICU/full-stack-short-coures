## 🛠️ TypeScript Declaration Merging សម្រាប់ Express

បង្កើតឯកសារ Type Definition ដើម្បីបន្ថែម `req.user`៖

```typescript
// src/types/express.d.ts
import { UserTokenPayload } from "../utils/jwt";

declare global {
  namespace Express {
    interface Request {
      user?: UserTokenPayload;
    }
  }
}
```

## 🛡️ Authentication Middleware ពេញលេញ

```typescript
// src/middlewares/authenticate.ts
import { Request, Response, NextFunction } from "express";
import { verifyToken } from "../utils/jwt";

export const authenticate = (
  req: Request,
  res: Response,
  next: NextFunction
) => {
  const authHeader = req.headers.authorization;

  if (!authHeader || !authHeader.startsWith("Bearer ")) {
    return res.status(401).json({
      success: false,
      message: "Unauthorized: Token ត្រូវបានទាមទារ (Bearer <token>)",
    });
  }

  const token = authHeader.split(" ")[1];

  try {
    const payload = verifyToken(token);
    req.user = payload; // Attach user payload ទៅកាន់ Request object
    next();
  } catch (error: any) {
    return res.status(401).json({
      success: false,
      message: error.message || "Invalid or expired token",
    });
  }
};
```

## 🚀 Router Pipeline Integration ជាក់ស្តែង

```typescript
// src/routes/admin.routes.ts
import { Router } from "express";
import { authenticate } from "../middlewares/authenticate";
import { authorizeRoles } from "../middlewares/authorize";
import { getAdminDashboardStats, deleteUserAccount } from "../controllers/admin.controller";

const router = Router();

// គ្រប់ Routes ទាំងអស់ខាងក្រោមនេះទាមទារ Login ជាមុនសិន
router.use(authenticate);

// គ្រប់ Routes ទាំងអស់ខាងក្រោមនេះទាមទារ Role ជា 'admin'
router.use(authorizeRoles("admin"));

router.get("/dashboard-stats", getAdminDashboardStats);
router.delete("/users/:id", deleteUserAccount);

export default router;
```
