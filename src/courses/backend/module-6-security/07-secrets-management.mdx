## 🔐 ការទុកដាក់ព័ត៌មានសម្ងាត់ (Secrets)

ដូចដែលបានលើកឡើងនៅក្នុង Module 1 ការលាក់ទុកលេខសម្ងាត់ Database ឫ API Keys (Stripe, AWS) គឺជារឿងសំខាន់បំផុត។

### កំហុសដែលតែងតែកើតមាន
- **Hardcoding:** ការសរសេរអក្សរលេខសម្ងាត់ផ្ទាល់ក្នុងកូដ JS (ឧ. `const apiKey = "12345"`)។
- **Pushing .env ទៅ Git:** ភ្លេចដាក់ឯកសារ `.env` ចូលទៅក្នុង `.gitignore` ធ្វើអោយអ្នកដទៃឃើញ។

### Best Practices (ទម្លាប់ល្អៗ)
1. **ប្រើប្រាស់ `.env`.** រក្សាទិន្នន័យសម្ងាត់ក្នុងឯកសារនេះជានិច្ច ពេល Develop។
2. **កុំ Push ឯកសារ `.env`.** បង្កើតឯកសារ `.env.example` មួយសម្រាប់ទុកមើលជាគំរូដោយដាក់តម្លៃទទេរ ឫទិន្នន័យសាកល្បង។
3. **Environment Variables នៅលើ Production:** នៅពេល Deploy (ដាក់កម្មវិធីអោយរត់ពិតប្រាកដ) អ្នកត្រូវចូលទៅកំណត់ Environment Variables នៅលើផ្ទាំងបញ្ជារបស់ Cloud Provider របស់អ្នក (ឧ. Vercel, Render, AWS, Docker) ផ្ទាល់ មិនមែនយកឯកសារ `.env` ទៅដាក់លើនោះទេ។
