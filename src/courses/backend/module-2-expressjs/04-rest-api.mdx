## 🏛️ គោលការណ៍គ្រឹះនៃ RESTful API Design

**REST (Representational State Transfer)** គឺជាស្តង់ដារស្ថាបត្យកម្មសម្រាប់ការរចនា Web API៖

1. **Resource-Oriented (ផ្អែកលើ Resource):** ប្រើប្រាស់ Nouns ពហុវចនៈ (Plural) ដូចជា `/api/v1/products` មិនប្រើកិរិយាសព្ទ `/api/v1/getProducts` ឡើយ។
2. **Stateless (គ្មានការចងចាំ State):** រាល់ Request ត្រូវតែផ្ទុកព័ត៌មានគ្រប់គ្រាន់ដោយខ្លួនឯង។
3. **Standard HTTP Methods:**
   - `GET /products` -> ទាញយកបញ្ជី Products ទាំងអស់
   - `GET /products/:id` -> ទាញយក Product តែមួយតាម ID
   - `POST /products` -> បង្កើត Product ថ្មី
   - `PUT /products/:id` -> កែប្រែជំនួស Product ទាំងមូល
   - `PATCH /products/:id` -> កែប្រែតែ Fields មួយចំនួន (ឧ. ប្តូរតែតម្លៃ price)
   - `DELETE /products/:id` -> លុប Product ចោល

## 📐 ទម្រង់ Standard API Response (JSend Pattern)

ការកំណត់ទម្រង់ Response ឱ្យមានរចនាសម្ព័ន្ធដូចគ្នាជួយឱ្យក្រុម Frontend ស្រួលសរសេរ Fetch Logic៖

```json
// Success Response
{
  "success": true,
  "data": { "id": 1, "name": "MacBook Pro M3", "price": 1999 },
  "message": "Product retrieved successfully"
}

// Error Response
{
  "success": false,
  "error": {
    "code": "NOT_FOUND",
    "message": "Product with ID 999 does not exist"
  }
}
```

## 💻 ការអនុវត្ត Full CRUD REST API ជាមួយ Express

```javascript
import express from 'express';

const app = express();
app.use(express.json());

// Mock In-memory Database
let products = [
  { id: 1, name: "Mechanical Keyboard", price: 89, inStock: true },
  { id: 2, name: "Wireless Mouse", price: 49, inStock: false }
];

// 1. READ ALL (ជាមួយ Query Filtering)
app.get('/api/v1/products', (req, res) => {
  const { inStock } = req.query;
  let result = [...products];
  if (inStock !== undefined) {
    result = result.filter(p => p.inStock === (inStock === 'true'));
  }
  res.status(200).json({ success: true, count: result.length, data: result });
});

// 2. READ ONE BY ID
app.get('/api/v1/products/:id', (req, res) => {
  const id = parseInt(req.params.id, 10);
  const product = products.find(p => p.id === id);

  if (!product) {
    return res.status(404).json({ success: false, message: "រកមិនឃើញ Product ឡើយ" });
  }

  res.status(200).json({ success: true, data: product });
});

// 3. CREATE PRODUCT
app.post('/api/v1/products', (req, res) => {
  const { name, price, inStock = true } = req.body;

  if (!name || price === undefined) {
    return res.status(400).json({ success: false, message: "Name និង Price គឺចាំបាច់" });
  }

  const newProduct = { id: Date.now(), name, price: Number(price), inStock: Boolean(inStock) };
  products.push(newProduct);

  res.status(201).json({ success: true, data: newProduct });
});

// 4. UPDATE (PATCH)
app.patch('/api/v1/products/:id', (req, res) => {
  const id = parseInt(req.params.id, 10);
  const index = products.findIndex(p => p.id === id);

  if (index === -1) {
    return res.status(404).json({ success: false, message: "រកមិនឃើញ Product ឡើយ" });
  }

  products[index] = { ...products[index], ...req.body };
  res.status(200).json({ success: true, data: products[index] });
});

// 5. DELETE
app.delete('/api/v1/products/:id', (req, res) => {
  const id = parseInt(req.params.id, 10);
  const index = products.findIndex(p => p.id === id);

  if (index === -1) {
    return res.status(404).json({ success: false, message: "រកមិនឃើញ Product ឡើយ" });
  }

  products.splice(index, 1);
  res.status(200).json({ success: true, message: `Product ${id} ត្រូវបានលុបជោគជ័យ` });
});

app.listen(3000, () => console.log("REST API running on port 3000"));
```
