## 🐘 ហេតុអ្វីបានជាត្រូវជ្រើសរើស PostgreSQL?

**PostgreSQL** (ត្រូវបានគេស្គាល់ថា Postgres) គឺជាប្រព័ន្ធទិន្នន័យ Open-Source RDBMS កម្រិត Advanced បំផុតលើលោក។

- **ACID Compliance សុក្រឹត ១០០%:** ធានាសុវត្ថិភាពទិន្នន័យខ្ពស់បំផុត
- **Advanced Data Types:** គាំទ្រ UUID, Arrays, Geometric Data, និង **JSONB** (រហ័សស្មើ Document DB)
- **Extensibility:** គាំទ្រ Extensions ល្បីៗដូចជា `PostGIS` (Geospatial) និង `pgvector` (AI/Embeddings)
- **Active Community & Cloud Support:** មាននៅលើ AWS RDS, Supabase, Neon, GCP Cloud SQL

## 🐳 ការដំណើរការ PostgreSQL ជាមួយ Docker Compose

វិធីដ៏ល្អបំផុតក្នុងការ Setup Postgres ក្នុងម៉ាស៊ីនអភិវឌ្ឍន៍ គឺការបង្កើតឯកសារ `docker-compose.yml`៖

```yaml
version: '3.8'

services:
  postgres:
    image: postgres:16-alpine
    container_name: postgres_ecommerce
    restart: always
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: supersecretpassword
      POSTGRES_DB: ecommerce_dev
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

volumes:
  postgres_data:
```

### ពាក្យបញ្ជាបញ្ជា Docker៖
```bash
# ចាប់ផ្តើម Postgres ក្នុង Background
docker compose up -d

# ពិនិត្យមើលដំណើរការ
docker compose ps

# បញ្ឈប់ Container
docker compose down
```

## 💻 ពាក្យបញ្ជា psql CLI សំខាន់ៗ

ដើម្បីចូលទៅកាន់ Interactive Terminal របស់ Postgres៖

```bash
docker exec -it postgres_ecommerce psql -U postgres -d ecommerce_dev
```

| ពាក្យបញ្ជា psql | មុខងារ |
|---|---|
| `\l` | បង្ហាញបញ្ជី Databases ទាំងអស់ |
| `\c database_name` | ភ្ជាប់ទៅកាន់ Database ណាមួយ |
| `\dt` | បង្ហាញបញ្ជី Tables ទាំងអស់ក្នុង Schema បច្ចុប្បន្ន |
| `\d table_name` | បង្ហាញព័ត៌មានលម្អិតនៃ Columns, Data Types, Constraints ក្នុង Table |
| `\q` | ចាកចេញពី psql |

## 🖥️ ការភ្ជាប់តាមរយៈ GUI Tools (TablePlus / DBeaver)

1. ទាញយក **TablePlus** ឬ **DBeaver** (ឥតគិតថ្លៃ)
2. បង្កើត New Connection -> ជ្រើសរើស **PostgreSQL**
3. បំពេញព័ត៌មាន Connection៖
   - **Host:** `localhost` ឬ `127.0.0.1`
   - **Port:** `5432`
   - **User:** `postgres`
   - **Password:** `supersecretpassword`
   - **Database:** `ecommerce_dev`
4. ចុច **Test** រួចចុច **Connect** ដើម្បីមើលតារាង និង Run Query តាម GUI។
