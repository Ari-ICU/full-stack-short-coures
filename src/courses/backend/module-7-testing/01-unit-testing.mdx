## 🧪 អ្វីទៅជា Unit Testing?

**Unit Testing** គឺជាការសរសេរកូដ ដើម្បីយកទៅតេស្តកូដរបស់អ្នក។ វាមិនមែនជាការតេស្តទាំងមូលនោះទេ ប៉ុន្តែជាការតេស្តផ្នែកតូចៗ (Units) ដូចជា Function នីមួយៗ ដើម្បីប្រាកដថាវាធ្វើការបានត្រឹមត្រូវ។

Library ដែលពេញនិយមបំផុតសម្រាប់តេស្តកូដ JavaScript គឺ **Jest**។

### ការដំឡើង Jest

```bash
npm install --save-dev jest
```

> ត្រូវបន្ថែម `"test": "jest"` ទៅក្នុង `package.json` ត្រង់ `scripts`។

### ឧទាហរណ៍នៃការសរសេរកូដ Test

  // នេះគឺជា Function ដែលយើងចង់តេស្ត
  export const add = (a, b) => {
      if (typeof a !== 'number' || typeof b !== 'number') {

      }
      return a + b;
  };

  <TabItem value="utils/math.test.js" label="utils/math.test.js">
  ឯកសារតេស្ត តែងតែមានកន្ទុយ `.test.js` ឬ `.spec.js` ដើម្បីអោយ Jest អាចរកឃើញ។

  ```javascript
  import { add } from './math.js';

  // describe ប្រើសម្រាប់ដាក់ឈ្មោះក្រុមអោយ Tests
  describe('Math Helper Functions', () => {
      
      // it (ឫ test) គឺជាការធ្វើតេស្តមួយករណី
      it('គួរតែបូកលេខ ២ ចូលគ្នាបានត្រឹមត្រូវ', () => {
          const result = add(2, 3);
          expect(result).toBe(5); // រំពឹងថាវាស្មើ ៥
      });

      it('គួរតែបោះ Error ប្រសិនបើមានអថេរជាអក្សរ', () => {
          expect(() => add(2, "3")).toThrow("ត្រូវតែជាលេខ");
      });

  });
  ```
