## 🧍 អ្វីទៅជា Entity?

**Entity** គឺជា Class របស់ JavaScript ដែលតំណាងអោយតារាង (Table) មួយនៅក្នុង Database។ យើងប្រើប្រាស់ Decorators (`@`) ដើម្បីប្រាប់ TypeORM ថាតើ Column មួយណាជាប្រភេទអ្វី។

```tabs
javascript
// entities/User.js
import { EntitySchema } from "typeorm";

  // ដោយសារយើងប្រើ Javascript មិនមែន TypeScript យើងត្រូវប្រើ EntitySchema
  export const User = new EntitySchema({
      name: "User",          // ឈ្មោះ Entity សម្រាប់ TypeORM ស្គាល់
      tableName: "users",    // ឈ្មោះតារាងពិតប្រាកដក្នុង PostgreSQL
      columns: {
          id: {
              primary: true,
              type: "int",
              generated: true // AUTO_INCREMENT / SERIAL
          },
          firstName: {
              type: "varchar",
              length: 100
          },
          email: {
              type: "varchar",
              length: 150,
              unique: true
          },
          isActive: {
              type: "boolean",
              default: true
          },
          createdAt: {
              type: "timestamp",
              createDate: true // អោយ TypeORM បញ្ចូលម៉ោងដោយស្វ័យប្រវត្តិ
          }
      }
  });
```

> [!TIP]
> ពេលអ្នកប្រើ `synchronize: true` នៅក្នុង `DataSource` រាល់ពេលអ្នកបន្ថែម Column ថ្មីចូលទៅក្នុង EntitySchema នេះ TypeORM នឹងរត់ទៅបង្កើត Column នោះក្នុង Database អោយអ្នកដោយស្វ័យប្រវត្តិ!
