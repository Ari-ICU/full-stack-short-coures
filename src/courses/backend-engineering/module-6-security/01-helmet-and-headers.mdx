## 🪖 ហេតុអ្វីបានជាត្រូវបិទបាំង Headers?

តាមលំនាំដើម (Default) Express.js តែងតែផ្ញើ HTTP Header មួយដែលមានឈ្មោះថា `X-Powered-By: Express` ត្រលប់ទៅកាន់ Client វិញ។ 
ទោះបីជាវាមើលទៅមិនមានអ្វីធំដុំ ប៉ុន្តែវាគឺជាការប្រាប់ Hacker ថា "ខ្ញុំប្រើ Express" ដូច្នេះពួកគេអាចស្វែងរកចន្លោះប្រហោង (Vulnerabilities) របស់ Express យកមកវាយប្រហារយើងបាន។

### ការដោះស្រាយជាមួយ Helmet

**Helmet** គឺជាកញ្ចប់ Middleware ដ៏តូចមួយដែលជួយលាក់បាំង Headers បែបនេះ និងបន្ថែមនូវ Headers សុវត្ថិភាពជាច្រើនទៀតដោយស្វ័យប្រវត្តិ។ 

*វាមិនមែនជាថ្នាំទិព្វដែលអាចការពារកម្មវិធីរបស់អ្នក ១០០% ទេ ប៉ុន្តែវាជារបាំងការពារទី១ ដ៏មានប្រសិទ្ធភាពដែលគ្រប់គម្រោង Backend គួរតែមាន។*

```bash
npm install helmet
```

```tabs
javascript
// app.js
import express from 'express';
import helmet from 'helmet';

const app = express();

// គ្រាន់តែដាក់វាជា Middleware នៅខាងលើគេ នោះវានឹងធ្វើការដោយស្វ័យប្រវត្តិ
app.use(helmet());

app.get('/', (req, res) => {
    res.json({ message: "Hello Secure World!" });
});

app.listen(3000);
```

> [!TIP]
> អ្នកក៏អាចបិទ `X-Powered-By` ដោយមិនចាំបាច់ប្រើ Helmet ក៏បាន តាមរយៈកូដ `app.disable('x-powered-by');`
