## 🔍 ការបញ្ជាក់សុវត្ថិភាពទិន្នន័យ (Input Validation & Sanitization)

នៅក្នុង Module ទី២ យើងបានរៀនប្រើ **Zod** ដើម្បីឆែកមើល Validation ម្តងរួចមកហើយ។ 
ចំនុចសំខាន់នៅក្នុងសុវត្ថិភាពគឺ **Sanitization (ការសំអាតទិន្នន័យ)**។ 

Hacker អាចបញ្ជូនកូដ JavaScript (XSS) ឫកូដ SQL (SQL Injection) មកតាមរយៈទិន្នន័យធម្មតាដូចជា ឈ្មោះ ឬ អត្ថបទបញ្ចេញមតិ (Comments)។

> ការប្រើប្រាស់ Validation Library ដូចជា Zod ឬ Joi ជួយដោះស្រាយបញ្ហានេះបានយ៉ាងច្រើន ព្រោះវាកាត់ចោល (Strip) នូវ Field ដែលយើងមិនបានកំណត់ ព្រមទាំងពិនិត្យប្រវែង និងប្រភេទអក្សរយ៉ាងត្រឹមត្រូវ។

*(យើងបានរៀនពីចំណុចនេះរួចហើយនៅក្នុង Module 2 ដូច្នេះសូមមើលមេរៀនមុនសម្រាប់កូដឧទាហរណ៍នៃការប្រើ Zod)*
