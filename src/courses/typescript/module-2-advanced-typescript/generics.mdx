## 🧬 អ្វីទៅជា Generics?

ស្រមៃថាអ្នកចង់សរសេរ Function មួយដើម្បីយកធាតុទីមួយពី Array។ 

```typescript
function getFirstString(arr: string[]): string {
  return arr[0];
}

function getFirstNumber(arr: number[]): number {
  return arr[0];
}
```

ដើម្បីឲ្យ Function នេះអាចប្រើបានជាមួយទិន្នន័យគ្រប់ប្រភេទ តើយើងគួរប្រើ `any` មែនទេ?
**ទេ!** ប្រសិនបើប្រើ `any` យើងនឹងបាត់បង់មុខងារពិនិត្យកំហុស (Type Checking) និង Autocomplete របស់ TypeScript ទាំងអស់។

ដំណោះស្រាយដ៏ល្អបំផុតគឺ **Generics**! Generics ប្រៀបដូចជា "អថេរ" (Variables) សម្រាប់ Types អញ្ចឹង។

---

## 🛠️ ការបង្កើត Generic Functions

យើងប្រើសញ្ញា `<T>` (ឬឈ្មោះផ្សេងៗក៏បាន តែគេនិយមប្រើ `T` ដែលមកពីពាក្យ Type) នៅពីក្រោយឈ្មោះ Function។

```typescript
// យើងប្រាប់ TypeScript ថា វានឹងទទួលបាន Type 'T' មួយ
// បន្ទាប់មក Array ក៏ត្រូវតែជាប្រភេទ 'T' 
// និងតម្លៃដែល return មកវិញ ក៏ត្រូវតែជាប្រភេទ 'T' ដែរ
function getFirstElement<T>(arr: T[]): T {
  return arr[0];
}

// ពេលហៅប្រើជាមួយលេខ (T នឹងក្លាយជា number)
let firstNumber = getFirstElement([10, 20, 30]); 
// firstNumber ត្រូវបានស្គាល់ស្វ័យប្រវត្តិថាជា number

// ពេលហៅប្រើជាមួយអក្សរ (T នឹងក្លាយជា string)
let firstWord = getFirstElement(["Apple", "Banana"]); 
// firstWord ត្រូវបានស្គាល់ស្វ័យប្រវត្តិថាជា string
```

អស្ចារ្យមែនទេ? Function តែមួយអាចប្រើបានគ្រប់ទិន្នន័យដោយមិនបាត់បង់ Type ឡើយ!

## 🏗️ Generics ជាមួយ Interfaces

យើងក៏អាចប្រើ Generics ជាមួយ Interface បានដែរ ឧទាហរណ៍ដូចជាការឆ្លើយតប (Response) ពី API ដែលមានទម្រង់ដូចៗគ្នា តែខុសទិន្នន័យផ្នែកខាងក្នុង។

```typescript
// Data អាចជាអីក៏បាន (T)
interface ApiResponse<T> {
  status: number;
  message: string;
  data: T;
}

// ឧបមាថា User Type មានរាងបែបនេះ
type User = { id: number; name: string };

// ពេលយើងប្រើ ApiResponse យើងត្រូវបញ្ជាក់ប្រាប់វាថា T នោះគឺជា User
let response1: ApiResponse<User> = {
  status: 200,
  message: "Success",
  data: { id: 1, name: "Sok" }
};

// ពេលខ្លះ Data អាចជា Array នៃ String វិញ
let response2: ApiResponse<string[]> = {
  status: 200,
  message: "Success",
  data: ["Apple", "Banana", "Orange"]
};
```

Generics គឺជាគន្លឹះដ៏សំខាន់ក្នុងការបង្កើតកូដដែលមានភាពបត់បែនខ្ពស់ (Reusable Code) នៅក្នុង TypeScript ជាពិសេសនៅពេលអ្នកប្រើប្រាស់បណ្ណាល័យ (Libraries) ធំៗដូចជា React។
