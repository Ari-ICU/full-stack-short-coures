## 🔍 អ្វីទៅជា Type Narrowing?

នៅពេលអ្នកប្រើ **Union Types** (ឧទាហរណ៍ `number | string`) TypeScript នឹងមិនអនុញ្ញាតឲ្យអ្នកហៅ Methods ឬ Operations ណាដែលមិនអាចប្រើបានសម្រាប់ទាំងពីរប្រភេទនោះទេ។ 

**Type Narrowing** គឺជាដំណើរការនៃការសរសេរកូដ ដើម្បីជួយបញ្ជាក់ប្រាប់ TypeScript (តាមរយៈ Logic ដូចជា `if/else`) ថាប្រភេទរបស់ទិន្នន័យនោះគឺជាអ្វីឲ្យប្រាកដនៅក្នុង Block នីមួយៗ។

---

## ១. ការប្រើប្រាស់ `typeof` (Type Guards)

នេះជាវិធីសាមញ្ញបំផុតសម្រាប់ primitive types ដូចជា `string`, `number`, `boolean`, `symbol` ជាដើម។

```typescript
function printLength(textOrNumber: string | number) {
  // textOrNumber.length នឹង Error នៅត្រង់នេះ ព្រោះ number អត់មាន length ទេ
  
  if (typeof textOrNumber === "string") {
    // នៅក្នុង if នេះ TypeScript ដឹងថាវាជា string 100%
    console.log(`ចំនួនអក្សរ: ${textOrNumber.length}`);
  } else {
    // នៅក្នុង else នេះ TypeScript ដឹងថាវាត្រូវតែជា number
    console.log(`លេខគឺ: ${textOrNumber}`);
  }
}
```

## ២. ការប្រើប្រាស់ `instanceof`

`instanceof` ត្រូវប្រើសម្រាប់ត្រួតពិនិត្យថា Object មួយត្រូវបានបង្កើតចេញពី Class ណា (មានប្រយោជន៍ពេលធ្វើការជាមួយ DOM elements ឬ Custom Classes)។

```typescript
function formatDate(value: string | Date) {
  if (value instanceof Date) {
    // TypeScript ដឹងថា 'value' ជា Date object
    return value.toISOString();
  } else {
    // 'value' ជា string
    return value;
  }
}
```

## ៣. ការប្រើប្រាស់ `in` Operator សម្រាប់ Objects

ចុះបើអ្នកមាន Objects ពីរផ្សេងគ្នា? តើធ្វើដូចម្តេចដើម្បីបំបែកវា? អ្នកអាចប្រើ `in` ដើម្បីឆែកមើលថា Property ណាមួយមាននៅក្នុង Object នោះឬអត់។

```typescript
type Admin = {
  name: string;
  role: string; // Admin មាន role
};

type User = {
  name: string;
  email: string; // User ធម្មតាគ្មាន role ទេ, តែមាន email
};

function login(person: Admin | User) {
  if ("role" in person) {
    // បើវាមាន Property "role", វាប្រាកដជា Admin
    console.log(`សូមស្វាគមន៍លោក Admin: ${person.name}, តួនាទី: ${person.role}`);
  } else {
    // បើមិនមែនទេ វាជា User
    console.log(`សូមស្វាគមន៍: ${person.name}, អ៊ីមែល: ${person.email}`);
  }
}
```

ការប្រើប្រាស់ Type Narrowing ធ្វើឲ្យកូដរបស់អ្នកមានសុវត្ថិភាពខ្ពស់ និងជួយឲ្យមុខងារ Autocomplete របស់ VS Code ដំណើរការបានយ៉ាងត្រឹមត្រូវទៅតាមលក្ខខណ្ឌនីមួយៗ!
