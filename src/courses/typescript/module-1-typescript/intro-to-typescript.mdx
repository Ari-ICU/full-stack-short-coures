## 🚀 អ្វីទៅជា TypeScript?

<img src="https://upload.wikimedia.org/wikipedia/commons/4/4c/Typescript_logo_2020.svg" alt="TypeScript Logo" width="120" style={{ display: "block", margin: "0 auto" }} />


**TypeScript** គឺជាភាសាសរសេរកូដមួយដែលបង្កើតឡើងដោយក្រុមហ៊ុន Microsoft។ តាមការពិតទៅ TypeScript គឺជា **JavaScript + Static Typing**។ អ្វីៗទាំងអស់ដែលអ្នកអាចធ្វើបានក្នុង JavaScript អ្នកក៏អាចធ្វើបានក្នុង TypeScript ដូចគ្នា គ្រាន់តែវាមានមុខងារបន្ថែមក្នុងការកំណត់ប្រភេទនទិន្នន័យ (Types) អោយបានច្បាស់លាស់។

ចំណាំ៖ Browser មិនអាចយល់ពីកូដ TypeScript ទេ ដូច្នេះនៅពេលអ្នក Run កម្មវិធី កូដ TypeScript របស់អ្នកនឹងត្រូវបានបំប្លែង (Compile) ទៅជាកូដ JavaScript ធម្មតាវិញ។

## ⚖️ Static Typing ធៀបនឹង Dynamic Typing

នៅក្នុង **JavaScript (Dynamic Typing)** អ្នកមិនចាំបាច់បញ្ជាក់ប្រាប់វាទេថា អថេរមួយជាលេខ ឬ ជាអក្សរ។ នេះធ្វើអោយងាយស្រួលសរសេរ ប៉ុន្តែងាយនឹងមានកំហុស។

```javascript
// JavaScript ធម្មតា (អាចមានបញ្ហា)
let age = 25;
age = "ម្ភៃប្រាំ"; // មិនមាន Error ទេ តែអាចធ្វើអោយខូចកម្មវិធីបើអ្នកយកវាទៅបូកលេខ
```

នៅក្នុង **TypeScript (Static Typing)** អ្នកត្រូវកំណត់ប្រភេទអោយច្បាស់លាស់៖

```typescript
// TypeScript (មានសុវត្ថិភាពខ្ពស់)
let age: number = 25;
age = "ម្ភៃប្រាំ"; // ❌ នឹងលោត Error ពណ៌ក្រហមភ្លាមៗក្នុង VS Code!
```

## 📦 Basic Types នៅក្នុង TypeScript

ការកំណត់ Type នៅក្នុង TypeScript គឺសាមញ្ញណាស់ គ្រាន់តែប្រើសញ្ញាពីរចំនុច `:` ហើយបន្ទាប់មកឈ្មោះ Type។

### 1. Primitive Types (String, Number, Boolean)
```typescript
let firstName: string = "Sok";
let score: number = 95.5;
let isGraduated: boolean = true;
```

### 2. Arrays (បញ្ជី)
ដើម្បីកំណត់ថាអថេរមួយជា Array ដែលផ្ទុកទិន្នន័យប្រភេទអ្វីមួយ យើងត្រូវដាក់ `[]` ពីក្រោយឈ្មោះ Type។

```typescript
// Array ដែលផ្ទុកតែអក្សរ
let hobbies: string[] = ["Reading", "Coding", "Gaming"];

// Array ដែលផ្ទុកតែលេខ
let prices: number[] = [10, 20, 30];
```

### 3. The `any` Type
`any` មានន័យថាទិន្នន័យអាចជាអ្វីក៏បាន (វាធ្វើអោយ TypeScript ត្រឡប់ទៅជា JavaScript ធម្មតាវិញ)។ **គួរចៀសវាងការប្រើ `any` តាមដែលអាចធ្វើបាន!**

```typescript
let mysteryData: any = "Hello";
mysteryData = 100; // ដំណើរការធម្មតា ព្រោះវាជា 'any'
```

ការប្រើប្រាស់ TypeScript ដំបូងអាចហាក់ដូចជារញ៉េរញ៉ៃព្រោះអ្នកត្រូវសរសេរកូដច្រើនជាងមុនបន្តិច ប៉ុន្តែសម្រាប់ Project ធំៗ វាគឺជារបាំងការពារដ៏រឹងមាំបំផុតមិនអោយកម្មវិធីរបស់អ្នកងាយនឹងខូច (Crash) នោះទេ!
