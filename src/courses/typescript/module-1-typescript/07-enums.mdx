## 🚦 អ្វីទៅជា Enums?

**Enum** (អានថា អ៊ីណាំ) មកពីពាក្យពេញថា Enumeration មានន័យថា ការរាយឈ្មោះតម្លៃ។ 
វាជាមុខងារពិសេសមួយរបស់ TypeScript (ដែល JavaScript មិនមាន) សម្រាប់អនុញ្ញាតអោយអ្នកកំណត់ក្រុមនៃតម្លៃថេរ (Constants) ដែលទាក់ទងគ្នា ដើម្បីអោយកូដរបស់អ្នកងាយស្រួលអានជាងមុន។

ឧទាហរណ៍ ស្រមៃថាអ្នកចង់តំណាងអោយទំហំអាវ (Small, Medium, Large)។ 
បើអ្នកប្រើលេខ (1=Small, 2=Medium, 3=Large) កូដរបស់អ្នកនឹងមើលទៅពិបាកយល់ណាស់។ នៅទីនេះហើយដែល Enum អាចជួយបាន!

## 1. Numeric Enums (Enum ជាលេខ)

តាមលំនាំដើម TypeScript នឹងភ្ជាប់តម្លៃជា "លេខ" ទៅកាន់ឈ្មោះនិមួយៗនៅក្នុង Enum ដោយចាប់ផ្តើមពីលេខ `0`។

```ts
enum Size {
  Small,  // ស្មើ 0
  Medium, // ស្មើ 1
  Large,  // ស្មើ 2
}

let myShirtSize: Size = Size.Medium;

console.log(myShirtSize); // លទ្ធផល: 1
```

ប្រសិនបើអ្នកមិនចង់អោយវាចាប់ផ្តើមពីលេខ 0 ទេ អ្នកអាចកំណត់លេខអោយវាដោយខ្លួនឯងបាន៖
```ts
enum Size {
  Small = 1, // ឥឡូវវាចាប់ផ្តើមពី 1
  Medium,    // ស្មើ 2
  Large,     // ស្មើ 3
}
```

## 2. String Enums (Enum ជាអក្សរ)

ការប្រើលេខពេលខ្លះក៏ពិបាកក្នុងការសរសេរកូដដែរ (Debug) ព្រោះយើងមិនដឹងថាលេខ 2 មានន័យថាម៉េចទេ។ 
ដូច្នេះអ្នកអភិវឌ្ឍន៍ភាគច្រើននិយមប្រើ **String Enums** ជាជាងលេខ ដោយយើងកំណត់អក្សរផ្ទាល់ទៅអោយវាជានិច្ច!

```ts
enum Direction {
  Up = "UP",
  Down = "DOWN",
  Left = "LEFT",
  Right = "RIGHT"
}

// ពេលសរសេរកូដ យើងគ្រាន់តែវាយ Direction. វានឹងលោតពាក្យទាំង ៤ មកអោយរើស!
function moveCharacter(dir: Direction) {
  if (dir === Direction.Up) {
    console.log("កំពុងរត់ទៅលើ...");
  }
}

moveCharacter(Direction.Up); // ត្រឹមត្រូវ ✅
// moveCharacter("UP"); // ❌ Error! អ្នកមិនអាចវាយអក្សរ "UP" ផ្ទាល់បានទេ ត្រូវតែហៅតាមរយៈ Direction.Up
```

> **អត្ថប្រយោជន៍:** Enums ជួយកាត់បន្ថយកំហុសអក្ខរាវិរុទ្ធ (Spelling mistakes) ព្រោះ VS Code នឹងលោតបញ្ជីឈ្មោះអោយអ្នករើសដោយស្វ័យប្រវត្តិ!
