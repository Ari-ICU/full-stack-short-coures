## 🛠️ Typing Functions (ការកំណត់ Type សម្រាប់អនុគមន៍)

នៅក្នុង JavaScript ការបង្កើត Function គឺមិនមានការកំហិតប្រភេទទិន្នន័យ (Data Types) ដែលត្រូវបញ្ជូនទៅក្នុង ឬ ត្រឡប់មកវិញនោះទេ។ ប៉ុន្តែនៅក្នុង TypeScript យើងត្រូវកំណត់វាឲ្យបានច្បាស់លាស់។

### 1. Parameters និង Return Types

យើងអាចកំណត់ Type ឲ្យ **Parameters** និង **តម្លៃដែល Function ត្រឡប់មកវិញ (Return Type)**៖

```typescript
// 'name' ត្រូវតែជា string
// Function នេះត្រូវតែ return ត្រឡប់មកវិញនូវ string
function greet(name: string): string {
  return `សួស្តី ${name}!`;
}

greet("Sok"); // ✅ ត្រឹមត្រូវ
greet(123);   // ❌ Error: Argument of type 'number' is not assignable to parameter of type 'string'.
```

### 2. អនុគមន៍ដែលមិន Return អ្វីសោះ (Void)

ប្រសិនបើ Function មួយគ្រាន់តែធ្វើការងារអ្វីមួយដោយមិនមាន `return` តម្លៃអ្វីទេ យើងប្រើ type `void`៖

```typescript
function logMessage(message: string): void {
  console.log("សាររបស់អ្នកគឺ:", message);
}
```

## 📦 Typing Objects (ការកំណត់ Type សម្រាប់ Object)

Objects គឺជាកន្លែងដែល TypeScript បង្ហាញភាពខ្លាំងរបស់វា។ យើងអាចកំណត់ថា Object មួយត្រូវតែមាន Property អ្វីខ្លះ។

### 1. ការកំណត់ Object Type ជាមូលដ្ឋាន

```typescript
// កំណត់ថា user ត្រូវតែមាន name (string) និង age (number)
let user: { name: string; age: number } = {
  name: "Bopha",
  age: 22
};

// ❌ នឹង Error ប្រសិនបើបាត់ age ឬ name
let user2: { name: string; age: number } = {
  name: "Dara" 
}; 
```

### 2. Optional Properties (Property ដែលមានក៏បាន អត់ក៏បាន)

ជួនកាល ទិន្នន័យខ្លះនៅក្នុង Object មិនចាំបាច់មានជានិច្ចទេ។ យើងអាចប្រើសញ្ញាសួរ `?` ដើម្បីបញ្ជាក់ថាវាជា **Optional**៖

```typescript
let product: { 
  name: string; 
  price: number; 
  description?: string; // 👈 អាចមាន ឬ គ្មានក៏បាន
} = {
  name: "MacBook Air",
  price: 999
  // មិនដាក់ description ក៏មិន Error ដែរ
};
```

### 3. Readonly Properties (Property ដែលមិនអាចកែប្រែបាន)

ប្រសិនបើអ្នកចង់អោយ Property ណាមួយមិនអាចប្តូរតម្លៃបានបន្ទាប់ពីបានបង្កើតហើយ អ្នកអាចប្រើពាក្យ `readonly`៖

```typescript
let myCar: {
  readonly brand: string; // 👈 មិនអាចកែប្រែបានឡើយ
  year: number;
} = {
  brand: "Toyota",
  year: 2020
};

myCar.year = 2022; // ✅ អាចកែបាន
myCar.brand = "Honda"; // ❌ Error: Cannot assign to 'brand' because it is a read-only property.
```

ការប្រើប្រាស់ Types សម្រាប់ Functions និង Objects ជួយឲ្យកូដរបស់យើងច្បាស់លាស់ ងាយយល់ និងកាត់បន្ថយកំហុសបានយ៉ាងច្រើន!
