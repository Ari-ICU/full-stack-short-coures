## 🚀 អ្វីទៅជា Express.js?

<div align="center">
  <img src="https://upload.wikimedia.org/wikipedia/commons/6/64/Expressjs.png" alt="Express.js Logo" width="200" />
</div>

ទោះបីជា **Node.js** អាចអោយយើងបង្កើត Server បានដោយខ្លួនវាក៏ពិតមែន ប៉ុន្តែការសរសេរកូដដោយប្រើ Node.js សុទ្ធ (Core `http` module) គឺមានភាពស្មុគស្មាញ សរសេរកូដវែងឆ្ងាយ និងពិបាកគ្រប់គ្រង។

**Express.js** គឺជា Web Application Framework ដ៏តូច និងរហ័ស (Minimalist) សម្រាប់ Node.js ដែលជួយសម្រួលដល់ការបង្កើត Server, រៀបចំ Routing, និងគ្រប់គ្រង Request/Response បានយ៉ាងងាយស្រួល។

---

## 🛠️ ការបង្កើត Server ដំបូងរបស់អ្នក

ដើម្បីប្រើប្រាស់ Express អ្នកត្រូវដំឡើងវាតាមរយៈ NPM សិន៖

```bash
npm init -y
npm install express
```

បន្ទាប់មក អ្នកអាចបង្កើត Server សាមញ្ញមួយបានដោយកូដត្រឹមតែប៉ុន្មានបន្ទាត់ប៉ុណ្ណោះ៖

```javascript
// នាំចូល (Import) express
const express = require('express');

// បង្កើតកម្មវិធី express (app)
const app = express();
const port = 3000;

// បង្កើត Route សាមញ្ញមួយ
app.get('/', (req, res) => {
  res.send('សួស្តីពី Express Server!');
});

// ចាប់ផ្តើមបើក Server អោយរង់ចាំស្តាប់ Request
app.listen(port, () => {
  console.log(`Server កំពុងដំណើរការលើ http://localhost:${port}`);
});
```

## 🚦 ការរៀបចំ Routing

**Routing** គឺជារបៀបដែលកម្មវិធីរបស់អ្នកឆ្លើយតបទៅនឹងការស្នើសុំ (Request) របស់អ្នកប្រើប្រាស់តាមរយៈ URL និង HTTP Method ជាក់លាក់ណាមួយ។ 

នៅក្នុង Express, ការសរសេរ Route មានទម្រង់ដូចខាងក្រោម៖
`app.METHOD(PATH, HANDLER)`

- `app`: គឺជាកម្មវិធី express របស់អ្នក
- `METHOD`: ជា HTTP request method (ដូចជា get, post, put, delete)
- `PATH`: ជាផ្លូវ (URL path) នៅលើ server របស់អ្នក
- `HANDLER`: ជាអនុគមន៍ (Function) ដែលនឹងដំណើរការពេល Route នោះត្រូវគេហៅ។

### ឧទាហរណ៍នៃ Routes ផ្សេងៗគ្នា

```javascript
// ទទួលទិន្នន័យ (Read)
app.get('/users', (req, res) => {
  res.send('ទទួលបានបញ្ជីឈ្មោះអ្នកប្រើប្រាស់');
});

// បង្កើតទិន្នន័យថ្មី (Create)
app.post('/users', (req, res) => {
  res.send('អ្នកប្រើប្រាស់ថ្មីត្រូវបានបង្កើត');
});

// កែប្រែទិន្នន័យ (Update)
app.put('/users/:id', (req, res) => {
  res.send(`អ្នកប្រើប្រាស់លេខសម្គាល់ ${req.params.id} ត្រូវបានកែប្រែ`);
});

// លុបទិន្នន័យ (Delete)
app.delete('/users/:id', (req, res) => {
  res.send(`អ្នកប្រើប្រាស់លេខសម្គាល់ ${req.params.id} ត្រូវបានលុប`);
});
```

### ការចាប់យកទិន្នន័យពី Request

ជាញឹកញាប់អ្នកត្រូវយកទិន្នន័យដែលអ្នកប្រើប្រាស់បញ្ជូនមក។ Express ផ្តល់វិធីងាយៗ ៣ យ៉ាង៖

1. **`req.params`**: សម្រាប់ទិន្នន័យដែលមានក្នុង URL Path ផ្ទាល់ (ឧ. `/users/123` យកលេខ 123)
2. **`req.query`**: សម្រាប់ទិន្នន័យដែលមានសញ្ញា `?` ក្នុង URL (ឧ. `/search?keyword=apple`)
3. **`req.body`**: សម្រាប់ទិន្នន័យដែលបញ្ជូនមកតាមរយៈ POST Request (ត្រូវដំឡើង `express.json()` middleware សិន)

នៅក្នុងមេរៀនបន្ទាប់ យើងនឹងរៀនពីរបៀបរចនា Route ទាំងនេះអោយត្រូវតាមស្តង់ដារ **RESTful API** ដែលពិភពលោកកំពុងប្រើប្រាស់។
