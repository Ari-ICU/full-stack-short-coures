## 🚀 JavaScript លើសពី Browser

អស់រយៈពេលជាយូរមកហើយ JavaScript ត្រូវបានដាក់កម្រិតឱ្យប្រើតែនៅលើ web browser ប៉ុណ្ណោះ។ វាត្រូវបានប្រើដើម្បីធ្វើឱ្យប៊ូតុងអាចចុចបាន ផ្ទៀងផ្ទាត់ទម្រង់ (forms) និងបង្កើតចលនាសាមញ្ញៗ (animations)។

នៅក្នុងឆ្នាំ ២០០៩ លោក Ryan Dahl បានយក **V8 JavaScript Engine** ដ៏លឿនបំផុតរបស់ Google Chrome មកដាក់បញ្ចូលទៅក្នុងកម្មវិធី C++ មួយ ហើយដាក់ឈ្មោះវាថា **Node.js**។

ភ្លាមៗនោះ JavaScript អាចដំណើរការដោយផ្ទាល់នៅលើកុំព្យូទ័រ ឬ server របស់អ្នក ក្រៅពី browser!

---

## ⚙️ ហេតុអ្វីត្រូវប្រើ Node.js?

1. **ភាសាតែមួយសម្រាប់គ្រប់យ៉ាង៖** អ្នកអាចសរសេរទាំង frontend (React) និង backend (Node) របស់អ្នកដោយប្រើ JavaScript។
2. **Asynchronous & Non-Blocking:** Node.js ត្រូវបានរចនាឡើងដើម្បីគ្រប់គ្រងការតភ្ជាប់រាប់ពាន់ក្នុងពេលដំណាលគ្នាយ៉ាងមានប្រសិទ្ធភាព ដែលធ្វើឱ្យវាស័ក្តិសមបំផុតសម្រាប់កម្មវិធី real-time ដូចជាកម្មវិធីឆាត និងការស្ទ្រីម (streaming)។
3. **ប្រព័ន្ធអេកូឡូស៊ីដ៏ធំធេង៖** Node Package Manager (NPM) គឺជាប្រព័ន្ធអេកូឡូស៊ីដ៏ធំបំផុតនៃបណ្ណាល័យ (libraries) open-source នៅក្នុងពិភពលោក។

---

## 🖥️ Client-Side ប្រៀបធៀបជាមួយ Server-Side

- **Client-Side (Browser):** JavaScript ធ្វើអន្តរកម្មជាមួយ DOM (HTML elements), គ្រប់គ្រងការចុចរបស់អ្នកប្រើប្រាស់ និងធ្វើការស្នើសុំ API។
- **Server-Side (Node.js):** JavaScript ធ្វើអន្តរកម្មជាមួយប្រព័ន្ធឯកសារ (អាន/សរសេរឯកសារ), ភ្ជាប់ទៅកាន់មូលដ្ឋានទិន្នន័យ (PostgreSQL, MongoDB) និងគ្រប់គ្រង HTTP network requests ដែលចូលមក។

*ចំណាំ៖ នៅក្នុង Node.js មិនមាន `window` ឬ `document` object ទេ ព្រោះវាមិនមាន browser ឡើយ!*

## 🛠️ Node.js Server ដំបូងរបស់អ្នក

Node.js ភ្ជាប់មកជាមួយ modules ស្រាប់ៗ។ តោះប្រើ `http` module ដើម្បីបង្កើត web server មួយ។

បង្កើតឯកសារមួយឈ្មោះថា `server.js`៖

```javascript
const http = require('http');

const server = http.createServer((req, res) => {
  res.statusCode = 200;
  res.setHeader('Content-Type', 'text/plain');
  res.end('សួស្តី Backend Architecture!\n');
});

const PORT = 3000;
server.listen(PORT, () => {
  console.log(`Server កំពុងដំណើរការនៅ http://localhost:${PORT}/`);
});
```

ដើម្បីដំណើរការវា អ្នកត្រូវវាយ `node server.js` នៅក្នុង terminal របស់អ្នក។ អ្នកទើបតែបានបង្កើត backend server មួយដែលដំណើរការបាន ក្នុងចំនួនតិចជាង ១០ បន្ទាត់កូដ!
