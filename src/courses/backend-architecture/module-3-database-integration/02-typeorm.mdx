## 🏗️ អ្វីទៅជា ORM?

**ORM (Object-Relational Mapping)** គឺជាបច្ចេកទេសដែលអនុញ្ញាតឱ្យអ្នកធ្វើការជាមួយ Database ដោយប្រើ **"Objects"** (ដូចជា Classes ក្នុង TypeScript) ជាជាងការសរសេរកូដ SQL (`SELECT * FROM users`) ដោយផ្ទាល់។ 

**TypeORM** គឺជា ORM ដ៏មានប្រជាប្រិយភាពបំផុតមួយសម្រាប់ Node.js និង TypeScript (វាអាចប្រើជាមួយ JS ធម្មតាក៏បានដែរ)។

### 💡 ហេតុអ្វីត្រូវប្រើ TypeORM?
- **សរសេរកូដស្អាត:** កូដរៀបចំជា Classes មានរបៀបរៀបរយល្អ។
- **ងាយផ្លាស់ប្តូរ:** បើថ្ងៃណាមួយអ្នកចង់ដូរពី Postgres ទៅ MySQL មិនបាច់សរសេរកូដឡើងវិញទេ។
- **មិនសូវមានកំហុស:** TypeORM ចេះចាប់កំហុស Data Type ពេលយើងសរសេរកូដ (ជាមួយ TypeScript)។
- **Migrations:** ងាយស្រួលក្នុងការគ្រប់គ្រងការផ្លាស់ប្តូររចនាសម្ព័ន្ធ Table នៅពេលគម្រោងកាន់តែធំ។

## 🛠️ ការប្រើប្រាស់ជាមូលដ្ឋាន (Entities)

នៅក្នុង TypeORM, គ្រប់ Table នៅក្នុង Database ត្រូវមានកូដ **Entity** (Class មួយ) ដើម្បីតំណាងអោយវា។

ឧទាហរណ៍ ការបង្កើត Table `User` តាមរយៈ TypeORM (ជាទម្រង់ TypeScript):

```typescript
import { Entity, PrimaryGeneratedColumn, Column } from "typeorm"

@Entity("users") // ប្រាប់ថា Class នេះតំណាងអោយ Table ឈ្មោះ users
export class User {
    @PrimaryGeneratedColumn() // តំណាងអោយ Primary Key ស្វ័យប្រវត្តិ (SERIAL)
    id: number

    @Column({ type: "varchar", length: 100 })
    firstName: string

    @Column({ type: "varchar", length: 100 })
    lastName: string

    @Column({ type: "int" })
    age: number
    
    @Column({ default: true })
    isActive: boolean
}
```

## 🔄 ការធ្វើ CRUD ជាមួយ Repository Pattern

នៅពេលមាន Entity ហើយ យើងមិនសរសេរ `INSERT INTO` ទេ យើងប្រើ **Repository** ដែលផ្តល់ដោយ TypeORM ដើម្បីសរសេរ និងអានទិន្នន័យប្រៀបដូចជាការហៅមុខងាររបស់ Array អញ្ចឹង។

```typescript
import { AppDataSource } from "./data-source"
import { User } from "./entity/User"

// ទាញយកឃ្លាំង (Repository) សម្រាប់តារាង User
const userRepository = AppDataSource.getRepository(User)

// ១. ការបង្កើតថ្មី (Create)
const newUser = new User()
newUser.firstName = "Sokha"
newUser.lastName = "Sao"
newUser.age = 25
await userRepository.save(newUser)

// ២. ការស្វែងរក (Read)
// រកអ្នកប្រើប្រាស់ទាំងអស់
const allUsers = await userRepository.find()

// រកអ្នកប្រើប្រាស់ដែលអាយុលើសពី ២០ និងនៅសកម្ម
const activeUsers = await userRepository.find({
    where: {
        isActive: true,
        age: MoreThan(20)
    }
})

// ៣. ការកែប្រែ (Update)
const userToUpdate = await userRepository.findOneBy({ id: 1 })
if (userToUpdate) {
    userToUpdate.age = 26
    await userRepository.save(userToUpdate)
}

// ៤. ការលុប (Delete)
await userRepository.remove(userToUpdate)
```

អ្នកនឹងសម្គាល់ឃើញថាកូដខាងលើគឺសុទ្ធតែជា **JavaScript/TypeScript សុទ្ធ** គ្មានពាក្យកាត់ SQL បន្តិចសោះ។ នេះគឺជាភាពអស្ចារ្យរបស់ TypeORM ដែលធ្វើអោយកូដ Backend របស់យើងកាន់តែទំនើប និងមានស្តង់ដារ។
