## 🔐 Authentication ទល់នឹង Authorization

- **Authentication (ការបញ្ជាក់អត្តសញ្ញាណ):** "តើអ្នកជានរណា?" ដំណើរការនេះកើតឡើងនៅពេលអ្នកបញ្ចូល Email និង Password ដើម្បី **Login**។
- **Authorization (ការផ្តល់សិទ្ធិ):** "តើអ្នកមានសិទ្ធិធ្វើអ្វីខ្លះ?" ឧទាហរណ៍ ទោះបីជាអ្នកបាន Login ក៏ដោយ អ្នកមិនមានសិទ្ធិលុបទិន្នន័យគេទេ ព្រោះអ្នកមិនមែនជា Admin។

---

## 🎟️ អ្វីទៅជា JSON Web Token (JWT)?

កាលពីមុន ពេលយើង Login រួច Server បង្កើតក្រដាសមួយសន្លឹក (Session) ទុកក្នុង Database ហើយផ្ញើលេខកូដសម្ងាត់តាមរយៈ Cookie។ របៀបនេះពិបាកគ្រប់គ្រងពេលយើងមាន Server ច្រើន (Mobile App ក៏ពិបាកប្រើ)។

**JWT** ដោះស្រាយបញ្ហានេះដោយ៖
១. ពេលអ្នក Login ត្រូវ, Server នឹងខ្ចប់ព័ត៌មានរបស់អ្នក (ឧ. `id: 1, role: 'admin'`) ទៅជាអក្សរវែងមួយ (Token) ហើយយកពាក្យសម្ងាត់ (Secret Key) របស់ Server មកស៊ីញ៉េ (Sign) ពីលើវា។
២. បន្ទាប់មក Server ផ្ញើ Token នោះទៅឱ្យអ្នកប្រើប្រាស់រក្សាទុក (ឧទាហរណ៍ ទុកក្នុង LocalStorage)។
៣. រាល់ពេលអ្នកប្រើប្រាស់ចង់ហៅ API (ឧទាហរណ៍ មើលប្រវត្តិទិញទំនិញ) ពួកគេត្រូវផ្ញើ Token នោះមកវិញ។
៤. Server មិនបាច់សួរ Database ទេ វាគ្រាន់តែពិនិត្យមើល "ហត្ថលេខា" លើ Token នោះ។ បើហត្ថលេខាត្រូវ និងមិនទាន់ហួសកំណត់ (Expired) វានឹងអនុញ្ញាត។

## 🛠️ ការប្រើប្រាស់ JWT ក្នុង Express

**១. ដំឡើងកញ្ចប់ `jsonwebtoken`:**
```bash
npm install jsonwebtoken
```

**២. ការបង្កើត Token ពេល Login (Sign):**
```javascript
const jwt = require('jsonwebtoken');

app.post('/api/login', (req, res) => {
    // ឧបមាថា User បានផ្តល់អុីមែល និងលេខសម្ងាត់ត្រឹមត្រូវ
    const user = { id: 123, role: 'user' }; 
    const SECRET_KEY = "my_super_secret_key"; // ជាក់ស្តែងត្រូវទុកក្នុង .env
    
    // បង្កើត Token ដោយមានសុពលភាព ១ម៉ោង
    const token = jwt.sign(user, SECRET_KEY, { expiresIn: '1h' });
    
    res.json({ message: "Login ជោគជ័យ", token });
});
```

**៣. បង្កើត Middleware ដើម្បីការពារ Routes (Verify):**
យើងបង្កើត Middleware មួយសម្រាប់ដាក់នៅពីមុខ Route ណាដែលទាមទារការ Login។

```javascript
const verifyToken = (req, res, next) => {
    // យក Token ពី Header (ទម្រង់: Bearer <token>)
    const bearerHeader = req.headers['authorization'];
    
    if (bearerHeader) {
        const token = bearerHeader.split(' ')[1];
        
        // ផ្ទៀងផ្ទាត់ Token
        jwt.verify(token, "my_super_secret_key", (err, decodedUser) => {
            if (err) {
                return res.status(403).json({ message: "Token មិនត្រឹមត្រូវ ឬហួសកំណត់" });
            }
            
            // បើត្រឹមត្រូវ ផ្ទុកព័ត៌មាន User ចូលក្នុង req សម្រាប់ Route បន្ទាប់ប្រើ
            req.user = decodedUser; 
            next();
        });
    } else {
        res.status(401).json({ message: "អ្នកមិនទាន់បាន Login ទេ" });
    }
};

// ប្រើប្រាស់វា
app.get('/api/my-profile', verifyToken, (req, res) => {
    // កូដនេះដំណើរការបាន លុះត្រាតែ Token ត្រឹមត្រូវប៉ុណ្ណោះ
    res.json({ message: `សួស្តី User លេខ ${req.user.id}` });
});
```

ជាមួយនឹង JWT កម្មវិធីរបស់អ្នកអាចគាំទ្រទាំងការប្រើប្រាស់លើ Web (React, Next.js) និងនៅលើ Mobile App (iOS, Android) បានយ៉ាងងាយស្រួល!
