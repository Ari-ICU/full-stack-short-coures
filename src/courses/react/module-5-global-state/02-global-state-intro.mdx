## 🌐 Global State Management

នៅពេលកម្មវិធី React របស់អ្នករីកធំធាត់ ការប្រើប្រាស់ **Context API** ជួនកាលអាចបង្កជាផលវិបាក ដូចជាការសរសេរ boilerplate ច្រើន និងបញ្ហា Re-render ធាតុដែលមិនពាក់ព័ន្ធ (Performance issues)។

ដើម្បីដោះស្រាយបញ្ហានេះ គេតែងតែប្រើប្រាស់បណ្ណាល័យខាងក្រៅ (State Management Libraries)។ ក្នុងមេរៀននេះ យើងនឹងស្គាល់បណ្ណាល័យពីរគឺ **Zustand** និង **Redux Toolkit (RTK)**។

---

## 1. ស្គាល់ពី Zustand (សាមញ្ញ និងពេញនិយមខ្លាំង)

**Zustand** គឺជាបណ្ណាល័យគ្រប់គ្រង State ដ៏សាមញ្ញ ស្រាល និងលឿន។ វាអនុញ្ញាតឱ្យយើងបង្កើត Store មួយយ៉ាងងាយស្រួល និងហៅប្រើក្នុង Component ដូចជា Custom Hook ធម្មតា។

### ក. ការបង្កើត Store ជាមួយ Zustand
យើងប្រើប្រាស់ `create` ពី `zustand` ដើម្បីបង្កើត store ផ្ទុកទាំង state និង actions៖

```javascript
import { create } from 'zustand';

// បង្កើត Store រក្សាទុកកុងទ័រ (Counter Store)
const useCounterStore = create((set) => ({
  count: 0,
  // វិធី update state
  increment: () => set((state) => ({ count: state.count + 1 })),
  decrement: () => set((state) => ({ count: state.count - 1 })),
  reset: () => set({ count: 0 })
}));
export default useCounterStore;
```

### ខ. ការយកទៅប្រើប្រាស់ក្នុង Components
យើងគ្រាន់តែហៅ `useCounterStore` មកប្រើជា Hook បានភ្លាមៗ មិនបាច់ត្រូវការ `Provider` ណាមួយឡើយ!

```jsx
import useCounterStore from './counterStore';

function CounterComponent() {
  // ចាប់យក state និង actions មកប្រើ
  const { count, increment, decrement } = useCounterStore();

  return (
    <div>
      <h2>🔢 ចំនួន៖ {count}</h2>
      <button onClick={increment}>បូក ១</button>
      <button onClick={decrement}>ដក ១</button>
    </div>
  );
}
```

## 2. ស្គាល់ពី Redux Toolkit (RTK)

**Redux** គឺជាប្រព័ន្ធគ្រប់គ្រង State បែបប្រពៃណី និងរឹងមាំបំផុតដែលត្រូវបានប្រើប្រាស់ក្នុងគម្រោងខ្នាតយក្ស។ **Redux Toolkit (RTK)** គឺជាជំនាន់ថ្មីដែលជួយសម្រួល syntax របស់ Redux ឱ្យខ្លីជាងមុន។

វាដំណើរការទៅតាមគំនិតបី៖
1. **Store**: កន្លែងកណ្តាលរក្សាទុក State ទាំងអស់។
2. **Action**: សារបញ្ជូនបញ្ជាថាតើយើងចង់ធ្វើអ្វី (ឧ. `{ type: 'counter/increment' }`)។
3. **Reducer**: Function ទទួលយក state ចាស់ និង action ដើម្បីបង្កើត state ថ្មី។

### រចនាសម្ព័ន្ធមូលដ្ឋានរបស់ RTK (Slice):
```javascript
import { createSlice, configureStore } from '@reduxjs/toolkit';

// 1. បង្កើត Slice (ផ្ទុក reducers និង actions)
const counterSlice = createSlice({
  name: 'counter',
  initialState: { value: 0 },
  reducers: {
    increment: (state) => {
      state.value += 1; // អាចកែតម្លៃបានដោយផ្ទាល់ (RTK ប្រើ Immer ពីក្រោយខ្នង)
    },
    decrement: (state) => {
      state.value -= 1;
    }
  }
});

// ទាញយក Actions
export const { increment, decrement } = counterSlice.actions;

// 2. បង្កើត Store
export const store = configureStore({
  reducer: {
    counter: counterSlice.reducer
  }
});
```

## 💡 តើគួរជ្រើសរើសមួយណា?
*   **ជ្រើសរើស Zustand**៖ ប្រសិនបើអ្នកចង់បានអ្វីដែលសាមញ្ញ ស្រាល សរសេរកូដរហ័ស និងគ្មាន Boilerplate ស្មុគស្មាញ (ស័ក្តិសមសម្រាប់គម្រោងខ្នាតតូច និងមធ្យម)។
*   **ជ្រើសរើស Redux Toolkit**៖ ប្រសិនបើអ្នកធ្វើការក្នុងក្រុមហ៊ុនធំៗ ឬគម្រោងខ្នាតយក្ស (Enterprise-level) ដែលទាមទារប្រព័ន្ធរឹងមាំ ការធ្វើតេស្តលម្អិត និងមាន DevTools ជំនួយកម្រិតខ្ពស់។
