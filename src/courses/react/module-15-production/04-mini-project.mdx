## 🚀 Complete Deployment Walkthrough

### Step 1: Final Code Review

```bash
# Check for common issues before deploying
grep -r "localhost" src/            # Find hardcoded localhost URLs
grep -r "console.log" src/          # Find debug logs (optional cleanup)
cat .gitignore | grep ".env"        # Verify .env.local is gitignored
```

### Step 2: Build Verification

```bash
# Run full verification suite
npm run build       # Must pass with 0 errors

# Check bundle size
ls -la dist/assets/*.js
# Good: main chunk < 500kb
# Warning: main chunk > 1MB (consider code splitting)

npm run preview     # Test at http://localhost:4173
# Manually test: Login, Navigation, API calls, Logout
```

### Step 3: Push to GitHub

```bash
git add .
git commit -m "feat: production-ready React app with auth, API, testing"
git push origin main
```

### Step 4: Deploy to Vercel

**Option A: Vercel Dashboard (GUI)**
1. Login at [vercel.com](https://vercel.com)
2. **New Project** → Import from GitHub → Select your repo
3. Vercel auto-detects Vite:
   - Framework: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Click **Deploy** → Wait 60-90 seconds
5. ✅ Live at `https://your-app.vercel.app`

**Option B: Vercel CLI**
```bash
npm install -g vercel
vercel login
vercel --prod
```

### Step 5: Configure Environment Variables

```
Vercel Dashboard → your-project → Settings → Environment Variables

Name: VITE_API_URL
Value: https://api.yourbackend.com
Environments: ✅ Production ✅ Preview

→ Save → Redeploy (Settings → Deployments → Redeploy latest)
```

## 🐛 Common Deployment Issues & Fixes

### Issue 1: Blank White Page
```
Symptom: App deploys but shows blank screen

Causes & Fixes:
1. Build error → Check Vercel build logs
2. Wrong base URL → Check vite.config.js base option
3. JS errors → Open browser console on live site
4. Missing env vars → Add VITE_* vars in Vercel dashboard
```

### Issue 2: Routes Return 404
```
Symptom: /dashboard → 404 Not Found (only on direct access)

Fix for Vercel: Create vercel.json in project root:
```

```json
{
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}
```

```
Fix for Netlify: Create public/_redirects:
/*    /index.html    200
```

### Issue 3: API CORS Error
```
Symptom: API calls fail in production with CORS error

Fix: Update backend CORS to include your Vercel domain:
```

```js
// backend/app.js — Update allowed origins
app.use(cors({
  origin: [
    'http://localhost:5173',                    // Local dev
    'https://your-app.vercel.app',              // Vercel production
    'https://your-custom-domain.com',           // Custom domain
  ],
}));
```
