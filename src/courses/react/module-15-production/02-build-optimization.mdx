## ✂️ 2. Route-based Code Splitting ជាមួយ `React.lazy`

### 💻 Code សម្រាប់ Code Splitting (`App.jsx`):

```jsx
// src/App.jsx
import { lazy, Suspense } from 'react';
import { Routes, Route } from 'react-router-dom';

// 1. Eager Loading សម្រាប់ទំព័រដំបូងដែលត្រូវការបង្ហាញភ្លាមៗ
import HomePage from './pages/HomePage';

// 2. Lazy Loading: Download ទំព័រទាំងនេះតែពេលណា User ចុចចូលប៉ុណ្ណោះ!
const DashboardPage = lazy(() => import('./pages/DashboardPage'));
const AnalyticsPage = lazy(() => import('./pages/AnalyticsPage'));
const AdminSettings = lazy(() => import('./pages/AdminSettings'));

// Loading Fallback Component
function PageLoader() {
  return (
    <div className="flex h-64 items-center justify-center">
      <div className="h-8 w-8 animate-spin rounded-full border-4 border-blue-600 border-t-transparent" />
    </div>
  );
}

export default function App() {
  return (
    // 3. ស្រោប Suspense ពីលើ Routes
    <Suspense fallback={<PageLoader />}>
      <Routes>
        <Route path="/" element={<HomePage />} />
        <Route path="/dashboard" element={<DashboardPage />} />
        <Route path="/analytics" element={<AnalyticsPage />} />
        <Route path="/admin" element={<AdminSettings />} />
      </Routes>
    </Suspense>
  );
}
```

### 🔍 ការពន្យល់មួយជួរៗ (Line-by-Line Explanation):

1. `import HomePage from './pages/HomePage';`
   - **Eager Import:** ត្រូវបានដាក់បញ្ចូលក្នុង Main Bundle ភ្លាមៗ ព្រោះ User ត្រូវការមើលឃើញ Home Page មុនគេ។
2. `const DashboardPage = lazy(() => import('./pages/DashboardPage'));`
   - **Dynamic Import:** Vite នឹងកាត់ `DashboardPage` ទៅជា File ដាច់ដោយឡែកមួយ (ឧ. `Dashboard-B4.js`)។ កូដនេះនឹងមិនត្រូវបាន Download ឡើយ រហូតទាល់តែ User ចុចបើក URL `/dashboard`។
3. `<Suspense fallback={<PageLoader />}>`
   - ក្នុងអំឡុងពេល Browser កំពុង Download JS Chunk នៃទំព័រថ្មី `Suspense` នឹងបង្ហាញ `PageLoader` (Spinner) ជូន User ជាបណ្ដោះអាសន្ន។

## 📊 3. Bundle Analysis ជាមួយ Rollup Visualizer

```bash
npm install -D rollup-plugin-visualizer
```

### 💻 Code សម្រាប់ `vite.config.js`:

```javascript
// vite.config.js
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import { visualizer } from 'rollup-plugin-visualizer';

export default defineConfig({
  plugins: [
    react(),
    visualizer({
      open: true, // បើក Browser បង្ហាញក្រាហ្វិកទំហំកូដស្វ័យប្រវត្តិក្រោយ Build
      filename: 'dist/stats.html',
      gzipSize: true,
    }),
  ],
});
```

### 🔍 ការពន្យល់មួយជួរៗ (Line-by-Line Explanation):

1. `visualizer({ open: true, filename: 'dist/stats.html' })`
   - ពេលអ្នក run `npm run build` Plugin នេះនឹងបង្កើត Interactive Visual Map មួយបង្ហាញយ៉ាងច្បាស់ថា Library ណាធំជាងគេ (ឧ. Lodash, Moment.js, Lucide Icons) ដើម្បីងាយស្រួល Refactor។
