## 📁 1. Env File Hierarchy

```
.env                # Default values (រត់គ្រប់ environments)
.env.local          # Local overrides (ផ្ទាល់ខ្លួន — កុំ commit ចូល git)
.env.development    # ប្រើពេល run `npm run dev`
.env.production     # ប្រើពេល run `npm run build`
```

---

## 🔒 2. Setting Up `.env` Files

### 💻 Code សម្រាប់ `.env.development`:

```bash
# .env.development
VITE_API_BASE_URL=http://localhost:5000/api
VITE_APP_TITLE=EduApp (Dev Mode)
VITE_ENABLE_ANALYTICS=false

# ❌ អថេរគ្មាន VITE_ នឹងមិនត្រូវបានបញ្ជូនទៅ Browser ឡើយ
DB_PASSWORD=secret123_hidden_from_browser
```

### 💻 Code សម្រាប់ `.env.production`:

```bash
# .env.production
VITE_API_BASE_URL=https://api.eduapp.com/v1
VITE_APP_TITLE=EduApp
VITE_ENABLE_ANALYTICS=true
```

## 💻 3. Accessing Env Variables in React

### 💻 Code សម្រាប់អាន Env Variable:

```javascript
// src/api/client.js
// 1. ប្រើ import.meta.env ជំនួស process.env ក្នុង Vite
const API_URL = import.meta.env.VITE_API_BASE_URL;
const IS_DEV = import.meta.env.DEV; // Vite Built-in Boolean (true ក្នុង dev mode)

console.log('Current API Endpoint:', API_URL);

export const apiClient = {
  baseURL: API_URL,
};
```

### 🔍 ការពន្យល់មួយជួរៗ (Line-by-Line Explanation):

1. `import.meta.env.VITE_API_BASE_URL`
   - ទាញយកតម្លៃ URL តាម Environment បច្ចុប្បន្ន។ ពេល dev វាយក `localhost:5000` ពេល build production វាយក `https://api.eduapp.com` ស្វ័យប្រវត្តិ។
2. `import.meta.env.DEV`
   - អថេរ Built-in របស់ Vite ផ្តល់តម្លៃ `true` ពេលកំពុង run dev server និង `false` ពេល build production។

## 🛡️ 4. Safe Runtime Validation Module

### 💻 Code សម្រាប់ Validation Config (`src/config/env.js`):

```javascript
// src/config/env.js
const requiredEnvVars = ['VITE_API_BASE_URL'];

// ត្រួតពិនិត្យអថេរដែលខ្វះមិនបាន
for (const key of requiredEnvVars) {
  if (!import.meta.env[key]) {
    throw new Error(
      `❌ Missing required environment variable: ${key}\n` +
      `សូមបង្កើត file .env ឬ .env.local រួចកំណត់ ${key}=your_value`
    );
  }
}

export const ENV = {
  API_URL: import.meta.env.VITE_API_BASE_URL,
  APP_TITLE: import.meta.env.VITE_APP_TITLE || 'My React App',
  IS_DEV: import.meta.env.DEV,
};
```

### 🔍 ការពន្យល់មួយជួរៗ (Line-by-Line Explanation):

1. `for (const key of requiredEnvVars)`
   - ពិនិត្យរកមើលថាតើ Developer បានកំណត់ environment variables គ្រប់គ្រាន់ហើយឬនៅ។
2. `throw new Error(...)`
   - ប្រសិនបើភ្លេចដាក់ `VITE_API_BASE_URL` កម្មវិធីនឹងបោះ Error ប្រាប់ភ្លាមៗ ជៀសវាងការ Render App មកចេញកំហុសស្ងាត់ៗ (Silent Failures)។
