## 🔒 អ្វីទៅជា Environment Variables?

នៅក្នុងការអភិវឌ្ឍន៍កម្មវិធី មានទិន្នន័យមួយចំនួនដែលអ្នក **មិនគួរ** សរសេរវាចូលទៅក្នុងកូដដោយផ្ទាល់ (Hardcode) ឡើយ ដូចជា៖
- API Keys (កូនសោរសម្រាប់ភ្ជាប់ទៅប្រព័ន្ធផ្សេងៗ ឧទាហរណ៍ ផែនទី Google Maps ឬការទូទាត់ប្រាក់ Stripe)
- API URLs (ទីតាំងរបស់ Server) ព្រោះពេលអ្នកធ្វើការក្នុងម៉ាស៊ីនអ្នកវាជា `http://localhost:3000` តែពេលយកទៅដាក់លើអុីនធឺណិតវាជា `https://api.mywebsite.com`។

ដើម្បីដោះស្រាយបញ្ហានេះ យើងយកទិន្នន័យទាំងនោះទៅលាក់ទុកក្នុងឯកសារមួយឈ្មោះថា **`.env`**។

> ⚠️ **ក្បួនដ៏សំខាន់បំផុត:** កុំបញ្ជូនឯកសារ `.env` នេះចូលទៅក្នុង GitHub អោយសោះ! (ជាធម្មតាវាត្រូវបានលាក់រួចជាស្រេចនៅក្នុង `.gitignore`)។

## 1. ការបង្កើតឯកសារ `.env`

នៅក្នុងគម្រោង Vite របស់អ្នក សូមបង្កើតឯកសារថ្មីមួយនៅ **ខាងក្រៅបង្អស់ (ក្រៅថត src)** ហើយដាក់ឈ្មោះវាថា `.env`។

**ច្បាប់របស់ Vite:** រាល់អថេរដែលអ្នកចង់ហៅមកប្រើក្នុងកូដ React ត្រូវតែផ្តើមដោយពាក្យ **`VITE_`** ជាដាច់ខាត!

**ឯកសារ `.env`:**
```env
# នេះគឺជា Comment
VITE_API_URL=https://api.example.com/v1
VITE_GOOGLE_MAPS_KEY=AIzaSyB-xxxxxxx_yyyyyyyy
```

## 2. ការទាញយកអថេរមកប្រើប្រាស់

ដើម្បីទាញយកតម្លៃពី `.env` នៅក្នុងកូដ React របស់អ្នក (ដោយប្រើ Vite) យើងត្រូវប្រើពាក្យបញ្ជាពិសេសគឺ **`import.meta.env`** (មិនមែន `process.env` ដូចក្នុង Create React App ទេ)។

**ឯកសារ `App.jsx`:**
```jsx
export default function App() {
  // ទាញយក URL ចេញពីឯកសារ .env
  const API_URL = import.meta.env.VITE_API_URL;
  const MAPS_KEY = import.meta.env.VITE_GOOGLE_MAPS_KEY;

  const fetchUsers = async () => {
    try {
      // ប្រើប្រាស់ API_URL ជំនួសអោយការសរសេរ Link ផ្ទាល់!
      const response = await fetch(`${API_URL}/users`);
      const data = await response.json();
      console.log(data);
    } catch (error) {
      console.error("មានបញ្ហា", error);
    }
  };

  return (
    <div>
      <h1>រៀនពី Environment Variables</h1>
      <p>API ដែលយើងកំពុងភ្ជាប់ទៅគឺ៖ <b>{API_URL}</b></p>
      
      <button onClick={fetchUsers}>ទាញយកសិស្ស</button>
    </div>
  );
}
```

## 3. ហេតុអ្វីបានជាត្រូវប្រើវា? 🚀

អត្ថប្រយោជន៍ដ៏ធំបំផុតគឺនៅពេលអ្នកយកគម្រោងនេះទៅបង្ហោះ (Deploy) នៅលើ Vercel ឬ Netlify។ អ្នកមិនចាំបាច់កែប្រែកូដរបស់អ្នកទេ។ អ្នកគ្រាន់តែចូលទៅកាន់ផ្ទាំងគ្រប់គ្រងរបស់ Vercel ហើយបញ្ចូលតម្លៃ `VITE_API_URL` ថ្មី (Production URL) នោះកូដរបស់អ្នកនឹងភ្ជាប់ទៅទីតាំងថ្មីដោយស្វ័យប្រវត្តិ!
