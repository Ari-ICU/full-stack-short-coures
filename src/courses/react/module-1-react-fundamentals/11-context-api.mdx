## 😫 បញ្ហា Prop Drilling

ស្រមៃថាអ្នកមាន `App` ជាអ្នករក្សាទុកពត៌មានរបស់អ្នកប្រើប្រាស់ (User) ហើយអ្នកចង់បង្ហាញឈ្មោះរបស់គាត់នៅក្នុង Component `ProfileText` ដែលនៅជ្រៅខ្លាំង៖

`App` ➡️ `Dashboard` ➡️ `Sidebar` ➡️ `UserProfile` ➡️ `ProfileText`

ដើម្បីអោយ `ProfileText` ទទួលបានទិន្នន័យ, `App` ត្រូវបញ្ជូន Props កាត់ `Dashboard`, `Sidebar` និង `UserProfile` ទោះបីជាពួកវាមិនត្រូវការទិន្នន័យនេះក៏ដោយ! បញ្ហានេះត្រូវបានគេហៅថា **Prop Drilling**។

ដើម្បីដោះស្រាយវា React មានមុខងារមួយឈ្មោះថា **Context API** (មិនចាំបាច់ដំឡើង Redux ឬ Zustand ភ្លាមៗទេ)!

---

## 1. ការបង្កើត Context

ដំបូងយើងត្រូវបង្កើត Context មួយសិន (ប្រៀបដូចជាការបង្កើតឃ្លាំងទិន្នន័យថ្មីមួយ)។

**ឯកសារ `UserContext.js`:**
```jsx
import { createContext } from 'react';

// បង្កើត Context ដោយទុកចន្លោះទទេ (null) ជាតម្លៃដើម
export const UserContext = createContext(null);
```

---

## 2. ការផ្តល់ទិន្នន័យ (Provider)

ឥឡូវនៅ Component ធំបំផុត (ឧ. `App.jsx`) អ្នកត្រូវរុំ Component កូនៗទាំងអស់របស់អ្នកជាមួយនឹង `<UserContext.Provider>` ហើយផ្តល់តម្លៃទៅអោយវា។

**ឯកសារ `App.jsx`:**
```jsx
import { useState } from 'react';
import { UserContext } from './UserContext';
import Dashboard from './Dashboard'; // ឧបមាថាវាមាន Component កូនៗច្រើនទៀតនៅខាងក្នុង

export default function App() {
  const [user, setUser] = useState({ name: "រដ្ឋា", role: "Admin" });

  return (
    // អ្នករាល់គ្នាដែលនៅក្នុង Provider នេះអាចទាញយក user បានទាំងអស់!
    <UserContext.Provider value={user}>
      <div>
        <h1>កម្មវិធីរបស់ខ្ញុំ</h1>
        <Dashboard />
      </div>
    </UserContext.Provider>
  );
}
```

## 3. ការទាញយកទិន្នន័យមកប្រើ (`useContext`)

នៅ Component ណាក៏ដោយអោយតែស្ថិតនៅក្នុង `Provider` នោះ (ទោះនៅកម្រិតទី ១០០ ក៏ដោយ) អ្នកអាចទាញយកទិន្នន័យបានដោយប្រើ Hook **`useContext`**!

**ឯកសារ `ProfileText.jsx`:**
```jsx
import { useContext } from 'react';
import { UserContext } from './UserContext'; // ទាញយកឃ្លាំងរបស់យើងមក

export default function ProfileText() {
  // ហៅប្រើ useContext ដើម្បីយកទិន្នន័យចេញពីឃ្លាំងដោយផ្ទាល់!
  const user = useContext(UserContext);

  return (
    <div className="profile-box">
      <h3>ឈ្មោះ: {user.name}</h3>
      <p>តួនាទី: {user.role}</p>
    </div>
  );
}
```

**សន្និដ្ឋាន:** 
ប្រើប្រាស់ Context សម្រាប់ទិន្នន័យដែលគេត្រូវការប្រើប្រាស់ជាទូទៅ (Global) ដូចជា ព័ត៌មានអ្នកប្រើប្រាស់ (User auth), ភាសា (Language/Locale) ឬ ការកំណត់ពណ៌ (Light/Dark Theme) ជាដើម។ កុំប្រើវាសម្រាប់ទិន្នន័យធម្មតាៗដែលជិតគ្នាក្នុង Component!
