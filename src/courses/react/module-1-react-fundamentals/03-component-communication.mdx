## 📡 អ្វីទៅជា Props?

**Props** (មកពីពាក្យ Properties) គឺជាមធ្យោបាយដែល React Components ប្រើសម្រាប់ទំនាក់ទំនងគ្នា។ អ្នកអាចគិតថាវាស្រដៀងទៅនឹងការបញ្ជូន Arguments ទៅអោយ Function ឬស្រដៀងទៅនឹង HTML Attributes អញ្ចឹងដែរ។

ទិន្នន័យនៅក្នុង React ហូរក្នុងទិសដៅតែមួយប៉ុណ្ណោះ គឺពីលើចុះក្រោម **(Parent ➡️ Child)**។

---

## 1. ការបញ្ជូនទិន្នន័យ (Parent ទៅ Child)

ឧបមាថាយើងមាន `UserCard` Component ហើយយើងចង់បញ្ជូនឈ្មោះ (Name) ពី `App` ទៅអោយវា។

**ឯកសារ Child (`UserCard.jsx`):**
```jsx
// ទទួលយកទិន្នន័យតាមរយៈប៉ារ៉ាម៉ែត្រ props 
export default function UserCard(props) {
  return (
    <div className="card">
      <h3>ឈ្មោះ: {props.name}</h3>
      <p>អាយុ: {props.age}</p>
    </div>
  );
}
```

**ឯកសារ Parent (`App.jsx`):**
```jsx
import UserCard from './UserCard';

function App() {
  return (
    <div>
      {/* បញ្ជូនទិន្នន័យទៅអោយ Child */}
      <UserCard name="សុខា" age={25} />
      <UserCard name="ធីតា" age={22} />
    </div>
  );
}
```

> 💡 **ចំណាំ:** ពេលបញ្ជូនអក្សរ (String) យើងប្រើ `""`។ តែបើបញ្ជូនលេខ ឬអថេរ យើងត្រូវប្រើ `{}` (ឧ. `age={25}`)។

---

## 2. ការបំបែក Props (Object Destructuring)

ជំនួសអោយការសរសេរ `props.name` ឬ `props.age` រហូត យើងអាចបំបែកវាដោយផ្ទាល់ (Destructure) នៅត្រង់ប៉ារ៉ាម៉ែត្រ ដើម្បីអោយកូដខ្លី និងស្រួលអានជាងមុន។

```jsx
// ប្រើប្រាស់ {} ដើម្បីចាប់យក name និង age ផ្ទាល់
export default function UserCard({ name, age }) {
  return (
    <div className="card">
      <h3>ឈ្មោះ: {name}</h3>
      <p>អាយុ: {age}</p>
    </div>
  );
}
```

---

## 3. Child ទំនាក់ទំនងទៅ Parent វិញ (Callbacks)

ចុះបើ Component កូន (Child) ចង់ប្រាប់ Component មេ (Parent) ថាមានគេចុចប៊ូតុង? ដោយសារ Props មិនអាចកែប្រែបានពី Child ដូច្នេះ **Parent ត្រូវតែបញ្ជូន Function មួយទៅអោយ Child**។ ពេល Child ចង់ទំនាក់ទំនងមកវិញ វាគ្រាន់តែហៅ Function នោះ!

**ឯកសារ Parent (`App.jsx`):**
```jsx
import ChildButton from './ChildButton';

function App() {
  // បង្កើត Function នៅ Parent
  const handleSave = (data) => {
    alert("ទទួលបានទិន្នន័យពី Child: " + data);
  };

  return (
    <div>
      {/* បញ្ជូន Function នោះទៅអោយ Child តាមរយៈ Prop ឈ្មោះ onSave */}
      <ChildButton onSave={handleSave} />
    </div>
  );
}
```

**ឯកសារ Child (`ChildButton.jsx`):**
```jsx
export default function ChildButton({ onSave }) {
  return (
    // ពេលគេចុចប៊ូតុង វានឹងហៅ Function onSave ដែល Parent អោយមក
    <button onClick={() => onSave("រក្សាទុកជោគជ័យ!")}>
      ចុចរក្សាទុក
    </button>
  );
}
```

**សន្និដ្ឋាន:**
- Parent ចង់ប្រាប់ Child ➡️ ប្រើប្រាស់ **Props** ធម្មតា (អក្សរ, លេខ, Object...)
- Child ចង់ប្រាប់ Parent ➡️ Parent ត្រូវបញ្ជូន **Callback Function** អោយ Child ហៅ។
