## 🧩 ១. Component Anatomy & Architecture

> [!IMPORTANT]
> **និយមន័យ Functional Component (Definition) ៖**  
> **React Functional Component** គឺជា JavaScript Function ធម្មតាមួយដែលទទួលទិន្នន័យពីខាងក្រៅ (ហៅថា `props`) ជា Argument ហើយ Return ត្រឡប់មកវិញនូវ React Elements (តាមរយៈ JSX) ដើម្បី Render បង្ហាញលើ UI។ ឈ្មោះរបស់ Component ត្រូវតែសរសេរជា **PascalCase** (ចាប់ផ្តើមដោយអក្សរធំ)។

នៅក្នុង React, **Component** គឺជា Pure JavaScript Function មួយដែលទទួល Inputs (Props) និង Return ចេញជា JSX Element សម្រាប់បង្ហាញលើអេក្រង់ ៖

```jsx
// 1. Function Name ត្រូវតែជា PascalCase (អក្សរធំនៅខាងមុខ)
export function StatusBadge({ status = 'active' }) {
  // 2. Component Logic (JavaScript code)
  const isOnline = status === 'active';

  // 3. Return JSX UI
  return (
    <span className={`inline-flex items-center gap-1.5 px-2.5 py-1 rounded-full text-xs font-bold ${
      isOnline ? 'bg-emerald-50 text-emerald-600' : 'bg-slate-100 text-slate-500'
    }`}>
      <span className={`w-2 h-2 rounded-full ${isOnline ? 'bg-emerald-500' : 'bg-slate-400'}`} />
      {isOnline ? 'Active' : 'Offline'}
    </span>
  );
}
```

## 📦 ៣. ការបែងចែក ES6 Modules: Default vs Named Exports

| លក្ខណៈពិសេស | `Default Export` | `Named Export` |
| :--- | :--- | :--- |
| **ចំនួនក្នុងមួយ File** | មានបានតែ **១ គត់** (`export default ...`) | អាចមាន **ច្រើន** (`export function A()`, `export const B`) |
| **ការ Export** | `export default function Navbar() { ... }` | `export function Button() { ... }` |
| **ការ Import** | `import Navbar from './Navbar'` | `import { Button } from './Button'` |
| **ការប្តូរឈ្មោះពេល Import** | អាចដាក់ឈ្មោះតាមចិត្ត (`import MyNav ...`) | ត្រូវប្រើ `as` (`import { Button as PrimaryBtn } ...`) |
| **ការណែនាំប្រើប្រាស់** | សមស្របសម្រាប់ **Page ឬ Main Component** | សមស្របសម្រាប់ **UI Kits, Icons, Utilities** |

### ១. `src/components/FeatureCard.jsx` (Named Export)

```jsx
// src/components/FeatureCard.jsx
import React from 'react';

export function FeatureCard({ icon, title, description, isHighlighted = false }) {
  return (
    <div className={`p-6 rounded-3xl border transition-all duration-300 hover:shadow-lg ${
      isHighlighted
        ? 'bg-gradient-to-br from-blue-600 to-indigo-700 text-white border-blue-500 shadow-blue-500/20 shadow-md'
        : 'bg-white dark:bg-slate-900 text-slate-800 dark:text-white border-slate-200 dark:border-slate-800'
    }`}>
      <div className={`w-12 h-12 rounded-2xl flex items-center justify-center text-2xl mb-4 ${
        isHighlighted ? 'bg-white/20' : 'bg-blue-50 dark:bg-blue-900/30 text-blue-600'
      }`}>
        {icon}
      </div>
      <h3 className="text-lg font-black leading-tight mb-2">{title}</h3>
      <p className={`text-xs leading-relaxed ${isHighlighted ? 'text-blue-100' : 'text-slate-500 dark:text-slate-400'}`}>
        {description}
      </p>
    </div>
  );
}
```

## 🔍 ៥. ការពន្យល់កូដមួយជួរៗតាមឯកសារ និង Component (Deep-Dive Breakdown)

ដើម្បីឱ្យយល់ច្បាស់ ១០០% ពីរបៀបដែលកូដដំណើរការ ខាងក្រោមនេះជាការពន្យល់លម្អិតតាមឯកសារ (File-by-File), តាម Component (Component-by-Component), និងតាមបន្ទាត់កូដនីមួយៗ (Line-by-Line) ៖

### 📁 ឯកសារទី ១ ៖ `src/components/FeatureCard.jsx` (Domain Component)
* **តួនាទីឯកសារ (File Role) ៖** ឯកសារនេះផ្ទុក `<FeatureCard />` Component ដែលមានភារកិច្ចតែមួយគត់ (Single Responsibility) គឺបង្ហាញកាតព័ត៌មាន Feature ដោយទទួលទិន្នន័យពីខាងក្រៅតាមរយៈ Props។

```jsx
// src/components/FeatureCard.jsx
import React from 'react'; // [Line 1]

export function FeatureCard({ icon, title, description, isHighlighted = false }) { // [Line 3]
  return ( // [Line 4]
    <div className={`p-6 rounded-3xl border transition-all duration-300 hover:shadow-lg ${ // [Line 5]
      isHighlighted // [Line 6]
        ? 'bg-gradient-to-br from-blue-600 to-indigo-700 text-white border-blue-500 shadow-blue-500/20 shadow-md' // [Line 7]
        : 'bg-white dark:bg-slate-900 text-slate-800 dark:text-white border-slate-200 dark:border-slate-800' // [Line 8]
    }`}> // [Line 9]
      <div className={`w-12 h-12 rounded-2xl flex items-center justify-center text-2xl mb-4 ${ // [Line 10]
        isHighlighted ? 'bg-white/20' : 'bg-blue-50 dark:bg-blue-900/30 text-blue-600' // [Line 11]
      }`}> // [Line 12]
        {icon} // [Line 13]
      </div> // [Line 14]
      <h3 className="text-lg font-black leading-tight mb-2">{title}</h3> // [Line 15]
      <p className={`text-xs leading-relaxed ${isHighlighted ? 'text-blue-100' : 'text-slate-500 dark:text-slate-400'}`}> // [Line 16]
        {description} // [Line 17]
      </p> // [Line 18]
    </div> // [Line 19]
  ); // [Line 20]
} // [Line 21]
```

#### 📋 តារាងពន្យល់បន្ទាត់កូដនៃ `FeatureCard.jsx`:
| បន្ទាត់ (Line) | សេចក្តីពន្យល់លម្អិត |
| :--- | :--- |
| **Line 1** | `import React from 'react';` — នាំចូល React Library សម្រាប់គាំទ្រ JSX និង IDE Type Safety។ |
| **Line 3** | `export function FeatureCard({ ... })` — **Named Export** ជាមួយ **Props Destructuring** ៖ ដកស្រង់យក props ទាំង ៤ ដោយផ្ទាល់ (`icon`, `title`, `description`, `isHighlighted`) ព្រមទាំងផ្តល់តម្លៃ Default `isHighlighted = false` ក្នុងករណី Caller មិនបានបញ្ជូនវា។ |
| **Line 4-5** | `return ( <div className={...}>` — ចាប់ផ្តើម JSX Container ដោយកំណត់ base styles (padding `p-6`, កាច់ជ្រុង `rounded-3xl`, ព្រមទាំង smooth hover animation `transition-all duration-300 hover:shadow-lg`)។ |
| **Line 6-8** | `isHighlighted ? '...' : '...'` — **Conditional Styling** ៖ ប្រសិនបើកាតត្រូវបាន Highlight វានឹងប្រើ Gradient Background ពណ៌ខៀវ-ស្វាយ (`from-blue-600 to-indigo-700`) អមដោយ Glow Shadow; បើមិន Highlight ទេ វានឹងប្រើសាច់ពណ៌សស្អាតលើ Light mode ឬ slate លើ Dark mode។ |
| **Line 10-14** | `<div className={...}>{icon}</div>` — កន្លែងដាក់រូប Emoji ឬ Icon ដោយមានរាងមូលកោង និង Background ទន់ភ្លន់តាម Theme នៃកាត។ |
| **Line 15** | `<h3 className="..."> {title} </h3>` — បង្ហាញចំណងជើង Feature ដោយអក្សរដិតខ្លាំង (`font-black`) និងទំហំសមល្មម (`text-lg`)។ |
| **Line 16-18** | `<p className="..."> {description} </p>` — បង្ហាញអត្ថបទពិពណ៌នា ដោយប្តូរពណ៌អក្សរទៅជាពណ៌សស្រាល (`text-blue-100`) ពេល Highlight ឬពណ៌ប្រផេះ (`text-slate-500`) ពេលធម្មតា។ |
| **Line 19-21** | បិទ `<div>` tag និងបញ្ចប់មុខងារ `FeatureCard` Component។ |

### 📁 ឯកសារទី ២ ៖ `src/components/Navbar.jsx` (Layout Component)
* **តួនាទីឯកសារ (File Role) ៖** បង្ហាញ Header Navigation Bar ដែលស្ថិតនៅជាប់ខាងលើគេជានិច្ច (`sticky top-0`) ជាមួយកញ្ចក់ថ្លាព្រាល (Glassmorphism Effect)។

```jsx
// src/components/Navbar.jsx
import React from 'react'; // [Line 1]

  return ( // [Line 4]

        <div className="flex items-center gap-2 font-black text-lg text-slate-900 dark:text-white"> // [Line 7]
          <span className="text-2xl">⚡</span> // [Line 8]
          <span>FastReact</span> // [Line 9]
        </div> // [Line 10]
        <nav className="flex items-center gap-4"> // [Line 11]
          <button className="px-4 py-2 text-xs font-bold text-slate-600 dark:text-slate-300 hover:text-blue-600"> // [Line 12]
            មេរៀន // [Line 13]
          </button> // [Line 14]
          <button className="px-4 py-2 bg-blue-600 hover:bg-blue-700 text-white font-bold text-xs rounded-xl shadow-sm transition"> // [Line 15]
```

#### 📋 តារាងពន្យល់បន្ទាត់កូដនៃ `Navbar.jsx`:
| បន្ទាត់ (Line) | សេចក្តីពន្យល់លម្អិត |
| :--- | :--- |
| **Line 3** | `export function Navbar() {` — **Named Export** នៃ Stateless Component (គ្មានទទួល Props ទេ ព្រោះវាជា Static UI Header)។ |
| **Line 5** | `<header className="... backdrop-blur-md sticky top-0 z-40">` —<br/>• `sticky top-0`: ធ្វើឱ្យ Header អណ្តែតនៅជាប់កំពូលអេក្រង់រហូតពេល User Scroll ចុះក្រោម។<br/>• `backdrop-blur-md`: បង្កើត Glassmorphism Effect ព្រាលផ្ទៃខាងក្រោយពេល Content ធ្លាក់មកក្រោម Header។<br/>• `z-40`: កំណត់ជាន់ z-index ខ្ពស់ ដើម្បីកុំឱ្យ Content ខាងក្រោមលេចធ្លាយមកពីលើ Header។ |
| **Line 6** | `<div className="max-w-6xl mx-auto flex ... justify-between">` — កំណត់ទំហំទទឹងអតិបរមា (`max-w-6xl`), តម្រឹមកណ្តាលអេក្រង់ (`mx-auto`), និងរុញ Logo ទៅឆ្វេង រុញ Navigation Buttons ទៅស្តាំ (`justify-between`)។ |
| **Line 7-10** | Brand Identity — បង្ហាញ Logo Icon និងឈ្មោះ Brand `FastReact`។ |
| **Line 11-18** | `<nav>` Navigation Actions — បង្ហាញ Menu Buttons រួមទាំង Call-To-Action (CTA) Button ពណ៌ខៀវ (`bg-blue-600`)។ |

## 💡 ៦. Component Best Practices សម្រាប់ Developer

- [x] ដាក់ឯកសារ Component មួយក្នុងមួយ File ជានិច្ច (ឧ. `Navbar.jsx`)
- [x] ដាក់ឈ្មោះ Component និង File ជា **PascalCase** (ឧ. `FeatureCard.jsx` មិនមែន `featureCard.jsx`)
- [x] រក្សា Component ឱ្យខ្លី និងងាយយល់ (ក្រោម ១៥០ បន្ទាត់) — បើវែងពេក ចូរពិចារណាបំបែកជា Sub-components
- [x] ដាក់ Reusable Components ក្នុង Folder `src/components/` និង Page Views ក្នុង `src/pages/`
