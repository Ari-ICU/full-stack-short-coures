## 🎯 គោលដៅ Mini Project

យើងនឹងសាងសង់ **Card Component Library** ដែលមានរចនាសម្ព័ន្ធឯកសារដាច់ដោយឡែកពីគ្នា សម្រាប់បង្ហាញទាំង **User Profile Card** និង **E-Commerce Product Card**។

```text
src/
├── components/
│   ├── cards/
│   │   ├── ProfileCard.jsx
│   │   └── ProductCard.jsx
│   └── ui/
│       ├── Avatar.jsx
│       └── PriceTag.jsx
└── App.jsx
```

---

## 🛠️ ការសរសេរកូដអនុវត្តជាក់ស្តែង

### 1. បង្កើត UI Primitives (`src/components/ui/Avatar.jsx`)
```jsx
export function Avatar({ src, alt }) {
  return (
    <img 
      src={src} 
      alt={alt} 
      className="w-20 h-20 rounded-full border-2 border-blue-500 object-cover shadow-sm" 
    />
  );
}
```

### 2. បង្កើត ProfileCard (`src/components/cards/ProfileCard.jsx`)
```jsx
import { Avatar } from '../ui/Avatar';

export default function ProfileCard({ name, role, bio, avatarUrl }) {
  return (
    <div className="bg-white rounded-2xl shadow-md p-6 max-w-sm text-center border border-gray-100">
      <div className="flex justify-center mb-4">
        <Avatar src={avatarUrl} alt={name} />
      </div>
      <h3 className="text-xl font-bold text-gray-800">{name}</h3>
      <p className="text-sm font-semibold text-blue-600 mb-2">{role}</p>
      <p className="text-gray-600 text-sm">{bio}</p>
      <button className="mt-4 px-4 py-2 bg-blue-600 text-white rounded-lg hover:bg-blue-700 transition">
        Connect Profile
      </button>
    </div>
  );
}
```

### 3. បង្កើត ProductCard (`src/components/cards/ProductCard.jsx`)
```jsx
export default function ProductCard({ title, price, category, imageUrl }) {
  return (
    <div className="bg-white rounded-2xl shadow-md overflow-hidden max-w-sm border border-gray-100">
      <img src={imageUrl} alt={title} className="w-full h-48 object-cover" />
      <div className="p-5">
        <span className="text-xs uppercase font-bold text-indigo-500 bg-indigo-50 px-2.5 py-1 rounded-full">
          {category}
        </span>
        <h4 className="text-lg font-bold text-gray-800 mt-2">{title}</h4>
        <div className="flex items-center justify-between mt-4">
          <span className="text-2xl font-black text-gray-900">${price}</span>
          <button className="px-4 py-2 bg-emerald-600 text-white rounded-lg hover:bg-emerald-700 transition">
            Add to Cart
          </button>
        </div>
      </div>
    </div>
  );
}
```
