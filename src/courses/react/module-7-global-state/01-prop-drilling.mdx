## 😫 1. បញ្ហា Prop Drilling

នៅពេល Component Tree កាន់តែជ្រៅ ការបញ្ជូន State ចុះក្រោមតាមរយៈ Props ច្រើនជាន់ ធ្វើឱ្យកូដពិបាក Maintain និងងាយ Error ពេល Refactor៖

```mermaid
flowchart TD
    subgraph Problem["❌ Prop Drilling: Cluttered Intermediate Components"]
        direction TB
        App["&lt;App /&gt; (Holds user state)"] -->|Passes user prop| Layout["&lt;Layout /&gt; (Doesn't use user)"]
        Layout -->|Passes user prop| Side["&lt;Sidebar /&gt; (Doesn't use user)"]
        Side -->|Passes user prop| Nav["&lt;NavMenu /&gt; (Doesn't use user)"]
        Nav -->|Finally uses user!| Avatar["&lt;UserAvatar /&gt; 🎯"]
    end

    subgraph Solution["✅ React Context API: Direct Teleportation"]
        direction TB
        Provider["&lt;UserContext.Provider value={user}&gt;"]
        Target["&lt;UserAvatar /&gt;<br><code>const user = useContext(UserContext)</code> 🚀"]
        Provider -.->|Direct Wireless Access (No Middlemen)| Target
    end

    style Problem fill:#fff5f5,stroke:#e53e3e,color:#000

    style Target fill:#c6f6d5,stroke:#38a169,color:#000
```
