## 🎨 1. Normal HTML Select vs Headless Accessible Dropdown

### 🌐 Normal HTML Structure:

```html
<!-- HTML Native Select Dropdown -->
<select class="custom-select">
  <option value="edit">✏️ Edit Profile</option>
  <option value="settings">⚙️ Settings</option>
  <option value="delete">🗑️ Delete Account</option>
</select>
```

### 💻 React Code ជាមួយ Lucide Icons:

```jsx
import { User, Settings, Trash2, ChevronDown } from 'lucide-react';

export function ActionMenu() {
  return (
    <div className="w-56 p-2 bg-white dark:bg-slate-800 rounded-2xl shadow border space-y-1">
      <button className="w-full flex items-center gap-3 px-3 py-2 text-xs font-semibold text-slate-700 dark:text-slate-200 hover:bg-slate-100 dark:hover:bg-slate-700 rounded-xl transition">
        <User className="w-4 h-4 text-blue-500" />
        <span>Edit Profile</span>
      </button>

      <button className="w-full flex items-center gap-3 px-3 py-2 text-xs font-semibold text-slate-700 dark:text-slate-200 hover:bg-slate-100 dark:hover:bg-slate-700 rounded-xl transition">
        <Settings className="w-4 h-4 text-slate-400" />
        <span>Settings</span>
      </button>

      <button className="w-full flex items-center gap-3 px-3 py-2 text-xs font-semibold text-red-600 hover:bg-red-50 dark:hover:bg-red-900/30 rounded-xl transition">
        <Trash2 className="w-4 h-4" />
        <span>Delete Account</span>
      </button>
    </div>
  );
}
```

### 🔍 ការពន្យល់មួយជួរៗ (Line-by-Line Explanation):

1. `import { User, Settings, Trash2 } from 'lucide-react';`
   - Import Icon ជា React Components (Tree-shakable SVGs)។
2. `<User className="w-4 h-4 text-blue-500" />`
   - អាច Style ទំហំ និងពណ៌របស់ Icon តាមរយៈ Tailwind CSS classes បានយ៉ាងងាយស្រួល។
3. `flex items-center gap-3`
   - រៀបចំ Icon និងអក្សរឱ្យតម្រឹមផ្ដេកស្អាតបាត។
