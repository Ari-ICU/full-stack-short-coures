## 🧩 1. Modern Component Architecture ជាមួយ shadcn/ui

```mermaid
flowchart TD
    subgraph Traditional["Traditional UI Libraries (Black Box)"]
        direction TB
        T1["Install <code>node_modules/material-ui</code>"] --> T2["Hard to customize styles & logic"]
        T2 --> T3["Heavy bundle size with unused components"]
    end

    subgraph Modern["Modern shadcn/ui Architecture (Full Ownership)"]
        direction TB
        M1["Radix UI (Accessible Headless Primitives)"] --> M2["Tailwind CSS (Utility Styling)"]
        M2 --> M3["CLI Copies Code Direct to <code>src/components/ui/</code>"]
```
