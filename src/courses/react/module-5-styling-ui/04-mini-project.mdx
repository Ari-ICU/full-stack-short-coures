## 💻 2. Building Variant-based React Button

### 💻 Code សម្រាប់ `Button` Component:

```jsx
const VARIANTS = {
  primary: 'bg-blue-600 hover:bg-blue-700 text-white',
  danger: 'bg-red-600 hover:bg-red-700 text-white',
  outline: 'border border-slate-300 dark:border-slate-600 text-slate-700 dark:text-slate-200 hover:bg-slate-100 dark:hover:bg-slate-700',
};

export function Button({ variant = 'primary', children, onClick }) {
  return (
    <button
      onClick={onClick}
      className={`px-4 py-2 rounded-xl text-xs font-bold transition ${VARIANTS[variant] || VARIANTS.primary}`}
    >
      {children}
    </button>
  );
}
```

### 🔍 ការពន្យល់មួយជួរៗ (Line-by-Line Explanation):

1. `const VARIANTS = { ... }`
   - Object ផ្គូផ្គងឈ្មោះ Variant ទៅកាន់ Tailwind CSS classes ជាក់លាក់។
2. `variant = 'primary'`
   - កំណត់លំនាំដើមថា `primary` ប្រសិនបើ caller មិនបានបញ្ជូន variant prop មក។
3. `${VARIANTS[variant]}`
   - ជ្រើសរើស Style តាម prop ដោយស្វ័យប្រវត្តិ។
