> [!TIP]
> **សាកល្បងពិសោធន៍:**
> 1. ក្នុង **ករណីទី ១ (Derived State) ៖** សាកល្បងវាយប្តូរឈ្មោះ ➔ សង្កេតមើលថា របៀបខុសដែលប្រើ `useEffect` បណ្តាលឱ្យ Component ត្រូវ **Re-render ២ ដង** ខណៈដែលរបៀបត្រូវ (Derived State) Render តែ **១ ដងគត់** និងលឿនបំផុត!
> 2. ក្នុង **ករណីទី ២ (Button Click) ៖** ចុចប៊ូតុងទាំងពីរ ដើម្បីមើលភាពខុសគ្នារវាងការហៅ API ក្នុង Event Handler ផ្ទាល់ ធៀបនឹងការប្រើ useEffect។

## 🧮 ៣. កំហុសទី ១ ៖ ប្រើ useEffect ដើម្បីបូកទិន្នន័យ (Derived State Trap)

ស្រមៃថាអ្នកមាន `firstName` និង `lastName` ហើយចង់បាន `fullName`៖

### ❌ របៀបខុស (Anti-pattern ធ្វើឱ្យ Re-render ២ ដង):
```jsx
function UserProfile() {
  const [firstName, setFirstName] = useState('Sok');
  const [lastName, setLastName] = useState('Dara');
  const [fullName, setFullName] = useState(''); // ❌ បង្កើត State ស្ទួនឥតប្រយោជន៍!

  // ⚠️ អាក្រក់ណាស់: Component ត្រូវ Render លើកទី ១ រួចទើប Effect រត់ ➔ ហៅ setFullName ➔ Re-render លើកទី ២!
  useEffect(() => {
    setFullName(`${firstName} ${lastName}`);
  }, [firstName, lastName]);

  return <h1>{fullName}</h1>;
}
```

### ✅ របៀបត្រូវ (Derived State — គណនាផ្ទាល់):
```jsx
function UserProfile() {
  const [firstName, setFirstName] = useState('Sok');
  const [lastName, setLastName] = useState('Dara');

  // ✨ គណនាផ្ទាល់ភ្លាមៗក្នុងពេល Render គ្មាន Re-render លើកទី ២ ស៊ីពេលត្រឹម 0.001ms!
  const fullName = `${firstName} ${lastName}`;

  return <h1>{fullName}</h1>;
}
```

## 🔍 ៤. កំហុសទី ២ ៖ Filter បញ្ជីទិន្នន័យពេល User Search

### ❌ របៀបខុស:
```jsx
function ProductList({ products }) {
  const [query, setQuery] = useState('');
  const [filteredProducts, setFilteredProducts] = useState([]); // ❌

  useEffect(() => {
    setFilteredProducts(
      products.filter((p) => p.name.toLowerCase().includes(query.toLowerCase()))
    );
  }, [products, query]);

  return (/* បង្ហាញ filteredProducts */);
}
```

### ✅ របៀបត្រូវ:
```jsx
function ProductList({ products }) {
  const [query, setQuery] = useState('');

  // ✨ គណនាផ្ទាល់តែម្តង! បើទិន្នន័យច្រើនរាប់ម៉ឺន rows អាចរុំជាមួយ useMemo
  const filteredProducts = products.filter((p) =>
    p.name.toLowerCase().includes(query.toLowerCase())
  );

  return (/* បង្ហាញ filteredProducts */);
}
```

## 🛒 ៥. កំហុសទី ៣ ៖ ដាក់កូដ User Actions ចូលក្នុង `useEffect`

ស្រមៃថា User ចុចប៊ូតុង **«ទិញឥឡូវនេះ (Buy Now)»**៖

### ❌ របៀបខុស:
```jsx
function Checkout() {
  const [isBuying, setIsBuying] = useState(false);

  // ❌ ខុស! ការទិញទំនិញជា Action របស់ User មិនមែនជាការធ្វើសមកាលកម្មទេ
  useEffect(() => {
    if (isBuying) {
      sendPaymentToServer();
    }
  }, [isBuying]);

  return <button onClick={() => setIsBuying(true)}>ទិញឥឡូវនេះ</button>;
}
```

### ✅ របៀបត្រូវ:
```jsx
function Checkout() {
  // ✅ ដាក់ក្នុង Event Handler ផ្ទាល់តែម្តង ងាយយល់ និងគ្មាន Bug!
  const handleBuyClick = () => {
    sendPaymentToServer();
  };

  return <button onClick={handleBuyClick}>ទិញឥឡូវនេះ</button>;
}
```

## 🔄 ៦. កំហុសទី ៤ ៖ Reset Form State តាមរយៈ `useEffect`

ចុះបើអ្នកចង់ Reset ប្រអប់ Comment ឱ្យទទេស្អាត នៅពេល User ប្តូរទៅមើល Profile របស់មនុស្សម្នាក់ទៀត (`userId` ប្រែប្រួល)?

### ❌ របៀបស្មុគស្មាញ:
```jsx
function CommentBox({ userId }) {
  const [comment, setComment] = useState('');

  // ⚠️ ត្រូវ Render comment ចាស់សិន រួចទើប Effect reset comment តាមក្រោយ
  useEffect(() => {
    setComment('');
  }, [userId]);

  return <textarea value={comment} onChange={(e) => setComment(e.target.value)} />;
}
```

### ✅ ដំណោះស្រាយដ៏ឆ្លាតវៃ ៖ ប្រើ `key` prop!
```jsx
// នៅក្នុង Component មេ:
export default function App() {
  const [selectedUserId, setSelectedUserId] = useState(1);

  // ✨ គ្រាន់តែដាក់ key={selectedUserId}
  // React នឹងដឹងថាជា Component ថ្មី ➔ លុប state ចាស់ចោល ហើយបង្កើត state ដើមឡើងវិញដោយស្វ័យប្រវត្តិ!
  return <CommentBox key={selectedUserId} userId={selectedUserId} />;
}
```

## 🛑 ៧. កំហុសទី ៥ ៖ Infinite Re-render Loop

```jsx
// ❌ គ្រោះថ្នាក់បំផុត
function InfiniteCounter() {
  const [count, setCount] = useState(0);

  // គ្មាន Dependency Array ➔ រត់រាល់ Render ➔ setState ➔ Re-render ➔ រត់ Effect ➔ ...
  useEffect(() => {
    setCount(count + 1);
  });
}
```

### 💡 វិធានការដោះស្រាយ៖
1. **តែងតែផ្តល់ Dependency Array ជានិច្ច** (`[]` ឬ `[dependencies]`)។
2. បើចង់ធ្វើ Timer ចូរប្រើ `setInterval` រួមជាមួយ `clearInterval` ក្នុង Cleanup។

## 🧠 ៨. តារាងវិនិច្ឆ័យ "តើខ្ញុំគួរប្រើ useEffect ដែរឬទេ?"

| ស្ថានភាព / ការងារ | ដំណោះស្រាយត្រឹមត្រូវ | ហេតុផល |
| :--- | :--- | :--- |
| បូកអក្សរ, គណនាតម្លៃសរុប (Total) | **Derived State** (គណនាផ្ទាល់ក្នុង Render) | គ្មាន extra re-render, លឿនបំផុត |
| Filter បញ្ជីទិន្នន័យតាម Search Query | **Direct Filter / `useMemo`** | មិនចាំបាច់មាន useState ស្ទួន |
| User ចុចប៊ូតុង Submit ឬ Buy | **Event Handler (`onClick`)** | ជាសកម្មភាពផ្ទាល់របស់ User |
| Reset Form ពេលប្តូរ ID | **ប្រើ `key={id}` prop** | React reset state ដោយស្វ័យប្រវត្តិ |
| ទាញទិន្នន័យពី API លើកដំបូង | **`useEffect(..., [])`** | ធ្វើសមកាលកម្មជាមួយ Network Server |
| កែប្រែ Browser Tab Title (`document.title`) | **`useEffect(..., [val])`** | ធ្វើសមកាលកម្មជាមួយ Browser DOM |
| បង្កើត Timer (`setInterval`) | **`useEffect` + Cleanup** | ធ្វើសមកាលកម្មជាមួយ Browser Timer |
