## 🛡️ ១. Why State Immutability Matters (Memory Reference & Diffing)

> [!IMPORTANT]
> **និយមន័យ State Immutability (Definition) ៖**  
> យោងតាមគេហទំព័រផ្លូវការរបស់ React (**react.dev**), **State Immutability** គឺជាគោលការណ៍គ្រឹះដែលចែងថា State របស់ React ត្រូវតែចាត់ទុកដូចជា **Read-Only**។  
> 
> អ្នកមិនត្រូវធ្វើ **Direct Mutation** (ដូចជា `user.age = 26` ឬ `items.push(...)`) លើ Objects ឬ Arrays ដែលមានស្រាប់ឡើយ។ រាល់ពេលធ្វើបច្ចុប្បន្នភាព State អ្នកត្រូវតែបង្កើត **New Object / New Array Reference (Copy ថ្មី)** ជានិច្ច តាមរយៈ Spread Operator (`...`) ឬ Immutable Array Methods (`.map()`, `.filter()`) ដើម្បីឱ្យ React Shallow Equality Check (`oldState === newState`) វាយតម្លៃថា `false` និងធ្វើការ Re-render UI។

## 🛠️ ២. ឧទាហរណ៍ជាក់ស្តែង ៖ Profile & Skills Manager

```jsx
// src/components/ProfileManager.jsx
import React, { useState } from 'react';

export default function ProfileManager() {
  // 1. Object State
  const [profile, setProfile] = useState({
    name: 'រដ្ឋា',
    role: 'Frontend Developer',
    level: 1,
  });

  // 2. Array of Objects State
  const [skills, setSkills] = useState([
    { id: 1, name: 'HTML & CSS', mastered: true },
    { id: 2, name: 'React 19', mastered: false },
  ]);

  // A. Update Object ដោយប្រើ Spread Operator
  const handleLevelUp = () => {
    setProfile({
      ...profile,          // Copy properties ចាស់ៗ
      level: profile.level + 1, // Overwrite property ជាក់លាក់
    });
  };

  // B. Add to Array ដោយប្រើ Spread Operator
  const handleAddSkill = (skillName) => {
    const newSkill = { id: Date.now(), name: skillName, mastered: false };
    setSkills([...skills, newSkill]); // បង្កើត Array ថ្មីមួយ
  };

  // C. Toggle Item ក្នុង Array ដោយប្រើ .map()
  const handleToggleSkill = (skillId) => {
    setSkills(
      skills.map((s) =>
        s.id === skillId ? { ...s, mastered: !s.mastered } : s
      )
    );
  };

  // D. Delete Item ពី Array ដោយប្រើ .filter()
  const handleDeleteSkill = (skillId) => {
    setSkills(skills.filter((s) => s.id !== skillId));
  };

  return (
    <div className="p-6 max-w-md mx-auto bg-white dark:bg-slate-900 border border-slate-200 dark:border-slate-800 rounded-2xl shadow-lg space-y-5">
      {/* Profile Header */}
      <div className="flex justify-between items-center border-b pb-3">
        <div>
          <h2 className="font-black text-lg text-slate-800 dark:text-white">{profile.name}</h2>
          <p className="text-xs text-slate-500">{profile.role} • Level {profile.level}</p>
        </div>
        <button
          onClick={handleLevelUp}
          className="px-3 py-1.5 bg-blue-600 hover:bg-blue-700 text-white text-xs font-bold rounded-xl transition"
        >
          +1 Level Up
        </button>
      </div>

      {/* Skills List */}
      <div>
        <h3 className="font-bold text-sm text-slate-700 dark:text-slate-300 mb-2">ជំនាញបច្ចេកទេស ៖</h3>
        <ul className="space-y-2">
          {skills.map((skill) => (
            <li 
              key={skill.id} 
              className="flex justify-between items-center p-2.5 bg-slate-50 dark:bg-slate-800 rounded-xl text-xs"
            >
              <span 
                onClick={() => handleToggleSkill(skill.id)}
                className={`cursor-pointer font-bold ${skill.mastered ? 'text-emerald-600 line-through' : 'text-slate-700 dark:text-slate-300'}`}
              >
                {skill.mastered ? '✓ ' : '○ '} {skill.name}
              </span>
              <button
                onClick={() => handleDeleteSkill(skill.id)}
                className="text-rose-500 hover:text-rose-700 font-bold px-2 py-0.5"
              >
                លុប
              </button>
            </li>
          ))}
        </ul>
      </div>

      <button
        onClick={() => handleAddSkill('TypeScript Mastery')}
        className="w-full py-2 bg-slate-100 hover:bg-slate-200 dark:bg-slate-800 text-slate-700 dark:text-slate-300 font-bold text-xs rounded-xl transition"
      >
        + បន្ថែមជំនាញ TypeScript
      </button>
    </div>
  );
}
```

## 📋 ៤. តារាងសង្ខេប Array Methods (Safe vs Unsafe in React)

| ប្រតិបត្តិការ | ❌ ហាមដាច់ខាត (Mutates State) | ✅ វិធីស្តង់ដារ (Immutable Copy) |
| :--- | :--- | :--- |
| **បន្ថែម (Add)** | `arr.push(item)`, `arr.unshift(item)` | `[...arr, item]`, `[item, ...arr]` |
| **លុប (Delete)** | `arr.pop()`, `arr.shift()`, `arr.splice(idx, 1)` | `arr.filter(item => item.id !== id)` |
| **កែប្រែ (Update)** | `arr[idx] = newItem`, `item.done = true` | `arr.map(item => item.id === id ? { ...item, ...updates } : item)` |
| **តម្រៀប (Sort/Reverse)** | `arr.sort()`, `arr.reverse()` | `[...arr].sort()`, `[...arr].reverse()` (ចម្លងមុនសិន) |
