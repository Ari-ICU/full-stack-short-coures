# 🎣 useState Deep Dive & Best Practices

`useState` គឺជា Hook មូលដ្ឋានបំផុតនៅក្នុង React សម្រាប់បន្ថែម Local State ទៅកាន់ Functional Component។

---

## ១. Lazy Initial State (សម្រាប់កិច្ចការធ្ងន់ៗ)

ប្រសិនបើ Initial State របស់អ្នកត្រូវអានពី `localStorage` ឬ Parse JSON ធំៗ ចូរប្រើ **Lazy Initializer** ដោយបញ្ជូន Function៖

```tsx
import { useState } from "react";

export function HeavyComponent() {
  const [savedConfig, setSavedConfig] = useState(() => {
    try {
      const item = localStorage.getItem("app_config");
      return item ? JSON.parse(item) : { theme: "dark", zoom: 100 };
    } catch {
      return { theme: "dark", zoom: 100 };
    }
  });

  return <div>Config Theme: {savedConfig.theme}</div>;
}
```

## ២. ចៀសវាង Redundant State (ប្រើ Derived State)

```tsx
export function CartSummary({ items }: { items: { id: string; price: number; quantity: number }[] }) {
  // ✅ ត្រឹមត្រូវ: គណនាជា Derived Variable ដោយផ្ទាល់ពេល Render
  const totalPrice = items.reduce((sum, item) => sum + item.price * item.quantity, 0);
  const totalItemsCount = items.reduce((sum, item) => sum + item.quantity, 0);

  return (
    <div className="p-4 bg-slate-900 rounded-xl">
      <p>សរុបចំនួនទំនិញ: {totalItemsCount}</p>
      <p className="text-xl font-bold text-emerald-400">តម្លៃសរុប: ${totalPrice.toFixed(2)}</p>
    </div>
  );
}
```
