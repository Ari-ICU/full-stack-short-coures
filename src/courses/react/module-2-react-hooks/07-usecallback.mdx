# 🔗 useCallback: Function Reference Stability

នៅក្នុង JavaScript Function នីមួយៗគឺជា Object មួយ។ រាល់ពេលដែល Component Re-render នោះ Function ថ្មីមួយនឹងត្រូវបានបង្កើតឡើងជាមួយនឹង **Memory Reference ថ្មី** ជានិច្ច (`() => {} !== () => {}`)។

`useCallback` ជួយ **ចងចាំ Function Reference ដដែល** រវាង Render cycles ទាំងអស់។

---

## ការប្រើប្រាស់ `useCallback` ជាមួយ `React.memo`

```tsx
import { useState, useCallback, memo } from "react";

const ExpensiveRow = memo(function ExpensiveRow({
  id,
  onDelete,
}: {
  id: string;
  onDelete: (id: string) => void;
}) {
  return (
    <div className="flex justify-between items-center p-3 bg-slate-800 rounded-lg">
      <span>Item #{id}</span>
      <button onClick={() => onDelete(id)} className="px-3 py-1 bg-rose-600 text-white rounded text-sm">
        Delete
      </button>
    </div>
  );
});

export function ParentList() {
  const [items, setItems] = useState(["1", "2", "3"]);

  const handleDelete = useCallback((id: string) => {
    setItems((prev) => prev.filter((item) => item !== id));
  }, []);

  return (
    <div className="space-y-2">
      {items.map((id) => (
        <ExpensiveRow key={id} id={id} onDelete={handleDelete} />
      ))}
    </div>
  );
}
```
