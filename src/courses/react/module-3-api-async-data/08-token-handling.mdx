# 🔐 Token Handling & Secure HTTP Requests

នៅក្នុងស្ថាបត្យកម្មទំនើប React Client ផ្ទៀងផ្ទាត់សិទ្ធិជាមួយ REST API តាមរយៈ **JSON Web Tokens (JWT)**។

```mermaid
sequenceDiagram
    participant React as React App
    participant Storage as localStorage / Memory
    participant API as Backend Server

    React->>API: POST /login { email, password }
    API-->>React: 200 OK { token: "jwt_abc123" }
    React->>Storage: រក្សាទុក Token
    Note over React,API: រាល់ Requests បន្ទាប់ទាំងអស់...
    React->>API: GET /profile (Header: Authorization: Bearer jwt_abc123)
    API-->>React: 200 OK { profile data }
```

## ការភ្ជាប់ Authorization Header ដោយស្វ័យប្រវត្តិតាម Axios

```tsx
import axios from "axios";

export const authAxios = axios.create({
  baseURL: import.meta.env.VITE_API_URL,
});

authAxios.interceptors.request.use((config) => {
  const token = localStorage.getItem("auth_token");
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});
```
