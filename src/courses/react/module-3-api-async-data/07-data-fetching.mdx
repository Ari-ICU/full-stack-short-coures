# 🏎️ Data Fetching Patterns & Race Conditions

នៅពេលដែលអ្នកប្រើប្រាស់ចុចប្តូរ Tabs ឬវាយពាក្យស្វែងរកលឿនៗ Requests ជាច្រើនត្រូវបានបាញ់ចេញដំណាលគ្នា។

```mermaid
sequenceDiagram
    participant User as អ្នកប្រើប្រាស់
    participant React as React Component
    participant Server as Backend API

    User->>React: វាយ "Cat" (Request 1)
    React->>Server: GET /search?q=cat (យឺត 800ms)
    User->>React: វាយ "Dog" (Request 2)
    React->>Server: GET /search?q=dog (លឿន 200ms)
    Server-->>React: Response 2 ("Dog") មកដល់មុន -> set UI = Dog
    Server-->>React: Response 1 ("Cat") មកដល់ក្រោយ -> set UI = Cat (❌ RACE CONDITION BUG)
```

## ការដោះស្រាយដោយប្រើ Cleanup Flag Pattern

```tsx
import { useState, useEffect } from "react";

export function SearchResults({ query }: { query: string }) {
  const [data, setData] = useState<string[]>([]);

  useEffect(() => {
    let ignore = false; // Flag ដើម្បីទប់ស្កាត់ Stale Response

    async function fetchData() {
      const res = await fetch(`https://api.example.com/search?q=${query}`);
      const json = await res.json();
      if (!ignore) {
        setData(json.results);
      }
    }

    if (query) {
      fetchData();
    }

    return () => {
      ignore = true; // ប្រសិនបើ query ផ្លាស់ប្តូរ Ignore response ចាស់ចោលភ្លាម
    };
  }, [query]);

  return <div>{/* Render Results */}</div>;
}
```
