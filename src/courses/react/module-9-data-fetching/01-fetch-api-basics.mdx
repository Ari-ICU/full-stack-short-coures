## 🌐 1. Tri-State Architecture

ក្នុងការទាញទិន្នន័យពី Network តែងតែមាន ៣ ដំណាក់កាល (Tri-State)៖
1. **Loading State:** កំពុងរង់ចាំទិន្នន័យពី Server
2. **Error State:** មានបញ្ហា Network ឬ Server Error (4xx, 5xx)
3. **Success State:** ទទួលបានទិន្នន័យត្រឹមត្រូវ ហើយ Render លើ Screen

---

## 📦 2. Tri-State Definition (State Hooks)

### 💻 Code សម្រាប់តែ State Declaration:

```javascript
const [data, setData] = useState(null);          // ផ្ទុក Response Data (ចាប់ផ្តើមដោយ null)
const [isLoading, setIsLoading] = useState(true); // ស្ថានភាពកំពុងទាញ (ចាប់ផ្តើមដោយ true)
const [error, setError] = useState(null);        // ផ្ទុកសារ Error បើមានបញ្ហា
```

### 🔍 ការពន្យល់មួយជួរៗ (Line-by-Line Explanation):

1. `const [data, setData] = useState(null);`
   - កំណត់ initial state ជា `null` បញ្ជាក់ថាមិនទាន់ទទួលបានទិន្នន័យនៅឡើយ។
2. `const [isLoading, setIsLoading] = useState(true);`
   - ដាក់ `true` ពីដំបូង ដើម្បីឱ្យ UI បង្ហាញ Loading Spinner/Skeleton ភ្លាមៗពេល Page ចាប់ផ្តើម Render។
3. `const [error, setError] = useState(null);`
   - ដាក់ `null` — ប្រសិនបើ Fetch បរាជ័យ ទើបយើង update វាជា Error string message។

## ⚡ 3. Fetch Logic ជាមួយ async/await និង Error Checking

### 💻 Code សម្រាប់តែ Fetch Request Logic:

```javascript
const fetchUsers = async () => {
  setIsLoading(true);
  setError(null);

  try {
    const res = await fetch('https://jsonplaceholder.typicode.com/users');

    // fetch() មិនបោះ Error ដោយស្វ័យប្រវត្តិលើ 404/500 ទេ ត្រូវឆែក res.ok
    if (!res.ok) {
      throw new Error(`HTTP Error Status: ${res.status}`);
    }

    const json = await res.json();
    setData(json); // រក្សាទុកទិន្នន័យចូលក្នុង State
  } catch (err) {
    setError(err.message); // ចាប់សារ Error
  } finally {
    setIsLoading(false);   // បិទ Loading មិនថាជោគជ័យ ឬបរាជ័យ
  }
};
```

### 🔍 ការពន្យល់មួយជួរៗ (Line-by-Line Explanation):

1. `setIsLoading(true); setError(null);`
   - Reset State ឱ្យស្អាតមុនពេលចាប់ផ្តើមទាញទិន្នន័យថ្មី។
2. `const res = await fetch(...)`
   - ហៅ native browser fetch API ដោយរង់ចាំ Promise resolve។
3. `if (!res.ok) throw new Error(...)`
   - **សំខាន់:** fetch() នឹង reject តែពេលបាត់ Network ប៉ុណ្ណោះ។ បើ Server ឆ្លើយតប 404 ឬ 500 វានៅតែចូល try block ដដែល ដូច្នេះយើងត្រូវឆែក `res.ok` (status 200–299) ដោយខ្លួនឯង។
4. `const json = await res.json(); setData(json);`
   - Parse HTTP response body ជា JavaScript Object/Array រួច update ចូល `data` state។
5. `finally { setIsLoading(false); }`
   - Block `finally` ដំណើរការជានិច្ច ធានាថា Loading Indicator នឹងត្រូវបិទជានិច្ច។

## 🛑 4. AbortController & Cleanup Pattern

### 💻 Code សម្រាប់តែ AbortController ក្នុង useEffect:

```javascript
useEffect(() => {
  const controller = new AbortController();

  const loadData = async () => {
    try {
      const res = await fetch(url, { signal: controller.signal });
      const json = await res.json();
      setData(json);
    } catch (err) {
      if (err.name === 'AbortError') return; // បើជា Abort កុំចាត់ទុកជា Error
      setError(err.message);
    }
  };

  loadData();

  // Cleanup: Cancel request ពេល User ចាកចេញពី Component
  return () => controller.abort();
}, []);
```

### 🔍 ការពន្យល់មួយជួរៗ (Line-by-Line Explanation):

1. `const controller = new AbortController();`
   - បង្កើត Controller instance របស់ Web API ដើម្បីគ្រប់គ្រងការផ្អាក/បោះបង់ HTTP Request។
2. `{ signal: controller.signal }`
   - ភ្ជាប់ Signal ទៅក្នុង fetch option ដើម្បីឱ្យ Request នេះស្តាប់តាមបញ្ជា Cancel។
3. `if (err.name === 'AbortError') return;`
   - ពេល `controller.abort()` ត្រូវបានហៅ fetch នឹងបោះ error ឈ្មោះ `'AbortError'`។ យើងត្រូវ ignore វា ដើម្បីកុំឱ្យលោត error ក្រហមលើ UI ពេល user គ្រាន់តែប្តូរ page។
4. `return () => controller.abort();`
   - useEffect cleanup function នឹងរត់នៅពេល Component Unmount ដើម្បី cancel in-flight request ការពារ Memory Leak។

## 🎨 5. Conditional UI Rendering

### 💻 Code សម្រាប់តែ UI States (Loading, Error, Success):

```jsx
// 1. Loading UI
if (isLoading) {
  return <div className="spinner">⏳ កំពុងទាញទិន្នន័យ...</div>;
}

// 2. Error UI
if (error) {
  return <div className="error-box">⚠️ មានបញ្ហា៖ {error}</div>;
}

// 3. Success UI
return (
  <ul>
    {data?.map((user) => (
      <li key={user.id}>{user.name}</li>
    ))}
  </ul>
);
```

### 🔍 ការពន្យល់មួយជួរៗ (Line-by-Line Explanation):

1. `if (isLoading)`
   - Early return បង្ហាញ Loading indicator បើ state កំពុង fetch។
2. `if (error)`
   - Early return បង្ហាញផ្ទាំង Error ពណ៌ក្រហម និងសារបញ្ជាក់ជូន User។
3. `data?.map(...)`
   - ប្រើ Optional Chaining `?.` ដើម្បី render list ដោយសុវត្ថិភាព។

## 🚀 6. Complete Integrated Component

```jsx
import { useState, useEffect } from 'react';

export default function UserList() {
  const [users, setUsers] = useState([]);
  const [isLoading, setIsLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const controller = new AbortController();

    const fetchUsers = async () => {
      setIsLoading(true);
      setError(null);

      try {
        const res = await fetch(
          'https://jsonplaceholder.typicode.com/users',
          { signal: controller.signal }
        );

        if (!res.ok) {
          throw new Error(`HTTP ${res.status}: ${res.statusText}`);
        }

        const json = await res.json();
        setUsers(json);
      } catch (err) {
        if (err.name === 'AbortError') return;
        setError(err.message);
      } finally {
        setIsLoading(false);
      }
    };

    fetchUsers();

    return () => controller.abort();
  }, []);

  if (isLoading) {
    return (
      <div className="max-w-md mx-auto p-4 text-center text-slate-500">
        <p className="animate-pulse">⏳ កំពុងផ្ទុកទិន្នន័យ Users...</p>
      </div>
    );
  }

  if (error) {
    return (
      <div className="max-w-md mx-auto p-4 bg-red-50 text-red-600 rounded-xl text-center">
        <p className="font-bold">⚠️ បរាជ័យក្នុងការទាញទិន្នន័យ</p>
        <p className="text-sm mt-1">{error}</p>
      </div>
    );
  }

  return (
    <div className="max-w-md mx-auto p-4">
      <h2 className="text-xl font-bold mb-4 text-slate-800 dark:text-white">
        👥 បញ្ជីឈ្មោះ Users ({users.length})
      </h2>
      <ul className="space-y-2">
        {users.map((user) => (
          <li
            key={user.id}
            className="p-3 bg-white dark:bg-slate-800 rounded-xl border border-slate-100 dark:border-slate-700 shadow-sm"
          >
            <p className="font-semibold text-slate-800 dark:text-white">{user.name}</p>
            <p className="text-xs text-slate-500">{user.email}</p>
          </li>
        ))}
      </ul>
    </div>
  );
}
```
