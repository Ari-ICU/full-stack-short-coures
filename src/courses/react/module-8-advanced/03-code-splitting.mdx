## ⚡ Code Splitting & Lazy Loading

តាមធម្មតា នៅពេលយើង build កម្មវិធី React នោះកូដ JavaScript ទាំងអស់នឹងត្រូវចងក្រងបញ្ចូលគ្នាជា File តែមួយ (ហៅថា Bundle)។ ប្រសិនបើកម្មវិធីរបស់អ្នកមានទំហំធំ អ្នកប្រើប្រាស់នឹងត្រូវរង់ចាំយូរដើម្បីទាញយក bundle នោះមកបើកទំព័រដំបូង។

**Code Splitting** គឺជាការបំបែក bundle ធំមួយ ទៅជាបំណែកតូចៗជាច្រើន ដែលនឹងត្រូវទាញយកមកប្រើតែនៅពេលណាដែលអ្នកប្រើប្រាស់រត់ទៅកាន់ទំព័រ ឬត្រូវការវាតែប៉ុណ្ណោះ (Lazy Loading)។

---

## 1. របៀបប្រើប្រាស់ `React.lazy()` និង `<Suspense>`

React ផ្តល់នូវមុខងារ `React.lazy()` សម្រាប់ធ្វើការនាំចូល (Import) component មួយមកប្រើបែបយឺតៗ (Dynamic Import)។

```jsx
import { lazy, Suspense } from 'react';

// នាំចូល component បែប lazy load
const LargeChartComponent = lazy(() => import('./LargeChartComponent'));

function Dashboard() {
  return (
    <div>
      <h1>📊 Dashboard របស់ខ្ញុំ</h1>
      
      {/* Suspense រង់ចាំទាញយកកូដមកគ្រប់គ្រាន់ ទើបបង្ហាញ component */}
      <Suspense fallback={<div>🔄 កំពុងផ្ទុកតារាង...</div>}>
        <LargeChartComponent />
      </Suspense>
    </div>
  );
}
```

## 2. Code Splitting ជាមួយ React Router

កន្លែងដែលល្អបំផុតក្នុងការអនុវត្ត Code Splitting គឺនៅលើប្រព័ន្ធ **Routes**។ យើងនឹងផ្ទុកទំព័រ (Pages) នីមួយៗតាមរបៀប lazy loading ដូច្នេះនៅពេលអ្នកប្រើប្រាស់ចូលទៅកាន់ route ណា ទើបកូដទំព័រនោះត្រូវទាញយកមក។

```jsx
import { lazy, Suspense } from 'react';
import { createBrowserRouter, RouterProvider } from 'react-router-dom';

// ផ្ទុក Pages បែប Lazy
const Home = lazy(() => import('./pages/Home'));
const About = lazy(() => import('./pages/About'));
const Products = lazy(() => import('./pages/Products'));

const router = createBrowserRouter([
  {
    path: "/",
    element: (
      <Suspense fallback={<div>🌀 loading page...</div>}>
        <Home />
      </Suspense>
    ),
  },
  {
    path: "/about",
    element: (
      <Suspense fallback={<div>🌀 loading page...</div>}>
        <About />
      </Suspense>
    ),
  }
]);

function App() {
  return <RouterProvider router={router} />;
}
```

## 🚀 អត្ថប្រយោជន៍ចម្បងនៃ Code Splitting
*   **កាត់បន្ថយទំហំទាញយកដំបូង (Initial Bundle Size)**៖ អ្នកប្រើប្រាស់ទាញយកតែទិន្នន័យដែលចាំបាច់សម្រាប់ទំព័រដំបូង។
*   **ល្បឿនដំណើរការលឿន (Faster Load Times)**៖ កាត់បន្ថយពេលវេលារង់ចាំ (Time to Interactive) ធ្វើឱ្យគេហទំព័ររត់លឿនជាងមុន។
*   **សន្សំសំចៃ bandwidth**៖ ទាញយកកូដបន្ថែមតែនៅពេលដែលចុចមើលប៉ុណ្ណោះ។
