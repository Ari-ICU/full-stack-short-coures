## 🛠️ ការរៀបចំគម្រោង React ជាមួយ Vite

មុនពេលយើងអាចសរសេរកូដ React បាន យើងត្រូវដំឡើងឧបករណ៍មួយចំនួនជាមុនសិន។ នៅក្នុងការអភិវឌ្ឍន៍គេហទំព័រទំនើប យើងមិនសរសេរកូដ HTML/JS ធម្មតា ហើយបើកវាផ្ទាល់ក្នុង Browser នោះទេ យើងត្រូវការ **Development Server** និងឧបករណ៍ដើម្បីបម្លែងកូដរបស់យើង។

---

## 1. អ្វីទៅជា Node.js និង npm?

- **Node.js**: គឺជាកម្មវិធីដែលអនុញ្ញាតអោយយើងដំណើរការកូដ JavaScript នៅលើកុំព្យូទ័ររបស់យើង (មិនមែនក្នុង Browser ទេ)។ React ត្រូវការ Node.js ដើម្បីដំណើរការ Development Server។
- **npm (Node Package Manager)**: គឺជាកម្មវិធីសម្រាប់ទាញយកបណ្ណាល័យ (Libraries) កូដផ្សេងៗពីអុីនធឺណិតមកប្រើក្នុងគម្រោងយើង។ វាត្រូវបានដំឡើងមកជាមួយ Node.js ដោយស្វ័យប្រវត្តិ។
- **npx**: ជាកម្មវិធីតូចមួយរបស់ npm ដែលប្រើសម្រាប់ **ដំណើរការ (Execute)** កញ្ចប់កូដដោយមិនចាំបាច់ដំឡើងវាទុកក្នុងកុំព្យូទ័រជារៀងរហូត។

*(ប្រសិនបើអ្នកមិនទាន់មាន Node.js សូមចូលទៅកាន់ [nodejs.org](https://nodejs.org) ដើម្បីទាញយក និងដំឡើង)*

---

## 2. ការបង្កើតគម្រោងជាមួយ Vite ⚡

កាលពីមុន គេនិយមប្រើ `create-react-app` តែបច្ចុប្បន្ន **Vite** (អានថា វីត) គឺជាជម្រើសដ៏ល្អបំផុតព្រោះវាមានល្បឿនលឿនខ្លាំង។

បើកកម្មវិធី Terminal (ឬ Command Prompt) ហើយវាយពាក្យបញ្ជាខាងក្រោម៖

```bash
npm create vite@latest my-react-app
```

បន្ទាប់មកវានឹងសួរអ្នកសំណួរមួយចំនួន៖
1. **Select a framework:** ជ្រើសរើសយក `React`
2. **Select a variant:** ជ្រើសរើសយក `JavaScript` (ឬ `TypeScript` បើអ្នកចង់ប្រើ)

---

## 3. ការដំឡើង និង ដំណើរការគម្រោង

បន្ទាប់ពីបង្កើតរួចរាល់ សូមធ្វើតាមជំហានទាំង ៣ នេះ៖

```bash
# ចូលទៅកាន់ថតគម្រោងរបស់អ្នក
cd my-react-app

# ទាញយកឯកសារចាំបាច់ទាំងអស់ (ទាមទារអុីនធឺណិត)
npm install

# ដំណើរការ Development Server 
npm run dev
```
បន្ទាប់មកបើក Browser ហើយចូលទៅកាន់ `http://localhost:5173` អ្នកនឹងឃើញគេហទំព័រ React របស់អ្នក!

---

## 4. រចនាសម្ព័ន្ធថត (Folder Structure)

នៅពេលអ្នកបើកគម្រោងនេះក្នុង VS Code អ្នកនឹងឃើញ Folder សំខាន់ៗដូចជា៖

- `node_modules/`: ផ្ទុកឯកសារកូដដែល `npm install` បានទាញយកមក។ **(កុំកែប្រែកូដក្នុងនេះអោយសោះ!)**
- `public/`: ផ្ទុករូបភាព ឬឯកសារដែលមិនត្រូវការផ្លាស់ប្តូរ (Static assets)។
- `src/`: នេះគឺជាកន្លែងដែលអ្នកនឹងសរសេរកូដ React ភាគច្រើន!
  - `main.jsx`: ជាកន្លែងដែលកូដ React ចាប់ផ្តើមដំណើរការ និងបញ្ចូលខ្លួនវាទៅក្នុង HTML។
  - `App.jsx`: នេះគឺជា Component មេ (Root Component) នៃកម្មវិធីរបស់អ្នក។
- `index.html`: ជាឯកសារ HTML តែមួយគត់ដែល Browser បើកអាន (Single Page Application)។
- `package.json`: ផ្ទុកឈ្មោះគម្រោង និងបញ្ជីឈ្មោះ Libraries ដែលគម្រោងយើងត្រូវការ។
