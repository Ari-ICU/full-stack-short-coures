## 🔄 ការបង្ហាញបញ្ជីទិន្នន័យ (Lists)

នៅក្នុងគម្រោងជាក់ស្តែង ទិន្នន័យដែលយើងទទួលបានពី Database ច្រើនតែមកជាទម្រង់ **Array of Objects** (បញ្ជីទិន្នន័យ)។ ដើម្បីបង្ហាញវាចូលទៅក្នុង HTML (JSX) យើងត្រូវប្រើប្រាស់អនុគមន៍ `.map()` របស់ JavaScript។

> **ចំណាំ:** យើងមិនអាចប្រើប្រាស់ `for` ឬ `while` loop ផ្ទាល់នៅក្នុង JSX `{}` បានទេ។

---

## 1. ការប្រើប្រាស់ `.map()`

អនុគមន៍ `.map()` នឹងទាញយកធាតុនីមួយៗពីក្នុង Array មករុំក្នុងកូដ HTML របស់អ្នក។

```jsx
export default function FruitList() {
  const fruits = ["ផ្លែប៉ោម", "ចេក", "ក្រូច"];

  return (
    <ul>
      {fruits.map((fruit, index) => {
        // អ្នកត្រូវតែ Return កូដ JSX ត្រលប់មកវិញ
        return <li key={index}>{fruit}</li>;
      })}
    </ul>
  );
}
```
*ទម្រង់សរសេរកាត់:* បើអ្នក `return` តែមួយជួរ អ្នកអាចដកពាក្យ `return` និង `{}` ចេញបាន។ 
`{fruits.map(fruit => <li key={fruit}>{fruit}</li>)}`

---

## 2. សារៈសំខាន់នៃ `key` Prop 🔑

តើអ្នកកត់សម្គាល់ឃើញពាក្យ `key` នៅក្នុងកូដខាងលើទេ? 

នៅពេលអ្នកបង្កើតបញ្ជីក្នុង React ធាតុនីមួយៗ (Element) **ត្រូវតែមាន `key` មួយដែលមិនជាន់គ្នា**។ វាជួយអោយ React ចំណាំបានថាតើទិន្នន័យណាមួយត្រូវបាន លុប បន្ថែម ឬផ្លាស់ប្តូរទីតាំង។

> ⚠️ **ក្បួនដ៏សំខាន់:** ចៀសវាងការប្រើប្រាស់ `index` (លេខរៀង) ជា `key` ប្រសិនបើបញ្ជីទិន្នន័យរបស់អ្នកអាចមានការលុប ឬរៀបរៀងឡើងវិញ (Sort)។ **ចូរប្រើប្រាស់ ID របស់ទិន្នន័យ (ឧ. `item.id`) ជានិច្ច!**

## 3. ឧទាហរណ៍ជាក់ស្តែង (Array of Objects)

នេះគឺជាទម្រង់ទិន្នន័យដែលអ្នកនឹងជួបប្រទះញឹកញាប់បំផុតនៅពេលទាញយកទិន្នន័យពី API។

```jsx
const users = [
  { id: 1, name: "រដ្ឋា", role: "Admin" },
  { id: 2, name: "សុខា", role: "Editor" },
  { id: 3, name: "ធីតា", role: "Viewer" }
];

export default function UserTable() {
  return (
    <table className="table">
      <thead>
        <tr>
          <th>ID</th>
          <th>ឈ្មោះ</th>
          <th>តួនាទី</th>
        </tr>
      </thead>
      <tbody>
        {/* ចាប់ផ្តើម Loop ទិន្នន័យ */}
        {users.map((user) => (
          <tr key={user.id}> {/* ប្រើប្រាស់ user.id ជា key គឺល្អបំផុត! */}
            <td>{user.id}</td>
            <td>{user.name}</td>
            <td>{user.role}</td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

## 4. ការចម្រាញ់ទិន្នន័យ (Filtering)

ជារឿយៗ យើងមិនចង់បង្ហាញទិន្នន័យទាំងអស់នោះទេ យើងចង់បង្ហាញតែអ្នកណាដែលត្រូវនឹងលក្ខខណ្ឌប៉ុណ្ណោះ។ ពេលនោះយើងអាចប្រើប្រាស់ `.filter()` បញ្ចូលគ្នាជាមួយ `.map()` បានយ៉ាងស្រួល!

```jsx
// បង្ហាញតែអ្នកដែលមានតួនាទីជា Admin ប៉ុណ្ណោះ
{users
  .filter(user => user.role === "Admin")
  .map(admin => (
    <div key={admin.id}>{admin.name} គឺជាអ្នកគ្រប់គ្រង!</div>
  ))
}
```
