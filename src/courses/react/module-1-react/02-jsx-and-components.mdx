## 📝 ស្គាល់ពី JSX (JavaScript XML)

**JSX** គឺជាទម្រង់ពិសេសមួយដែលអនុញ្ញាតអោយយើងសរសេរកូដ **HTML នៅក្នុង JavaScript**។ ទោះបីជាវាមើលទៅដូចជា HTML តែតាមពិតវាជាកូដ JavaScript សុទ្ធសាធ (វានឹងត្រូវបម្លែងដោយ Vite ពេលដំណើរការ)។

### ច្បាប់សំខាន់ៗរបស់ JSX:

**១. ត្រូវមាន Parent Element តែមួយគត់ (Return a single root element)៖**
```jsx
// ❌ ខុស: គ្មាន Parent រុំ
function App() {
  return (
    <h1>សួស្តី</h1>
    <p>ស្វាគមន៍មកកាន់ React</p>
  );
}

// ✅ ត្រូវ: ប្រើ `<div>` ឬ `<> </>` (Fragment) រុំ
function App() {
  return (
    <>
      <h1>សួស្តី</h1>
      <p>ស្វាគមន៍មកកាន់ React</p>
    </>
  );
}
```

**២. បិទ Tag អោយជិត (Close all the tags):**
នៅក្នុង JSX រាល់ Element ទាំងអស់ទោះបីជាគ្មានកូន (Self-closing) ក៏ត្រូវតែមានសញ្ញាបិទ `/` ដែរ។ 
(ឧទាហរណ៍ `<img src="..." />`, `<br />`, `<input type="text" />`)។

**៣. ប្រើប្រាស់ `className` ជំនួសអោយ `class`:**
ដោយសារពាក្យ `class` គឺជាពាក្យតំណាងរបស់ JavaScript (Reserved keyword) រួចទៅហើយ ទើបនៅក្នុង JSX យើងត្រូវប្រើ `className` សម្រាប់កំណត់ CSS។
```jsx
<div className="bg-blue-500 text-white">Button</div>
```

**៤. ការបង្កប់កូដ JavaScript ក្នុងវង់ក្រចក `{}`:**
អ្នកអាចសរសេរអថេរ (Variables) ឬអនុគមន៍ JavaScript ផ្ទាល់នៅក្នុង HTML របស់អ្នកបានយ៉ាងងាយ!
```jsx
function Greeting() {
  const name = "រដ្ឋា";
  const today = new Date().toLocaleDateString();
  
  return <h1>សួស្តី, {name}! ថ្ងៃនេះគឺជា {today}</h1>;
}
```

## 🧩 Functional Components

នៅក្នុង React ទំនើប យើងប្រើប្រាស់ **Functional Components** (អនុគមន៍) ដើម្បីបង្កើត UI។ Component នីមួយៗគឺគ្រាន់តែជា JavaScript Function មួយដែល `return` កូដ JSX ត្រលប់មកវិញ។ វាប្រៀបដូចជាការបង្កើត Custom HTML Tag ផ្ទាល់ខ្លួនរបស់អ្នកអញ្ចឹង!

**ក្បួនសរសេរ Component៖**
- ឈ្មោះ Component ត្រូវតែចាប់ផ្តើមដោយ **អក្សរធំ** ជានិច្ច (ឧ. `Header`, `Button`, `UserCard`)។ បើអ្នកសរសេរអក្សរតូច React នឹងគិតថាវាជា HTML tag ធម្មតា។

**ឧទាហរណ៍នៃការបង្កើត និងប្រើប្រាស់ Component:**

```jsx
// ឯកសារ: Button.jsx
export default function Button() {
  return <button className="btn">ចុចទីនេះ</button>;
}

// ឯកសារ: App.jsx
import Button from './Button'; // ទាញយក Component ពីឯកសារផ្សេង

function App() {
  return (
    <div>
      <h1>រៀន React Components</h1>
      {/* ហៅ Component មកប្រើ (អ្នកអាចហៅប៉ុន្មានដងក៏បាន) */}
      <Button />
      <Button />
    </div>
  );
}
```

**សន្និដ្ឋាន:** ការប្រើប្រាស់ Components ជួយអោយកូដរបស់យើងស្អាត ងាយស្រួលរកកំហុស និងអាចយកទៅប្រើឡើងវិញ (Reusable) នៅកន្លែងផ្សេងៗបាន។
