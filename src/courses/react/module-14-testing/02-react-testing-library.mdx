## 🎯 1. RTL Query Priority Order

1. **`getByRole`** (អាទិភាពទី ១: `button`, `textbox`, `heading`, `checkbox`)
2. **`getByLabelText`** (ល្អសម្រាប់ Form Inputs ដែលមាន `<label>`)
3. **`getByPlaceholderText`** (សម្រាប់ Input Placeholders)
4. **`getByText`** (សម្រាប់ Paragraphs, Spans)
5. **`getByTestId`** (ជម្រើសចុងក្រោយ ប្រសិនបើគ្មាន Semantic Role)

## 💻 2. Testing a Button Component

### 💻 Code នៃ Component ដែលត្រូវ Test (`Button.jsx`):

```jsx
// src/components/Button.jsx
export function Button({ onClick, disabled, children }) {
  return (
    <button
      onClick={onClick}
      disabled={disabled}
      className="px-4 py-2 bg-blue-600 text-white rounded-xl disabled:opacity-50"
    >
      {children}
    </button>
  );
}
```

### 💻 Code នៃ Test Suite (`Button.test.jsx`):

```jsx
// src/components/Button.test.jsx
import { describe, it, expect, vi } from 'vitest';
import { render, screen } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import { Button } from './Button';

describe('Button Component', () => {
  it('renders correctly with children text', () => {
    // 1. Render Component ចូលក្នុង Virtual DOM
    render(<Button>ចុចទីនេះ</Button>);

    // 2. ស្វែងរក Element តាម Role 'button'
    const button = screen.getByRole('button', { name: /ចុចទីនេះ/i });

    // 3. ផ្ទៀងផ្ទាត់ (Assertion)
    expect(button).toBeInTheDocument();
  });

  it('calls onClick handler when clicked', async () => {
    const handleClick = vi.fn(); // Mock function
    render(<Button onClick={handleClick}>Submit</Button>);

    // Simulate User Click
    const button = screen.getByRole('button', { name: /submit/i });
    await userEvent.click(button);

    // ផ្ទៀងផ្ទាត់ថា Function ត្រូវបានហៅ ១ ដង
    expect(handleClick).toHaveBeenCalledTimes(1);
  });

  it('does NOT trigger onClick when disabled', async () => {
    const handleClick = vi.fn();
    render(<Button onClick={handleClick} disabled>Disabled</Button>);

    const button = screen.getByRole('button', { name: /disabled/i });
    expect(button).toBeDisabled();

    await userEvent.click(button);
    expect(handleClick).not.toHaveBeenCalled(); // មិនត្រូវហៅឡើយ
  });
});
```

### 🔍 ការពន្យល់មួយជួរៗ (Line-by-Line Explanation):

1. `render(<Button>ចុចទីនេះ</Button>);`
   - Render Component ចូលក្នុង jsdom environment ដើម្បីត្រៀម query។
2. `screen.getByRole('button', { name: /ចុចទីនេះ/i })`
   - ស្វែងរកប៊ូតុងដែលមានឈ្មោះអក្សរ "ចុចទីនេះ" (ប្រើ Regular Expression `i` មិនប្រកាន់អក្សរតូចធំ)។
3. `expect(button).toBeInTheDocument();`
   - Matcher ពី `@testing-library/jest-dom` បញ្ជាក់ថា Element ពិតជាមានវត្តមានលើ DOM។
4. `const handleClick = vi.fn();`
   - បង្កើត Mock (Spy) Function របស់ Vitest ដើម្បីតាមដានថាតើ Function នោះត្រូវបានហៅប៉ុន្មានដង និងជាមួយ parameter អ្វីខ្លះ។
5. `await userEvent.click(button);`
   - ក្លែងធ្វើសកម្មភាព User ចុចកណ្ដុរ (Mouse Click) លើប៊ូតុង។
6. `expect(handleClick).toHaveBeenCalledTimes(1);`
   - បញ្ជាក់ថា Handler ដំណើរការត្រឹមត្រូវ ១ ដងគត់។
