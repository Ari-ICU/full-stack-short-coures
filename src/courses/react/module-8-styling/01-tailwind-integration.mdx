## 🎨 ហេតុអ្វីបានជា Tailwind CSS?

នៅពេលសរសេរកូដ React ប្រសិនបើអ្នកសរសេរ CSS ធម្មតា (Vanilla CSS) អ្នកនឹងជួបបញ្ហាដូចជា៖
- ពិបាកគិតឈ្មោះ Class អោយបានសមរម្យ (`.card-wrapper`, `.btn-primary-large`, ...)
- ឯកសារ CSS រីកធំទៅៗ ពិបាករកកូដចាស់ៗមកកែប្រែ
- ត្រូវបើកឯកសារចុះឡើងរវាង `.jsx` និង `.css`

**Tailwind CSS** ត្រូវបានបង្កើតឡើងដើម្បីដោះស្រាយបញ្ហាទាំងនេះ! វាគឺជា **Utility-First CSS Framework** ដែលបានរៀបចំកូដ CSS ខ្លីៗជាស្រេច អោយយើងហៅប្រើផ្ទាល់នៅលើ HTML (ឫ JSX) តែម្តង។

ឧទាហរណ៍៖ ជាជាងសរសេរ CSS `<button class="btn">` ហើយទៅបង្កើត `.btn { background-color: blue; padding: 8px 16px; border-radius: 4px; color: white; }` យើងគ្រាន់តែសរសេរ៖
```jsx
<button className="bg-blue-500 px-4 py-2 rounded text-white hover:bg-blue-600">
  Click Me
</button>
```

## ⚙️ ការដំឡើង Tailwind CSS (ក្នុងគម្រោង Vite + React)

ឧបមាថាអ្នកបានបង្កើតគម្រោង React ដោយប្រើ `npm create vite@latest` រួចហើយ។ សូមបើក Terminal ក្នុង Folder គម្រោងរបស់អ្នក ហើយធ្វើតាមជំហានទាំងនេះ៖

### ជំហានទី ១៖ ដំឡើងកញ្ចប់ Tailwind
ដំណើរការពាក្យបញ្ជា (Command) នេះដើម្បីទាញយក Tailwind និងឧបករណ៍ពាក់ព័ន្ធ៖
```bash
npm install -D tailwindcss postcss autoprefixer
```

### ជំហានទី ២៖ បង្កើតឯកសារ Configuration
ដំណើរការពាក្យបញ្ជានេះដើម្បីបង្កើតឯកសារ `tailwind.config.js` និង `postcss.config.js`៖
```bash
npx tailwindcss init -p
```

### ជំហានទី ៣៖ កែប្រែឯកសារ `tailwind.config.js`
បើកឯកសារ `tailwind.config.js` ហើយកែប្រែកន្លែង `content` ដើម្បីប្រាប់ Tailwind ថាឯកសារណាខ្លះដែលអ្នកនឹងសរសេរ Class របស់វា៖
```javascript
/** @type {import('tailwindcss').Config} */
export default {
  // ប្រាប់ Tailwind អោយស្វែងរក Class នៅក្នុងឯកសារ HTML និង JS/TS/JSX/TSX ទាំងអស់ក្នុង /src
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}",
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}
```

### ជំហានទី ៤៖ បន្ថែម Tailwind ទៅក្នុង CSS កណ្តាល
បើកឯកសារ `src/index.css` (លុបកូដចាស់ៗចេញអោយអស់) រួចថែមបន្ទាត់ ៣ នេះចូល៖
```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

## 🚀 របៀបប្រើប្រាស់ Tailwind ក្នុង React

ឥឡូវនេះ អ្នកអាចចាប់ផ្តើមប្រើ Tailwind បានហើយ! សូមសាកល្បងសរសេរកូដនេះចូលទៅក្នុង `src/App.jsx` របស់អ្នក៖

```jsx
function App() {
  return (
    // 'min-h-screen' = កម្ពស់ពេញអេក្រង់
    // 'bg-gray-100' = ផ្ទៃខាងក្រោយពណ៌ប្រផេះខ្ចី
    // 'flex items-center justify-center' = ដាក់ Content ចំកណ្តាល (Center)
    <div className="min-h-screen bg-gray-100 flex items-center justify-center">
      
      {/* 'max-w-md' = ទំហំទទឹងអតិបរមា 
          'bg-white' = ផ្ទៃខាងក្រោយពណ៌ស
          'rounded-xl shadow-lg' = កោងជ្រុង និងមានស្រមោល
          'p-8' = Padding ធំទូលាយ */}
      <div className="max-w-md bg-white rounded-xl shadow-lg p-8 text-center">
        
        {/* 'text-3xl font-bold text-blue-600' = អក្សរធំ ដិត និងពណ៌ខៀវ 
            'mb-4' = Margin ខាងក្រោម */}
        <h1 className="text-3xl font-bold text-blue-600 mb-4">
          សួស្តី Tailwind CSS! 🌊
        </h1>
        
        <p className="text-gray-600 mb-6">
          ការសរសេរកូដ UI ឥឡូវនេះគឺលឿន និងងាយស្រួលជាងមុន ព្រោះយើងមិនបាច់ចាកចេញពីឯកសារ JSX ឡើយ!
        </p>
        
        {/* 'transition-colors' = ធ្វើអោយចលនាប្តូរពណ៌រលូន (Smooth) */}
        <button className="bg-blue-500 hover:bg-blue-600 text-white font-bold py-2 px-6 rounded-full transition-colors">
          ចាប់ផ្តើមសិក្សា
        </button>
        
      </div>
      
    </div>
  );
}

export default App;
```

សូមមើលលទ្ធផលនៅលើ Browser របស់អ្នក! (បើក `npm run dev`)។

នៅមេរៀនបន្ទាប់ យើងនឹងចាប់ផ្តើមសិក្សាពីច្បាប់ផ្សេងៗរបស់ React ចាប់ពី **JSX** ទៅ!
