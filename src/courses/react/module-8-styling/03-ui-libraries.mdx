## 🎨 UI Component & Icons Libraries

ដើម្បីសាងសង់កម្មវិធី React ឱ្យបានឆាប់រហ័ស មានសោភ័ណភាពខ្ពស់ និងស្របតាមស្តង់ដាររចនា (Design System) គេច្រើនប្រើប្រាស់បណ្ណាល័យជំនួយសម្រាប់បង្កើត **Icons** និង **UI Components**។

---

## 1. ការប្រើប្រាស់ Icons (Lucide React)

**Lucide React** គឺជាបណ្ណាល័យ icon ដ៏ពេញនិយមបំផុតមួយសម្រាប់ React ព្រោះវាផ្តល់ icon ស្អាតៗ សាមញ្ញ និងមានទំហំស្រាល (Vector SVGs)។

### របៀបប្រើប្រាស់៖
1. ដំឡើងតាមរយៈ npm: `npm install lucide-react`
2. នាំចូល icon ដែលចង់បាន ហើយហៅវាប្រើដូច component ធម្មតា៖

```jsx
import { User, Settings, ArrowRight } from 'lucide-react';

function Header() {
  return (
    <div className="flex items-center justify-between p-4 bg-gray-100">
      <div className="flex items-center gap-2">
        {/* អាចកំណត់ size និង color បានយ៉ាងងាយស្រួល */}
        <User size={24} className="text-blue-500" />
        <span>ប្រវត្តិរូប</span>
      </div>
      
      <button className="flex items-center gap-1.5 px-3 py-1.5 bg-blue-600 text-white rounded">
        បន្តទៅមុខ
        <ArrowRight size={16} />
      </button>
    </div>
  );
}
```

## 2. ស្គាល់ពី shadcn/ui

**shadcn/ui** គឺជាបដិវត្តន៍ថ្មីនៃការប្រើប្រាស់ Component Libraries។ វាខុសប្លែកពីបណ្ណាល័យចាស់ៗ (ដូចជា Material UI, Ant Design) ដែលត្រូវ install ទាំងមូលចូល `node_modules`។

shadcn/ui ប្រើប្រាស់ CLI មួយដើម្បី **ចម្លងកូដ components** (ដូចជា Button, Dialog, Dropdown) មកដាក់ក្នុង folder `components/ui/` ក្នុង project របស់អ្នកដោយផ្ទាល់។

### អត្ថប្រយោជន៍របស់ shadcn/ui៖
*   **ការគ្រប់គ្រងពេញលេញ (Full Control)**៖ កូដស្ថិតនៅក្នុង project របស់អ្នក ដូច្នេះអ្នកអាចកែប្រែ HTML, React logic ឬ Tailwind classes របស់វាបាន ១០០%។
*   **គ្មានកូដឥតប្រយោជន៍ (No Bloat)**៖ ប្រសិនបើអ្នកប្រើតែ Button និង input គឺមានតែកូដ Button និង input ប៉ុណ្ណោះដែលត្រូវបានបញ្ចូល ធ្វើឱ្យ bundle size ស្រាលបំផុត។
*   **ស្អាត និងទំនើប**៖ វាត្រូវបានរចនាឡើងយ៉ាងស្រស់ស្អាតដោយប្រើប្រាស់ Tailwind CSS និង Radix UI (សម្រាប់ accessibility)។

## 3. ស្គាល់ពី Tailwind UI

**Tailwind UI** គឺជាបណ្តុំនៃ component templates ផ្លូវការដែលរចនាដោយក្រុមការងារបង្កើត Tailwind CSS ផ្ទាល់។

*   វាផ្តល់នូវបំណែកកូដ (Code snippets) សម្រាប់ទាំងផ្នែក Marketing, Application UI, និង E-commerce។
*   អ្នកគ្រាន់តែ **Copy** កូដពីគេហទំព័ររបស់គេ ហើយយកមក **Paste** ចូលទៅក្នុង project របស់អ្នកជាការស្រេច។
*   វាសមស្របបំផុតសម្រាប់ការកសាង Layouts ធំៗដូចជា Landing Pages, Navbars, Dashboards, និង Tables បានយ៉ាងឆាប់រហ័ស។
