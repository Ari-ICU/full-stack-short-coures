## 🔗 1. ហេតុអ្វីត្រូវប្រើ `<Link>` ជំនួស `<a href>`?

- **`<a href="/about">`:** បង្ខំឱ្យ Browser ធ្វើ **Full Page Reload 🔄** (បាត់បង់ State ក្នុង Memory និងដើរយឺត)។
- **`<Link to="/about">`:** ផ្លាស់ប្តូរ URL ក្នុង Browser Address Bar និង update React Components ភ្លាមៗ **ដោយគ្មានការ Reload ⚡**។

---

## 🛠️ 2. កូដគំរូ: Active Link Styling ជាមួយ `<NavLink>`

```jsx
import { NavLink } from 'react-router-dom';

export function NavigationBar() {
  return (
    <nav className="flex gap-4 p-4 bg-slate-900 text-slate-300">
      <NavLink
        to="/"
        className={({ isActive }) =>
          `px-3 py-1.5 rounded-lg text-sm font-semibold transition ${
            isActive ? 'bg-blue-600 text-white' : 'hover:text-white'
          }`
        }
      >
        ទំព័រដើម
      </NavLink>

      <NavLink
        to="/products"
        className={({ isActive }) =>
          `px-3 py-1.5 rounded-lg text-sm font-semibold transition ${
            isActive ? 'bg-blue-600 text-white' : 'hover:text-white'
          }`
        }
      >
        ផលិតផល
      </NavLink>

      <NavLink
        to="/contact"
        className={({ isActive }) =>
          `px-3 py-1.5 rounded-lg text-sm font-semibold transition ${
            isActive ? 'bg-blue-600 text-white' : 'hover:text-white'
          }`
        }
      >
        ទំនាក់ទំនង
      </NavLink>
    </nav>
  );
}
```
