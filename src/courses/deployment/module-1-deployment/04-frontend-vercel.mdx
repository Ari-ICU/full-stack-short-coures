## ⚡ ហេតុអ្វី Vercel?

<img src="https://upload.wikimedia.org/wikipedia/commons/5/5e/Vercel_logo_black.svg" alt="Vercel Logo" width="150" style={{ display: "block", margin: "0 auto" }} />

សម្រាប់ផ្នែក Backend យើងបានប្រើប្រាស់ Render។ ចំណែកឯផ្នែក Frontend វិញ ជម្រើសដ៏ល្អបំផុត និងពេញនិយមបំផុតនាពេលបច្ចុប្បន្ន (ជាពិសេសសម្រាប់គម្រោង React និង Next.js) គឺ **Vercel**។ 

Vercel គឺជាវេទិកា Cloud ដែលបង្កើតឡើងដោយក្រុមហ៊ុនផ្ទាល់របស់ Next.js ដែលធ្វើឱ្យការ Deploy កម្មវិធី Frontend កាន់តែមានភាពងាយស្រួល លឿន និងមិនគិតថ្លៃសម្រាប់គម្រោងផ្ទាល់ខ្លួន (Hobby)។

## ⚙️ ជំហានទី ១: រៀបចំកូដ Frontend 

មុននឹងបញ្ជូនកូដទៅ Vercel ចំណុចសំខាន់បំផុតគឺការផ្លាស់ប្តូរ **API URL**។

ពេលអ្នកសរសេរកូដនៅលើកុំព្យូទ័រ អ្នកប្រហែលជាទាញទិន្នន័យ (Fetch) បែបនេះ៖
```javascript
// កូដពេលកំពុងសរសេរ (Development)
const response = await fetch('http://localhost:3000/api/users');
```

ប៉ុន្តែនៅពេល Deploy អ្នកមិនអាចប្រើ `localhost` ទៀតទេ ព្រោះ Backend របស់អ្នកឥឡូវនេះស្ថិតនៅលើ Render ទៅហើយ។ ដើម្បីដោះស្រាយបញ្ហានេះ យើងត្រូវប្រើប្រាស់ **Environment Variables**។

បង្កើត File `.env` នៅក្នុង Frontend:
```text
NEXT_PUBLIC_API_URL=https://my-api-abcd.onrender.com
```

បន្ទាប់មកនៅក្នុងកូដ React/Next.js អ្នកត្រូវដូរមកសរសេរជា៖
```javascript
const apiUrl = process.env.NEXT_PUBLIC_API_URL;
const response = await fetch(`${apiUrl}/api/users`);
```

ក្រោយពីរៀបចំរួចរាល់ សូម Push កូដ Frontend របស់អ្នកទៅកាន់ GitHub Repository ដាច់ដោយឡែកមួយ។

## 🚀 ជំហានទី ២: ការ Deploy ទៅកាន់ Vercel

ការ Deploy លើ Vercel គឺងាយស្រួលមែនទែន ដោយចំណាយពេលត្រឹមតែប៉ុន្មាននាទីប៉ុណ្ណោះ៖

1. ចូលទៅកាន់ [vercel.com](https://vercel.com) រួចបង្កើតគណនីដោយចុះឈ្មោះតាមរយៈ GitHub។
2. ចុចប៊ូតុង **"Add New"** > **"Project"**។
3. Vercel នឹងបង្ហាញបញ្ជី Repositories ពី GitHub របស់អ្នក។ សូមស្វែងរក Repository របស់ Frontend រួចចុចប៊ូតុង **"Import"**។
4. នៅក្នុងផ្ទាំង Configure Project:
   - Framework Preset: វានឹងស្គាល់ដោយស្វ័យប្រវត្តិថាវាជា Next.js ឬ Create React App។
   - ចុចបើកផ្ទាំង **Environment Variables**។
   - បញ្ចូល Name: `NEXT_PUBLIC_API_URL` និង Value: `https://my-api-abcd.onrender.com` (Link របស់ Render)។ រួចចុច Add។
5. ចុចប៊ូតុង **Deploy** ពណ៌ខ្មៅ។
