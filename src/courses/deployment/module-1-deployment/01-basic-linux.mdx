## 🐧 ហេតុអ្វី Server ត្រូវប្រើប្រាស់ Linux?

<img src="https://upload.wikimedia.org/wikipedia/commons/3/35/Tux.svg" alt="Linux Logo" width="100" style={{ display: "block", margin: "0 auto" }} />

នៅលើកុំព្យូទ័រផ្ទាល់ខ្លួន អ្នកប្រហែលជាប្រើប្រាស់ Windows ឬ macOS ប៉ុន្តែនៅពេលនិយាយដល់ Server ភាគច្រើនលើសលប់ (ជាង 90%) នៅលើពិភពលោកគឺប្រើប្រាស់ **Linux** (ដូចជា Ubuntu, Debian, CentOS ជាដើម)។

មូលហេតុចម្បងគឺដោយសារតែ Linux៖
- **ឥតគិតថ្លៃ (Open Source):** មិនបាច់ទិញ License ដូច Windows
- **មានសុវត្ថិភាព និងស្ថេរភាពខ្ពស់:** មិនសូវមានមេរោគ និងកម្រគាំង
- **ស្រាល:** មិនត្រូវការផ្ទាំងក្រាហ្វិក (UI) ធ្ងន់ៗ ដើរតាមរយៈផ្ទាំងកូដ (Terminal) សុទ្ធសាធ។

## 💻 បញ្ជា (Commands) ដែលត្រូវដឹង

ដោយសារ Server ដើរតាមរយៈផ្ទាំង Terminal ការចេះប្រើប្រាស់ Command គឺជាជំនាញចាំបាច់បំផុតមុននឹងយើង Deploy កម្មវិធី។

### ១. ការរុករក (Navigation)
- `pwd` (Print Working Directory): បង្ហាញប្រាប់ថាឥឡូវអ្នកកំពុងឈរនៅ Folder ណា (ឧ. `/home/user/app`)
- `ls` (List): បង្ហាញបញ្ជី File និង Folder។ ប្រើ `ls -la` ដើម្បីមើលទាំង File លាក់ និងសិទ្ធិប្រើប្រាស់។
- `cd` (Change Directory): ផ្លាស់ប្តូរទីតាំង។ 
  - `cd /var/www` (ចូលទៅកាន់ /var/www)
  - `cd ..` (ថយក្រោយមួយកម្រិត)

### ២. ការគ្រប់គ្រង File និង Folder
- `mkdir folder_name`: បង្កើត Folder ថ្មី
- `touch file.txt`: បង្កើត File ថ្មីទទេស្អាត
- `rm file.txt`: លុប File។ បើចង់លុប Folder ទាំងមូលត្រូវប្រើ `rm -rf folder_name`
- `cp source destination`: ចម្លង (Copy)
- `mv source destination`: ផ្លាស់ទី (Move) ឬ ប្តូរឈ្មោះ (Rename)

### ៣. ការអាន និងកែប្រែ File ផ្ទាល់លើ Server
- `cat file.txt`: អាន និងបង្ហាញខ្លឹមសារក្នុង File
- `nano file.txt`: បើកកម្មវិធីកែអត្ថបទ (Text Editor) សាមញ្ញមួយនៅក្នុង Terminal ដើម្បីសរសេរកូដ។ ពេលកែរួច ចុច `Ctrl + O` រួច `Enter` ដើម្បី Save នឹង `Ctrl + X` ដើម្បីចេញ។

## 🔐 សិទ្ធិប្រើប្រាស់ (Permissions)

នៅក្នុង Linux គ្រប់ File ទាំងអស់មានម្ចាស់ និងសិទ្ធិប្រើប្រាស់យ៉ាងតឹងរ៉ឹង។ ប្រសិនបើអ្នកព្យាយាមតំឡើងកម្មវិធី ឬកែប្រែ File សំខាន់ៗ អ្នកនឹងជួបកំហុស **Permission Denied**។

ដើម្បីដោះស្រាយបញ្ហានេះ យើងប្រើប្រាស់ពាក្យ `sudo` (SuperUser DO) នៅពីមុខ Command។ វាប្រៀបបាននឹងការ Run as Administrator នៅលើ Windows ដែរ។

ឧទាហរណ៍៖ `sudo apt update` (ធ្វើបច្ចុប្បន្នភាពប្រព័ន្ធ)

ការចេះមូលដ្ឋានទាំងនេះ នឹងជួយអោយអ្នកយល់បានងាយស្រួល នៅក្នុងមេរៀនបន្ទាប់ ពេលដែលយើងរៀនអំពី Docker និងការ Deploy។
