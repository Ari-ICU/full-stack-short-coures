## 🎓 គម្រោងបញ្ចបការសិក្សា (Capstone Project)

សូមអបអរសាទរ! អ្នកបានរៀនចប់គ្រប់មុខវិជ្ជាទាំងអស់ ទាំងការរចនា Web Design, រៀបចំ Database, សរសេរ Backend API និងការ Deploy អោយវាដំណើរការលើអុីនធឺណិត។ 

ឥឡូវនេះ ដល់ពេលដែលអ្នកត្រូវបញ្ចេញសមត្ថភាពទាំងនេះបញ្ចូលគ្នា ដើម្បីបង្កើតជា **គម្រោងចុងក្រោយមួយដ៏ពេញលេញ (Full Stack Final Project)** ដែលអ្នកអាចយកវាទៅដាក់ក្នុង CV ដើម្បីស្វែងរកការងារធ្វើ។

---

## 📋 តម្រូវការនៃគម្រោង (Project Requirements)

ដើម្បីឱ្យគម្រោងរបស់អ្នកអាចចាត់ទុកថាជាប្រព័ន្ធពេញលេញបាន វាត្រូវតែមានលក្ខណៈពិសេសខាងក្រោមយ៉ាងហោចណាស់ ៨០%៖

១. **Frontend (React / Next.js):**
   - រចនា UI ស្អាត (Responsive) អាចបើកលើទូរសព្ទបាន
   - មានទំព័រច្រើន (Home, Products, Login, Profile)

២. **Backend (Node.js / Express):**
   - មាន RESTful API ត្រឹមត្រូវ (GET, POST, PUT, DELETE)
   - ការពារសុវត្ថិភាពទិន្នន័យ និងមាន Error Handling (Global)
   - អនុញ្ញាតអោយអ្នកប្រើប្រាស់ Login & Register ដោយប្រើប្រាស់ JWT (Authentication & Authorization)
   - អាច Upload រូបភាពបាន (Profile Picture ឬ Product Image)

៣. **Database (PostgreSQL / TypeORM):**
   - មានតារាងទិន្នន័យយ៉ាងហោចណាស់ ៣ ទៅ ៤ (ឧ. `Users`, `Products`, `Orders`, `Categories`)
   - មានទំនាក់ទំនងត្រឹមត្រូវ (One-to-Many ឬ Many-to-Many)

៤. **Deployment (Live):**
   - ត្រូវបង្ហោះ Frontend លើ Vercel
   - ត្រូវបង្ហោះ Backend និង DB លើ Render
   - អ្នកគ្រប់គ្នាអាចចូលមើលបាន (Live URL)

## 🎤 ការត្រៀមខ្លួនធ្វើបទបង្ហាញ (Demo Presentation)

ការសរសេរកូដពូកែគឺជារឿងមួយ ប៉ុន្តែការចេះពន្យល់ពីអ្វីដែលអ្នកសរសេរអោយអ្នកដទៃ (ឬអ្នកសម្ភាសន៍ការងារ) ស្តាប់យល់ គឺជាជំនាញមួយទៀតដ៏សំខាន់។

នៅពេលអ្នកធ្វើ Demo សូមអនុវត្តតាមលំដាប់លំដោយនេះ៖
1. **សេចក្តីផ្តើម (The What & Why):** តើគម្រោងនេះជាអ្វី? ដោះស្រាយបញ្ហាអ្វី? (ឧ. "នេះជាប្រព័ន្ធលក់កាហ្វេដែលអនុញ្ញាតឱ្យអតិថិជនបញ្ជាទិញតាមអនឡាញ")
2. **ការបង្ហាញផ្ទាល់ (Live Demo):** បើកវេបសាយ Live របស់អ្នក (មិនមែន localhost) ហើយធ្វើជាអ្នកប្រើប្រាស់ម្នាក់៖
   - សាកល្បងចុះឈ្មោះ (Register)
   - សាកល្បង Login
   - សាកល្បងទិញទំនិញ
3. **បង្ហាញស្ថាបត្យកម្ម (The Architecture):** ពន្យល់ត្រួសៗថា "រូបភាពដែលបងឃើញនេះ គឺទាញមកពី Database តាមរយៈ API ឈ្មោះ `/products` ដែលសរសេរដោយ Express ឆ្លងកាត់ការផ្ទៀងផ្ទាត់ Token..."។
4. **បញ្ហាប្រឈម (Challenges):** តើពេលសរសេរកូដនេះ អ្នកជួបការលំបាកអ្វីជាងគេ? ហើយអ្នកដោះស្រាយវាយ៉ាងដូចម្តេច? (ក្រុមហ៊ុនចូលចិត្តស្តាប់ចំណុចនេះណាស់)។
