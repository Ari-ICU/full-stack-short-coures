## 🔍 អ្វីទៅជា Subquery?

**Subquery (ឬ Inner Query)** គឺជាការសរសេរកូដ `SELECT` មួយទៀតនៅខាងក្នុងកូដ `SELECT` ធំមួយ (Query ត្រួត Query)។ គេប្រើវាដើម្បីទាញយកតម្លៃបណ្តោះអាសន្នមកធ្វើជាលក្ខខណ្ឌអោយ Query ខាងក្រៅ។

**ឧទាហរណ៍៖** ចូររកទំនិញណាដែលមានតម្លៃថ្លៃជាង "តម្លៃមធ្យម" របស់ទំនិញទាំងអស់។

យើងមិនអាចសរសេរ `WHERE price > AVG(price)` បានទេ ព្រោះកូដនឹង Error។ យើងត្រូវប្រើ Subquery៖

```sql
SELECT id, name, price
FROM products
WHERE price > (
    -- នេះគឺជា Subquery
    SELECT AVG(price) 
    FROM products
);
```

## 🎯 ការប្រើប្រាស់ IN និង EXISTS

នៅពេលដែល Subquery បញ្ចេញទិន្នន័យច្រើនជាងមួយជួរ យើងត្រូវប្រើ `IN` ឬ `EXISTS`។

### ការប្រើប្រាស់ `IN`
`IN` ប្រើដើម្បីផ្ទៀងផ្ទាត់ថាតើតម្លៃមួយ មាននៅក្នុងបញ្ជីលទ្ធផលរបស់ Subquery ដែរឬទេ។

**ឧទាហរណ៍៖** រកមើលអតិថិជនណាដែលធ្លាប់បានបញ្ជាទិញទំនិញយ៉ាងហោចណាស់ម្តង។
```sql
SELECT *
FROM users
WHERE id IN (
    -- ទាញយកតែ id របស់អតិថិជនដែលធ្លាប់ទិញ
    SELECT DISTINCT user_id 
    FROM orders
);
```

### ការប្រើប្រាស់ `EXISTS`
`EXISTS` ផ្តល់លទ្ធផលត្រឡប់មកវិញជា True បើ Subquery នោះមានទិន្នន័យយ៉ាងហោចណាស់មួយជួរ។ ជាទូទៅ វាដើរលឿនជាង `IN` សម្រាប់តារាងដែលមានទិន្នន័យច្រើនខ្លាំង។

```sql
SELECT *
FROM users u
WHERE EXISTS (
    SELECT 1 
    FROM orders o 
    WHERE o.user_id = u.id
);
```

## 🛠️ Correlated Subqueries

**Correlated Subquery** គឺជា Subquery ដែលទាញយកតម្លៃពី Query ខាងក្រៅមកប្រើប្រាស់។ វានឹងដំណើរការម្តងមួយជួរៗ សម្រាប់ជួរនិមួយៗរបស់ Query ខាងក្រៅ (ប្រៀបដូចជា Nested Loop)។

**ឧទាហរណ៍៖** បង្ហាញឈ្មោះអតិថិជន និងការបញ្ជាទិញចុងក្រោយបំផុតរបស់គាត់ម្នាក់ៗ។
```sql
SELECT u.name,
       (SELECT MAX(created_at) 
        FROM orders o 
        WHERE o.user_id = u.id) AS last_order_date
FROM users u;
```

## 🌟 Common Table Expressions (CTE)

ការសរសេរ Subquery ច្រើនជាន់ពេក អាចធ្វើអោយកូដ SQL ពិបាកអាន។ **CTE** (ប្រើពាក្យ `WITH`) អនុញ្ញាតអោយយើងដាក់ឈ្មោះអោយ Subquery នោះ រួចហៅវាមកប្រើប្រាស់នៅពេលក្រោយបាន។

**ឧទាហរណ៍៖** រកអតិថិជនណាដែលចំណាយប្រាក់សរុប **លើសពីមធ្យមភាគចំណាយរបស់អតិថិជនទាំងអស់**។

បើមិនប្រើ CTE កូដនេះនឹងស្មុគស្មាញខ្លាំងណាស់។ ដោយប្រើ CTE យើងអាចបំបែកវាជាជំហានៗ៖

```sql
WITH UserSpending AS (
    -- ជំហានទី 1: គណនាការចំណាយសរុបរបស់អតិថិជនម្នាក់ៗ
    SELECT user_id, SUM(total_price) AS total_spent
    FROM orders
    GROUP BY user_id
),
AverageSpending AS (
    -- ជំហានទី 2: គណនាមធ្យមភាគនៃការចំណាយទាំងអស់
    SELECT AVG(total_spent) AS avg_spent
    FROM UserSpending
)
-- ជំហានទី 3: ទាញយកចម្លើយចុងក្រោយ
SELECT u.name, us.total_spent
FROM users u
JOIN UserSpending us ON u.id = us.user_id
WHERE us.total_spent > (SELECT avg_spent FROM AverageSpending);
```
*(ការប្រើប្រាស់ CTE ធ្វើអោយកូដ SQL ងាយស្រួលយល់ និងស្រដៀងទៅនឹងការសរសេរកូដធម្មតាដែលមាន Variables ដែរ!)*
