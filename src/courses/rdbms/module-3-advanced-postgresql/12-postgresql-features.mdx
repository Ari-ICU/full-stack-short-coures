## 🚀 1. ទទួលបានលទ្ធផលត្រឡប់មកវិញ (RETURNING)

ជាទូទៅនៅពេលដែលអ្នកធ្វើការ `INSERT`, `UPDATE`, ឬ `DELETE` ប្រព័ន្ធ Database ផ្សេងៗគ្រាន់តែឆ្លើយតបថាជោគជ័យប៉ុណ្ណោះ។ ប៉ុន្តែនៅក្នុង **PostgreSQL** អ្នកអាចប្រើពាក្យ `RETURNING` ដើម្បីអោយវាបញ្ជូនទិន្នន័យត្រឡប់មកវិញភ្លាមៗ (ចំណេញ Query ម្តង)។

```sql
INSERT INTO users (name, email)
VALUES ('Sok', 'sok@email.com')
RETURNING id, created_at;
```
នេះមានប្រយោជន៍ខ្លាំងណាស់នៅពេលសរសេរ Backend API (ឧទាហរណ៍ ចង់បាន `id` យកទៅប្រើបន្ត)។

## ⚔️ 2. ដោះស្រាយជម្លោះទិន្នន័យ (ON CONFLICT / Upsert)

ស្រមៃថាអ្នកចង់បញ្ចូលអតិថិជនម្នាក់ តែអ្នកមិនដឹងថាគាត់មានក្នុងប្រព័ន្ធហើយឬនៅ។ បើអ្នក `INSERT` វាអាច Error បើ Email ជាន់គ្នា។ PostgreSQL ដោះស្រាយបញ្ហានេះយ៉ាងងាយស្រួលដោយប្រើ `ON CONFLICT`!

```sql
INSERT INTO users (email, name, login_count)
VALUES ('dara@email.com', 'Dara', 1)
ON CONFLICT (email) 
DO UPDATE SET login_count = users.login_count + 1;
```
*(មានន័យថា៖ បញ្ចូលទិន្នន័យនេះទៅ។ បើវាជាន់ `email` ដដែល សូមគ្រាន់តែ Update ចំនួន `login_count` អោយកើនឡើង ១។ នេះហៅថា **Upsert**)*

## 📦 3. ទិន្នន័យបត់បែន (JSONB)

អ្នកអាចផ្ទុកទិន្នន័យបែប NoSQL (ដូច MongoDB) នៅក្នុង PostgreSQL បាន!

```sql
CREATE TABLE products (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100),
    attributes JSONB
);

INSERT INTO products (name, attributes)
VALUES ('Laptop', '{"color": "silver", "ram": "16GB"}');
```
ស្វែងរកទិន្នន័យក្នុង JSON ផ្ទាល់៖
```sql
SELECT * FROM products WHERE attributes->>'color' = 'silver';
```

## 🧩 4. ចងទិន្នន័យជា Array (`JSON_AGG`)

ជាញឹកញាប់ Frontend Developer ត្រូវការទិន្នន័យដែលតារាងមួយមានកូនចៅច្រើន (One-to-Many) អោយចេញមកជា Array `[...]`។

```sql
SELECT users.name, 
       JSON_AGG(orders) AS order_history
FROM users
JOIN orders ON users.id = orders.user_id
GROUP BY users.name;
```
*(លទ្ធផល៖ វានឹងប្រមូលរាល់ Object របស់ Order ទៅជា JSON Array ដែលងាយស្រួលបំផុតសម្រាប់ JavaScript យកទៅប្រើប្រាស់!)*

## 👁️ 5. ការបង្កើត Views

បើសិនជាអ្នកមានកូដ SQL (Query) ដ៏វែងនិងស្មុគស្មាញ (មាន JOIN និង GROUP BY ច្រើន) ដែលអ្នកត្រូវហៅប្រើរាល់ថ្ងៃ អ្នកមិនចាំបាច់វាយវាឡើងវិញរាល់ដងទេ។ អ្នកអាចបង្កើតជា **View**។

```sql
CREATE VIEW user_spending_summary AS
SELECT users.name, SUM(orders.total_price) AS total_spent
FROM users
JOIN orders ON users.id = orders.user_id
GROUP BY users.id, users.name;
```
ឥឡូវនេះ `user_spending_summary` ប្រៀបដូចជាតារាងមួយអញ្ចឹង អ្នកអាច Select ពីវាបានធម្មតា៖
```sql
SELECT * FROM user_spending_summary WHERE total_spent > 1000;
```
