## 🏛️ អ្វីទៅជា Relational Database?

**Relational Database Management System (RDBMS)** គឺជាប្រព័ន្ធគ្រប់គ្រងមូលដ្ឋានទិន្នន័យដែលរៀបចំទិន្នន័យជាទម្រង់ **តារាង (Tables)** ដែលមានជួរដេក និងជួរឈរ ហើយតារាងទាំងនោះមានទំនាក់ទំនងគ្នាទៅវិញទៅមក (Relations)។

### សមាសភាគសំខាន់ៗ៖
*   **Table (តារាង)**៖ បណ្តុំទិន្នន័យនៃប្រធានបទណាមួយ (ឧ. តារាង Users, តារាង Products)។
*   **Row/Record (ជួរដេក)**៖ ទិន្នន័យមួយជួរពេញរបស់ធាតុណាមួយ (ឧ. ព័ត៌មានរបស់ User ម្នាក់)។
*   **Column/Field (ជួរឈរ)**៖ ព័ត៌មានលម្អិតជាក់លាក់ (ឧ. name, email, price) ដែលមានកំណត់ប្រភេទប្រភេទរៀងៗខ្លួន (Data Types)។
*   **Data Consistency (សុក្រឹតភាពទិន្នន័យ)**៖ ធានាថារាល់ទិន្នន័យទាំងអស់ត្រូវតែគោរពតាមច្បាប់ និងទំនាក់ទំនងរបស់ Database ដែលបានកំណត់។

## 🐘 ស្គាល់ពី PostgreSQL

**PostgreSQL** (ហៅកាត់ថា Postgres) គឺជា Relational Database បែប Open-source ដ៏រឹងមាំ និងទំនើបបំផុតមួយនៅលើលោក។

### ហេតុអ្វី Postgres ជាជម្រើសលេខមួយសម្រាប់ Web Backends?
1.  **រឹងមាំ និងមានស្ថិរភាព (Reliability)**៖ វាអនុលោមតាមគោលការណ៍ ACID ១០០% ការពារការបាត់បង់ទិន្នន័យ។
2.  **សំបូរមុខងារ (Extensibility)**៖ គាំទ្រទាំង SQL ធម្មតា, JSON/JSONB (NoSQL style), UUIDs, និង Full-Text Search។
3.  **គាំទ្រ Cloud សម័យថ្មី**៖ ងាយស្រួលដំណើរការលើ Cloud databases ទំនើបៗដូចជា **Supabase**, **Neon**, ឬ **Render**។

## 🛠️ ការប្រើប្រាស់ GUI Client Tools

ដើម្បីគ្រប់គ្រងទិន្នន័យក្នុង Postgres Server យើងច្រើនប្រើប្រាស់កម្មវិធី GUI (Graphical User Interface) ជំនួសឱ្យការសរសេរកូដលើ command line។ ឧបករណ៍ពេញនិយមរួមមាន៖ **pgAdmin**, **DBeaver**, និង **TablePlus**។

### ១. ការបង្កើត Connection
ដើម្បីភ្ជាប់ទៅកាន់ Postgres Server យើងត្រូវការ៖
*   **Host**: អាសយដ្ឋាន Server (ឧ. `localhost` ឬ Cloud URL)
*   **Port**: លំនាំដើមគឺ `5432`
*   **Username**: ឈ្មោះអ្នកប្រើប្រាស់ (លំនាំដើម `postgres`)
*   **Password**: លេខសម្ងាត់ដែលបានកំណត់ពេលដំឡើង
*   **Database**: ឈ្មោះ database ដែលចង់ភ្ជាប់

### ២. ការដំណើរការ SQL Scripts (Query Tool)
នៅក្នុង GUI tools នីមួយៗមានប៊ូតុង **Query Tool** ឬ **SQL Editor** ដែលអនុញ្ញាតឱ្យយើងសរសេរកូដ SQL និងចុចដំណើរការ (Execute / Run) ដើម្បីបង្កើត ឬទាញយកទិន្នន័យ។

### ៣. ការ Import/Export SQL Files (Backup & Restore)
*   **Export (Backup)**៖ ចុច Right-click លើ Database រួចយក **Backup** ដើម្បីទាញយកឯកសារកូដ `.sql` រក្សាទុក។
*   **Import (Restore)**៖ ចុច Right-click លើ Database យក **Restore** ឬបើក file `.sql` នៅក្នុង SQL Editor ហើយចុច Run ដើម្បីបង្កើតរចនាសម្ព័ន្ធ និងបញ្ចូលទិន្នន័យឡើងវិញ។
