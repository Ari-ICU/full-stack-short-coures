## 🏗️ Data Definition Language (DDL)

**SQL (Structured Query Language)** ត្រូវបានបែងចែកជាផ្នែកផ្សេងៗ។ ផ្នែកដែលប្រើសម្រាប់ "សាងសង់ផ្ទះ" (រចនាសម្ព័ន្ធ) គឺហៅថា **DDL** រួមមាន `CREATE`, `ALTER`, និង `DROP`។

### 1. ការគ្រប់គ្រង Database
មុននឹងមានតារាង យើងត្រូវមាន Database សិន។

```sql
-- បង្កើត Database ថ្មី
CREATE DATABASE ecommerce_db;

-- លុប Database ចោល (ប្រយ័ត្ន! ទិន្នន័យនឹងបាត់បង់ទាំងអស់)
DROP DATABASE ecommerce_db;
```

### 2. ការគ្រប់គ្រងតារាង (Tables)

**បង្កើតតារាង (CREATE TABLE):**
អ្នកត្រូវប្រាប់ឈ្មោះតារាង ឈ្មោះជួរឈរ និងប្រភេទទិន្នន័យ (Data Type) រួមទាំងលក្ខខណ្ឌ (Constraints) ដូចជា `NOT NULL` ឬ `UNIQUE`។

```sql
CREATE TABLE users (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);
```

**លុបតារាង (DROP TABLE):**
```sql
DROP TABLE users;
```

### 3. ការកែប្រែរចនាសម្ព័ន្ធ (ALTER TABLE)

ចុះបើអ្នកបង្កើតតារាងរួចហើយ ស្រាប់តែនឹកឃើញចង់បន្ថែមជួរឈរ `phone_number` មួួយទៀត? អ្នកមិនចាំបាច់លុបតារាងចោលទេ អ្នកអាចកែប្រែវាបាន។

```sql
-- បន្ថែម Column ថ្មី
ALTER TABLE users 
ADD COLUMN phone_number VARCHAR(20);

-- ប្តូរឈ្មោះ Column
ALTER TABLE users 
RENAME COLUMN name TO full_name;

-- លុប Column ចោល
ALTER TABLE users 
DROP COLUMN phone_number;
```

## 📝 ការអនុវត្តជាក់ស្តែង (Mini Case Study)

**លំហាត់:** ចូរអ្នកសរសេរកូដ SQL ដើម្បីបង្កើតតារាង `products` មួយដោយមានលក្ខខណ្ឌដូចខាងក្រោម៖
- មានលេខសម្គាល់ `id` ជា Primary Key
- មានឈ្មោះ `name` (មិនអាចទទេរបាន)
- មានតម្លៃ `price` ជាលេខទសភាគ (មិនអាចទទេរបាន)

**ចម្លើយ:**
```sql
CREATE TABLE products (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    price NUMERIC(10,2) NOT NULL
);
```
