## 🐘 អ្វីទៅជា PostgreSQL?

<div align="center">
  <img src="https://upload.wikimedia.org/wikipedia/commons/2/29/Postgresql_elephant.svg" alt="PostgreSQL Logo" width="120" />
</div>


**RDBMS (Relational Database Management System)** គឺជាប្រព័ន្ធគ្រប់គ្រងមូលដ្ឋានទិន្នន័យដែលរក្សាទុកទិន្នន័យជាទម្រង់ **តារាង (Tables)**។ តារាងទាំងនេះមានទំនាក់ទំនង (Relationships) គ្នាទៅវិញទៅមក ជួយអោយការស្វែងរក និងគ្រប់គ្រងទិន្នន័យមានភាពងាយស្រួល និងមានសុវត្ថិភាពខ្ពស់។

នៅក្នុង RDBMS:
- **Table:** ប្រៀបដូចជា File Excel មួយ (ឧទាហរណ៍៖ តារាង `users`)
- **Column (Field):** ប្រៀបដូចជាចំណងជើងជួរឈរ (ឧទាហរណ៍៖ `id`, `name`, `email`)
- **Row (Record):** ប្រៀបដូចជាទិន្នន័យរបស់មនុស្សម្នាក់ក្នុងជួរដេកនីមួយៗ។

## 🐘 ហេតុអ្វីបានជាយើងជ្រើសរើស PostgreSQL?

នៅក្នុងការអភិវឌ្ឍកម្មវិធីបែប Full Stack ទំនើប ការជ្រើសរើស Database ដែលត្រឹមត្រូវគឺជារឿងសំខាន់បំផុត។ យើងជ្រើសរើសយក **![PostgreSQL](https://cdn.simpleicons.org/postgresql/4169E1) PostgreSQL** (អានថា: *ផូស-ហ្គ្រេស-ឃ្យូ-អិល*) សម្រាប់វគ្គសិក្សានេះដោយសារហេតុផលសំខាន់ៗដូចជា៖

1. **Open Source & ឥតគិតថ្លៃ ១០០%:** គ្មានការបង់ថ្លៃ License មិនថាគម្រោងអ្នកធំប៉ុណ្ណាឡើយ។
2. **ACID Compliance:** ធានាថារាល់ប្រតិបត្តិការទិន្នន័យ (Transactions) របស់អ្នកមានសុវត្ថិភាព ទោះបីជាមានបញ្ហាដាច់ភ្លើងក៏ដោយ។ (ឧទាហរណ៍៖ ការផ្ទេរប្រាក់ឆ្លងគណនី)។
3. **ការគាំទ្រ JSON (JSONB):** ផ្តល់សមត្ថភាពក្នុងការផ្ទុកទិន្នន័យបែប NoSQL នៅក្នុង RDBMS ធ្វើអោយមានភាពបត់បែនខ្ពស់ (Hybrid Database)។
4. **ទីផ្សារការងារ:** ក្រុមហ៊ុនធំៗ និង Startups ភាគច្រើនបច្ចុប្បន្ននិយមប្រើប្រាស់ PostgreSQL សម្រាប់គម្រោងរបស់ពួកគេ។

## 🛠️ Database Server ទល់នឹង Database Client

មុននឹងប្រើប្រាស់ PostgreSQL អ្នកត្រូវយល់ពីភាពខុសគ្នារវាង **Server** និង **Client** ជាមុនសិន។ អ្នកអាចប្រៀបធៀបវាទៅនឹង **ទូរទស្សន៍ និងប៉ុស្តិ៍ទូរទស្សន៍**៖

1. **PostgreSQL (Database Server):** 
   ប្រៀបដូចជាស្ថានីយ៍បញ្ជូនផ្សាយ (ស្ថានីយ៍ទូរទស្សន៍) ដែលជាអ្នកផ្ទុកទិន្នន័យ និងដំណើរការការងារនៅពីក្រោយ (Background Service)។ វាមិនមានផ្ទាំង (Interface) អោយយើងចុចមើលផ្ទាល់នោះទេ។
2. **Database Client:** 
   ប្រៀបដូចជាអេក្រង់ទូរទស្សន៍របស់អ្នក។ វាមិនមានផ្ទុកទិន្នន័យខ្លួនឯងទេ តែវាមានតួនាទី **ភ្ជាប់ (Connect)** ទៅកាន់ Server ដើម្បីទាញយកទិន្នន័យមកបង្ហាញនៅលើអេក្រង់អោយអ្នកអាចមើលឃើញ និងបញ្ជាបានយ៉ាងងាយស្រួល។

ដើម្បីទាក់ទងជាមួយ PostgreSQL (Server) យើងត្រូវការឧបករណ៍ (Client) ដូចខាងក្រោម៖

- **psql:** ជាកម្មវិធី (CLI - Command Line Interface) សម្រាប់សរសេរកូដ SQL ផ្ទាល់នៅលើ Terminal របស់អ្នក។ វាលឿន និងមានថាមពលខ្ពស់សម្រាប់អ្នកអភិវឌ្ឍជំនាញ (Advanced Users)។
- **pgAdmin ឫ DBeaver:** គឺជាកម្មវិធីប្រភេទ GUI (Graphical User Interface)។ 
  - **pgAdmin:** ជាកម្មវិធីផ្លូវការសម្រាប់គ្រប់គ្រង PostgreSQL។
  - **DBeaver:** ជាកម្មវិធីដ៏ពេញនិយមមួយដែលអាចភ្ជាប់ទៅកាន់ Database ច្រើនប្រភេទ (PostgreSQL, MySQL, SQLite...)។
  កម្មវិធីទាំងពីរនេះអនុញ្ញាតអោយអ្នកចុចមើល បង្កើតតារាង និងកែប្រែទិន្នន័យបានយ៉ាងងាយស្រួលតាមរយៈការចុច (Click) ដោយមិនចាំបាច់សរសេរកូដគ្រប់សកម្មភាពនោះទេ ដែលវាស័ក្តិសមបំផុតសម្រាប់អ្នកទើបចាប់ផ្តើម។
