## ⌨️ មូលដ្ឋានគ្រឹះនៃភាសា SQL

**SQL (Structured Query Language)** គឺជាភាសាស្តង់ដារសម្រាប់ទាក់ទងជាមួយ Relational Database។ SQL ត្រូវបានបែងចែកជាប្រភេទផ្សេងៗគ្នា តែសំខាន់បំផុតគឺ **DDL** និង **DML**។

---

### 1. DDL (Data Definition Language)
ប្រើសម្រាប់បង្កើត និងកែប្រែរចនាសម្ព័ន្ធរបស់ Database (Tables)។

**បង្កើតតារាង (CREATE TABLE):**
```sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);
```
*(ចំណាំ៖ `gen_random_uuid()` គឺជាអនុគមន៍មានស្រាប់ក្នុង PostgreSQL សម្រាប់បង្កើត UUID ដោយស្វ័យប្រវត្តិ។)*

**លុបតារាង (DROP TABLE):**
```sql
DROP TABLE users;
```

---

### 2. DML (Data Manipulation Language) - ដំណើរការ CRUD
ប្រើសម្រាប់បញ្ចូល ទាញយក កែប្រែ និងលុបទិន្នន័យពីក្នុងតារាង។

**បញ្ចូលទិន្នន័យ (INSERT / Create):**
```sql
INSERT INTO users (name, email)
VALUES ('Dara', 'dara@email.com');
```

**ទាញយកទិន្នន័យ (SELECT / Read):**
```sql
SELECT * FROM users;                  -- ទាញយកទិន្នន័យទាំងអស់
SELECT name, email FROM users;        -- ទាញយកតែ Column ឈ្មោះ និង អ៊ីមែល
SELECT * FROM users WHERE name = 'Dara'; -- ទាញយកតែទិន្នន័យដែលមានឈ្មោះ Dara
```

**កែប្រែទិន្នន័យ (UPDATE / Update):**
```sql
UPDATE users
SET name = 'Dara Updated'
WHERE email = 'dara@email.com';
```
*(⚠️ ប្រយ័ត្ន៖ បើភ្លេចដាក់ `WHERE` វានឹងកែប្រែទិន្នន័យទាំងអស់ក្នុងតារាង!)*

**លុបទិន្នន័យ (DELETE / Delete):**
```sql
DELETE FROM users
WHERE email = 'dara@email.com';
```

## 🚀 លក្ខណៈពិសេសរបស់ PostgreSQL: RETURNING Clause

ជាទូទៅនៅពេលដែលអ្នកធ្វើការ `INSERT`, `UPDATE`, ឬ `DELETE` ប្រព័ន្ធ Database ផ្សេងៗគ្រាន់តែឆ្លើយតបថាជោគជ័យប៉ុណ្ណោះ។ ប៉ុន្តែនៅក្នុង **PostgreSQL** អ្នកអាចប្រើពាក្យ `RETURNING` ដើម្បីអោយវាបញ្ជូនទិន្នន័យដែលទើបតែបានបញ្ចួល ឬកែប្រែនោះ ត្រឡប់មកវិញភ្លាមៗ (ចំណេញ Query ម្តង)។

**ឧទាហរណ៍៖** បញ្ចូលទិន្នន័យថ្មី ហើយទាញយក `id` ត្រឡប់មកវិញ។
```sql
INSERT INTO users (name, email)
VALUES ('Sok', 'sok@email.com')
RETURNING id, created_at;
```
នេះមានប្រយោជន៍ខ្លាំងណាស់នៅពេលសរសេរ Backend API!
