## 🔽 ម៉ឺនុយទម្លាក់ចុះ (Dropdowns)

**Dropdowns** គឺជាវិធីដ៏ល្អបំផុតក្នុងការប្រមូលផ្តុំ Link ឬសកម្មភាពជាច្រើនចូលទៅក្នុងប៊ូតុងតែមួយ ដើម្បីសន្សំសំចៃទំហំអេក្រង់។ មុខងារនេះត្រូវការជំនួយពី **Popper.js** (ដែលបានបញ្ចូលរួចជាស្រេចនៅក្នុងឯកសារ `bootstrap.bundle.min.js`) ដើម្បីជួយគណនាទីតាំងបង្ហាញអោយបានត្រឹមត្រូវ។

---

## 1. រចនាសម្ព័ន្ធមូលដ្ឋាន

Dropdown មួយទាមទារធាតុផ្សំ ៣ យ៉ាង៖
1.  **ប្រអប់រុំ (`.dropdown`)**: ជាធម្មតាគេប្រើ `<div class="dropdown">` ដើម្បីរុំកូដទាំងអស់។
2.  **ប៊ូតុងបញ្ជា (`.dropdown-toggle`)**: ជាប៊ូតុងដែលយើងត្រូវចុច។ វាត្រូវតែមាន `data-bs-toggle="dropdown"`។
3.  **ម៉ឺនុយបញ្ជី (`.dropdown-menu`)**: ជាប្រអប់លាក់កំបាំងដែលមានផ្ទុកជម្រើសខាងក្នុង ហើយវានឹងបង្ហាញឡើងពេលគេចុចប៊ូតុង។

```html
<div class="dropdown">
  <button class="btn btn-secondary dropdown-toggle" type="button" data-bs-toggle="dropdown" aria-expanded="false">
    ជ្រើសរើសភាសា
  </button>
  <ul class="dropdown-menu">
    <li><a class="dropdown-item" href="#">ភាសាខ្មែរ</a></li>
    <li><a class="dropdown-item" href="#">English</a></li>
    <li><a class="dropdown-item" href="#">Français</a></li>
  </ul>
</div>
```

## 2. ការតុបតែងម៉ឺនុយ (Menu Formatting)

អ្នកមិនត្រឹមតែអាចដាក់ Link នោះទេ អ្នកក៏អាចដាក់អត្ថបទ, ចំណងជើងរង (Headers), និងបន្ទាត់ខណ្ឌចែក (Dividers) បានយ៉ាងស្អាតផងដែរ។

```html
<div class="dropdown">
  <button class="btn btn-primary dropdown-toggle" type="button" data-bs-toggle="dropdown" aria-expanded="false">
    ការកំណត់គណនី
  </button>
  <ul class="dropdown-menu">
    <!-- ចំណងជើងរង -->
    <li><h6 class="dropdown-header">ព័ត៌មានផ្ទាល់ខ្លួន</h6></li>
    
    <!-- ជម្រើសធម្មតា -->
    <li><a class="dropdown-item" href="#">កែប្រែប្រវត្តិរូប</a></li>
    <li><a class="dropdown-item" href="#">ប្តូរពាក្យសម្ងាត់</a></li>
    
    <!-- បន្ទាត់ខណ្ឌចែក -->
    <li><hr class="dropdown-divider"></li>
    
    <!-- ជម្រើសពណ៌ក្រហម -->
    <li><a class="dropdown-item text-danger" href="#">ចាកចេញ (Log out)</a></li>
  </ul>
</div>
```

## 3. Dropdown ងងឹត (Dark Dropdowns)

ប្រសិនបើគេហទំព័ររបស់អ្នកជារចនាបថ Dark Mode អ្នកអាចប្តូរពណ៌ម៉ឺនុយអោយទៅជាងងឹតបានដោយងាយ គ្រាន់តែបន្ថែម Class `.dropdown-menu-dark` ទៅលើ `.dropdown-menu` នោះវាជាការស្រេច!

```html
<ul class="dropdown-menu dropdown-menu-dark">
  <li><a class="dropdown-item active" href="#">ជម្រើសទី ១ (Active)</a></li>
  <li><a class="dropdown-item" href="#">ជម្រើសទី ២</a></li>
  <li><hr class="dropdown-divider"></li>
  <li><a class="dropdown-item" href="#">ជម្រើសទី ៣</a></li>
</ul>
```
