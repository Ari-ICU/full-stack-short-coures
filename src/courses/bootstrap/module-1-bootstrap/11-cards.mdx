## 🃏 អ្វីទៅជា Card?

**Card** គឺជាប្រអប់មួយដែលមានស៊ុមព័ទ្ធជុំវិញ និងមានស្រមោលតិចៗ ប្រើសម្រាប់ផ្ទុកព័ត៌មានមួយដុំ ដូចជា៖ ផលិតផលមួយ, អត្ថបទព័ត៌មានមួយ, ឬប្រវត្តិរូបមនុស្សម្នាក់។ វាគឺជាធាតុផ្សំដែលពេញនិយមបំផុតក្នុងការរចនាគេហទំព័រទំនើប។

---

## 1. រចនាសម្ព័ន្ធមូលដ្ឋាន

Card នីមួយៗត្រូវរុំដោយ Class `.card` ហើយមាតិកាខាងក្នុងត្រូវដាក់ក្នុង `.card-body`។

```html
<div class="card" style="width: 18rem;">
  <div class="card-body">
    <h5 class="card-title">ចំណងជើង Card</h5>
    <h6 class="card-subtitle mb-2 text-muted">ចំណងជើងរង</h6>
    <p class="card-text">នេះគឺជាអត្ថបទពិពណ៌នាខ្លីៗអំពីមាតិកានៅក្នុងកាតនេះ។ អ្នកអាចសរសេរអ្វីក៏បាន។</p>
    <a href="#" class="btn btn-primary">អានបន្ត</a>
  </div>
</div>
```

---

## 2. ការបញ្ចូលរូបភាព (Card Images)

ជាទូទៅ គេតែងតែដាក់រូបភាពនៅខាងលើគេបង្អស់នៃ Card (ឧទាហរណ៍៖ រូបផលិតផល)។ យើងប្រើ `.card-img-top`។

```html
<div class="card" style="width: 18rem;">
  <!-- រូបភាពនៅខាងលើ -->
  <img src="https://via.placeholder.com/150" class="card-img-top" alt="...">
  
  <div class="card-body">
    <h5 class="card-title">ផលិតផល ក</h5>
    <p class="card-text">តម្លៃត្រឹមតែ $10 ប៉ុណ្ណោះ!</p>
    <a href="#" class="btn btn-primary">ទិញឥឡូវនេះ</a>
  </div>
</div>
```

## 3. Header និង Footer

បើអ្នកចង់បែងចែក Card ជាផ្នែកៗអោយកាន់តែច្បាស់ អ្នកអាចប្រើប្រាស់ `.card-header` និង `.card-footer` បាន។

```html
<div class="card text-center">
  <div class="card-header">
    ប្រភេទអត្ថបទ: កីឡា
  </div>
  <div class="card-body">
    <h5 class="card-title">ព័ត៌មានបាល់ទាត់ប្រចាំថ្ងៃ</h5>
    <p class="card-text">ការប្រកួតដ៏ស្វិតស្វាញយប់មិញ...</p>
    <a href="#" class="btn btn-primary">អានលម្អិត</a>
  </div>
  <div class="card-footer text-muted">
    បង្ហោះកាលពី ២ ថ្ងៃមុន
  </div>
</div>
```

## 4. Horizontal Card (Card រាងផ្តេក)

ជួនកាលអ្នកចង់បានរូបភាពនៅខាងឆ្វេង ហើយអត្ថបទនៅខាងស្តាំវិញ។ ទីនេះយើងត្រូវប្រើ **Grid System** (`row` និង `col`) ចូលមកជួយ!

```html
<div class="card mb-3" style="max-width: 540px;">
  <div class="row g-0">
    <div class="col-md-4">
      <img src="https://via.placeholder.com/200" class="img-fluid rounded-start" alt="...">
    </div>
    <div class="col-md-8">
      <div class="card-body">
        <h5 class="card-title">ចំណងជើងផ្តេក</h5>
        <p class="card-text">នេះគឺជាអត្ថបទដែលស្ថិតនៅខាងស្តាំនៃរូបភាព។</p>
      </div>
    </div>
  </div>
</div>
```

## 5. ការដាក់តម្រៀបគ្នាជាក្រុម (Card Groups)

ប្រសិនបើអ្នកចង់តម្រៀប Card ៣ ទៅ ៤ អោយនៅជាប់ៗគ្នាមានកម្ពស់ស្មើគ្នា (ឧ. កញ្ចប់តម្លៃ ៣ ប្រភេទ) អ្នកអាចប្រើ `.card-group`។

```html
<div class="card-group">
  <div class="card">
    <div class="card-body">
      <h5 class="card-title">កញ្ចប់ធម្មតា</h5>
      <p class="card-text">$5 ក្នុងមួយខែ</p>
    </div>
  </div>
  <div class="card">
    <div class="card-body">
      <h5 class="card-title">កញ្ចប់ពិសេស</h5>
      <p class="card-text">$10 ក្នុងមួយខែ</p>
    </div>
  </div>
</div>
```
