## 🧭 ការរៀបចំ Navigation

Navigation គឺជាផ្នែកចម្បងដែលជួយអោយអ្នកប្រើប្រាស់ធ្វើដំណើរក្នុងគេហទំព័ររបស់អ្នក។ Bootstrap ផ្តល់ជូននូវជម្រើសដ៏សម្បូរបែប។

---

## 1. Navbar (របារខាងលើ)

**Navbar** គឺជាម៉ឺនុយធំដែលតែងតែនៅផ្នែកខាងលើគេបង្អស់។ ភាពអស្ចារ្យរបស់វាគឺវាមានមុខងារ Responsive ភ្ជាប់មកជាមួយស្រាប់ ដោយវានឹងប្តូរទៅជាប៊ូតុង (Hamburger button) នៅលើទូរស័ព្ទ។

```html
<!-- navbar-expand-lg មានន័យថាវានឹងលាតពេញលើកុំព្យូទ័រ និងលាក់លើទូរស័ព្ទ -->
<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
  <div class="container">
    <a class="navbar-brand" href="#">Logo</a>
    
    <!-- ប៊ូតុង Hamburger សម្រាប់ទូរស័ព្ទ -->
    <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#navbarNav">
      <span class="navbar-toggler-icon"></span>
    </button>
    
    <!-- មាតិកាដែលត្រូវលាក់នៅលើទូរស័ព្ទ -->
    <div class="collapse navbar-collapse" id="navbarNav">
      <ul class="navbar-nav ms-auto"> <!-- ms-auto រុញវាទៅស្តាំ -->
        <li class="nav-item">
          <a class="nav-link active" href="#">Home</a>
        </li>
        <li class="nav-item">
          <a class="nav-link" href="#">Features</a>
        </li>
      </ul>
    </div>
  </div>
</nav>
```

## 2. Nav និង Tabs (ម៉ឺនុយធម្មតា)

បើអ្នកគ្រាន់តែចង់បានបញ្ជី Link ធម្មតាដោយមិនចាំបាច់មានមុខងារ Responsive ស្មុគស្មាញ អ្នកអាចប្រើ `.nav` បាន។ វាស័ក្តិសមបំផុតសម្រាប់ធ្វើជា **Tabs** (ផ្ទាំង)។

```html
<ul class="nav nav-tabs">
  <li class="nav-item">
    <a class="nav-link active" aria-current="page" href="#">ព័ត៌មានទូទៅ</a>
  </li>
  <li class="nav-item">
    <a class="nav-link" href="#">ប្រវត្តិរូប</a>
  </li>
  <li class="nav-item">
    <a class="nav-link" href="#">ការកំណត់</a>
  </li>
</ul>
```

---

## 3. Breadcrumb (គន្លងផ្លូវ)

Breadcrumb ជួយប្រាប់អ្នកប្រើប្រាស់ថាពួកគេកំពុងស្ថិតនៅទីតាំងណា នៅក្នុងរចនាសម្ព័ន្ធគេហទំព័រ (ឧ. ទំព័រដើម > ផលិតផល > កុំព្យូទ័រ)។

```html
<nav aria-label="breadcrumb">
  <ol class="breadcrumb">
    <li class="breadcrumb-item"><a href="#">Home</a></li>
    <li class="breadcrumb-item"><a href="#">Library</a></li>
    <li class="breadcrumb-item active" aria-current="page">Data</li>
  </ol>
</nav>
```

---

## 4. Pagination (ការបែងចែកទំព័រ)

ប្រសិនបើអ្នកមានអត្ថបទ ឬទំនិញច្រើន អ្នកត្រូវបែងចែកវាជាទំព័រៗ (Page 1, 2, 3...)។

```html
<nav aria-label="Page navigation example">
  <ul class="pagination">
    <li class="page-item"><a class="page-link" href="#">Previous</a></li>
    <li class="page-item"><a class="page-link" href="#">1</a></li>
    <li class="page-item active"><a class="page-link" href="#">2</a></li>
    <li class="page-item"><a class="page-link" href="#">3</a></li>
    <li class="page-item"><a class="page-link" href="#">Next</a></li>
  </ul>
</nav>
```
