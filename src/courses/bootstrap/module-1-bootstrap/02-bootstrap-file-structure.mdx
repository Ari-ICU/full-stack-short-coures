## 📂 ស្វែងយល់ពីរចនាសម្ព័ន្ធឯកសារ Bootstrap

នៅពេលអ្នកទាញយក Bootstrap មកប្រើប្រាស់ ឬប្រើតាមរយៈ CDN អ្នកប្រហែលជាសង្កេតឃើញថាមានឈ្មោះឯកសារស្រដៀងៗគ្នាច្រើន។ តើពួកវាខុសគ្នាដូចម្តេចខ្លះ?

---

## 1. ឯកសារ CSS

CSS គឺជាបេះដូងរបស់ Bootstrap ក្នុងការតម្រៀបរចនាបទ (Styling) និង Layout។

*   **`bootstrap.css`**: នេះគឺជាកូដ CSS ពេញលេញ ងាយស្រួលអាន (មានការដកឃ្លា និងចុះបន្ទាត់)។ គេច្រើនប្រើវាសម្រាប់អាន និងសិក្សា។
*   **`bootstrap.min.css`**: ពាក្យ `min` មកពី `minified` (បង្រួម)។ កូដនេះត្រូវបានលុបចោលនូវការដកឃ្លា និងចុះបន្ទាត់ទាំងអស់ ដើម្បីអោយទំហំឯកសារតូច និងដើរលឿននៅលើអុីនធឺណិត។ **អ្នកគួរតែប្រើប្រាស់ File មួយនេះនៅក្នុងគម្រោងពិតប្រាកដ (Production)!**

---

## 2. ឯកសារ JavaScript (JS)

មុខងារខ្លះៗដូចជា Modal, Dropdown, ឬ Carousel ត្រូវការ JavaScript ដើម្បីដំណើរការបាន។

*   **`bootstrap.min.js`**: ឯកសារនេះមានត្រឹមតែកូដ JS របស់ Bootstrap តែប៉ុណ្ណោះ។ ប្រសិនបើអ្នកប្រើវា អ្នកត្រូវភ្ជាប់ឯកសារ `Popper.js` មួយទៀតដោយខ្លួនឯង។
*   **`bootstrap.bundle.min.js`**: (**សូមណែនាំ**) ឯកសារនេះបានបញ្ជូល (Bundle) មុខងាររបស់ `Popper.js` ចូលរួចជាស្រេច ដែលធ្វើអោយអ្នកងាយស្រួល ភ្ជាប់តែមួយ File គឺរួចរាល់!

---

## 3. អ្វីទៅជា Popper?

**Popper.js** គឺជាបណ្ណាល័យ (Library) ខាងក្រៅមួយដែល Bootstrap យកមកប្រើប្រាស់ដើម្បីគ្រប់គ្រងការបង្ហាញទីតាំង។ 
ឧទាហរណ៍៖ នៅពេលអ្នកចុចលើ **Dropdown** តើផ្ទាំង Dropdown គួរលោតមកខាងលើ ឬខាងក្រោមប៊ូតុង? រឿងនេះហើយគឺជាភារកិច្ចរបស់ Popper ដែលជួយគណនាទីតាំងយ៉ាងច្បាស់លាស់។

---

## 4. Bootstrap Icons

Bootstrap មិនមានភ្ជាប់មកជាមួយរូបតំណាង (Icons) ដោយស្វ័យប្រវត្តិនៅក្នុងឯកសារ CSS ដើមរបស់វាទេ។ វាគឺជាកញ្ចប់ដោយឡែកមួយទៀត។ យើងនឹងសិក្សាពីការតម្លើង និងប្រើប្រាស់ **Bootstrap Icons** លម្អិតនៅក្នុងមេរៀនក្រោយៗ!
