## 🔘 ការបង្កើតប៊ូតុង (Buttons)

Bootstrap មានរចនាបថប៊ូតុងស្រាប់ដែលស្រស់ស្អាត និង Responsive។ ដើម្បីបង្កើតប៊ូតុងណាមួយបាន ជាដំបូងអ្នក **ត្រូវតែ** ដាក់ Class គោលមួយគឺ `.btn`។ បន្ទាប់មកទើបអ្នកបន្ថែម Class ផ្សេងទៀតដើម្បីកំណត់ពណ៌ ឬទំហំ។

អ្នកអាចប្រើវាទៅលើ `<button>`, `<a>`, ឬ `<input>` ក៏បាន។

---

## 1. ពណ៌ប៊ូតុង (Solid Buttons)

យើងប្រើប្រព័ន្ធពណ៌របស់ Bootstrap ដែលមានស្រាប់មកអនុវត្តលើប៊ូតុង៖

```html
<button type="button" class="btn btn-primary">Primary (ចម្បង)</button>
<button type="button" class="btn btn-secondary">Secondary (បន្ទាប់បន្សំ)</button>
<button type="button" class="btn btn-success">Success (ជោគជ័យ)</button>
<button type="button" class="btn btn-danger">Danger (លុប/គ្រោះថ្នាក់)</button>
<button type="button" class="btn btn-warning">Warning (ព្រមាន)</button>
<button type="button" class="btn btn-info">Info (ព័ត៌មាន)</button>
<button type="button" class="btn btn-light">Light</button>
<button type="button" class="btn btn-dark">Dark</button>

<!-- ប៊ូតុងពិសេសសម្រាប់ Link -->
<button type="button" class="btn btn-link">Link Button</button>
```

---

## 2. ប៊ូតុងមានតែស៊ុម (Outline Buttons)

ប្រសិនបើអ្នកមិនចង់បានប៊ូតុងដែលមានពណ៌ផ្ទៃពេញលេចធ្លោពេកទេ អ្នកអាចប្រើ Outline Button បាន។ វាមានតែស៊ុម និងអក្សរទេ តែពេលអ្នកយកកណ្តុរទៅដាក់ពីលើ (Hover) វានឹងលេចពណ៌ពេញ។ ប្រើ `.btn-outline-*`។

```html
<button type="button" class="btn btn-outline-primary">Primary Outline</button>
<button type="button" class="btn btn-outline-danger">Danger Outline</button>
```

---

## 3. ទំហំប៊ូតុង (Button Sizes)

អ្នកចង់បានប៊ូតុងធំ ឬ តូច?
*   **`.btn-lg`**: សម្រាប់ប៊ូតុងខ្នាតធំ (Large)
*   **`.btn-sm`**: សម្រាប់ប៊ូតុងខ្នាតតូច (Small)

```html
<button type="button" class="btn btn-primary btn-lg">Large Button</button>
<button type="button" class="btn btn-primary">Normal Button</button>
<button type="button" class="btn btn-primary btn-sm">Small Button</button>
```

---

## 4. ប៊ូតុងអសកម្ម (Disabled Buttons)

ដើម្បីធ្វើអោយប៊ូតុងមិនអាចចុចបាន (ឧទាហរណ៍ ពេលកំពុង Submit ទិន្នន័យ) គ្រាន់តែបន្ថែមគុណលក្ខណៈ `disabled` ទៅក្នុង HTML tag។

```html
<button type="button" class="btn btn-primary" disabled>មិនអាចចុចបានទេ</button>
```

---

## 5. ការផ្គុំប៊ូតុងចូលគ្នា (Button Groups)

អ្នកអាចផ្គុំប៊ូតុងជាច្រើនចូលគ្នាអោយជាប់គ្នាតែមួយ (ប្រៀបដូចជា Navigation ដែរ) ដោយរុំពួកវាចូលទៅក្នុង `<div>` មួយដែលមាន Class `.btn-group`។

```html
<div class="btn-group" role="group">
  <button type="button" class="btn btn-secondary">ឆ្វេង</button>
  <button type="button" class="btn btn-secondary">កណ្តាល</button>
  <button type="button" class="btn btn-secondary">ស្តាំ</button>
</div>
```
