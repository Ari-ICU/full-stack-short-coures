## 📏 ការគ្រប់គ្រងគម្លាត (Spacing)

ដើម្បីរចនាគេហទំព័រអោយបានស្អាត ការទុកចន្លោះទំនេរ (Whitespace) គឺជារឿងសំខាន់បំផុត។ Bootstrap មានប្រព័ន្ធដ៏ឆ្លាតវៃសម្រាប់គ្រប់គ្រង **Margin** និង **Padding**។

រូបមន្តទូទៅគឺ៖ `{ប្រភេទ}{ទិសដៅ}-{ទំហំ}` (ឧទាហរណ៍៖ `mt-3`)

---

## 1. ប្រភេទ (Property)

*   **`m`**: តំណាងអោយ **Margin** (គម្លាតផ្នែកខាងក្រៅ)
*   **`p`**: តំណាងអោយ **Padding** (លំហផ្នែកខាងក្នុង)

---

## 2. ទិសដៅ (Direction)

*   **`t`**: ខាងលើ (top)
*   **`b`**: ខាងក្រោម (bottom)
*   **`s`**: ខាងឆ្វេង (start) 
*   **`e`**: ខាងស្តាំ (end)
*   **`x`**: ឆ្វេង និង ស្តាំព្រមគ្នា (អ័ក្សដេក x)
*   **`y`**: លើ និង ក្រោមព្រមគ្នា (អ័ក្សឈរ y)
*   *(បើមិនដាក់ទិសដៅទេ វាមានន័យថាគ្រប់ទិសទាំង ៤ តែម្តង)*

---

## 3. មាត្រដ្ឋានទំហំ (Sizes)

Bootstrap មានទំហំពី 0 ដល់ 5៖
*   `0`: លុបគម្លាតចោល (0px)
*   `1`: តូចបំផុត ($spacer * .25)
*   `2`: តូច ($spacer * .5)
*   `3`: មធ្យម ($spacer) - នេះគឺជាទំហំស្តង់ដារ ស្មើនឹង 16px
*   `4`: ធំ ($spacer * 1.5)
*   `5`: ធំបំផុត ($spacer * 3)
*   `auto`: ស្វ័យប្រវត្តិ

---

## 4. ឧទាហរណ៍ជាក់ស្តែង

```html
<!-- Padding គ្រប់ទិសទំហំ 3 -->
<div class="p-3 bg-light">មាន Padding ជុំវិញខ្លួន 16px</div>

<!-- Margin ខាងលើទំហំ 4 -->
<div class="mt-4 bg-primary text-white">មានគម្លាតពីប្រអប់ខាងលើធំបន្តិច (Margin Top)</div>

<!-- Padding លើនិងក្រោម (y) ទំហំ 5 -->
<div class="py-5 bg-secondary text-white">មានលំហខាងលើនិងក្រោមធំខ្លាំង</div>
```

---

## 5. ការរុញប្រអប់អោយចំកណ្តាល (Centering)

តើអ្នកធ្លាប់ប្រើ `margin: 0 auto;` ក្នុង CSS ទេ? នៅក្នុង Bootstrap អ្នកគ្រាន់តែប្រើ Class `.mx-auto` ទៅលើប្រអប់ដែលមានទំហំច្បាស់លាស់ (Fixed width) វានឹងរុញខ្លួនវាទៅចំកណ្តាលអេក្រង់។

```html
<div class="mx-auto bg-success text-white p-3" style="width: 200px;">
  ខ្ញុំនៅចំកណ្តាលអេក្រង់ជានិច្ច!
</div>
```
