## 📱 អ្វីទៅជា Responsive Web Design?

**Responsive Web Design (RWD)** គឺជាវិធីសាស្ត្ររចនាវេបសាយដែលអាចប្រែប្រួលទំហំ រូបរាង និងរចនាសម្ព័ន្ធ (Layout) របស់វាដោយស្វ័យប្រវត្តិតម្រូវទៅតាមទំហំអេក្រង់របស់ឧបករណ៍អ្នកប្រើប្រាស់ មិនថាពួកគេប្រើប្រាស់ទូរស័ព្ទដៃ (Mobile), ថេប្លេត (Tablet) ឬកុំព្យូទ័រ (Desktop) ឡើយ។

---

## 1. គ្រឹះដំបូង៖ Viewport Meta Tag (សំខាន់បំផុត!)

Viewport គឺជាផ្ទៃបង្ហាញជាក់ស្តែងនៅលើអេក្រង់ឧបករណ៍។ ប្រសិនបើគ្មាន **Viewport Meta tag** ទេ browser នៅលើទូរស័ព្ទនឹងព្យាយាមបង្ហាញទំព័រវេបសាយទាំងមូលដូចនៅលើ Desktop ដែរ ដែលធ្វើឱ្យរូបភាព និងអក្សរទាំងអស់រួមតូចល្អិតខ្លាំងរហូតមើលមិនច្បាស់។

ដូច្នេះ រាល់ពេលបង្កើតកូដ HTML ថ្មី អ្នកត្រូវតែដាក់កូដខាងក្រោមនេះនៅក្នុង `<head>` ជានិច្ច៖

```html
<head>
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
</head>
```

**ការពន្យល់លម្អិត៖**
*   `width=device-width`៖ កំណត់ទទឹងរបស់ទំព័រវេបសាយឱ្យស្មើនឹងទទឹងអេក្រង់ពិតរបស់ឧបករណ៍។
*   `initial-scale=1.0`៖ កំណត់កម្រិតពង្រីក (Zoom Level) ដំបូងឱ្យនៅកម្រិតធម្មតា (100%)។

---

## 2. របៀបប្រើប្រាស់ Media Queries (`@media`)

**Media Query** គឺជាការសរសេរលក្ខខណ្ឌនៅក្នុង CSS ដើម្បីសួរទៅកាន់ Browser ពីទំហំអេក្រង់បច្ចុប្បន្ន។ ប្រសិនបើអេក្រង់នោះត្រូវតាមលក្ខខណ្ឌដែលយើងបានកំណត់ នោះកូដ CSS នៅក្នុងប្លុក `@media` នឹងដំណើរការ។

### ២.១. ស្វែងយល់ពី Syntax គ្រឹះ
```css
/* កូដ CSS ធម្មតានៅទីនេះ (ដើរលើគ្រប់ឧបករណ៍) */
body {
  background-color: white;
}

@media (min-width: 768px) {
  /* កូដ CSS នៅទីនេះដំណើរការតែលើអេក្រង់ដែលមានទទឹងចាប់ពី 768px ឡើងទៅប៉ុណ្ណោះ */
  body {
    background-color: lightblue;
  }
}
```

### ២.២. breakpoints ពេញនិយម (Common Breakpoints)
breakpoints គឺជាចំណុចទទឹងអេក្រង់ដែល Layout របស់វេបសាយនឹងត្រូវផ្លាស់ប្តូរ៖
*   **`576px`**៖ សម្រាប់អេក្រង់ទូរស័ព្ទទម្រង់ផ្ដេក (Mobile Landscape)
*   **`768px`**៖ សម្រាប់អេក្រង់ Tablet
*   **`1024px`**៖ សម្រាប់ Laptop ឬ Desktop ខ្នាតតូច
*   **`1200px`**៖ សម្រាប់ Desktop ធំៗ

## 3. វិធីសាស្ត្រ Mobile-First Approach

**Mobile-First** គឺជាគោលការណ៍ដ៏ពេញនិយមបំផុតក្នុងការរចនាវេបសាយបច្ចុប្បន្ន។ យើងសរសេរកូដ CSS សម្រាប់អេក្រង់ទូរស័ព្ទ (Mobile) មុនគេជាកូដលំនាំដើម (Base Style) រួចទើបប្រើ `@media (min-width: ...)` ដើម្បីបន្ថែម ឬកែប្រែ Styles សម្រាប់អេក្រង់ធំៗ (Tablet/Desktop) តាមក្រោយ។

### ឧទាហរណ៍៖ របារម៉ឺនុយ (Navigation Bar)
យើងចង់ឱ្យម៉ឺនុយតម្រៀបជាជួរឈរនៅលើទូរស័ព្ទ (ដើម្បីកុំឱ្យចង្អៀត) និងបង្ហាញជាជួរដេកនៅលើកុំព្យូទ័រ។

ជាដំបូង នេះជាកូដ HTML ៖
```html
<nav class="site-nav">
  <div class="nav-brand">Logo</div>
  <ul class="nav-menu">
    <li><a href="#">Home</a></li>
    <li><a href="#">Products</a></li>
    <li><a href="#">About Us</a></li>
  </ul>
</nav>
```

បន្ទាប់មក យើងសរសេរកូដ CSS តាមគោលការណ៍ Mobile-First ៖

```css
/* ១. CSS សម្រាប់ទូរស័ព្ទដៃ (Mobile - កូដលំនាំដើម) */
.site-nav {
  display: flex;
  flex-direction: column; /* តម្រៀបជាជួរឈរ */
  padding: 16px;
  background-color: #1f2937;
}

.nav-menu {
  display: flex;
  flex-direction: column; /* ម៉ឺនុយរត់ចុះក្រោម */
  gap: 12px;
  list-style: none;
  padding: 0;
}
```

រួចទើបយើងបន្ថែម `@media` សម្រាប់អេក្រង់ Tablet និង Desktop ចាប់ពីទទឹង 768px ឡើងទៅ៖

```css
/* ២. CSS បន្ថែមសម្រាប់ Tablet/Desktop (Screen >= 768px) */
@media (min-width: 768px) {
  .site-nav {
    flex-direction: row; /* ប្តូរមកជាជួរដេក */
    justify-content: space-between;
    align-items: center;
  }

  .nav-menu {
    flex-direction: row; /* ម៉ឺនុយរត់ទទឹងផ្ដេក */
    gap: 20px;
  }
}
```

## 4. ឧទាហរណ៍ជាក់ស្តែង៖ Grid ប្រែប្រួលតាមអេក្រង់ (Responsive Grid)

នេះជាករណីសិក្សាទូទៅបំផុត៖ យើងមាន Cards ចំនួន ៣។ យើងចង់ឱ្យ៖
*   បង្ហាញ **១ ខ្ទង់ (1 column)** នៅលើ Mobile
*   បង្ហាញ **២ ខ្ទង់ (2 columns)** នៅលើ Tablet (ទទឹងចាប់ពី 768px)
*   បង្ហាញ **៣ ខ្ទង់ (3 columns)** នៅលើ Desktop (ទទឹងចាប់ពី 1024px)

ជាដំបូង កូដ HTML ៖
```html
<div class="card-grid">
  <div class="card">Card 1</div>
  <div class="card">Card 2</div>
  <div class="card">Card 3</div>
</div>
```

បន្ទាប់មក កូដ CSS ៖

```css
/* Mobile-First Base (លំនាំដើមដើរលើ Mobile) */
.card-grid {
  display: grid;
  grid-template-columns: 1fr; /* ១ ជួរឈរ */
  gap: 16px;
  padding: 16px;
}

.card {
  background-color: #ffffff;
  border: 1px solid #e5e7eb;
  padding: 24px;
  border-radius: 8px;
  text-align: center;
}

/* សម្រាប់ Tablet (ចាប់ពី 768px ឡើងទៅ) */
@media (min-width: 768px) {
  .card-grid {
    grid-template-columns: repeat(2, 1fr); /* ២ ជួរឈរ */
  }
}

/* សម្រាប់ Desktop (ចាប់ពី 1024px ឡើងទៅ) */
@media (min-width: 1024px) {
  .card-grid {
    grid-template-columns: repeat(3, 1fr); /* ៣ ជួរឈរ */
  }
}
```

ការអនុវត្តវិធីសាស្ត្រនេះជួយឱ្យកូដរបស់អ្នកមានសណ្តាប់ធ្នាប់ ដើរលឿននៅលើទូរស័ព្ទដៃ និងងាយស្រួលដោះស្រាយបញ្ហាកូដ (Debug) ទៅថ្ងៃក្រោយ!
