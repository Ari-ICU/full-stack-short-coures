## 📏 ខ្នាតរង្វាស់ (CSS Units)

CSS មានខ្នាតរង្វាស់ជាច្រើន — Click tab នីមួយៗ ដើម្បីឃើញ live demo!

```diagram
cssunits
```

```html
<!-- Typography scale ប្រើ rem -->
<section class="hero">
  <h1 class="hero-title">Modern CSS</h1>
  <p class="hero-subtitle">Build responsive layouts with ease</p>
</section>

<!-- Full-screen section ប្រើ vh/vw -->
<section class="fullscreen">
  <div class="fullscreen-content">Fullscreen Section</div>
</section>
```

```css
/* ✅ ប្រើ rem សម្រាប់ typography (ធៀប root 16px) */
.hero {
  padding: 4rem 2rem; /* 64px 32px */
}

.hero-title {
  font-size: 3rem;    /* 48px */
  font-weight: 800;
  color: #111827;
  margin: 0 0 1rem 0; /* 16px */
}

.hero-subtitle {
  font-size: 1.25rem; /* 20px */
  color: #6b7280;
  margin: 0;
}

/* vw/vh: full-screen sections */
.fullscreen {
  width: 100vw;
  min-height: 100vh;
  display: flex;
  align-items: center;
  justify-content: center;
  background: #f8fafc;
}

.fullscreen-content {
  font-size: 2rem;
  font-weight: 700;
  color: #1e293b;
}
```

## 🔧 `clamp()` — Responsive Typography

`clamp(minimum, preferred, maximum)` ធ្វើអោយ font-size **ផ្លាស់ប្ដូរដោយស្វ័យប្រវត្តិ** — ធំពេល viewport ធំ, តូចពេល viewport តូច, ប៉ុន្តែ**មិនអោយតូចឬធំពេក**។ ប្រើ slider ក្នុង diagram!

```diagram
clampdemo
```

```html
<!-- Hero section ជាមួយ responsive typography -->
<header class="site-header">
  <h1 class="site-heading">Full Stack Mastery</h1>
  <p class="site-tagline">Learn modern web development the right way</p>
  <a href="#courses" class="cta-btn">Start Learning</a>
</header>
```

```css
.site-header {
  text-align: center;
  padding: clamp(2rem, 8vw, 6rem); /* padding ក៏ responsive */
  background: linear-gradient(135deg, #667eea, #764ba2);
  color: white;
}

.site-heading {
  /* ✅ clamp: min=1.5rem, preferred=5vw, max=3.5rem */
  font-size: clamp(1.5rem, 5vw, 3.5rem);
  font-weight: 800;
  margin: 0 0 1rem 0;
  line-height: 1.1;
}

.site-tagline {
  font-size: clamp(1rem, 2.5vw, 1.5rem);
  opacity: 0.9;
  margin: 0 0 2rem 0;
}

.cta-btn {
  display: inline-block;
  padding: clamp(0.6rem, 2vw, 1rem) clamp(1.2rem, 4vw, 2rem);
  background: white;
  color: #764ba2;
  border-radius: 999px;
  font-weight: 700;
  font-size: clamp(0.875rem, 2vw, 1.125rem);
  text-decoration: none;
}
```

## 📦 CSS Variables (Custom Properties)

ជំនួស hardcoded values ដែលដដែលៗ — ប្រើ variables ដើម្បីងាយ maintain និង theme. ប្តូរ colors, spacing, radius ហើយឃើញ live preview!

```diagram
cssvariables
```

```html
<!-- Components ប្រើ CSS variables -->
<div class="card">
  <div class="card-header">
    <h2 class="card-title">Dashboard</h2>
    <span class="card-badge">Pro</span>
  </div>
  <p class="card-body">Your analytics overview for this week.</p>
  <div class="card-footer">
    <button class="btn btn-primary">View Details</button>
    <button class="btn btn-outline">Dismiss</button>
  </div>
</div>
```

```css
/* ១. ដាក់ variables ទៅ :root (global scope) */
:root {
  --primary:    #3b82f6;
  --primary-dk: #2563eb;
  --text:       #1f2937;
  --text-muted: #6b7280;
  --bg:         #ffffff;
  --border:     #e5e7eb;
  --radius:     12px;
  --spacing:    16px;
  --shadow:     0 4px 16px rgba(0, 0, 0, 0.08);
}

/* ២. ហៅប្រើ var() */
.card {
  background: var(--bg);
  border: 1px solid var(--border);
  border-radius: var(--radius);
  padding: var(--spacing);
  box-shadow: var(--shadow);
  max-width: 380px;
}

.card-header {
  display: flex;
  align-items: center;
  justify-content: space-between;
  margin-bottom: var(--spacing);
}

.card-title {
  margin: 0;
  font-size: 1.25rem;
  font-weight: 700;
  color: var(--text);
}

.card-badge {
  background: var(--primary);
  color: white;
  padding: 2px 10px;
  border-radius: 999px;
  font-size: 12px;
  font-weight: 600;
}

.card-body {
  color: var(--text-muted);
  font-size: 14px;
  margin: 0 0 var(--spacing) 0;
}

.card-footer {
  display: flex;
  gap: 8px;
}

.btn {
  padding: 8px 16px;
  border-radius: calc(var(--radius) / 2);
  font-size: 14px;
  font-weight: 600;
  cursor: pointer;
  border: none;
  transition: opacity 0.15s;
}

.btn-primary {
  background: var(--primary);
  color: white;
}

.btn-primary:hover { opacity: 0.9; }

.btn-outline {
  background: transparent;
  color: var(--text-muted);
  border: 1px solid var(--border);
}
```

## 🎨 Gradients — ការចាក់ពណ៌លាយ

ចាក់ gradient ស្រស់ស្អាតដោយមិនបាច់ប្រើរូបភាព។ ប្រើ builder ខាងក្រោម ដើម្បី customize!

```diagram
gradientdemo
```

```html
<!-- Hero ជាមួយ linear gradient -->
<section class="gradient-hero">
  <h1 class="gradient-hero__title">Learn to Code</h1>
  <p class="gradient-hero__sub">Build beautiful web apps</p>
</section>

<!-- Cards ជាមួយ gradient accents -->
<div class="feature-cards">
  <div class="feature-card feature-card--blue">
    <span class="feature-icon">🚀</span>
    <h3>Fast</h3>
  </div>
  <div class="feature-card feature-card--purple">
    <span class="feature-icon">🎨</span>
    <h3>Beautiful</h3>
  </div>
  <div class="feature-card feature-card--green">
    <span class="feature-icon">🔒</span>
    <h3>Secure</h3>
  </div>
</div>
```

```css
/* Linear gradient hero */
.gradient-hero {
  padding: 80px 40px;
  text-align: center;
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  color: white;
  border-radius: 16px;
}

.gradient-hero__title {
  font-size: 3rem;
  font-weight: 800;
  margin: 0 0 12px 0;
}

.gradient-hero__sub {
  font-size: 1.2rem;
  opacity: 0.85;
  margin: 0;
}

/* Feature cards with gradient */
.feature-cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
  margin-top: 24px;
}

.feature-card {
  padding: 24px;
  border-radius: 12px;
  color: white;
  text-align: center;
}

.feature-card--blue   { background: linear-gradient(135deg, #3b82f6, #06b6d4); }
.feature-card--purple { background: linear-gradient(135deg, #a855f7, #ec4899); }
.feature-card--green  { background: linear-gradient(135deg, #22c55e, #14b8a6); }

.feature-icon { font-size: 2rem; display: block; margin-bottom: 8px; }

.feature-card h3 { margin: 0; font-size: 1.1rem; font-weight: 700; }
```

## 🖼️ Responsive Images

រូបភាពតែងតែ**ហៀរ**ចេញពី container ប្រសិនបើ container តូចជាង natural width របស់វា។ Fix មួយជួរ CSS ដោះស្រាយ! ប្រើ slider ដើម្បីឃើញ!

```diagram
responsiveimg
```

```html
<!-- Responsive image inside a fluid container -->
<article class="blog-post">
  <figure class="post-figure">
    <img
      src="cover.jpg"
      alt="Blog post cover"
      class="post-img"
      loading="lazy"
    />
    <figcaption class="post-caption">Photo by the author</figcaption>
  </figure>
  <div class="post-content">
    <h2 class="post-title">Understanding CSS in 2024</h2>
    <p class="post-excerpt">Modern CSS has evolved dramatically...</p>
  </div>
</article>
```

```css
/* ✅ Global reset — ដាក់ជា default */
img,
video,
iframe {
  max-width: 100%; /* ✅ ព្រំដែនកំពូល */
  height: auto;    /* ✅ ratio ដើម */
  display: block;
}

.blog-post {
  max-width: 720px;
  margin: 0 auto;
  padding: 24px;
}

.post-figure {
  margin: 0 0 24px 0;
  border-radius: 12px;
  overflow: hidden; /* ✅ ត្រូវ hidden ពេល border-radius */
}

.post-img {
  width: 100%;
  height: 400px;
  object-fit: cover; /* ✅ fill box ដោយ crop */
}

.post-caption {
  font-size: 13px;
  color: #6b7280;
  padding: 8px 0;
  text-align: center;
}

.post-title {
  font-size: clamp(1.5rem, 4vw, 2.25rem);
  font-weight: 800;
  color: #111827;
  margin: 0 0 12px 0;
}

.post-excerpt {
  font-size: 1rem;
  color: #6b7280;
  line-height: 1.7;
  margin: 0;
}
```
