## ✨ CSS Transitions (ការផ្លាស់ប្តូរដោយរលូន)

ជារឿយៗនៅពេលដែលអ្នកយក Mouse ទៅដាក់លើប៊ូតុង វានឹងប្តូរពណ៌ភ្លាមៗ (កន្ត្រាក់)។ ដើម្បីអោយវាប្តូរដោយរលូនយឺតៗ យើងត្រូវប្រើ `transition`។

`transition` ត្រូវបានដាក់ទៅលើ State ដើម (មិនមែនដាក់លើ `:hover` ទេ)។

```css
button {
  background-color: blue;
  color: white;
  padding: 10px 20px;
  
  /* កំណត់អោយរាល់ការផ្លាស់ប្តូរទាំងអស់ ប្រើពេល 0.3 វិនាទី (យ៉ាងរលូន) */
  transition: all 0.3s ease-in-out;
}

button:hover {
  background-color: red; /* វានឹងប្រែពណ៌ពីខៀវ ទៅក្រហម ក្នុងរយះពេល 0.3s */
}
```

## 🔄 CSS Transform (ការផ្លាស់ប្តូររូបរាង និងទីតាំង)

`transform` អនុញ្ញាតអោយយើងកែប្រែរូបរាងរបស់ Element ដោយមិនប៉ះពាល់ដល់ទីតាំងរបស់ Elements ផ្សេងទៀតឡើយ (មិនរុញគេឯង)។

តម្លៃសំខាន់ៗរបស់ `transform`:
- `translate(x, y)`: រំកិលទីតាំង (ឆ្វេង-ស្តាំ, លើ-ក្រោម) ធៀបនឹងទីតាំងដើមរបស់វា។
- `scale(n)`: ពង្រីក ឬបង្រួម (ឧ. `scale(1.5)` គឺពង្រីក 1.5 ដង)។
- `rotate(deg)`: បង្វិល (ឧ. `rotate(45deg)` បង្វិល 45 ដឺក្រេ)។
- `skew(x-deg, y-deg)`: ធ្វើអោយវៀច ឬផ្អៀង។

**ឧទាហរណ៍ជាក់ស្តែង (ពង្រីកប៊ូតុងពេល Hover):**
```css
.card {
  transition: transform 0.2s;
}

.card:hover {
  /* ពេល Hover ពង្រីកធំបន្តិច (1.05 ដង) នឹង អណ្តែតឡើងលើ (-5px) */
  transform: scale(1.05) translateY(-5px);
}
```

## 🎬 CSS Animations (@keyframes)

`transition` ត្រូវការអ្នកប្រើប្រាស់បញ្ជា (ដូចជាយក Mouse ទៅ Hover ទើបវាដើរ)។ ប៉ុន្តែចុះបើអ្នកចង់អោយវាមានចលនាដោយស្វ័យប្រវត្តិ តាំងពីពេលបើកវេបសាយដំបូង?
នោះគឺយើងត្រូវប្រើ **`animation`** គួបផ្សំជាមួយ **`@keyframes`**។

`@keyframes` គឺជាកន្លែងដែលអ្នកគូសវាសសាច់រឿងនៃចលនា តាំងពីចំនុចចាប់ផ្តើម (0% ឬ `from`) រហូតដល់ចំនុចបញ្ចប់ (100% ឬ `to`)។

```css
/* ១. បង្កើតសាច់រឿងនៃចលនាឈ្មោះ "fade-in-up" */
@keyframes fade-in-up {
  from {
    opacity: 0;
    transform: translateY(20px); /* ធ្លាក់ចុះក្រោម 20px នឹងមើលមិនឃើញសោះ */
  }
  to {
    opacity: 1;
    transform: translateY(0); /* ងើបមកកន្លែងដើមវិញ នឹងច្បាស់ 100% */
  }
}

/* ២. ហៅចលនានោះមកប្រើ */
.welcome-text {
  /* ឈ្មោះចលនា | រយៈពេល | ល្បឿន | ពន្យារពេល (អត់មានក៏បាន) */
  animation: fade-in-up 1s ease-out;
}
```

**សន្និដ្ឋាន:** ការប្រើប្រាស់ Transitions នឹង Transforms បន្តិចបន្តួច ជួយអោយវេបសាយមើលទៅទំនើប និងមានភាពរស់រវើកជាងមុនខ្លាំង។ ប៉ុន្តែសូមកុំប្រើប្រាស់ Animation ច្រើនជ្រុលពេក ព្រោះវាអាចធ្វើអោយវេបសាយដើរយឺត និងរំខានដល់ភ្នែកអ្នកអាន។
