## ✨ CSS Transition — ការផ្លាស់ប្ដូរដោយរលូន

ជារឿយៗ ពេល Hover ប៊ូតុង ពណ៌ប្ដូរភ្លាមៗ (kn)។ `transition` ធ្វើអោយការប្ដូរទៅ **យឺតៗ រលូន**។ ប្ដូរ duration, easing, property ហើយ hover ប៊ូតុង ដើម្បីឃើញ live!

```diagram
transition
```

```html
<button class="btn">Hover Me</button>
<div class="nav-link">Navigation Link</div>
<div class="card">Card with transition</div>
```

```css
/* ✅ transition ដាក់លើ state ដើម — មិនមែន :hover */
.btn {
  background: #3b82f6;
  color: white;
  padding: 12px 24px;
  border: none;
  border-radius: 8px;
  cursor: pointer;
  transition: all 0.3s ease-in-out; /* ⭐ */
}

.btn:hover {
  background: #ef4444;
  transform: scale(1.05);
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.2);
}

/* transition specific properties (ល្អជាង "all") */
.nav-link {
  color: #6b7280;
  transition: color 0.2s ease; /* transition color តែម្ដង */
}

.nav-link:hover {
  color: #3b82f6;
}

.card {
  background: white;
  border-radius: 12px;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.08);
  /* transition multiple properties */
  transition: transform 0.25s ease, box-shadow 0.25s ease;
}

.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 12px 32px rgba(0, 0, 0, 0.15);
}
```

## 🔄 CSS Transform — ការផ្លាស់ប្ដូររូបរាង

`transform` ផ្លាស់ប្ដូររូបរាង **ដោយមិនប៉ះពាល់ layout** — Elements ផ្សេងមិនរំកិលឡើយ។ ប្រើ sliders ដើម្បីឃើញ translate, scale, rotate, skew live!

```diagram
transformdemo
```

```html
<div class="icon-btn">🔔</div>
<div class="product-card">
  <img src="product.jpg" alt="Product" class="product-img">
  <div class="product-info">Product Name</div>
</div>
<div class="badge">NEW</div>
```

```css
/* translate: រំកិល (ដូច position: relative ប៉ុន្តែ GPU-accelerated) */
.icon-btn {
  transition: transform 0.2s ease;
}
.icon-btn:hover {
  transform: translateY(-3px); /* ងើបឡើង 3px */
}

/* scale: ពង្រីក/បង្រួម */
.product-card {
  transition: transform 0.25s ease;
  overflow: hidden;
  border-radius: 12px;
}
.product-card:hover {
  transform: scale(1.03);
}

/* rotate: បង្វិល */
.badge {
  transition: transform 0.3s ease;
}
.badge:hover {
  transform: rotate(12deg) scale(1.1);
}

/* combined transforms — ✅ ល្អបំផុត */
.product-img {
  transition: transform 0.4s ease;
}
.product-card:hover .product-img {
  transform: scale(1.08) translateY(-4px);
}
```

## 🎬 @keyframes — ចលនាស្វ័យប្រវត្តិ

`transition` ចាំ user action (hover/click)។ `@keyframes` + `animation` ដំណើរការ**ដោយស្វ័យប្រវត្តិ** — ល្អសម្រាប់ loading spinners, page-load effects។ Click preset ដើម្បីឃើញ!

```diagram
keyframesdemo
```

```html
<div class="loader"></div>
<div class="hero-text">Welcome to Full Stack Mastery</div>
<div class="notification-dot"></div>
```

```css
/* ១. Spinning loader */
@keyframes spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}

.loader {
  width: 40px;
  height: 40px;
  border: 4px solid #e5e7eb;
  border-top-color: #3b82f6;
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
}

/* ២. Page-load fade-in effect */
@keyframes fade-in-up {
  from {
    opacity: 0;
    transform: translateY(24px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.hero-text {
  animation: fade-in-up 0.8s ease-out both;
  /* "both" = រក្សា state នៃ keyframe ចុងក្រោយ */
}

/* ៣. Pulsing notification dot */
@keyframes pulse-dot {
  0%, 100% { transform: scale(1);   opacity: 1; }
  50%       { transform: scale(1.4); opacity: 0.7; }
}

.notification-dot {
  width: 10px;
  height: 10px;
  background: #ef4444;
  border-radius: 50%;
  animation: pulse-dot 1.2s ease-in-out infinite;
}
```

## 🎯 Transition + Transform ជាមួយគ្នា

`transition` + `transform` ជាគូ Best Practice ។ `transform` ដំណើរការលើ GPU — ល្អ performance ជាង `width`, `top`, `left`។ Hover cards ខាងក្រោម!

```diagram
transitiontransform
```

```html
<!-- ✅ ប្រើ transform + transition — GPU accelerated -->
<div class="feature-grid">
  <div class="feature-card feature-card--lift">
    <span class="feature-icon">🚀</span>
    <h3>Lift Effect</h3>
  </div>
  <div class="feature-card feature-card--rotate">
    <span class="feature-icon">🎨</span>
    <h3>Rotate Effect</h3>
  </div>
  <div class="feature-card feature-card--glow">
    <span class="feature-icon">✨</span>
    <h3>Glow Effect</h3>
  </div>
</div>
```

```css
.feature-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

/* Base — transition ដាក់នៅទីនេះ */
.feature-card {
  background: white;
  border: 1px solid #e5e7eb;
  border-radius: 16px;
  padding: 24px;
  text-align: center;
  /* ✅ transition specific — ល្អជាង "all" */
  transition: transform 0.25s ease, box-shadow 0.25s ease;
}

.feature-icon {
  font-size: 2.5rem;
  display: block;
  margin-bottom: 12px;
}

.feature-card h3 {
  margin: 0;
  font-size: 14px;
  color: #374151;
}

/* Hover states — transform ដាក់នៅទីនេះ */
.feature-card--lift:hover {
  transform: translateY(-8px) scale(1.02);
  box-shadow: 0 20px 48px rgba(59, 130, 246, 0.25);
}

.feature-card--rotate:hover {
  transform: rotate(3deg) scale(1.05);
  box-shadow: 0 16px 40px rgba(168, 85, 247, 0.25);
}

.feature-card--glow:hover {
  transform: scale(1.04);
  box-shadow: 0 0 40px rgba(34, 197, 94, 0.4);
}

/* ⚠️ ចៀសវាង: កុំ animate width, height, top, left
   ✅ ប្រើ: transform (translate, scale) — GPU ។ */
```
