## 📍 CSS Position

តាមលំនាំដើម Elements ទាំងអស់នៅលើ HTML រៀបចំតម្រៀបពីលើចុះក្រោម (**Normal Flow**)។ ប៉ុន្តែពេលខ្លះ យើងចង់ដាក់ Element នៅទីតាំងជាក់លាក់ (ឧ. នៅជ្រុងអេក្រង់, នៅពីលើរូបភាព)។ យើងប្រើ `position`។

---

### 1. `position: static` — លំនាំដើម

Elements ទាំងអស់ default ជា `static`។ ស្ថិតនៅ Normal Flow។ **top / left / right / bottom / z-index មិនដំណើរការ**។

```diagram
positionstatic
```

```html
<div class="el">Element ១</div>
<div class="el el--static">Element ២ (static)</div>
<div class="el">Element ៣</div>
```

```css
/* ជា default — Elements ទាំងអស់ ហូរពីលើចុះក្រោម */
.el {
  background: #e5e7eb;
  padding: 8px 16px;
  margin-bottom: 8px;
  border-radius: 8px;
}

.el--static {
  position: static; /* default — មិនចាំបាច់សរសេរ */
  /* top: 10px;  ← ignored */
  /* z-index: 5; ← ignored */
}
```

---

### 2. `position: relative` — ធៀបនឹងទីតាំងដើម

**រក្សា space ដើម** ក្នុង Normal Flow — ហើយអាចរំកិលពីទីតាំងនោះ។ ប្រើ **slider** ក្នុង diagram ដើម្បីឃើញ live!

```diagram
positionrelative
```

```html
<div class="el">Element ១</div>
<div class="el el--relative">Element ២ (relative)</div>
<div class="el">Element ៣ — space ដើម reserve ទុក</div>
```

```css
.el {
  background: #e5e7eb;
  padding: 8px 16px;
  margin-bottom: 8px;
  border-radius: 8px;
}

.el--relative {
  position: relative;
  top: 10px;   /* ចុះក្រោម 10px ពីទីតាំងដើម */
  left: 20px;  /* រំកិលស្ដាំ 20px */
  background: #3b82f6;
  color: white;
  /* space ដើម នៅតែ reserve → Element ៣ មិនឡើងមក */
}

/* ⭐ ការប្រើ relative ដ៏ពេញនិយម: ជា parent container */
.parent {
  position: relative; /* ឃុំ .child absolute */
}
```

---

### 3. `position: absolute` — ធៀបនឹង relative parent

**លោតចេញពី Normal Flow** — Elements ផ្សេងបូកជិតដូចជាវាបាត់។ ធៀបនឹង **relative parent ជិតបំផុត**។ ប្រើ **sliders** ដើម្បីផ្លាស់ top/left!

```diagram
positionabsolute
```

```html
<div class="card">
  <img class="card__img" src="product.jpg" alt="Product" />
  <h3 class="card__title">Product Name</h3>
  <span class="card__badge">NEW</span>
</div>

<p class="next-el">Element បន្ទាប់ — ឡើងមកបូក</p>
```

```css
.card {
  position: relative; /* ⭐ ត្រូវតែមាន! .card__badge ធៀបនឹង .card */
  width: 300px;
  height: 200px;
  border: 1px solid #e5e7eb;
  border-radius: 12px;
  overflow: hidden;
}

.card__img {
  width: 100%;
  height: 100%;
  object-fit: cover;
}

.card__title {
  /* static — ស្ថិតនៅ Normal Flow ក្នុង .card */
  padding: 8px 12px;
}

.card__badge {
  position: absolute; /* ធៀបនឹង .card (relative parent) */
  top: 8px;           /* 8px ពីខាងលើ .card */
  right: 8px;         /* 8px ពីខាងស្ដាំ .card */
  background: #ef4444;
  color: white;
  padding: 2px 8px;
  border-radius: 999px;
  font-size: 11px;
  font-weight: bold;
}

/* .card__badge លោតចេញ Normal Flow → .next-el ឡើងមក */
.next-el {
  margin-top: 8px;
  color: #6b7280;
}
```

---

### 4. `position: fixed` — ស្ងៀមជាប់នឹង Viewport

**Scroll ចុះប៉ុនណា element នៅ fixed ត្រង់កន្លែង** — ធៀបនឹងអេក្រង់ (Viewport)។ ឃើញ Navbar + Chat button ក្នុង diagram!

```diagram
positionfixed
```

```html
<nav class="navbar">
  <span class="navbar__logo">Full Stack Mastery</span>
  <ul class="navbar__links">
    <li><a href="#">Home</a></li>
    <li><a href="#">About</a></li>
  </ul>
</nav>

<main class="page-content">
  <p>Page content here...</p>
</main>

<button class="chat-btn">💬</button>
```

```css
.navbar {
  position: fixed; /* ស្ងៀមជាប់ខាងលើ Viewport */
  top: 0;
  left: 0;
  right: 0;        /* ទទឹងពេញ */
  height: 60px;
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 0 24px;
  background: white;
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
  z-index: 100;
}

.navbar__logo { font-weight: bold; }

.navbar__links {
  display: flex;
  gap: 16px;
  list-style: none;
}

.page-content {
  /* ⚠️ ត្រូវ offset ព្រោះ .navbar ស៊ីទំហំ 60px */
  padding-top: 60px;
}

.chat-btn {
  position: fixed; /* ស្ងៀមជាប់ជ្រុងខាងស្ដាំ-ក្រោម */
  bottom: 24px;
  right: 24px;
  width: 52px;
  height: 52px;
  border-radius: 50%;
  background: #3b82f6;
  color: white;
  border: none;
  font-size: 20px;
  cursor: pointer;
  z-index: 999;
}
```

### 5. `position: sticky` — relative + fixed hybrid

ដើរតួជា `relative` — **រហូតដល់ Scroll ទៅដល់ threshold** ហើយក្លាយជា fixed។ **Scroll ចុះក្នុង diagram** ដើម្បីឃើញ!

```diagram
positionsticky
```

```html
<article class="content">
  <p>Content before...</p>

  <h2 class="section-header">Section ១ — Basics</h2>
  <p>Content of section 1...</p>
  <p>More content here...</p>

  <h2 class="section-header">Section ២ — Advanced</h2>
  <p>Content of section 2...</p>
</article>
```

```css
.content {
  max-width: 800px;
  margin: 0 auto;
  padding: 16px;
}

.section-header {
  position: sticky; /* relative ជាធម្មតា → fixed ពេល scroll ដល់ */
  top: 0;           /* ⭐ ត្រូវតែ! threshold = 0px ពីខាងលើ */
  background: white;
  padding: 12px 0;
  margin: 0;
  z-index: 10;
  border-bottom: 2px solid #3b82f6;
}
```

## 🥞 Z-Index — ស្រទាប់ Layer

នៅពេល Elements ត្រួតស៊ីគ្នា (overlap) — `z-index` កំណត់ **មួយណានៅលើ មួយណានៅក្រោម**។ ប្រើ **sliders** ដើម្បីបំប្ដូរ z-index live:

```diagram
zindex
```

```html
<div class="layer-wrap">
  <div class="layer layer--blue">Box ១</div>
  <div class="layer layer--purple">Box ២</div>
  <div class="layer layer--orange">Box ៣</div>
</div>
```

```css
.layer-wrap {
  position: relative; /* context សម្រាប់ absolute children */
  height: 160px;
}

/* ⚠️ z-index ត្រូវការ position ≠ static! */
.layer {
  position: absolute;
  width: 120px;
  height: 80px;
  border-radius: 10px;
  display: flex;
  align-items: center;
  justify-content: center;
  font-weight: bold;
  color: white;
}

.layer--blue   { background: #3b82f6; top: 20px; left: 20px;  z-index: 1; }
.layer--purple { background: #a855f7; top: 50px; left: 60px;  z-index: 2; }
.layer--orange { background: #f97316; top: 35px; left: 100px; z-index: 3; }

/* z-index ៣ (orange) > ២ (purple) > ១ (blue) → orange នៅលើគេ */
```

> 💡 **គន្លឹះ:** ប្រើលេខ rounded (10, 20, 100, 999) ដើម្បីងាយបញ្ចូល Elements ថ្មីនៅចន្លោះ — ជាជាង 1, 2, 3 ដែលងាយអស់កន្លែង។
