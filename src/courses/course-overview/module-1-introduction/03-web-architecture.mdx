## 🏗️ Web Architecture ជាអ្វី?

**Web Architecture** សំដៅលើការរៀបចំ និងរបៀបដែលផ្នែកផ្សេងៗនៃប្រព័ន្ធវិប (Client, Server, Database) ទំនាក់ទំនងគ្នាដើម្បីឱ្យកម្មវិធីមួយដំណើរការបានត្រឹមត្រូវ។

### សមាសធាតុគោលទាំង ៣ (Three-Tier Architecture)

1. **Presentation Tier (Frontend):** 
   - ជាអ្វីដែលអ្នកប្រើប្រាស់មើលឃើញ និងធ្វើអន្តរកម្ម។ បង្កើតឡើងដោយ HTML, CSS, JavaScript (React/Next.js).
2. **Application Tier (Backend):**
   - ជាកន្លែងផ្ទុក logic របស់កម្មវិធី។ វាទទួលសំណើ (requests) ពី Frontend ដំណើរការវា និងបញ្ជូនលទ្ធផលត្រឡប់ទៅវិញ។ បង្កើតឡើងដោយ Node.js, Express.js.
3. **Data Tier (Database):**
   - ជាកន្លែងរក្សាទុកទិន្នន័យ។ ឧទាហរណ៍៖ ការប្រើប្រាស់ PostgreSQL ដើម្បីរក្សាទុកព័ត៌មានអ្នកប្រើប្រាស់។
