## 🛠️ គម្រោងជាក់ស្តែង (Real-world Project)

ការរៀនទ្រឹស្តីតែមួយមុខមិនគ្រប់គ្រាន់ទេ ដូច្នេះក្នុងវគ្គនេះយើងនឹងបង្កើតគម្រោងធំមួយដែលស្រដៀងនឹងកម្មវិធីក្នុងពិភពពិត។ 

### គម្រោង: E-Commerce Platform ឬ Task Management System

ដើម្បីអនុវត្តចំណេះដឹងទាំងអស់ យើងនឹងបង្កើតកម្មវិធីមួយដែលមានមុខងារពេញលេញ៖
1. **User Authentication:** ការចុះឈ្មោះ, ចូលប្រើប្រាស់, និងសុវត្ថិភាព (Login/Register).
2. **Product/Task Management:** ការបង្កើត, អាន, កែប្រែ, និងលុបទិន្នន័យ (CRUD operations).
3. **Database Integration:** ការរក្សាទុកទិន្នន័យជាមួយ ![PostgreSQL](https://cdn.simpleicons.org/postgresql/4169E1) PostgreSQL.
4. **Responsive UI:** ដំណើរការបានល្អទាំងលើកុំព្យូទ័រ និងទូរស័ព្ទដៃ ដោយប្រើ ![Tailwind CSS](https://cdn.simpleicons.org/tailwindcss/06B6D4) Tailwind CSS.

### ដំណើរការនៃការអនុវត្តគម្រោង (Project Milestones)

ការអភិវឌ្ឍគម្រោងនឹងត្រូវបែងចែកជាដំណាក់កាលសំខាន់ៗចំនួន ៦ ដូចខាងក្រោម៖
1. **Project Proposal & Requirements:** ការកំណត់គោលដៅ និងតម្រូវការ (Features) របស់គម្រោង។
2. **Database Design (ERD & Schema):** ការរចនាមូលដ្ឋានទិន្នន័យ និងទំនាក់ទំនងរវាងទិន្នន័យ។
3. **Backend REST API:** ការសរសេរកូដ Backend និងបង្កើត API ដើម្បីគ្រប់គ្រងទិន្នន័យ។
4. **React Frontend:** ការរចនា និងសរសេរកូដចំណុចប្រទាក់អ្នកប្រើប្រាស់ (UI) ដោយប្រើប្រាស់ React។
5. **Integration:** ការតភ្ជាប់ Frontend ជាមួយ Backend API ដើម្បីអោយកម្មវិធីដំណើរការពេញលេញ។
6. **Final Deployment & Presentation:** ការដាក់អោយដំណើរការ (Deploy) កម្មវិធីនៅលើ Internet និងការធ្វើបទបង្ហាញ (Demo)។

ការអនុវត្តគម្រោងទាំងនេះនឹងជួយឱ្យអ្នកមាន Portfolio មួយដ៏ល្អសម្រាប់បង្ហាញដល់និយោជកនៅពេលស្វែងរកការងារ!

### ការវាយតម្លៃពិន្ទុ (Assessment)

ការវាយតម្លៃសម្រាប់វគ្គសិក្សានេះនឹងត្រូវធ្វើឡើងដោយផ្អែកលើចំណុចដូចខាងក្រោម៖

| ការវាយតម្លៃ (Assessment) | ភាគរយពិន្ទុ (Weight) |
| :--- | :---: |
| ការអនុវត្តលំហាត់ (Laboratory Exercises) | 10% |
| គម្រោងតូច (Mini Project: Backend + Frontend) | 20% |
| គម្រោងបញ្ចប់ (Final Capstone Project) | 50% |
| ការធ្វើបទបង្ហាញគម្រោង (Project Presentation) | 20% |
