## 🏗️ Web Architecture ជាអ្វី?

**Web Architecture** សំដៅលើការរៀបចំ និងរបៀបដែលផ្នែកផ្សេងៗនៃប្រព័ន្ធវិប (Client, Server, Database) ទំនាក់ទំនងគ្នាដើម្បីឱ្យកម្មវិធីមួយដំណើរការបានត្រឹមត្រូវ។

### សមាសធាតុគោលទាំង ៣ (Three-Tier Architecture)

1. **Presentation Tier (Frontend):** 
   - ជាអ្វីដែលអ្នកប្រើប្រាស់មើលឃើញ និងធ្វើអន្តរកម្ម។ បង្កើតឡើងដោយ ![HTML5](https://cdn.simpleicons.org/html5/E34F26) HTML, ![CSS3](https://cdn.simpleicons.org/css3/1572B6) CSS, ![JavaScript](https://cdn.simpleicons.org/javascript/F7DF1E) JavaScript (![React](https://cdn.simpleicons.org/react/61DAFB) React/![Next.js](https://cdn.simpleicons.org/nextdotjs/000000) Next.js).
2. **Application Tier (Backend):**
   - ជាកន្លែងផ្ទុក logic របស់កម្មវិធី។ វាទទួលសំណើ (requests) ពី Frontend ដំណើរការវា និងបញ្ជូនលទ្ធផលត្រឡប់ទៅវិញ។ បង្កើតឡើងដោយ ![Node.js](https://cdn.simpleicons.org/nodedotjs/5FA04E) Node.js, ![Express](https://cdn.simpleicons.org/express/000000) Express.js.
3. **Data Tier (Database):**
   - ជាកន្លែងរក្សាទុកទិន្នន័យ។ ឧទាហរណ៍៖ ការប្រើប្រាស់ ![PostgreSQL](https://cdn.simpleicons.org/postgresql/4169E1) PostgreSQL ដើម្បីរក្សាទុកព័ត៌មានអ្នកប្រើប្រាស់។
