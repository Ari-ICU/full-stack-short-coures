## ⚙️ Development Environment

ដើម្បីចាប់ផ្តើមការងារជា Full Stack Developer អ្នកត្រូវការកម្មវិធីជាមូលដ្ឋានមួយចំនួននៅលើកុំព្យូទ័ររបស់អ្នក។

### 1. Visual Studio Code (VS Code)
VS Code គឺជា Code Editor ដ៏មានប្រជាប្រិយភាពបំផុត។ វាលឿន ងាយស្រួលប្រើ និងមាន Extensions រាប់ពាន់។
- **ទាញយក:** [code.visualstudio.com](https://code.visualstudio.com/)
- **Extensions ដែលណែនាំ:** Prettier (សម្រាប់តម្រឹមកូដ), ESLint, និង Tailwind CSS IntelliSense។

### 2. Node.js 
Node.js អនុញ្ញាតឱ្យយើងដំណើរការកូដ JavaScript នៅក្រៅ Browser (ប្រើសម្រាប់ Backend)។ វាក៏ភ្ជាប់មកជាមួយ `npm` សម្រាប់គ្រប់គ្រងកញ្ចប់កូដ (Packages)។
- **ទាញយក:** [nodejs.org](https://nodejs.org/) (ជ្រើសរើសជំនាន់ LTS)។

### 3. PostgreSQL
PostgreSQL គឺជាប្រព័ន្ធគ្រប់គ្រងទិន្នន័យ (Database) ប្រភេទ Relational ដ៏ខ្លាំងក្លា និងមានស្ថេរភាព។
- **ទាញយក:** [postgresql.org](https://www.postgresql.org/download/)
- យើងនឹងប្រើប្រាស់វាដើម្បីរក្សាទុកទិន្នន័យទាំងអស់នៃគម្រោងរបស់យើង។

### 4. Git 
Git គឺជាប្រព័ន្ធសម្រាប់គ្រប់គ្រងកំណែកូដ (Version Control System) ការពារការបាត់បង់ និងងាយស្រួលធ្វើការងារជាក្រុម។
- **ទាញយក:** [git-scm.com](https://git-scm.com/)

**ត្រៀមខ្លួនរួចរាល់ហើយ!** ឥឡូវនេះយើងអាចចាប់ផ្តើមសរសេរកូដបានហើយ! 🚀
