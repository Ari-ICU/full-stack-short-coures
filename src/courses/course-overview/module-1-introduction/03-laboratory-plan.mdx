## 🧪 ផែនការអនុវត្តជាក់ស្តែង (Laboratory Plan)

ដើម្បីធានាបាននូវប្រសិទ្ធភាពនៃការសិក្សា វគ្គនេះត្រូវបានបែងចែកជាការអនុវត្តជាក់ស្តែង (Labs) តាមលំដាប់លំដោយដូចខាងក្រោម៖

1. **Development Environment Setup:** ការរៀបចំកម្មវិធី និងបរិស្ថានសម្រាប់ការសរសេរកូដ (VS Code, Node.js, PostgreSQL)។
2. **Git & GitHub:** ការគ្រប់គ្រង Version កូដ និងការធ្វើការងារជាក្រុមដោយប្រើ Git និង GitHub។
3. **HTML & CSS:** ការកសាងរចនាសម្ព័ន្ធ និងតុបតែងគេហទំព័រជាមូលដ្ឋាន។
4. **Compare Bootstrap and Tailwind:** ការប្រៀបធៀប និងអនុវត្តការប្រើប្រាស់ CSS Frameworks (Bootstrap ទល់នឹង Tailwind)។
5. **JavaScript Practice:** ការអនុវត្តតក្កវិជ្ជា (Logic), DOM Manipulation, និងការប្រើប្រាស់ Array Methods ក្នុង JavaScript។
6. **RDBMS (Relational Database):** ការរចនា និងគ្រប់គ្រងទិន្នន័យដោយប្រើប្រាស់ PostgreSQL។
7. **Research Prisma (after middleware):** ការស្រាវជ្រាវ និងអនុវត្តការតភ្ជាប់ Database ដោយប្រើប្រាស់ Prisma ORM (បន្ទាប់ពីរៀនពី Middleware)។
8. **Research CRUD with API (after TypeORM):** ការសិក្សាពីប្រតិបត្តិការ CRUD (Create, Read, Update, Delete) តាមរយៈ API (ការស្រាវជ្រាវបន្ទាប់ពីរៀនពី TypeORM)។
9. **Express REST API:** ការបង្កើត Backend API ពេញលេញដោយប្រើប្រាស់ Node.js និង Express។
10. **React Components:** ការបង្កើតចំណុចប្រទាក់អ្នកប្រើប្រាស់ (UI) ដោយបែងចែកជា Components ផ្សេងៗគ្នាក្នុង React។
11. **React CRUD:** ការភ្ជាប់ Frontend React ទៅកាន់ API ដើម្បីបង្ហាញ និងគ្រប់គ្រងទិន្នន័យជាក់ស្តែង (CRUD)។
12. **Full PERN Integration:** ការរួមបញ្ចូលបច្ចេកវិទ្យាទាំងអស់ចូលគ្នា (PostgreSQL, Express, React, Node.js) ដើម្បីបង្កើតកម្មវិធីពេញលេញមួយ។
13. **Deployment:** ការដាក់ដំណើរការកម្មវិធី (Deploy) ទៅកាន់ Internet ដើម្បីអោយអ្នកដទៃអាចប្រើប្រាស់បាន។
14. **Final Project Demo & Lab Session:** ការធ្វើបទបង្ហាញគម្រោងបញ្ចប់ និងការអនុវត្តជាក់ស្តែងបន្ថែមសម្រាប់សិស្ស (Lab practice)។

ផែនការនេះនឹងជួយឱ្យអ្នកមានការយល់ដឹងស៊ីជម្រៅ តាមរយៈការអនុវត្តជាក់ស្តែងបន្ទាប់ពីការរៀនទ្រឹស្តីនីមួយៗ!
