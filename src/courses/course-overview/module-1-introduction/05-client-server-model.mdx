## 🔄 អ្វីទៅជា Client-Server Model?

**Client-Server Model** គឺជាគំរូនៃស្ថាបត្យកម្មបណ្តាញ (Network Architecture) ដ៏មានប្រជាប្រិយបំផុតនៅលើអ៊ីនធឺណិត។ វាបែងចែកការងារជាពីរផ្នែកធំៗគឺ៖ **អ្នកស្នើសុំសេវាកម្ម (Client)** និង **អ្នកផ្តល់សេវាកម្ម (Server)**។

ដើម្បីងាយយល់ សូមប្រៀបធៀបវាទៅនឹង **អតិថិជន និងអ្នកលក់នៅក្នុងហាងកាហ្វេ**៖
- **អតិថិជន (Client):** ដើរចូលក្នុងហាង ហើយកុម្ម៉ង់កាហ្វេ (ស្នើសុំ)។
- **អ្នកលក់ (Server):** ទទួលការកុម្ម៉ង់ ឆុងកាហ្វេ រួចប្រគល់កាហ្វេនោះទៅឱ្យអតិថិជនវិញ (ឆ្លើយតប)។

---

## 💻 តើ Client ជាអ្វី?

**Client** គឺជាឧបករណ៍ ឬកម្មវិធីដែលត្រូវបានប្រើប្រាស់ដោយមនុស្ស ដើម្បីធ្វើការទាក់ទងទៅកាន់ប្រព័ន្ធផ្សេងទៀត។ វាមានតួនាទី **ចាប់ផ្តើម** ផ្ញើសំណើ (Request) មុនជានិច្ច។

**ឧទាហរណ៍នៃ Clients ពេញនិយម៖**
- **Web Browsers:** Chrome, Safari, Firefox, Edge
- **Mobile Apps:** កម្មវិធី Facebook, YouTube, TikTok នៅលើទូរស័ព្ទដៃ
- **Desktop Apps:** កម្មវិធី Telegram ឬ Spotify នៅលើកុំព្យូទ័រ

---

## 🗄️ តើ Server ជាអ្វី?

**Server** គឺជាកុំព្យូទ័រដែលមានថាមពលខ្លាំង (ច្រើនតែស្ថិតនៅក្នុង Data Center) ដែលបើកចោល ២៤ ម៉ោង សម្រាប់រង់ចាំស្តាប់ និងឆ្លើយតបទៅនឹងសំណើរបស់ Client។ វាមិនដែលផ្តួចផ្តើមការសន្ទនាមុននោះទេ វាគ្រាន់តែរង់ចាំឆ្លើយតបប៉ុណ្ណោះ។

**ប្រភេទ Servers ទូទៅមានដូចជា៖**
- **Web Server:** ផ្ទុកឯកសារ HTML, CSS, និងរូបភាព (ឧទាហរណ៍៖ Nginx, Apache)។
- **Database Server:** ផ្ទុកនិងគ្រប់គ្រងទិន្នន័យ (ឧទាហរណ៍៖ PostgreSQL, MySQL)។
- **API Server:** ផ្តល់ទិន្នន័យជាទម្រង់ JSON សម្រាប់ Mobile Apps ឫ Web Apps។

## 🔁 វដ្ត Request និង Response (The Request-Response Cycle)

រាល់សកម្មភាពទាំងអស់នៅលើអ៊ីនធឺណិត តែងតែវិលជុំនៅក្នុងវដ្តនៃ **Request** (សំណើ) និង **Response** (ការឆ្លើយតប)។ ខាងក្រោមនេះជាដំណើរការជាជំហានៗ នៅពេលអ្នកចូលមើលគេហទំព័រមួយ៖

1. **Request (សំណើ):** កុំព្យូទ័ររបស់អ្នក (Client) ផ្ញើសារមួយទៅកាន់ Server ដោយប្រាប់ថា៖ *"សុំផ្ញើទំព័រដើម (Homepage) របស់គេហទំព័រនេះមកអោយខ្ញុំ។"*
2. **Processing (ដំណើរការ):** Server ទទួលបានសារនោះ វាធ្វើការស្វែងរកឯកសារ ឬទាញយកទិន្នន័យចាំបាច់ពី Database។
3. **Response (ការឆ្លើយតប):** Server រៀបចំឯកសាររួចរាល់ ហើយផ្ញើវាត្រឡប់មកកុំព្យូទ័ររបស់អ្នកវិញ ក្នុងទម្រង់ជាកូដ HTML ឬទិន្នន័យ JSON។
4. **Rendering (ការបង្ហាញ):** Browser របស់អ្នក (Client) ទទួលយកកូដនោះ មកគូរជាផ្ទាំង UI ដ៏ស្រស់ស្អាតអោយអ្នកមើលឃើញ។

> **ចំណាំ:** ដំណើរការទាំងអស់នេះកើតឡើងយ៉ាងលឿន ត្រឹមតែប៉ុន្មានមិល្លីវិនាទី (milliseconds) ប៉ុណ្ណោះ!
