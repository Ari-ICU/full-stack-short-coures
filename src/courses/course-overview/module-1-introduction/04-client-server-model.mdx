## 🔄 ទំនាក់ទំនងរវាង Client និង Server

**Client-Server Model** គឺជាគំរូនៃស្ថាបត្យកម្មកុំព្យូទ័រដែលបែងចែកការងាររវាងអ្នកផ្តល់សេវាកម្ម (Server) និងអ្នកស្នើសុំសេវាកម្ម (Client)។

### តើ Client ជាអ្វី?
**Client** ជាធម្មតាគឺជា Web Browser (ដូចជា Chrome, Safari) ឬកម្មវិធីទូរស័ព្ទ ដែលស្នើសុំទិន្នន័យឬសេវាកម្ម។ ឧទាហរណ៍៖ ពេលអ្នកវាយបញ្ចូល `www.google.com` កុំព្យូទ័ររបស់អ្នកគឺជា Client ដែលស្នើសុំទំព័រវិប។

### តើ Server ជាអ្វី?
**Server** គឺជាកុំព្យូទ័រដែលមានថាមពលខ្លាំង ដែលរង់ចាំ និងឆ្លើយតបទៅនឹងសំណើរបស់ Client។ វាផ្ទុកកូដ និងទិន្នន័យរបស់កម្មវិធី។

### វដ្ត Request-Response
1. **Request:** Client ផ្ញើសំណើ (Request) ទៅកាន់ Server។
2. **Process:** Server ទទួលសំណើ ធ្វើការគណនា ឬទាញយកទិន្នន័យពី Database។
3. **Response:** Server ផ្ញើលទ្ធផលត្រឡប់មក Client វិញ (Response) ជាទម្រង់ HTML, JSON, ល។
