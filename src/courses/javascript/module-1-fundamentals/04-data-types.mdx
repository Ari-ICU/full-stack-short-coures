## 🗂️ អ្វីទៅជា Data Types?

នៅក្នុងការសរសេរកូដ Variables ប្រៀបបាននឹងប្រអប់ ចំណែកឯ **Data Types** គឺជាប្រភេទនៃទំនិញដែលអ្នកដាក់ចូលទៅក្នុងប្រអប់នោះ (ឧ. ជាលេខ, ជាអក្សរ, ជាបញ្ជី)។ JavaScript មានប្រភេទទិន្នន័យសំខាន់ៗចំនួន ៨ ដែលចែកចេញជាពីរក្រុមធំៗ៖ **Primitive Types** និង **Structural Types**។

## 1. Primitive Types

Primitive Types គឺជាប្រភេទទិន្នន័យមូលដ្ឋានបំផុត ដែលផ្ទុកតម្លៃតែមួយប៉ុណ្ណោះ។

### 📝 String (អក្សរ)
String ត្រូវបានប្រើសម្រាប់ផ្ទុកអត្ថបទ។ អ្នកអាចប្រើសញ្ញា `' '` (Single quotes), `" "` (Double quotes), ឬ `` ` ` `` (Backticks)។

```javascript
let firstName = "Sok";
let lastName = 'Sao';

// ប្រើ Backticks សម្រាប់ Template Literals (ES6) 
// អនុញ្ញាតអោយយើងបញ្ចូលអថេរ (Variables) ទៅក្នុង String យ៉ាងងាយស្រួលដោយប្រើ ${}
let greeting = `សួស្តី ខ្ញុំឈ្មោះ ${firstName} ${lastName}`; 
console.log(greeting); // សួស្តី ខ្ញុំឈ្មោះ Sok Sao
```

### 🔢 Number (លេខ)
ផ្ទុយពីភាសាផ្សេងៗ JavaScript មានតែប្រភេទ Number មួយគត់សម្រាប់ផ្ទុកលេខទាំងអស់ (ទាំងលេខគត់ និងលេខទសភាគ)។

```javascript
let age = 25; // លេខគត់ (Integer)
let price = 19.99; // លេខទសភាគ (Float)
```

### ⚖️ Boolean (ពិត ឬ មិនពិត)
Boolean មានតម្លៃតែពីរគត់គឺ `true` (ពិត) ឬ `false` (មិនពិត)។ វាត្រូវបានប្រើញឹកញាប់បំផុតនៅក្នុងការធ្វើលក្ខខណ្ឌ (Conditional Statements)។

```javascript
let isStudent = true;
let isGraduated = false;
```

### ❓ Undefined
នៅពេលអ្នកប្រកាស Variable មួយ ប៉ុន្តែមិនទាន់បានដាក់តម្លៃអោយវា តម្លៃរបស់វាគឺ `undefined`។ 

```javascript
let myCar;
console.log(myCar); // undefined
```

### 🚫 Null
`null` គឺជាតម្លៃពិសេសដែលតំណាងអោយ "ភាពទទេ" ឬ "គ្មានតម្លៃអ្វីទាំងអស់"។ ភាពខុសគ្នារវាង `null` និង `undefined` គឺអ្នកជាអ្នកកំណត់ `null` ដោយខ្លួនឯង ដើម្បីបញ្ជាក់ថា Variable នោះទទេ។

```javascript
let currentScore = null; // យើងដឹងច្បាស់ថាឥឡូវអត់មានពិន្ទុទេ
```

### 🪙 Symbol (ES6)
Symbol ត្រូវបានប្រើដើម្បីបង្កើតតម្លៃពិសេសមួយដែលមិនអាចជាន់គ្នា (Unique identifier) សម្រាប់ Object properties។ យើងនឹងមិនសូវបានប្រើវាញឹកញាប់ទេនៅកម្រិតដំបូង។

```javascript
let sym1 = Symbol("id");
let sym2 = Symbol("id");
console.log(sym1 === sym2); // false (ពួកវាមានតែមួយគត់)
```

### 🐘 BigInt (ES2020)
BigInt ត្រូវបានប្រើសម្រាប់ផ្ទុកលេខដែលធំខ្លាំង (ធំជាង $2^{53}-1$) ដែល Number ធម្មតាមិនអាចផ្ទុកបាន។ យើងបន្ថែមអក្សរ `n` នៅខាងចុងលេខ។

```javascript
let hugeNumber = 9007199254740991n;
```

## 2. Structural Types

Structural Types អាចផ្ទុកទិន្នន័យបានច្រើនបញ្ចូលគ្នា (Collections)។

### 📦 Object
Object ត្រូវបានប្រើដើម្បីផ្ទុកទិន្នន័យជាគូ `key: value`។ វាស័ក្តិសមបំផុតសម្រាប់ពណ៌នាពីរបស់អ្វីមួយ (ឧ. មនុស្ស ឡាន)។

```javascript
let user = {
  name: "Dara", // កូនសោរ name មានតម្លៃ "Dara" (String)
  age: 30,      // កូនសោរ age មានតម្លៃ 30 (Number)
  isAdmin: true // កូនសោរ isAdmin មានតម្លៃ true (Boolean)
};

console.log(user.name); // ទាញយកឈ្មោះ: "Dara"
```

### 📚 Array
Array គឺជាប្រភេទពិសេសរបស់ Object ដែលប្រើសម្រាប់ផ្ទុកទិន្នន័យជាបញ្ជី (List) តាមលំដាប់លំដោយ។

```javascript
let fruits = ["Apple", "Banana", "Orange"]; // បញ្ជី String
let scores = [95, 80, 100, 75]; // បញ្ជី Number

console.log(fruits[0]); // "Apple" (រាប់ចាប់ពីលេខ 0)
```

> **កំណត់ចំណាំ៖** អ្នកនឹងបានរៀនលម្អិតស៊ីជម្រៅអំពី Objects និង Arrays នៅក្នុងមេរៀនខាងមុខ។ ការយល់ដឹងពី Data Types មូលដ្ឋាននេះគឺគ្រប់គ្រាន់ហើយសម្រាប់ពេលនេះ!
