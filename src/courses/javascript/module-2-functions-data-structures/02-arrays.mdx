## 📚 អ្វីទៅជា Arrays?

ប្រសិនបើ Object ជាទូសម្រាប់ដាក់ឯកសារមានឈ្មោះត្រឹមត្រូវ នោះ **Array** គឺជាធ្នើរដាក់សៀវភៅដែលរៀបជាជួរៗ។ Array គឺជាប្រភេទ Structural Data Type មួយដែលអនុញ្ញាតអោយយើងផ្ទុកទិន្នន័យច្រើនប្រភេទបញ្ចូលគ្នា ជាទម្រង់បញ្ជី (List) ហើយមានលំដាប់លំដោយច្បាស់លាស់។

---

## 1. ការបង្កើត និងប្រើប្រាស់ Arrays

យើងបង្កើត Array ដោយប្រើប្រាស់សញ្ញា `[]` (Square brackets)។ តម្លៃនីមួយៗត្រូវបានខណ្ឌចែកដោយសញ្ញាក្បៀស (`,`)។

```javascript
// Array ផ្ទុក String ទាំងអស់
const fruits = ["Apple", "Banana", "Orange", "Mango"];

// Array អាចផ្ទុកទិន្នន័យចម្រុះគ្នាបាន
const mixedArray = ["Sok", 25, true, null];
```

### ការទាញយកទិន្នន័យតាម Index
ដើម្បីយកទិន្នន័យណាមួយចេញមកប្រើ យើងត្រូវបញ្ជាក់ពីទីតាំង (Index) របស់វា។ **សំខាន់បំផុត៖ Index តែងតែចាប់ផ្តើមពីលេខ 0!**

```javascript
console.log(fruits[0]); // "Apple" (ផ្លែឈើទី១)
console.log(fruits[2]); // "Orange" (ផ្លែឈើទី៣)

// កែប្រែតម្លៃនៅក្នុង Array
fruits[1] = "Cherry"; // ប្តូរពី Banana ទៅ Cherry
console.log(fruits); // ["Apple", "Cherry", "Orange", "Mango"]
```

## 📂 2. Nested Arrays (Arrays ត្រួតគ្នា)

**Nested Array (ឬ 2D Array)** គឺជា Array ដែលផ្ទុក Array ដទៃទៀតនៅខាងក្នុង។ វាប្រៀបបាននឹង **តារាង (Table)** ដែលមាន **ជួរដេក (Rows)** និង **ជួរឈរ (Columns)**។

ដើម្បីងាយស្រួលយល់ សូមមើលការបកស្រាយលម្អិតខាងក្រោម៖

### ២.១. ការបង្កើត និងមើលទម្រង់ (Visualization)
ឧបមាថាយើងមានតារាងទិន្នន័យលេខមួយ៖

```javascript
const matrix = [
  [1, 2, 3], // ជួរដេកទី ១ (Index 0)
  [4, 5, 6], // ជួរដេកទី ២ (Index 1)
  [7, 8, 9]  // ជួរដេកទី ៣ (Index 2)
];
```

ទម្រង់នេះអាចតំណាងជាគំរូជួរដេក (Row) និងជួរឈរ (Column) ដូចខាងក្រោម៖
*   **ជួរដេកទី ០:** `[1, 2, 3]` -> index `0` គឺ `1`, index `1` គឺ `2`, index `2` គឺ `3`
*   **ជួរដេកទី ១:** `[4, 5, 6]` -> index `0` គឺ `4`, index `1` គឺ `5`, index `2` គឺ `6`
*   **ជួរដេកទី ២:** `[7, 8, 9]` -> index `0` គឺ `7`, index `1` គឺ `8`, index `2` គឺ `9`

---

### ២.២. របៀបទាញយកទិន្នន័យជាជំហានៗ
ដើម្បីទាញយកទិន្នន័យចេញពី Nested Array យើងប្រើប្រាស់សញ្ញាធ្នៀបពីរជាន់៖ `array[row_index][column_index]`

*   **ធ្នៀបទី១ (`array[row_index]`)**: ទាញយក **ជួរដេកទាំងមូល** (ដែលជា Array ខាងក្នុង)
*   **ធ្នៀបទី២ (`[column_index]`)**: ទាញយក **ធាតុជាក់លាក់** នៅក្នុងជួរដេកនោះ

សូមសាកល្បងទាញយកលេខ `6` ពីក្នុងតារាង `matrix` ខាងលើ៖

```javascript
// ជំហានទី១៖ ទាញយកជួរដេកទី ២ (Index 1)
let row = matrix[1]; // ទទួលបាន [4, 5, 6]

// ជំហានទី២៖ ទាញយកធាតុទី ៣ (Index 2) នៅក្នុងជួរដេកនោះ
let number = row[2]; // ទទួលបាន 6

// យើងអាចសរសេរបង្រួមចូលគ្នាក្នុងពេលតែមួយ៖
console.log(matrix[1][2]); // 6
```

---

### ២.៣. ការកែប្រែតម្លៃក្នុង Nested Array
យើងក៏អាចផ្លាស់ប្តូរតម្លៃនៃធាតុណាមួយដោយបញ្ជាក់ពី Row និង Column របស់វាផងដែរ៖

```javascript
// ប្តូរលេខ 5 (ជួរដេកទី ១, ជួរឈរទី ១) ទៅជាលេខ 99
matrix[1][1] = 99;

console.log(matrix[1][1]); // 99
console.log(matrix); 
// លទ្ធផល៖ [ [1, 2, 3], [4, 99, 6], [7, 8, 9] ]
```

---

### ២.៤. ឧទាហរណ៍ជាក់ស្តែង៖ ក្តារហ្គេម Tic-Tac-Toe
ក្តារហ្គេម 3x3 គឺជាគំរូដ៏ល្អបំផុតនៃ Nested Array៖

```javascript
const ticTacToe = [
  ["X", "O", "X"], // ជួរដេកទី ០
  ["O", "X", "O"], // ជួរដេកទី ១
  ["O", "O", "X"]  // ជួរដេកទី ២
];

// ទាញយកអក្សរ "X" ដែលនៅចំកណ្តាលក្តារ (ជួរដេកទី ១, ជួរឈរទី ១)
console.log(ticTacToe[1][1]); // "X"

// ទាញយក "O" នៅជួរដេកទី ០, ជួរឈរទី ១
console.log(ticTacToe[0][1]); // "O"
```

## 📌 ការប្រើប្រាស់ទូទៅ (Common Use Cases)

*   **រក្សាទុកបញ្ជីទិន្នន័យពី Database៖** ឧទាហរណ៍ បញ្ជីអត្ថបទ បញ្ជីទំនិញ បញ្ជីអ្នកប្រើប្រាស់។
*   **ធ្វើការរួមគ្នាជាមួយ Loops៖** យើងតែងតែយក Loop (ដូចជា `for...of`) មកប្រើដើម្បីដើរអានតម្លៃនីមួយៗក្នុង Array ដោយស្វ័យប្រវត្តិ។
*   **បម្លែង និងត្រងទិន្នន័យ៖** នៅក្នុងមេរៀនបន្ទាប់ អ្នកនឹងរៀនពី Array Methods (`map`, `filter`, `reduce`) ដែលមានប្រយោជន៍ខ្លាំងបំផុត!
