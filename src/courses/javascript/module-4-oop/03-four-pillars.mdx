## 🏛️ សសរស្ដម្ភទាំង ៤ នៃ OOP (4 Pillars)

ដើម្បីយល់ដឹង និងសរសេរកូដបែប **Object-Oriented Programming (OOP)** ប្រកបដោយប្រសិទ្ធភាព យើងត្រូវស្វែងយល់ពីសសរស្ដម្ភទាំង ៤ យ៉ាងដូចខាងក្រោម៖

---

## 1. Encapsulation (ការវេចខ្ចប់ និងលាក់ទិន្នន័យ)

**Encapsulation** គឺជាការចងក្រងទិន្នន័យ (Properties) និងសកម្មភាព (Methods) ចូលទៅក្នុងប្រអប់តែមួយ (Class) ហើយលាក់បាំងទិន្នន័យសំខាន់ៗពីខាងក្រៅ ដើម្បីការពារការកែប្រែដោយចៃដន្យ។ នៅក្នុង JavaScript ទំនើប យើងប្រើសញ្ញា **`#`** នៅពីមុខឈ្មោះ ដើម្បីបង្កើត **Private Fields**។

ជាដំបូង យើងសរសេរកូដបង្កើត Class `BankAccount` ដោយកំណត់ property `#balance` ជា Private ដើម្បីកុំឱ្យកូដខាងក្រៅអាចចូលមកកែប្រែ ឬអានតម្លៃរបស់វាដោយផ្ទាល់បាន៖

```javascript
class BankAccount {
  // ប្រកាស private property (មិនអាចហៅប្រើពីខាងក្រៅ class បានទេ)
  #balance;

  constructor(owner, initialBalance) {
    this.owner = owner;
    this.#balance = initialBalance;
  }

  // បង្កើត public method សម្រាប់ដាក់លុយ (មានសុវត្ថិភាព)
  deposit(amount) {
    if (amount > 0) {
      this.#balance += amount;
    }
  }

  // បង្កើត public method សម្រាប់មើលទឹកប្រាក់
  getBalance() {
    return this.#balance;
  }
}
```

បន្ទាប់មក យើងសាកល្បងបង្កើត instance ឈ្មោះ `myAcc` ដាក់ប្រាក់ និងទាញយកប្រាក់មកបង្ហាញ ដោយមិនអាចចូលទៅប៉ះពាល់ property `#balance` ផ្ទាល់ឡើយ៖

```javascript
const myAcc = new BankAccount("Sok", 100);
myAcc.deposit(50);

console.log(myAcc.getBalance()); // 150
// console.log(myAcc.#balance); // ❌ Error: Private field '#balance' must be declared in an enclosing class
```

## 2. Inheritance (ការបន្តពូជ/ការស្នងមរតក)

**Inheritance** អនុញ្ញាតឱ្យ Class ថ្មី (Child Class) ស្នងយក properties និង methods ពី Class ចាស់ (Parent Class) ដោយមិនបាច់សរសេរកូដដដែលៗឡើងវិញ។ យើងប្រើប្រាស់ពាក្យគន្លឹះ `extends` និង `super()`។

ជាដំបូង យើងបង្កើត Class មេ (Parent Class) មួយឈ្មោះថា `Animal` ដែលមាន constructor សម្រាប់ផ្ទុកឈ្មោះសត្វ និងមាន method `eat()` សម្រាប់បង្ហាញសកម្មភាពស៊ីចំណី៖

```javascript
class Animal {
  constructor(name) {
    this.name = name;
  }
  eat() {
    console.log(`${this.name} is eating.`);
  }
}
```

បន្ទាប់មក យើងបង្កើត Class កូន (Child Class) មួយឈ្មោះថា `Dog` ដែលស្នងលក្ខណៈ (Inherited) ពី Class `Animal` ដោយប្រើប្រាស់ពាក្យគន្លឹះ `extends`។ នៅក្នុង Class `Dog` នេះ យើងគ្រាន់តែសរសេរ method បន្ថែមឈ្មោះ `bark()` ប៉ុណ្ណោះ។ នៅពេលយើងបង្កើត instance `dog` វានឹងទទួលបានទាំង method `eat()` របស់ `Animal` និង `bark()` របស់ `Dog`៖

```javascript
// Dog ស្នងលក្ខណៈពី Animal
class Dog extends Animal {
  bark() {
    console.log("Woof! Woof!");
  }
}

const dog = new Dog("Rex");
dog.eat();  // ✅ Rex is eating (ស្នងពី Animal)
dog.bark(); // Woof! Woof! (របស់ Dog ផ្ទាល់ខ្លួន)
```

## 3. Polymorphism (ពហុរូបភាព)

**Polymorphism** អនុញ្ញាតឱ្យ Class កូន អាចផ្លាស់ប្តូរ ឬសរសេរជាន់លើ (Override) វិធីសាស្ត្រ (Methods) ដែលស្នងមកពី Class មេ ដើម្បីឱ្យវាដំណើរការសមស្របទៅនឹងតម្រូវការរបស់វា។ នេះហៅថា **Method Overriding**។

ជាដំបូង យើងបង្កើត Class មេ `Animal` ដែលមាន method `makeSound()` និងបង្កើត Class កូនៗគឺ `Dog` និង `Cat` ដែលស្នងលក្ខណៈពី `Animal` ប៉ុន្តែសរសេរជាន់លើ (Override) លើ method `makeSound()` ដើម្បីឱ្យវាបញ្ចេញសម្លេងទៅតាមប្រភេទសត្វរៀងៗខ្លួន៖

```javascript
class Animal {
  makeSound() {
    console.log("Some generic animal sound");
  }
}

class Dog extends Animal {
  makeSound() { // Overriding method makeSound
    console.log("Woof! Woof!");
  }
}

class Cat extends Animal {
  makeSound() { // Overriding method makeSound
    console.log("Meow! Meow!");
  }
}
```

បន្ទាប់មក យើងបង្កើត Array ផ្ទុកគំរូសត្វទាំងពីរ និងសរសេរកូដរង្វិលជុំ (Loop) ហៅប្រើ method `makeSound()`។ យើងឃើញថា ទោះបីជាហៅឈ្មោះ method ដូចគ្នា តែវាបញ្ចេញសម្លេងខុសៗគ្នាទៅតាមប្រភេទជាក់ស្តែងរបស់វា៖

```javascript
const animals = [new Dog(), new Cat()];
animals.forEach(animal => animal.makeSound());
// Output:
// Woof! Woof!
// Meow! Meow!
```

## 4. Abstraction (ការទាញយកតែចំណុចសំខាន់)

**Abstraction** គឺជាការលាក់បាំងនូវភាពស្មុគស្មាញនៃដំណើរការកូដនៅខាងក្នុង (Internal logic/implementation) និងបង្ហាញតែចំណុចសំខាន់ៗដែលអ្នកប្រើប្រាស់ត្រូវការហៅប្រើប៉ុណ្ណោះ។

ជាដំបូង យើងបង្កើត Class `RemoteControl` ដែលមាន private method `#turnOnCircuit()` សម្រាប់ដោះស្រាយការដំណើរការសៀគ្វីស្មុគស្មាញនៅខាងក្នុង និងបង្កើត public method `pressPowerButton()` ជាចំណុចទំនាក់ទំនងសាមញ្ញទៅខាងក្រៅ៖

```javascript
class RemoteControl {
  #turnOnCircuit() {
    console.log("Sending signal... warming up components... power output stabilized.");
  }

  // អ្វីដែលបង្ហាញទៅខាងក្រៅមានតែប៊ូតុងចុចមួយនេះប៉ុណ្ណោះ
  pressPowerButton() {
    this.#turnOnCircuit();
    console.log("TV is now ON!");
  }
}
```

បន្ទាប់មក យើងបង្កើត instance ឈ្មោះ `remote` ហើយចុចដំណើរការប៊ូតុងបើកទូរទស្សន៍។ អ្នកសរសេរកូដខាងក្រៅអាចបញ្ជាទូរទស្សន៍បានយ៉ាងងាយស្រួល ដោយមិនបាច់ដឹង ឬគ្មានសិទ្ធិដំណើរការសៀគ្វី `#turnOnCircuit()` ដោយផ្ទាល់ឡើយ៖

```javascript
const remote = new RemoteControl();
remote.pressPowerButton(); // ងាយស្រួលប្រើប្រាស់
// remote.#turnOnCircuit(); // ❌ មិនអាចហៅប្រើពីខាងក្រៅបានទេ ( abstraction ជួយលាក់វា)
```
