## ⏱️ អ្វីទៅជា Timers?

ជាទូទៅ កូដ JavaScript ដំណើរការភ្លាមៗពីលើចុះក្រោម។ ប៉ុន្តែចុះបើអ្នកចង់អោយមានផ្ទាំង Popup លោតចេញមកក្រៅក្រោយពេលអ្នកប្រើប្រាស់ចូលមើលគេហទំព័របាន ៥ វិនាទី? ទីនេះហើយដែលយើងត្រូវការ **Timers** ដូចជា `setTimeout` និង `setInterval`។

---

## 1. ការប្រើប្រាស់ `setTimeout`

`setTimeout` ត្រូវបានប្រើដើម្បី **ពន្យារពេល** ដំណើរការកូដ។ វាមានន័យថា៖ *"រង់ចាំប៉ុណ្ណេះវិនាទី ទើបដំណើរការ Function នេះ"*។

```jsdiagram
jssettimeout
```

```tabs
html
<!-- popup លោតចេញក្រោយ 3 វិនាទី -->
<div id="popup"></div>
<p id="note" style="color: gray;">រង់ចាំ 2 វិនាទី...</p>
---
css
#popup {
  display: none;
  background: #6366f1;
  color: white;
  padding: 1rem 1.5rem;
  border-radius: 0.75rem;
  font-weight: bold;
  margin-bottom: 0.5rem;
  animation: slideIn 0.3s ease;
}
@keyframes slideIn {
  from { transform: translateY(-10px); opacity: 0; }
  to   { transform: translateY(0);     opacity: 1; }
}
#note { font-size: 0.875rem; }
---
js
// Function ដែលយើងចង់អោយវាដើរ
const showPopup = () => {
  const popup = document.getElementById("popup");
  popup.style.display = "block";
  popup.textContent = "🎉 សូមស្វាគមន៍! មានចង់ចុះឈ្មោះទេ?";
};

// រង់ចាំ 3000 មីលីវិនាទី (3 វិនាទី) ទើបហៅ showPopup
setTimeout(showPopup, 3000);

// ការសរសេរកាត់ជាមួយ Arrow Function ផ្ទាល់
setTimeout(() => {
  document.getElementById("note").textContent = "⏰ ចូលមើលបាន 2 វិនាទីហើយ!";
}, 2000);
```

> **ចំណាំ៖** កូដផ្សេងទៀតដែលនៅខាងក្រោម `setTimeout` នឹងបន្តដំណើរការភ្លាមៗដោយមិនរង់ចាំឡើយ។ វាជាផ្នែកមួយនៃ Asynchronous JavaScript!

## 2. ការប្រើប្រាស់ `setInterval`

ខុសពី `setTimeout` ដែលដើរតែម្តង, `setInterval` នឹងអោយកូដរបស់អ្នកដំណើរការ **ច្រំដែលៗ** រាល់ចន្លោះពេលដែលអ្នកបានកំណត់។ វាប្រៀបបាននឹងនាឡិកាដែលលោតមួយវិនាទីម្តងអញ្ចឹង។

```jsdiagram
jssetinterval
```

```tabs
html
<!-- នាឡិកា live ដែលប្រើ setInterval update រៀងរាល់ 1s -->
<div id="clock">🕐 --:--:--</div>
---
css
#clock {
  font-size: 2rem;
  font-weight: bold;
  font-family: monospace;
  color: #6366f1;
  background: #f0f0ff;
  padding: 1rem 2rem;
  border-radius: 0.75rem;
  display: inline-block;
  border: 2px solid #c7d2fe;
}
---
js
// នាឡិកា live — update រៀងរាល់ 1 វិនាទី
setInterval(() => {
  const now = new Date();
  const timeStr = now.toLocaleTimeString();
  document.getElementById("clock").textContent = "🕐 " + timeStr;
}, 1000);
```

នេះស័ក្តិសមបំផុតសម្រាប់ការបង្កើតនាឡិកា (Clock), នាឡិកាបញ្ច្រាស (Countdown Timer) ឬការផ្លាស់ប្តូររូបភាពស្លាយ (Image Slider) ដោយស្វ័យប្រវត្តិ។

## 🛑 3. របៀបបញ្ឈប់ Timers

បើអ្នកប្រើ `setInterval` ហើយមិនបញ្ឈប់វាទេ វានឹងរត់រហូតដល់ទំព័រនោះត្រូវបិទ! ដើម្បីបញ្ឈប់យើងមាន `clearTimeout` និង `clearInterval`។

ដើម្បីអាចបញ្ឈប់បាន យើងត្រូវរក្សាទុក ID របស់ Timer នោះទៅក្នុង Variable ជាមុនសិន។

### បញ្ឈប់ `setInterval`

```jsdiagram
jsclearinterval
```

```tabs
html
<!-- counter display ដែលបញ្ឈប់ itself នៅ 5 -->
<div id="counter">រាប់បាន: 0</div>
<p id="status" class="running">⚡ running...</p>
---
css
#counter {
  font-size: 2.5rem;
  font-weight: bold;
  font-family: monospace;
  color: #f97316;
}
#status {
  font-size: 0.875rem;
  font-weight: 600;
  margin-top: 0.25rem;
}
#status.running { color: #f97316; }
#status.stopped { color: #ef4444; }
---
js
let count = 0;
const timerId = setInterval(() => {
  count++;
  document.getElementById("counter").textContent = "រាប់បាន: " + count;

  if (count === 5) {
    clearInterval(timerId);
    document.getElementById("status").textContent = "🛑 បញ្ឈប់ការរាប់!";
    document.getElementById("status").className = "stopped";
  }
}, 1000);
```

### បញ្ឈប់ `setTimeout`

ការប្រើប្រាស់ `clearTimeout` គឺស្រដៀងគ្នា។ ប្រសិនបើអ្នកតាំងម៉ោងរួចរាល់ហើយ តែស្រាប់តែចង់លុបចោលវិញមុនពេលវារត់ដល់ អ្នកអាច `clear` វាបាន។

```tabs

<p id="msg" class="waiting">⏳ រង់ចាំ 5 វិនាទី...</p>
<button id="cancelBtn">✕ Cancel Timer</button>
---
css
#msg {
  font-size: 1rem;
  font-weight: 600;
  margin-bottom: 0.75rem;
}
#msg.waiting   { color: #f97316; }
#msg.fired     { color: #16a34a; }
#msg.cancelled { color: #ef4444; }

#cancelBtn {
  padding: 0.4rem 1rem;
  background: #ef4444;
  color: white;
  border: none;
  border-radius: 0.5rem;
  cursor: pointer;
  font-size: 0.875rem;

}

---
js
// ចុច "Cancel" ក្នុងរយៈ 5 វិនាទី ដើម្បី clear
const myTimeout = setTimeout(() => {
  document.getElementById("msg").textContent = "⏰ Timer ដំណើរការ!";
  document.getElementById("msg").className = "fired";
}, 5000);

document.getElementById("cancelBtn").addEventListener("click", () => {
  clearTimeout(myTimeout);
  document.getElementById("msg").textContent = "❌ Timer ត្រូវបាន Cancel!";
  document.getElementById("msg").className = "cancelled";
});
```
