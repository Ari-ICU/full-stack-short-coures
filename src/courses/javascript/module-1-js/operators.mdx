## 🧮 1. Arithmetic Operators (ប្រមាណវិធីគណិតវិទ្យា)

**Arithmetic Operators** ប្រើសម្រាប់ធ្វើការគណនាលេខ។

*   `+` : បូក
*   `-` : ដក
*   `*` : គុណ
*   `/` : ចែក
*   `%` : យកសំណល់ (Modulo/Remainder)
*   `**` : ស្វ័យគុណ (Exponentiation)

```javascript
console.log(10 + 5); // 15
console.log(10 - 5); // 5
console.log(10 * 5); // 50
console.log(10 / 2); // 5
console.log(10 % 3); // 1 (ព្រោះ 10 ចែក 3 បាន 3 សល់ 1)
console.log(2 ** 3); // 8 (2 ស្វ័យគុណ 3 ពោលគឺ 2 * 2 * 2)
```
> **ចំណាំ:** សញ្ញា `+` ក៏អាចប្រើសម្រាប់តភ្ជាប់ String ចូលគ្នាបានដែរ (String Concatenation): `"Hello " + "World" = "Hello World"`.

## ⚖️ 2. Comparison Operators (ប្រមាណវិធីប្រៀបធៀប)

**Comparison Operators** ប្រើដើម្បីប្រៀបធៀបតម្លៃពីរ ហើយលទ្ធផលរបស់វាជានិច្ចកាលគឺជា **Boolean** (`true` ឬ `false`)។

*   `>` (ធំជាង), `<` (តូចជាង)
*   `>=` (ធំជាង ឬស្មើ), `<=` (តូចជាង ឬស្មើ)

### ភាពខុសគ្នារវាង `==` និង `===` (សំខាន់ខ្លាំង! ⭐⭐⭐⭐⭐)

ការប្រៀបធៀបថាតើស្មើគ្នាឬទេ មានពីរប្រភេទនៅក្នុង JavaScript៖

**1. Loose Equality (`==`):**
វាប្រៀបធៀបតែ **តម្លៃ** ប៉ុណ្ណោះ។ បើប្រភេទ (Data Type) ខុសគ្នា វាព្យាយាមបំប្លែងវាអោយដូចគ្នាសិនមុននឹងប្រៀបធៀប។ នេះអាចបណ្តាលអោយមានកំហុសចម្លែកៗជាច្រើន!
```javascript
console.log(5 == "5"); // true (ព្រោះវាបំប្លែង "5" ទៅជាលេខ 5)
console.log(0 == false); // true
console.log(null == undefined); // true
```

**2. Strict Equality (`===`):**
វាប្រៀបធៀបទាំង **តម្លៃ** និង **ប្រភេទទិន្នន័យ (Type)**។ បើប្រភេទខុសគ្នា វាឱ្យលទ្ធផល `false` ភ្លាមៗដោយមិនបំប្លែងអ្វីទាំងអស់។
```javascript
console.log(5 === "5"); // false (ព្រោះមួយជា Number មួយទៀតជា String)
console.log(0 === false); // false
console.log(null === undefined); // false
```
> 💡 **Best Practice:** នៅក្នុង JavaScript ទំនើប សូមកុំប្រើ `==` អោយសោះ! **ត្រូវប្រើ `===` ជានិច្ច** ដើម្បីសុវត្ថិភាព។ ដូចគ្នាដែរ សម្រាប់មិនស្មើ ត្រូវប្រើ `!==` ជំនួសអោយ `!=`។

## 🧠 3. Logical Operators (ប្រមាណវិធីតក្កវិទ្យា)

**Logical Operators** ប្រើសម្រាប់ភ្ជាប់លក្ខខណ្ឌច្រើនចូលគ្នា។

*   **`&&` (AND):** ពិត (`true`) លុះត្រាតែលក្ខខណ្ឌ **ទាំងសងខាង** ពិតទាំងអស់។
*   **`||` (OR):** ពិត (`true`) ប្រសិនបើមានលក្ខខណ្ឌ **ណាមួយ** (ម្ខាងណាក៏បាន) ពិត។
*   **`!` (NOT):** ត្រឡប់តម្លៃពីពិតទៅមិនពិត ឬពីមិនពិតទៅពិតវិញ។

```javascript
let hasTicket = true;
let isVIP = false;

// ត្រូវមានសំបុត្រ "និង" ត្រូវតែជា VIP ផងដែរ
console.log(hasTicket && isVIP); // false

// គ្រាន់តែមានសំបុត្រ "ឬ" ជា VIP (មួយណាក៏បាន)
console.log(hasTicket || isVIP); // true

// បញ្ច្រាសតម្លៃ
console.log(!hasTicket); // false (ព្រោះ hasTicket គឺ true)
```

## 🚀 4. Modern Operators (ES6+)

### 1. Nullish Coalescing (`??`)
ប្រើសម្រាប់ផ្តល់តម្លៃលំនាំដើម (Default Value) នៅពេលដែលតម្លៃខាងឆ្វេងគឺ `null` ឬ `undefined`។
```javascript
let username = null;
// បើ username គឺ null ឬ undefined យក "Guest" ជំនួសវិញ
let displayName = username ?? "Guest"; 
console.log(displayName); // "Guest"
```

### 2. Optional Chaining (`?.`)
ប្រើដើម្បីអាន property របស់ Object ដោយមិនបាច់បារម្ភពី Error ពេលដែល Object នោះគ្មានទិន្នន័យ (null/undefined)។
```javascript
let user = { name: "Sok" };

// បើ user.address គ្មាន (undefined) កូដធម្មតានឹង Error ពេលអ្នកហៅ .city បន្តទៀត
// តែប្រើ ?. វានឹងត្រឡប់ undefined ដោយសុវត្ថិភាពជំនួសអោយការបោះ Error មក។
console.log(user.address?.city); // undefined
```
