## 📦 អ្វីទៅជា Modules?

នៅពេលដែលកម្មវិធីរបស់អ្នកកាន់តែធំ កូដ JavaScript របស់អ្នកអាចមានរាប់ពាន់បន្ទាត់ ប្រសិនបើអ្នកសរសេរវានៅក្នុង File តែមួយ វានឹងក្លាយជារញ៉េរញ៉ៃ (Spaghetti Code)!

**ES6 Modules** អនុញ្ញាតអោយយើងបំបែកកូដធំៗ ទៅជាកូនឯកសារតូចៗ (Files) ដែលងាយស្រួលអាន ងាយស្រួលរកកំហុស និងអាចយកទៅប្រើប្រាស់ឡើងវិញបានគ្រប់ទីកន្លែង។

---

## 1. Named Exports

អ្នកអាច Export កូដ (ដូចជា Variables ឬ Functions) បានច្រើនចេញពី File តែមួយដោយប្រើពាក្យគន្លឹះ `export` នៅពីមុខ។ នេះហៅថា **Named Export** ព្រោះនៅពេលអ្នក Import វាទៅប្រើ អ្នកត្រូវហៅ "ឈ្មោះ" វាអោយចំ។

```jsdiagram
jsnamedexport
```

```tabs
html
<!-- ត្រូវប្រើ type="module" ក្នុង browser -->
<script type="module" src="app.js"></script>
<div id="output"></div>
---
css
#output {
  font-family: monospace;
  font-size: 0.9rem;
  padding: 1rem;
  background: #f8fafc;
  border: 2px solid #e2e8f0;
  border-radius: 0.75rem;
  white-space: pre-line;
}
---
js
// ── math.js ──────────────────────────────
export const PI = 3.14;

export const add = (a, b) => {
  return a + b;
};

// ── app.js ───────────────────────────────
// import ដោយប្រើ {} ហើយឈ្មោះត្រូវដូចគ្នា
import { PI, add } from './math.js';

const out = document.getElementById("output");
out.textContent =
  "តម្លៃ PI គឺ: " + PI + "\n" +
  "លទ្ធផលបូក: " + add(10, 5);
```

## 2. Default Exports

ប្រសិនបើ File មួយបង្កើតឡើងសម្រាប់តែគោលបំណងចម្បង **តែមួយគត់** (ឧទាហរណ៍ Component មួយនៅក្នុង React) អ្នកគួរតែប្រើ **Default Export**។ ក្នុងមួយ File អាចមាន Default Export តែមួយប៉ុណ្ណោះ!

```jsdiagram
jsdefaultexport
```

```tabs
html
<!-- type="module" ចាំបាច់សម្រាប់ import/export -->
<script type="module" src="app.js"></script>
<div id="userCard"></div>
---
css
#userCard {
  display: inline-block;
  padding: 1rem 1.5rem;
  background: #f0fdf4;
  border: 2px solid #86efac;
  border-radius: 0.75rem;
  font-size: 0.875rem;
  font-weight: 600;
  color: #166534;
}
---
js
// ── User.js ──────────────────────────────
class User {
  constructor(name) {
    this.name = name;
  }
  greet() {
    return "👋 សួស្តី, " + this.name + "!";
  }
}

// export default — គ្មាន {}
export default User;

// ── app.js ───────────────────────────────
// import ដោយគ្មាន {} — ឈ្មោះអាចផ្លាស់ប្តូរបាន
import User from './User.js';

const user1 = new User("Sok");
document.getElementById("userCard").textContent = user1.greet();
```

## 🔄 3. ការ Import បញ្ចូលគ្នា

ចុះបើ File មួយមានទាំង Default ផង និង Named ផង? គ្មានបញ្ហាទេ! អ្នកអាច Import ពួកវាព្រមគ្នាបាន។

```jsdiagram
jscombinedimport
```

```tabs
html
<!-- ប្រើ type="module" ជានិច្ចពេលប្រើ import/export -->
<script type="module" src="app.js"></script>
<div id="result"></div>
---
css
#result {
  font-family: monospace;
  font-size: 0.9rem;
  padding: 1rem;
  background: #faf5ff;
  border: 2px solid #d8b4fe;
  border-radius: 0.75rem;
  white-space: pre-line;
  color: #581c87;
  font-weight: 600;
}
---
js
// ── myModule.js ──────────────────────────
export const name = "JavaScript";       // Named
const sayHello = () => "Hello! 👋";
export default sayHello;                // Default

// ── app.js ───────────────────────────────
// default ត្រូវមកមុន, named នៅក្នុង {}
import sayHello, { name } from './myModule.js';

const el = document.getElementById("result");
el.textContent =
  sayHello() + "\n" +
  "ភាសា: " + name;
```

> **ចំណាំសំខាន់សម្រាប់ Browser:** ប្រសិនបើអ្នកចង់ប្រើ `import`/`export` នៅក្នុង Browser ដោយផ្ទាល់ (ដោយមិនប្រើប្រព័ន្ធ Build Tools ដូចជា React/Vite) អ្នកត្រូវប្រាកដថាអ្នកបានបន្ថែម `type="module"` ទៅក្នុង Tag script របស់អ្នក៖ `<script type="module" src="app.js"></script>`។
