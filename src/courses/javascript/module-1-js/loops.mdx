## 🔁 អ្វីទៅជា Loops?

ប្រសិនបើអ្នកចង់ព្រីនពាក្យ "សួស្តី" ចំនួន ១០០ ដង អ្នកមិនចាំបាច់សរសេរ `console.log("សួស្តី")` ដល់ទៅ ១០០ បន្ទាត់នោះទេ។ អ្នកអាចប្រើ **Loops**! Loops អនុញ្ញាតអោយយើងអនុវត្តប្លុកនៃកូដដដែលៗ ច្រើនដងដោយស្វ័យប្រវត្តិ រហូតដល់លក្ខខណ្ឌណាមួយត្រូវបានបញ្ចប់។

---

## 1. របៀបប្រើប្រាស់ `for` Loop

`for` loop គឺពេញនិយមបំផុតនៅពេលដែលអ្នក **ដឹងច្បាស់ពីចំនួនដង** ដែលអ្នកចង់អោយកូដដំណើរការ។ វាទាមទារនូវ ៣ ផ្នែកធំៗ៖
1. **Initialization:** កំណត់តម្លៃចាប់ផ្តើម (ឧ. `let i = 0`)
2. **Condition:** លក្ខខណ្ឌ (រត់ដរាបណា `i < 5`)
3. **Increment/Decrement:** បង្កើន ឬបន្ថយតម្លៃរាល់ពេលចប់មួយជុំ (ឧ. `i++`)

```javascript
// វានឹងព្រីនលេខ 0 ដល់ 4
for (let i = 0; i < 5; i++) {
  console.log("ជុំទី:", i);
}
```

## 2. របៀបប្រើប្រាស់ `while` និង `do...while`

**`while` loop** ត្រូវបានប្រើនៅពេលដែលអ្នក **មិនដឹងច្បាស់ពីចំនួនដង** តែអ្នកដឹងថាលក្ខខណ្ឌត្រូវតែពិតទើបវាអាចរត់បាន។ វានឹងឆែកលក្ខខណ្ឌ **មុនពេល** រត់កូដ។

```javascript
let count = 0;

while (count < 3) {
  console.log("Count (while) គឺ:", count);
  count++; // កុំភ្លេចដាក់វា បើមិនអញ្ចឹងវានឹងរត់រហូត (Infinite Loop)
}
```

**`do...while` loop** គឺស្រដៀងនឹង `while` ដែរ ប៉ុន្តែវាធានាថាកូដនឹងរត់បាន **យ៉ាងហោចណាស់ម្តងជានិច្ច** ទោះបីជាលក្ខខណ្ឌខុសតាំងពីដំបូងក៏ដោយ។ ព្រោះវាឆែកលក្ខខណ្ឌ **ក្រោយពេល** រត់កូដចប់មួយជុំ។

```javascript
let num = 10;

do {
  console.log("វានឹងរត់ម្តងទោះជា num > 5 មិនពិតក៏ដោយ:", num);
  num++;
} while (num < 5); // លក្ខខណ្ឌខុស តែកូដដើរបានមួយដងបាត់ទៅហើយ
```

## 3. `for...of` (ពិសេសសម្រាប់ Arrays និង Strings)

នៅពេលដែលយើងមាន Array យើងអាចប្រើ `for...of` ដើម្បីយកតម្លៃរបស់វាមកបានយ៉ាងងាយស្រួលដោយមិនបាច់ខ្វល់ពីលំដាប់លេខ (Indexes) ដូច `for` ធម្មតាឡើយ។ វាត្រូវបានណែនាំក្នុង ES6។

```javascript
let fruits = ["Apple", "Banana", "Orange"];

for (let fruit of fruits) {
  console.log("ផ្លែឈើ:", fruit);
}
// លទ្ធផល:
// ផ្លែឈើ: Apple
// ផ្លែឈើ: Banana
// ផ្លែឈើ: Orange
```

## 4. `for...in` (ពិសេសសម្រាប់ Objects)

ប្រសិនបើអ្នកចង់ទាញយក Property នីមួយៗចេញពី Object អ្នកគួរប្រើ `for...in` វិញ។ វាជួយទាញយក **កូនសោរ (Keys)** ចេញពី Object នោះ។

```javascript
let user = {
  name: "Dara",
  age: 25,
  job: "Developer"
};

for (let key in user) {
  // key គឺ "name", "age", "job"
  // user[key] ទាញយកតម្លៃពិតរបស់វា
  console.log(`${key}: ${user[key]}`);
}
// លទ្ធផល:
// name: Dara
// age: 25
// job: Developer
```

> ⚠️ **កុំច្រឡំគ្នា!** ចងចាំរូបមន្តនេះ៖ `of` សម្រាប់ទាញតម្លៃចេញពី Array រីឯ `in` សម្រាប់ទាញកូនសោរចេញពី Object (គិតថា "in" = "Index/Key")។
