## 📄 អ្វីទៅជា JSON?

**JSON** (អានថា *ជេសុន*) តំណាងអោយ **J**ava**S**cript **O**bject **N**otation។ វាគឺជាទម្រង់អត្ថបទ (Text Format) ដ៏សាមញ្ញមួយដែលត្រូវបានប្រើប្រាស់ជាសកលសម្រាប់ **ផ្ទុក និងបញ្ជូនទិន្នន័យ** រវាង Server និង Client (គេហទំព័ររបស់អ្នក)។

ទោះបីជាវាមានឈ្មោះមានពាក្យ "JavaScript" ក៏ដោយ ក៏បច្ចុប្បន្ន JSON ត្រូវបានគាំទ្រដោយភាសាសរសេរកូដស្ទើរតែទាំងអស់ (Python, PHP, Java ជាដើម)!

## 1. ទម្រង់របស់ JSON

ទម្រង់របស់ JSON មើលទៅស្ទើរតែដូចគ្នាទាំងស្រុងទៅនឹង JavaScript Object ប៉ុន្តែវាមានក្បួនតឹងរ៉ឹងជាង៖
1. **Keys ទាំងអស់ត្រូវតែរុំដោយសញ្ញា Double Quotes (`""`) ជានិច្ច!**
2. មិនអាចប្រើប្រាស់ Single Quotes (`''`) សម្រាប់ Strings បានទេ។
3. មិនអាចមាន Functions ទេ។

**នេះគឺជាឧទាហរណ៍នៃទម្រង់ទិន្នន័យ JSON៖**
```json
{
  "name": "Sok",
  "age": 25,
  "isStudent": true,
  "hobbies": ["reading", "coding"],
  "address": {
    "city": "Phnom Penh",
    "country": "Cambodia"
  }
}
```

## 🔄 2. ការបំប្លែងទៅវិញទៅមក (Parse និង Stringify)

នៅក្នុង JavaScript ការបញ្ជូនទិន្នន័យតាមរយៈអុីនធឺណិត ឬការរក្សាទុកទិន្នន័យក្នុង Browser (Local Storage) តម្រូវអោយទិន្នន័យនោះស្ថិតក្នុងទម្រង់ជាអត្ថបទធម្មតា (String)។ ដូច្នេះយើងត្រូវចេះបំប្លែងចុះឡើង។

### `JSON.stringify()` (ពី Object ទៅ String)
ប្រសិនបើអ្នកមាន JavaScript Object ហើយអ្នកចង់បញ្ជូនវាទៅ Server អ្នកត្រូវប្រែក្លាយវាទៅជាអត្ថបទ (JSON String) ជាមុនសិន។

```javascript
const user = {
  name: "Dara",
  age: 30
};

// វាក្លាយជាអត្ថបទធម្មតា: '{"name":"Dara","age":30}'
const jsonString = JSON.stringify(user); 

console.log(jsonString);
console.log(typeof jsonString); // "string"
```

### `JSON.parse()` (ពី String មក Object)
ប្រសិនបើអ្នកទទួលបានទិន្នន័យពី Server វានឹងមកជាទម្រង់ JSON String។ ដើម្បីអាចទាញយកឈ្មោះ ឬអាយុមកប្រើប្រាស់ក្នុងកូដបាន អ្នកត្រូវប្រែក្លាយវាមកជា Object វិញ។

```javascript
const jsonFromServer = '{"name":"Alice","role":"Admin"}';

// ប្រែក្លាយពីអត្ថបទ មកជា JavaScript Object
const userObj = JSON.parse(jsonFromServer);

console.log(userObj.name); // "Alice"
console.log(userObj.role); // "Admin"
console.log(typeof userObj); // "object"
```

> 💡 **ចំណាំ៖** ការប្រើប្រាស់ `JSON.stringify()` និង `JSON.parse()` ក៏ជាវិធីដ៏សាមញ្ញមួយក្នុងការបង្កើត **Deep Copy** របស់ Object និង Array ផងដែរ!
