## 💾 អ្វីទៅជា Local Storage?

ធម្មតា នៅពេលអ្នក Refresh គេហទំព័រ ទិន្នន័យដែលរក្សាទុកក្នុង Variables (`let` ឬ `const`) នឹងត្រូវបាត់បង់ទាំងអស់! តើធ្វើដូចម្តេចទើបអាចរក្សាទុកទិន្នន័យដូចជា ការកំណត់ Dark Mode, ព័ត៌មាន User លៃឡក, ឬទំនិញក្នុងកន្ត្រក អោយនៅជាប់ជារហូតបាន?

ចម្លើយគឺ **Local Storage**! វាគឺជាកន្លែងរក្សាទុកទិន្នន័យខ្នាតតូច (ប្រហែល 5MB) ដែលភ្ជាប់មកជាមួយ Browser នីមួយៗ (Chrome, Safari, Firefox)។ ទិន្នន័យនឹងមិនបាត់ទេ ទាល់តែអ្នកប្រើប្រាស់លុបវាដោយខ្លួនឯង (Clear Browsing Data)។

// setItem — រក្សាទុក theme
function applyTheme(theme) {
  if (theme === "dark") {
    document.body.classList.add("dark");
    document.getElementById("themeBtn").textContent = "☀️ Switch to Light";
  } else {
    document.body.classList.remove("dark");
    document.getElementById("themeBtn").textContent = "🌙 Switch to Dark";
  }
  document.getElementById("status").textContent =
    "Current theme: " + theme;
}

// getItem — ទាញ theme ពី localStorage
const saved = localStorage.getItem("theme") || "light";
applyTheme(saved);

document.getElementById("themeBtn").addEventListener("click", () => {
  const current = localStorage.getItem("theme") || "light";
  const next = current === "light" ? "dark" : "light";
  localStorage.setItem("theme", next);
  applyTheme(next);
});
```

## 🔄 2. ការរក្សាទុក Objects និង Arrays

នេះគឺជាចំណុចដែលសិស្សថ្មីៗតែងតែមានកំហុស! **Local Storage ស្គាល់តែ String ប៉ុណ្ណោះ!** បើអ្នកព្យាយាមរុញ Object ចូលផ្ទាល់ វាប្រែទៅជាពាក្យ `[object Object]` ដែលគ្មានន័យអ្វីទាំងអស់។

ដើម្បីដោះស្រាយបញ្ហានេះ យើងត្រូវពឹងផ្អែកលើ **JSON** ដែលបានរៀនក្នុងមេរៀនមុន!

js
let cart = ["Apple", "Banana", "Milk"];

function renderCart() {
  document.getElementById("cartDisplay").textContent =
    "cart: " + JSON.stringify(cart);
}

renderCart();

document.getElementById("addBtn").addEventListener("click", () => {
  const val = document.getElementById("itemInput").value.trim();
  if (val) { cart.push(val); renderCart(); }
});

// ✅ ត្រូវ: JSON.stringify() មុន setItem
document.getElementById("saveBtn").addEventListener("click", () => {
  localStorage.setItem("myCart", JSON.stringify(cart));
  alert("Saved to localStorage!");
});

// ✅ ត្រូវ: JSON.parse() ក្រោយ getItem
document.getElementById("loadBtn").addEventListener("click", () => {
  const saved = localStorage.getItem("myCart");
  if (saved) {
    cart = JSON.parse(saved);
    renderCart();
  }
});

document.getElementById("clearBtn").addEventListener("click", () => {
  localStorage.removeItem("myCart");
  cart = [];
  renderCart();
});
```

> 💡 **ចំណាំ៖** តែងតែប្រើ `JSON.stringify()` ពេលរុញចូល និង `JSON.parse()` ពេលទាញចេញ ប្រសិនបើទិន្នន័យរបស់អ្នកមិនមែនជាអត្ថបទធម្មតា។ វានឹងជួយសង្គ្រោះអ្នកពីបញ្ហាឈឺក្បាលជាច្រើន!
