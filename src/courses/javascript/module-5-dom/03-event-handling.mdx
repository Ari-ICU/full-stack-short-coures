## 🎭 អ្វីទៅជា Events?

នៅក្នុង HTML ធម្មតា គេហទំព័រគឺនៅស្ងៀម។ វាមិនដឹងថាអ្នកកំពុងចុចប៊ូតុង ឬវាយបញ្ចូលអក្សរឡើយ។ **Events** គឺជាសកម្មភាពអ្វីមួយដែលកើតឡើងនៅលើគេហទំព័រ (ឧទាហរណ៍៖ ការចុច Mouse, ការវាយ Keyboard) ហើយ JavaScript អនុញ្ញាតអោយយើង "ចាំស្តាប់ (Listen)" និងធ្វើការឆ្លើយតបទៅនឹងសកម្មភាពទាំងនោះបាន។

## 1. ការប្រើប្រាស់ `addEventListener`

ដើម្បីស្តាប់ Events យើងប្រើប្រាស់ Method `addEventListener()` ដែលទទួលយកព័ត៌មាន ២ យ៉ាង៖

### 💡 ស្វែងយល់ពី Callback Function នៅក្នុង Events

**Callback Function** គឺជា Function ដែលយើងបញ្ជូនទៅជា Parameter/Argument របស់ Function មួយផ្សេងទៀត (ក្នុងករណីនេះគឺ `addEventListener`) ដើម្បីទុកអោយវាដំណើរការនៅពេលក្រោយ (នៅពេល Event ជាក់លាក់មួយកើតឡើង)។

យើងអាចសរសេរ Callback Function បាន ២ របៀប៖

**របៀបទី១៖ ប្រើប្រាស់ Arrow Function ផ្ទាល់ (Anonymous Callback)**
ពេញនិយមខ្លាំងព្រោះសរសេរខ្លី និងនៅជិតគ្នា៖
```javascript
button.addEventListener("click", () => {
  console.log("ប៊ូតុងត្រូវបានចុច!");
});
```

**របៀបទី២៖ បង្កើត Function ដាច់ដោយឡែក (Named Callback)**
ស័ក្តិសមសម្រាប់កូដដែលមានលក្ខណៈស្មុគស្មាញ ឬចង់យកទៅប្រើឡើងវិញនៅកន្លែងផ្សេង៖
```javascript
// ១. បង្កើត function
function handleClick() {
  console.log("ប៊ូតុងត្រូវបានចុច!");
}

// ២. បញ្ជូនឈ្មោះ function ទៅកាន់ listener (ចំណាំ៖ មិនត្រូវដាក់សញ្ញាវង់ក្រចក `()` ឡើយ)
button.addEventListener("click", handleClick); 
```
> ⚠️ **ប្រុងប្រយ័ត្ន៖** ពេលបញ្ជូន named function ទៅអោយ `addEventListener` ត្រូវសរសេរតែឈ្មោះ function ប៉ុណ្ណោះ (ឧ. `handleClick`)។ ប្រសិនបើអ្នកសរសេរ `handleClick()` វានឹងដំណើរការ function នោះភ្លាមៗនៅពេល Browser អានកូដដល់បន្ទាត់នោះ ជាជាងរង់ចាំទាល់តែមានការចុច click។

## 2. ប្រភេទ Events ពេញនិយម

### Events សម្រាប់ Mouse (កណ្តុរ)
*   **`click`**: កើតឡើងនៅពេលដែលអ្នកប្រើប្រាស់ចុច (Click) mouse ឆ្វេងលើ Element ណាមួយ។ (ពេញនិយមបំផុតសម្រាប់ Button, Links, etc.)។
*   **`dblclick`**: កើតឡើងនៅពេលចុចពីរដងលឿនៗផ្ទួនគ្នា (Double click) លើ Element តែមួយ។ (ឧទាហរណ៍៖ ចុចពីរដងដើម្បី Zoom រូបភាព ឬ Edit comment)។
*   **`mouseenter`**: កើតឡើងនៅពេលដែលចង្អុលកណ្តុរ (Mouse cursor) ត្រូវបានរំកិលចូលទៅក្នុងតំបន់របស់ Element។ (ល្អសម្រាប់បង្កើត Hover effect ដូចជា បង្ហាញ Tooltip ឬ Sub-menu)។
*   **`mouseleave`**: កើតឡើងនៅពេលដែលចង្អុលកណ្តុរ ត្រូវបានដកចេញពីតំបន់របស់ Element នោះវិញ។ (ឧ. លាក់ Tooltip មកវិញ)។

### Events សម្រាប់ Keyboard (ក្តារចុច)
*   **`keydown`**: ពេលដែលអ្នកចុចប៊ូតុងណាមួយចុះក្រោមភ្លាមៗ។
*   **`keyup`**: ពេលដែលអ្នកព្រលែងប៊ូតុងដែលបានចុចនោះមកវិញ។

### Events សម្រាប់ Forms និង Inputs
*   **`input`**: ដំណើរការរាល់ដងដែលតម្លៃក្នុង input ផ្លាស់ប្តូរ (ឧ. រាល់ពេលវាយមួយអក្សរ)។ ស័ក្តិសមសម្រាប់ការធ្វើការ Search ភ្លាមៗ។
*   **`change`**: ដំណើរការនៅពេលតម្លៃផ្លាស់ប្តូរ **ហើយ** អ្នកប្រើប្រាស់ចុចចេញពី input នោះ (lose focus)។ ស័ក្តិសមសម្រាប់ `<select>` ជ្រើសរើសជម្រើស។
*   **`submit`**: ដំណើរការនៅពេលចុចប៊ូតុង Submit នៅក្នុង Form។

## 📦 3. ការប្រើប្រាស់ Event Object (`e`)

នៅពេលមាន Event មួយកើតឡើង JavaScript តែងតែបង្កើត និងបញ្ជូន **Event Object** (ជាទូទៅតាងដោយអក្សរ `e` ឬ `event`) ដោយស្វ័យប្រវត្តទៅអោយ Callback Function របស់អ្នក។ 

គិតងាយៗ៖ **Event Object គឺជាកញ្ចប់ព័ត៌មានលម្អិត** អំពីអ្វីគ្រប់យ៉ាងដែលទើបតែបានកើតឡើង (ចុចចំកន្លែងណា? ចុចប៉ះអក្សរអ្វី? Element មួយណាជាអ្នកបង្ក? កូអរដោនេកណ្តុរនៅត្រង់ណា?)។

### 🔑 ស្វែងយល់ពី Properties សំខាន់ៗរបស់ `e`៖

1. **`e.target`**: សំខាន់ជាងគេបង្អស់! វាចង្អុលទៅកាន់ **Element ដើមចមដែលបង្ក Event នោះឡើង**។ 
   * ប្រសិនបើវាជា `<input>`, យើងអាចប្រើ `e.target.value` ដើម្បីយកតម្លៃអត្ថបទដែលគេវាយបញ្ចូល។
   * ប្រសិនបើវាជា `<button>`, `e.target` គឺជា Element Button នោះផ្ទាល់។
2. **`e.type`**: ប្រាប់ពីប្រភេទនៃ Event នោះជា String (ឧ. `"click"`, `"input"`, `"submit"`)។
3. **`e.clientX` / `e.clientY`**: សម្រាប់ Mouse Events វាផ្តល់នូវទីតាំងកូអរដោនេ X (ទទឹង) និង Y (បណ្តោយ) របស់ចង្អុលកណ្តុរនៅលើអេក្រង់ (គិតជា Pixel)។
4. **`e.key`**: សម្រាប់ Keyboard Events វាប្រាប់ពីឈ្មោះគ្រាប់ចុចដែលអ្នកប្រើប្រាស់បានចុច (ឧ. `"Enter"`, `"a"`, `"ArrowUp"`)។

```tabs
}

  updateEventDetails(e);
  valInput.textContent = "N/A";
});

input.addEventListener("input", (e) => {
  updateEventDetails(e);
  valInput.textContent = e.target.value;        // e.target.value យកតម្លៃអត្ថបទពី input
});
```

## 🛑 4. ការបញ្ឈប់អាកប្បកិរិយាដើម (preventDefault)

ពេលអ្នកប្រើប្រាស់ Forms អាកប្បកិរិយាដើមរបស់ (Default behavior) Browser គឺវានឹង **Refresh ទំព័រ (Reload)** នៅពេលអ្នកចុច Submit ដើម្បីបញ្ជូនទិន្នន័យ។

នៅក្នុងការបង្កើត **Single Page Applications (SPA)** យើងមិនចង់អោយវា Refresh ទេ យើងចង់អោយ JavaScript ជាអ្នកបញ្ជូនទិន្នន័យជំនួសវិញ។ ដូច្នេះ យើងត្រូវប្រើ `e.preventDefault()`។

```tabs

const form = document.querySelector("#login-form");
const usernameInput = document.querySelector("#username");
const welcomeMessage = document.querySelector("#welcome-message");

form.addEventListener("submit", (e) => {
  // បញ្ឈប់ការ Refresh ទំព័រ (Page Reload)
  e.preventDefault();

  // យកទិន្នន័យមកធ្វើការដោយខ្លួនឯង...
  const username = usernameInput.value;
  welcomeMessage.textContent = `ស្វាគមន៍, ${username}!`;
  console.log(`ស្វាគមន៍, ${username}!`);
});
```
