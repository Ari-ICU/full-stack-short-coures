## 📂 អ្វីទៅជា Version Control?

នៅពេលអ្នកសរសេរកូដ អ្នកប្រាកដជាធ្លាប់ជួបបញ្ហាដូចជា "កូដខូចក្រោយពេលកែប្រែ" ឬ "ចង់ត្រឡប់ទៅរកកូដដើមវិញ"។ ការ Save ឯកសារជាច្រើនដូចជា `project_v1`, `project_v2`, `project_final`, `project_final_final` គឺជារឿងដែលគួរអោយឈឺក្បាល។

**Version Control System (VCS)** គឺជាប្រព័ន្ធមួយដែលតាមដានរាល់ការផ្លាស់ប្តូរនៅលើឯកសាររបស់អ្នក (Tracking changes)។ វាអនុញ្ញាតអោយអ្នកអាច៖
- មើលប្រវត្តិសាស្រ្តនៃការកែប្រែ (ប្រៀបដូចជាមុខងារ Undo/Redo ដែលមានឥទ្ធិពលបំផុត)
- ត្រឡប់ទៅកាន់ Version ចាស់ៗវិញនៅពេលមានបញ្ហា
- ធ្វើការងារជាក្រុមដោយមិនជាន់កូដគ្នា

## 🚀 អ្វីទៅជា Git?

<img src="https://upload.wikimedia.org/wikipedia/commons/e/e0/Git-logo.svg" alt="Git Logo" width="120" style={{ display: "block", margin: "0 auto" }} />
 និង GitHub?

អ្នកចាប់ផ្តើមដំបូងច្រើនតែច្រឡំថា Git និង GitHub គឺជាមួយ។ តាមពិតពួកវាខុសគ្នា៖

- **Git** គឺជាកម្មវិធីអត់គិតថ្លៃ (Open-source tool) ដែលអ្នកតម្លើងលើកុំព្យូទ័ររបស់អ្នក ដើម្បីតាមដានការផ្លាស់ប្តូរនៅក្នុង Folder (Repository)។ អ្នកអាចប្រើ Git ដោយមិនចាំបាច់មាន Internet ទេ។
- **GitHub** គឺជាគេហទំព័រ (សេវាកម្ម Cloud) ដែលអនុញ្ញាតអោយអ្នក Upload (Push) កូដដែលគ្រប់គ្រងដោយ Git យកទៅរក្សាទុកនៅលើ Internet។ វាប្រៀបបានដូចជា Google Drive សម្រាប់អ្នកសរសេរកូដអញ្ចឹងដែរ!

## ⚙️ ការរៀបចំ Git ដំបូង (Initial Setup)

បន្ទាប់ពីអ្នកបានតម្លើង Git នៅលើកុំព្យូទ័ររួច (អ្នកអាចទាញយកវាពី [git-scm.com](https://git-scm.com/)) ជំហានដំបូងបំផុតដែលអ្នកត្រូវធ្វើគឺការប្រាប់ Git ពីឈ្មោះ និង Email របស់អ្នក ដើម្បីអោយវាដឹងថាអ្នកណាជាអ្នកកែប្រែកូដ។

សូមបើក **Terminal** (ឬ Git Bash) ហើយវាយបញ្ជាខាងក្រោម៖

```bash
# កំណត់ឈ្មោះរបស់អ្នក
git config --global user.name "Your Name"

# កំណត់ Email របស់អ្នក (គួរតែជា Email ដូចគ្នានឹងគណនី GitHub)
git config --global user.email "your.email@example.com"
```

ដើម្បីពិនិត្យមើលថាអ្នកបានកំណត់ជោគជ័យឬនៅ សូមវាយ៖
```bash
git config --list
```

នៅក្នុងមេរៀនបន្ទាប់ យើងនឹងរៀនពីរបៀបចាប់ផ្តើមប្រើប្រាស់ Git ដើម្បីតាមដានគម្រោង (Project) ដំបូងរបស់អ្នក!
