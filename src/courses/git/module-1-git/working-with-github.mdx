## ☁️ ស្វាគមន៍មកកាន់ Remote Workflow

បន្ទាប់ពីអ្នកចេះប្រើ `git add` និង `git commit` រួចហើយ កូដរបស់អ្នកគឺមានសុវត្ថិភាព **នៅលើតែកុំព្យូទ័ររបស់អ្នកប៉ុណ្ណោះ**។ ប្រសិនបើកុំព្យូទ័ររបស់អ្នកខូច ឬបាត់ កូដរបស់អ្នកក៏បាត់ទៅតាមនោះដែរ។ 

ដើម្បីដោះស្រាយបញ្ហានេះ យើងត្រូវបញ្ជូនកូដរបស់យើងទៅរក្សាទុកនៅលើ Cloud ដូចជា **GitHub** ជាដើម។

---

## 🔗 Adding Remote (`git remote`)

ជាដំបូង អ្នកត្រូវបង្កើត "New Repository" នៅលើគណនី GitHub របស់អ្នក។ បន្ទាប់មក GitHub នឹងអោយ URL មួយ (ឧទាហរណ៍៖ `https://github.com/yourname/my-project.git`)។

ដើម្បីភ្ជាប់ Folder កូដនៅលើកុំព្យូទ័ររបស់អ្នក (Local) ទៅកាន់ GitHub (Remote) សូមប្រើបញ្ជា៖

```bash
git remote add origin https://github.com/yourname/my-project.git
```
*(`origin` គឺជាឈ្មោះតំណាងអោយ URL របស់ GitHub នោះ ដើម្បីអោយងាយស្រួលហៅ)*

---

## 🚀 Pushing to GitHub (`git push`)

ក្រោយពីភ្ជាប់រួចរាល់ នៅពេលដែលអ្នកបានធ្វើការ `git commit` ជាច្រើនដង ហើយចង់រក្សាទុកវាទៅលើ Internet សូមប្រើបញ្ជា៖

```bash
# សម្រាប់លើកទី១ (ភ្ជាប់ branch 'main' ជាមួយ GitHub)
git push -u origin main

# សម្រាប់លើកក្រោយៗ គ្រាន់តែវាយ៖
git push
```
ឥឡូវនេះ កូដរបស់អ្នកមានវត្តមាននៅលើ GitHub ហើយ! អ្នកអាចបើកមើលវានៅលើ Browser បាន។

---

## 📥 Fetching and Pulling (`git clone` និង `git pull`)

**១. `git clone` (យកមកលើកដំបូង):** 
ប្រសិនបើអ្នកចង់យក Project ដែលមានស្រាប់នៅលើ GitHub មកកុំព្យូទ័រថ្មីរបស់អ្នក អ្នកមិនបាច់ `git init` ទេ គ្រាន់តែវាយ៖

```bash
git clone https://github.com/username/project.git
```

**២. `git pull` (យកកំណែទម្រង់ថ្មី):**
ប្រសិនបើមិត្តភ័ក្តិរបស់អ្នកបានសរសេរកូដ ហើយ `git push` ឡើងទៅ GitHub, ដើម្បីអោយកុំព្យូទ័ររបស់អ្នកទទួលបានកូដថ្មីនោះដែរ អ្នកត្រូវវាយ៖

```bash
git pull
```

**សង្ខេប Remote Workflow:**
- ធ្វើការងារខ្លួនឯង៖ `git add` ➡️ `git commit` ➡️ `git push`
- មុនពេលចាប់ផ្តើមសរសេរកូដរាល់ព្រឹក (បើធ្វើការជាក្រុម)៖ ត្រូវ `git pull` ជាមុនសិន ដើម្បីទទួលបានកូដថ្មីៗពីមិត្តភ័ក្តិ!
