## 🌳 អ្វីទៅជា Branch?

ស្រមៃថាកូដមេរបស់អ្នកគឺជាដើមឈើធំមួយ (ហៅថា `main` branch) ដែលមានផ្ទុកកម្មវិធីកំពុងដំណើរការយ៉ាងរលូន។ ថ្ងៃមួយ អ្នកចង់បន្ថែមមុខងារថ្មីមួយ តែអ្នកខ្លាចថាសរសេរខុសទៅ វាអាចធ្វើអោយខូចកម្មវិធីទាំងមូល។ 

ដូច្នេះហើយ Git អនុញ្ញាតអោយអ្នកបង្កើត **មែកឈើថ្មី (Branch)** ដែលជាច្បាប់ចម្លងនៃកូដដើម។ អ្នកអាចធ្វើអ្វីក៏បាននៅលើ Branch ថ្មីនេះដោយមិនប៉ះពាល់ដល់កូដនៅ Branch `main` ឡើយ!

---

## 🌿 ការបង្កើត និងផ្លាស់ប្តូរ Branch

ដើម្បីពិនិត្យមើលថាបច្ចុប្បន្នអ្នកមាន Branch ប៉ុន្មាន សូមវាយ៖
```bash
git branch
```

ដើម្បីបង្កើត Branch ថ្មីមួយឈ្មោះថា `feature-login` និងផ្លាស់ប្តូរទៅកាន់ Branch នោះភ្លាមៗ សូមប្រើបញ្ជា៖
```bash
# វិធីចាស់
git checkout -b feature-login

# វិធីថ្មី (ងាយយល់ជាង)
git switch -c feature-login
```

ឥឡូវនេះ អ្នកកំពុងស្ថិតនៅលើ Branch `feature-login` ហើយ! អ្នកអាចធ្វើការ `git add` និង `git commit` បានដោយសេរី។ កូដដែលអ្នកកែប្រែនៅទីនេះ នឹងមិនមាននៅលើ `main` ទេ។

ដើម្បីត្រឡប់ទៅកាន់ Branch `main` វិញ សូមវាយ៖
```bash
git switch main
```

## 🤝 ការបញ្ចូលកូដចូលគ្នា (`git merge`)

បន្ទាប់ពីអ្នកបានសរសេរមុខងារថ្មីនៅលើ `feature-login` ជោគជ័យហើយ អ្នកចង់យកកូដនោះមកបញ្ចូលក្នុងកូដដើម `main` វិញ។ ដំណើរការនេះហៅថា **Merging**។

ជំហានក្នុងការ Merge៖
1. ត្រូវប្រាកដថាអ្នកកំពុងនៅលើ Branch ដែលចង់អោយគេបញ្ចូលកូដមក (ជាទូទៅគឺ `main`)។
   ```bash
   git switch main
   ```
2. ទាញកូដពី Branch `feature-login` មកបញ្ចូលក្នុង `main`៖
   ```bash
   git merge feature-login
   ```

## ⚔️ ដោះស្រាយការជាន់កូដ (Merge Conflicts)

ពេលខ្លះ ពេលដែលអ្នក Merge, Git អាចនឹងប្រាប់ថាមាន **Merge Conflict**។ នេះកើតឡើងនៅពេលដែលមនុស្សពីរនាក់បានកែប្រែកូដ **នៅបន្ទាត់តែមួយ ក្នុងឯកសារតែមួយ**។ Git មិនហ៊ានសម្រេចចិត្តថាត្រូវយកមួយណាទេ ទើបវាទាមទារអោយយើងដោះស្រាយដោយខ្លួនឯង។

នៅពេលអ្នកបើកឯកសារនោះ (ឧទាហរណ៍ក្នុង VS Code) អ្នកនឹងឃើញរចនាសម្ព័ន្ធបែបនេះ៖

```text
<<<<<<< HEAD
<h1>សួស្តីពី Main Branch</h1>
=======
<h1>សួស្តីពី Feature Login</h1>
>>>>>>> feature-login
```

ដើម្បីដោះស្រាយ អ្នកគ្រាន់តែលុបសញ្ញា `<<<`, `===`, `>>>` ចោល ហើយជ្រើសរើសយកកូដមួយណាដែលត្រឹមត្រូវ (ឬទុកទាំងពីរ)។ បន្ទាប់មក គ្រាន់តែធ្វើការ `git add` និង `git commit` ជាការស្រេច!

**អបអរសាទរ! 🎉** អ្នកបានបញ្ចប់មូលដ្ឋានគ្រឹះនៃ Git ដែលអាចអោយអ្នកធ្វើការងារក្នុងក្រុមហ៊ុនបច្ចេកវិទ្យាធំៗបានយ៉ាងរលូន!
