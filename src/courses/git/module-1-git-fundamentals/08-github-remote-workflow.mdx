## ☁️ Local និង Remote

កន្លងមក យើងបានរៀនតែពីការគ្រប់គ្រងកូដនៅក្នុងកុំព្យូទ័រ (Local) តែប៉ុណ្ណោះ។ ដើម្បីអាចសហការជាមួយអ្នកដទៃបាន អ្នកត្រូវមានទីតាំងកណ្តាលមួយនៅលើ Internet (Cloud)។ ទីតាំងនោះហើយដែលគេហៅថា **Remote Repository** (ហើយ GitHub គឺជាអ្នកផ្តល់សេវាកម្ម Remote ដ៏ពេញនិយមបំផុត)។

តាមទម្លាប់ គេតែងតែដាក់ឈ្មោះ Remote Repository នោះថា **`origin`**។

## 📥 ការចម្លងកូដ (git clone)

ប្រសិនបើគម្រោងនោះមាននៅលើ GitHub រួចហើយ អ្នកមិនចាំបាច់ `git init` ទេ។ អ្នកគ្រាន់តែចម្លងវាមកកុំព្យូទ័ររបស់អ្នក៖

```bash
git clone https://github.com/username/project.git
```
ពាក្យបញ្ជានេះនឹងទាញយក Folder ទាំងមូល និងប្រវត្តិកូដទាំងអស់មកកុំព្យូទ័រអ្នក ហើយវាក៏បានភ្ជាប់ `origin` ទៅកាន់ GitHub ដោយស្វ័យប្រវត្តិផងដែរ។

---

## 🚀 ការរុញកូដទៅកាន់ GitHub (git push)

បន្ទាប់ពីអ្នកបាន `git commit` រួច កូដរបស់អ្នកនៅតែស្ថិតក្នុងកុំព្យូទ័រដដែល។ ដើម្បីបញ្ជូនវាទៅ GitHub អ្នកត្រូវប្រើប្រាស់ `git push`។

```bash
# ទម្រង់ពេញលេញ: git push <ឈ្មោះ remote> <ឈ្មោះសាខា>
git push origin main
```
ប្រសិនបើនេះជាសាខាថ្មី (ឧ. `feature/login`) ដែលមិនទាន់មាននៅលើ GitHub ទេ អ្នកត្រូវប្រើប្រាស់ជម្រើស `-u` ដើម្បីចងពួកវាចូលគ្នាជាលើកដំបូង៖
```bash
git push -u origin feature/login
```
*(លើកក្រោយ អ្នកគ្រាន់តែវាយ `git push` ជាការស្រេច)*

## 🧲 ការទាញយកកូដ (git fetch និង git pull)

នេះគឺជាចំណុចដ៏សំខាន់បំផុតនៅក្នុងការងារជាក្រុម!

### `git fetch` (អ្នកអង្កេតការណ៍ - សុវត្ថិភាព)
នៅពេលមិត្តភក្តិរបស់អ្នក Push កូដទៅកាន់ GitHub កុំព្យូទ័ររបស់អ្នកមិនដឹងរឿងនោះដោយស្វ័យប្រវត្តិទេ។ `git fetch` នឹងទៅទាញយក "ព័ត៌មាន" អំពីការផ្លាស់ប្តូរទាំងអស់មកកុំព្យូទ័ររបស់អ្នក **ប៉ុន្តែវាមិនប៉ះពាល់កូដបច្ចុប្បន្នរបស់អ្នកទេ**។ វាប្រៀបដូចជាការទាញទិន្នន័យមកទុកមើលសិន។

```bash
git fetch origin
```

### `git pull` (អ្នកប្រតិបត្តិ - ប្រយ័ត្ន)
`git pull` គឺជាផ្លូវកាត់! វាមានស្មើនឹងការវាយ `git fetch` បូកបញ្ជូលជាមួយ `git merge`។
វាទៅទាញយកកូដពី GitHub ហើយយកមកផ្គុំ (Merge) បញ្ចូលគ្នាយ៉ាងកំហុកជាមួយនឹងកូដបច្ចុប្បន្នរបស់អ្នក។

```bash
git pull origin main
```

> ⚠️ **បម្រាម:** ប្រសិនបើអ្នកកំពុងសរសេរកូដមិនទាន់ចប់ ហើយអ្នកទៅវាយ `git pull` វានឹងយកកូដពី GitHub មកជាន់គ្នា ដែលអាចបង្កជាបញ្ហា Merge Conflict ភ្លាមៗ។ ដូច្នេះ ត្រូវប្រាកដថាអ្នកបាន Commit រាល់ការងាររបស់អ្នកសិន មុននឹង Pull កូដថ្មីមក!
