## 🚀 ចាប់ផ្តើម Project ជាមួយ Git

ដើម្បីអោយ Git អាចតាមដានការកែប្រែនៅក្នុង Folder កូដរបស់អ្នកបាន ជាដំបូងអ្នកត្រូវប្រាប់វាអោយបង្កើត Repository សិន។

សូមបើក Terminal រួចចូលទៅកាន់ Folder Project របស់អ្នក ហើយវាយ៖

```bash
git init
```

បន្ទាប់ពីវាយរួច Git នឹងបង្កើត Folder លាក់មួយឈ្មោះ `.git` ដើម្បីផ្ទុកទិន្នន័យប្រវត្តិសាស្រ្តទាំងអស់។ ឥឡូវនេះ Project របស់អ្នកបានក្លាយជា **Git Repository** ហើយ!

## 🔍 Checking Status (`git status`)

នេះគឺជាបញ្ជាដែលអ្នកនឹងប្រើញឹកញាប់ជាងគេបំផុត! វាប្រាប់អ្នកពីស្ថានភាពបច្ចុប្បន្នរបស់ Project ថាមានឯកសារណាខ្លះដែលត្រូវបានបង្កើតថ្មី កែប្រែ ឬលុបចោល។

```bash
git status
```

## 📥 Staging Area នឹង `git add`

នៅពេលអ្នកសរសេរកូដរួចរាល់ Git មិនទាន់រក្សាទុកវាចូលទៅក្នុងប្រវត្តិសាស្រ្តភ្លាមៗទេ។ ជាដំបូង អ្នកត្រូវរើសយកឯកសារដែលអ្នកចង់រក្សាទុក ដាក់ចូលទៅក្នុងកន្លែងរង់ចាំមួយហៅថា **Staging Area** សិន។

ដើម្បីបន្ថែមឯកសារតែមួយចូលទៅកាន់ Staging Area៖
```bash
git add index.html
```

ដើម្បីបន្ថែមឯកសារ**ទាំងអស់**ដែលទើបតែកែប្រែ (វិធីពេញនិយមបំផុត)៖
```bash
git add .
```
*(សញ្ញាចុច `.` មានន័យថា "អ្វីៗទាំងអស់នៅក្នុង Folder នេះ")*

---

## 💾 Committing នឹង `git commit`

បន្ទាប់ពីដាក់ឯកសារក្នុង Staging Area រួចហើយ ជំហានបន្ទាប់គឺការថតរូបទុក (Take a snapshot) ចូលទៅក្នុងប្រវត្តិសាស្រ្តរបស់ Git ជាអចិន្ត្រៃយ៍។ ដំណើរការនេះហៅថា **Commit**។

រាល់ការ Commit នីមួយៗ ទាមទារអោយអ្នកសរសេរសារ (Message) បញ្ជាក់ពីអ្វីដែលអ្នកទើបតែកែប្រែ៖

```bash
git commit -m "បង្កើតទំព័រដើម (Homepage) ជាមួយនឹង HTML"
```

**គន្លឹះ៖** សារ Commit គួរតែខ្លី ច្បាស់លាស់ និងប្រាប់ពីអ្វីដែលកូដនេះធ្វើ។ ឧទាហរណ៍៖ "Add login button", "Fix header bug" ជាដើម។

## 📖 Viewing History (`git log`)

តើធ្វើដូចម្តេចទើបដឹងថាអ្នកបាន Commit អ្វីខ្លះកន្លងមក? អ្នកអាចមើលប្រវត្តិសាស្រ្តបានដោយប្រើ៖

```bash
git log
```

វានឹងបង្ហាញអ្នកនូវបញ្ជី Commits ទាំងអស់ ដោយបញ្ជាក់ពីអ្នកសរសេរ (Author), ពេលវេលា (Date), ព្រមទាំងសារ Commit Message។

ប្រសិនបើប្រវត្តិមានវែងពេក អ្នកអាចសរសេរខ្លីៗដោយប្រើ៖
```bash
git log --oneline
```

**សង្ខេបដំណើរការ (The Git Flow):**
សរសេរកូដ ➡️ `git status` ➡️ `git add .` ➡️ `git commit -m "សារ"` ➡️ ជោគជ័យ! 🎉
