## 🌿 Advanced Branch Management

បន្ទាប់ពីអ្នកចេះប្រើ `git branch` និង `git merge` រួចមក យើងនឹងស្វែងយល់ពីបញ្ជាបន្ថែមមួយចំនួនទៀត ដែលជួយអោយការធ្វើការជាមួយ Branch កាន់តែមានប្រសិទ្ធភាព និងរៀបរយ។

---

## 🔀 `git merge` vs `git rebase`

ទាំង `merge` និង `rebase` គឺប្រើសម្រាប់បញ្ចូលកូដពី Branch មួយទៅ Branch មួយទៀត ប៉ុន្តែវាដំណើរការខុសគ្នា។

- **`git merge`**: បញ្ចូល Branch ទាំងពីរចូលគ្នា ហើយបង្កើត "Merge Commit" ថ្មីមួយ។ វាបង្ហាញពីប្រវត្តិពិតប្រាកដថាតើការបញ្ចូលគ្នាកើតឡើងនៅពេលណា (ទោះបីជាមើលទៅរញ៉េរញ៉ៃបន្តិចក៏ដោយ)។
- **`git rebase`**: វាយកការផ្លាស់ប្តូររបស់អ្នក ទៅដាក់នៅ "ខាងចុងបង្អស់" នៃ Branch ដើម (ឧទាហរណ៍ main)។ វាធ្វើអោយប្រវត្តិ Commit មើលទៅត្រង់ស្អាត (Linear History) ដោយមិនមាន Merge Commit ទេ។

**របៀបប្រើ Rebase:**
```bash
git checkout feature-branch
git rebase main
```
*(ប្រយ័ត្ន៖ កុំប្រើ `rebase` លើ Public Branch ដូចជា `main` ព្រោះវានឹងផ្លាស់ប្តូរប្រវត្តិ ដែលប៉ះពាល់ដល់អ្នកដទៃ)*

## 📦 `git stash`

ឧបមាថាអ្នកកំពុងសរសេរកូដនៅក្នុង `feature` Branch ស្រាប់តែមេរបស់អ្នកប្រាប់អោយជួសជុលកំហុស (Bug) បន្ទាន់នៅលើ `main` Branch។ អ្នកមិនអាច `git checkout main` បានទេ ព្រោះអ្នកកំពុងមានកូដដែលមិនទាន់បាន Commit។

ក្នុងករណីនេះ អ្នកអាចប្រើ `git stash`:

```bash
# ១. រក្សាទុកការងារបណ្តោះអាសន្ន
git stash

# ២. ឥឡូវ Working Directory របស់អ្នកស្អាតហើយ អ្នកអាចប្តូរ Branch បាន
git checkout main
```

បន្ទាប់ពីអ្នកជួសជុល Bug លើ `main` រួចរាល់ ហើយត្រលប់មក `feature` Branch វិញ អ្នកអាចទាញយកការងារដែលបានរក្សាទុកនោះមកវិញ៖

```bash
git checkout feature-branch

# ៣. ទាញយកការងារដែលបាន stash មក Working Directory វិញ
git stash pop
```

## 🍒 `git cherry-pick`

ពេលខ្លះ អ្នកប្រហែលជាចង់យកការផ្លាស់ប្តូរតែមួយគត់ពី Branch ផ្សេង ដោយមិនចាំបាច់ Merge Branch ទាំងមូលនោះទេ។ ឧទាហរណ៍ នរណាម្នាក់បានជួសជុល Bug មួយនៅក្នុង Branch មួយទៀត ហើយអ្នកត្រូវការវា។

អ្នកអាចប្រើ `git cherry-pick` ដោយបញ្ជាក់ Commit ID ដែលអ្នកចង់បាន៖

```bash
# ស្វែងរក Commit ID ដែលអ្នកចង់បានពី Branch ផ្សេង
git log --oneline

# យក Commit នោះមកដាក់ក្នុង Branch បច្ចុប្បន្នរបស់អ្នក (ឧទាហរណ៍: f9a23c1)
git cherry-pick f9a23c1
```
បញ្ជានេះនឹងទាញយកតែការផ្លាស់ប្តូររបស់ Commit នោះតែម្តង មកបញ្ជូលក្នុង Branch របស់អ្នក។
