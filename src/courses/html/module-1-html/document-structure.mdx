## 🏗️ HTML Document Structure

រាល់ទំព័រ Web ទាំងអស់ទាមទារនូវគ្រោងឆ្អឹង ឬរចនាសម្ព័ន្ធគោលមួយដែលមិនអាចខ្វះបាន។ នេះគឺជាទម្រង់ស្តង់ដារនៃឯកសារ HTML៖

```html
<!DOCTYPE html>
<html lang="km">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>គេហទំព័ររបស់ខ្ញុំ</title>
</head>
<body>

    <!-- មាតិកាដែលអ្នកប្រើប្រាស់មើលឃើញ នឹងត្រូវសរសេរនៅទីនេះ -->

</body>
</html>
```

### ការពន្យល់លម្អិត៖
*   `<!DOCTYPE html>`: ប្រាប់ Browser ថានេះគឺជាឯកសារប្រភេទ HTML5។
*   `<html>`: គឺជា **Root Element** ដែលរុំព័ទ្ធរាល់កូដ HTML ទាំងអស់។ យើងច្រើនតែដាក់ `lang="km"` (សម្រាប់ភាសាខ្មែរ) ដើម្បីប្រាប់ Browser ពីភាសាចម្បងរបស់ទំព័រ។
*   `<head>`: ផ្នែកនេះផ្ទុកព័ត៌មាន "នៅពីក្រោយឆាក" (Metadata) អំពីទំព័រ។ អ្វីៗក្នុងនេះ **មិនត្រូវបានបង្ហាញ** លើអេក្រង់ផ្ទាល់ទេ។
*   `<body>`: ផ្នែកនេះផ្ទុកអ្វីៗគ្រប់យ៉ាងដែលអ្នក **ចង់បង្ហាញ** ដល់អ្នកប្រើប្រាស់ (អត្ថបទ, រូបភាព, វីដេអូ, លីង)។

## 🧠 Head Elements

ផ្នែក `<head>` គឺប្រៀបដូចជាខួរក្បាលរបស់ទំព័រ Web។ ទោះបីយើងមើលវាមិនឃើញ ប៉ុន្តែវាគ្រប់គ្រងរបៀបដែលទំព័រដំណើរការ និងបង្ហាញខ្លួនទៅកាន់ Search Engines។ Elements សំខាន់ៗមាន៖

1.  **`<meta>`**: ផ្តល់ទិន្នន័យ (Metadata) អំពីទំព័រ។
    *   `<meta charset="UTF-8">`: សំខាន់បំផុត! វាប្រាប់ Browser ឱ្យចេះអានអក្សរគ្រប់ភាសា (រួមទាំងខ្មែរ) កុំឱ្យលោតជាសញ្ញាសួរ (?)។
    *   `<meta name="viewport" content="width=device-width, initial-scale=1.0">`: ធានាថាគេហទំព័ររបស់អ្នកនឹងត្រូវខ្នាតនៅលើទូរស័ព្ទដៃ (Responsive)។
2.  **`<title>`**: កំណត់ចំណងជើងដែលនឹងបង្ហាញនៅលើ Tab របស់ Browser ព្រមទាំងចំណងជើងនៅលើលទ្ធផលស្វែងរករបស់ Google។
3.  **`<link>`**: ភ្ជាប់ឯកសារពីខាងក្រៅ ដូចជា CSS ជាដើម។ (ឧ. `<link rel="stylesheet" href="style.css">`)
4.  **`<style>`**: អនុញ្ញាតឱ្យអ្នកសរសេរកូដ CSS ដោយផ្ទាល់នៅក្នុងឯកសារ HTML។
5.  **`<script>`**: ប្រើសម្រាប់ភ្ជាប់ ឬសរសេរកូដ JavaScript ដើម្បីឱ្យទំព័រមានចលនា និងអន្តរកម្ម។

## 💬 Comments

Comments គឺជាកំណត់ចំណាំនៅក្នុងកូដរបស់អ្នក។ វានឹង **មិនត្រូវបានបង្ហាញ** នៅលើកញ្ចក់អេក្រង់របស់ Browser ទេ។
វាមានប្រយោជន៍ខ្លាំងណាស់សម្រាប់៖
*   ពន្យល់ថាតើកូដផ្នែកនោះធ្វើអ្វី (ងាយស្រួលអានពេលក្រោយ)
*   លាក់កូដបណ្តោះអាសន្នពេលកំពុងជួសជុល (Debugging)

**របៀបសរសេរ៖**

```html
<!-- នេះគឺជា Comment ។ Browser នឹងមើលរំលងវាទាំងស្រុង! -->

<!-- អ្នកអាចប្រើវាដើម្បីបិទកូដបណ្តោះអាសន្ន
<p>អត្ថបទនេះនឹងមិនត្រូវបានបង្ហាញទេ</p> 
-->
```

## 🔣 HTML Entities

តើនឹងមានអ្វីកើតឡើងបើអ្នកចង់សរសេរតួអក្សរ `<` (តូចជាង) ឬ `>` (ធំជាង) នៅលើទំព័រ? Browser នឹងគិតថាវាជាការចាប់ផ្តើមនៃ Tag ថ្មី! 
ដើម្បីដោះស្រាយបញ្ហានេះ យើងប្រើ **HTML Entities**។

| និមិត្តសញ្ញា (Symbol) | HTML Entity | ការប្រើប្រាស់ |
| :---: | :--- | :--- |
| `<` | `&lt;` | តូចជាង (Less than) |
| `>` | `&gt;` | ធំជាង (Greater than) |
| `&` | `&amp;` | សញ្ញា And (Ampersand) |
| ` ` | `&nbsp;` | ចន្លោះទទេ (Non-breaking space) - ការពារការចុះបន្ទាត់ផ្តេសផ្តាស |
| `©` | `&copy;` | រក្សាសិទ្ធិបញ្ញា (Copyright) |

**ឧទាហរណ៍៖**
បើអ្នកចង់បង្ហាញកូដ `<h1>សួស្តី</h1>` នៅលើអេក្រង់ អ្នកត្រូវសរសេរ៖
`&lt;h1&gt;សួស្តី&lt;/h1&gt;`
