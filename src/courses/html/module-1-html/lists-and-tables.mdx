## 📝 ការបង្កើត Lists

ការរៀបចំទិន្នន័យជាបញ្ជី ធ្វើឱ្យអត្ថបទមានសណ្តាប់ធ្នាប់ និងងាយស្រួលអាន។ នៅក្នុង HTML មានបញ្ជី ២ ប្រភេទសំខាន់ៗដែលយើងតែងតែប្រើប្រាស់៖ 

1. **Unordered List (`<ul>`)**: បញ្ជីដែលគ្មានលេខរៀង (ប្រើចំណុចត្រេ ឬ Bullet points)។ ស័ក្តិសមសម្រាប់បញ្ជីដែលលំដាប់លំដោយមិនសំខាន់។
2. **Ordered List (`<ol>`)**: បញ្ជីដែលមានលេខរៀង ឬអក្សររៀង។ ស័ក្តិសមសម្រាប់បញ្ជីដែលលំដាប់លំដោយជារឿងចាំបាច់ (ឧ. របៀបធ្វើម្ហូប, ជំហានទី១ ទី២...)។

ធាតុនីមួយៗនៅក្នុងបញ្ជីទាំងពីរប្រភេទនេះ ត្រូវតែរុំព័ទ្ធដោយ tag `<li>` ដែលតំណាងឱ្យ **List Item** ជានិច្ច។

```html
<!-- បញ្ជីគ្មានលេខរៀង (Unordered List) -->
<ul>
    <li>ផ្លែប៉ោម</li>
    <li>ផ្លែចេក</li>
    <li>ផ្លែក្រូច</li>
</ul>

<!-- បញ្ជីមានលេខរៀង (Ordered List) -->
<ol>
    <li>ក្រោកពីគេង</li>
    <li>ដុសធ្មេញ</li>
    <li>ញ៉ាំអាហារពេលព្រឹក</li>
</ol>
```

**គន្លឹះបន្ថែម (Nested Lists):** អ្នកអាចដាក់បញ្ជីមួយនៅក្នុងបញ្ជីមួយទៀតបាន (Nested Lists) ដើម្បីបង្កើតជាកម្រិតរង។
```html
<ul>
    <li>ភេសជ្ជៈក្ដៅ
        <ul>
            <li>កាហ្វេ</li>
            <li>តែ</li>
        </ul>
    </li>
    <li>ភេសជ្ជៈត្រជាក់</li>
</ul>
```

## 📊 ការរៀបចំទិន្នន័យជា Tables

តារាង (Tables) ត្រូវបានប្រើសម្រាប់បង្ហាញទិន្នន័យដែលមានរចនាសម្ព័ន្ធជាជួរដេក (Rows) និងជួរឈរ (Columns) ដូចជាទិន្នន័យក្នុង Excel ជាដើម។ ការបង្កើតតារាងក្នុង HTML ទាមទារការរួមបញ្ចូលគ្នានូវ tags ជាច្រើន៖

| Tag | ពាក្យពេញ | មុខងារ |
|---|---|---|
| `<table>` | Table | ជាកន្លែងផ្ទុក (Container) តំណាងឱ្យតារាងទាំងមូល។ |
| `<tr>` | Table Row | តំណាងឱ្យជួរដេកនីមួយៗ។ គ្រប់ Cell (`<th>` ឬ `<td>`) ត្រូវតែស្ថិតក្នុង `<tr>`។ |
| `<th>` | Table Header | តំណាងឱ្យក្បាលតារាង។ អក្សរខាងក្នុងនឹង **ដិត (Bold)** និងនៅ **កណ្តាល (Center)** ដោយស្វ័យប្រវត្តិ។ |
| `<td>` | Table Data | តំណាងឱ្យប្រអប់ទិន្នន័យធម្មតានៅក្នុងតារាង។ |

**ឧទាហរណ៍តារាងមូលដ្ឋាន៖**
```html
<table border="1">
    <tr>
        <th>ឈ្មោះ</th>
        <th>អាយុ</th>
        <th>មុខរបរ</th>
    </tr>
    <tr>
        <td>សុខ</td>
        <td>២៥</td>
        <td>Web Developer</td>
    </tr>
    <tr>
        <td>សៅ</td>
        <td>៣០</td>
        <td>Graphic Designer</td>
    </tr>
</table>
```
*(ចំណាំ៖ ការប្រើប្រាស់ Attribute `border="1"` គឺគ្រាន់តែដើម្បីឱ្យងាយស្រួលមើលបន្ទាត់តារាងបណ្តោះអាសន្នប៉ុណ្ណោះ។ ក្នុងការអនុវត្តជាក់ស្តែង យើងប្រើប្រាស់ CSS ដើម្បីរចនាបន្ទាត់តារាង។)*

### ផ្នែកកម្រិតខ្ពស់នៃតារាង (Semantic Table Elements)
ដើម្បីឱ្យកូដកាន់តែមានរបៀប និងងាយស្រួលយល់ (ជាពិសេសសម្រាប់តារាងធំៗ) យើងប្រើ tags បន្ថែមដើម្បីបែងចែកផ្នែកនៃតារាង៖
*   **`<thead>`**: សម្រាប់ផ្ទុកក្បាលតារាងទាំងមូល (ជួរដេកដែលមាន `<th>`)។
*   **`<tbody>`**: សម្រាប់ផ្ទុកទិន្នន័យគោលរបស់តារាង (ជួរដេកដែលមាន `<td>`)។
*   **`<tfoot>`**: សម្រាប់ផ្ទុកជួរដេកសរុប (Footer) នៅខាងក្រោមគេបញ្ជាក់ពីទិន្នន័យសរុប។

**ឧទាហរណ៍តារាងពេញលេញ៖**
```html
<table>
    <thead>
        <tr>
            <th>មុខវិជ្ជា</th>
            <th>ពិន្ទុ</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>គណិតវិទ្យា</td>
            <td>៩០</td>
        </tr>
        <tr>
            <td>រូបវិទ្យា</td>
            <td>៨៥</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td><strong>សរុប</strong></td>
            <td><strong>១៧៥</strong></td>
        </tr>
    </tfoot>
</table>
```
